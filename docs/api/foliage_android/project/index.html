What init decided, written down so nothing has to be told again.

Every value here is either an identity that must not drift between builds – the application id a device installs under, the library name the activity loads – or a version that has to agree with something else. Passing them per invocation is how they drift, so they are settled once and read from foliage-android.toml by every command afterwards.

The file is meant to be edited. It is read back by Project::load and rewritten in full by Project::save, so a changed SDK level survives a rerun of init and takes effect in the generated project.
