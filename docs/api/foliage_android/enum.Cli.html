The commands.

Variants§

§

Init

Write the Gradle project and the entry crate, and record the choices in foliage-android.toml.

Only --app-id is needed, and only the first time: a rerun reads the file back and takes every value from it, so this is also how the project is regenerated after editing it.

Fields

§app_id: Option<String>

Reverse-domain application id, e.g. io.github.yourname.yourapp.

Required the first time and permanent afterwards: it is the identity a device installs under, and an update has to carry the id it shipped with.

§app_crate: Option<String>

The crate holding the entry function. Defaults to the package in the current directory.

§app_name: Option<String>

The label under the launcher icon. Defaults to --app-crate.

§app_entry: String

The function in --app-crate taking a Foliage, called from android_main.

§overwrite_entry_crate: bool

Rewrite the entry crate even though one is already there.

Off by default. The Gradle project is generated output and safe to replace; the entry crate is a crate in your workspace and may hold edits worth keeping.

§skip_wrapper: bool

Do not fetch the Gradle wrapper – for a machine with no network, or a wrapper already set up elsewhere.

§

Setup

Install the toolchain into the sdk directory foliage-android.toml names.

Everything Android needs and nothing outside that directory, so removing it is one rm -rf and no part of the machine is left changed. The two exceptions are a rustup target and cargo-ndk, which are toolchain components shared with every Rust project and have no per-repo equivalent.

A JDK is the one thing this cannot install: it is the package manager’s, and every route to one needs a privilege this should not take. doctor says so if it is missing.

Fields

§host: Option<String>

The host to download the android CLI for, as <os>_<arch> – linux_x86_64, darwin_arm64, darwin_x86_64, windows_x86_64. Defaults to this machine.

§

Doctor

Report what the toolchain is missing, and the command that installs each piece.

§

Build

Compile every configured ABI and assemble the APK.

Fields

§release: bool

Build the Rust in release and assemble the release APK.

Unsigned unless <project>/keystore.properties is present, which no device will install. See the generated README’s “Release signing”.

§abi: Option<String>

Only this ABI, rather than every one in foliage-android.toml.

§

Run

Build, install onto a connected device, and launch.

Fields

§release: bool
§abi: Option<String>
§device: Option<String>

The device serial, as adb devices lists it. Only needed when more than one is attached.

§logcat: bool

Follow the log after launching, filtered to this app.
