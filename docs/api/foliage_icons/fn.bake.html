Function bake

pub fn bake(svg: &[u8], spec: Bake) -> Result<Baked, String>
Expand description

Bakes one SVG into a square field.

The artwork is fitted to the field’s interior, leaving a margin of range texels on each edge so the spread is not clipped at the mark’s own boundary. Bounds are taken from the unioned geometry rather than from the viewBox, so a stroke that overshoots still fits.

§Errors

If the SVG cannot be parsed, or holds no fill or stroke to bake.
