1//! Rowan -- resolution.
2//!
3//! # Rowan resolves. Elm decides what changed.
4//!
5//! Every pass runs in the same order over the same elements every frame, and each writes exactly one
6//! thing. What a pass may leave alone is an element **nothing it reads was written to**, whose
7//! answer is the one it already holds -- sitting in the column the pass would have written it to.
8//!
9//! That is not invalidation and nothing is ever marked stale. The tree records a write where the
10//! write happens ([`Tree::declared`](crate::tree::Tree::declared), which every declaration passes
11//! through), and [`read`] closes that over the dependencies before any pass runs. So an element
12//! resolves again if it was written to, if what it hangs off or is anchored to resolves again, or if
13//! a measure moved under it -- and if none of those happened, resolving it again would produce what
14//! it already has. A value here can be old. It cannot be wrong.
15//!
16//! A write that moves nothing is recorded apart from one that can
17//! ([`Tree::restyled`](crate::tree::Tree::restyled)): a fill, a rounding, a tint or a shape is read
18//! by extraction alone, and whether an element is shown, how opaque, whether disabled and how far
19//! forward are read by the passes below that run over every element anyway. Such an element is read
20//! again and drawn again, and nothing is placed again on its account.
21//!
22//! What still runs over everything is the accumulations, R3 through R7: what they carry is a running
23//! product rather than an answer per element, so there is no position in them to start from. They
24//! record what they actually changed as they go, which is what extraction then states -- and R8, the
25//! box stack, is built again only on a frame where one of them changed something it is built from.
26//!
27//! The read itself is kept between frames and repaired where the tree was written -- growing,
28//! withering and anchoring are the only things that change the order, so an ordinary frame reads
29//! none of it.
30//!
31//! Nothing is re-uploaded on account of any of it, because extraction compares against a cached copy
32//! and sends only genuine differences.
33//!
34//! The passes each write exactly one thing, and nothing writes what another owns:
35//!
36//! | | Pass | Direction | Produces |
37//! |---|---|---|---|
38//! | R1 | measure | — | the character cell, and the max-content width half of the intrinsic size |
39//! | R2a | horizontal | dependency order | the horizontal axis |
40//! | R2m | wrap | **bottom-up** | the measured-height half of the intrinsic size |
41//! | R2b | vertical | dependency order | the vertical axis, and with it the placed box |
42//! | R3 | extent | **bottom-up** | [`Extent`](crate::view::Extent): how far a region's content reaches |
43//! | R4 | scroll | top-down | the drawn box: the placed box less every scrolling ancestor's offset |
44//! | R5 | clip | top-down | the clip: what a scrolling ancestor leaves visible |
45//! | R6 | rank | dependency order | `ResolvedElevation`: elevation accumulated, then tie-broken |
46//! | R7 | inherit | top-down | [`Inherited`]: the visible, opacity and disabled products |
47//! | R8 | regions | rank order | the box stack the next frame's dispatch reads |
48//!
49//! Both halves of R2 call the same pure resolver, once per axis. That is only safe because it is
50//! pure: there is no accumulated state for a second call to corrupt.
51//!
52//! R2a and R2b resolve what was written to, and R1 only what says something new -- a run rewritten,
53//! an element grown, a breakpoint or a face that changed every cell. R2m resolves what was written to
54//! and everything above it, because
55//! what an element reaches over is what the elements under it resolved to -- a measure travels
56//! toward the trunk where a box travels away from it. A measure that moves under an element nothing
57//! wrote to makes that element resolve again, which is why R2m sits before R2b and not after it. And
58//! an element measuring again because one of its children moved asks that child alone: how far each
59//! of the others reaches is held from when it last resolved, which is the answer asking would give.
60//!
61//! # Every pass reads the order, not the world
62//!
63//! The passes ask the same questions of the same elements over and over: what an element hangs off,
64//! what it is anchored to, what is grown under it, and what each of those offers a placement reading
65//! it. Asked of the world each time, every one of those is a lookup by entity -- and the arithmetic a
66//! pass does is small enough that the lookups, not the arithmetic, are what a frame costs.
67//!
68//! So the tree is read once, into [`Elements`]: every live element in dependency order, holding what
69//! it depends on as **positions in that order** rather than as names, and holding what it offers a
70//! placement beside it. From there every pass indexes -- the accumulations R3 through R7 carry are
71//! arrays the length of the order, and a trunk's contribution is `[..]` rather than a lookup on a
72//! map keyed by element.
73//!
74//! **What resolution produces is held there and nowhere else.** The placed and drawn boxes, the
75//! measures, the clip, the rank and the inherited products are columns of the order, kept between
76//! frames and read by position -- by extraction, which walks the same order -- or by name through
77//! [`Elements`]'s accessors, by anything that asks about one element. None of it is written back
78//! into the world, so no pass pays to store a value per element per frame that the next pass would
79//! have to look up again.
80//!
81//! Nothing about what is computed changes, and neither does the ordering that makes it correct.
82//!
83//! Two passes run the other way, and each is a cycle that turns out not to be vicious.
84//!
85//! R2m is one: wrapping makes a height depend on a width, and the width comes from the layout, so a
86//! box sized to its contents looks circular. It is not, because **width flows down and height flows
87//! up** -- a monospaced run's widest unwrapped line is free from its character count, so the
88//! down-pass needs nothing measured. R2m sits between the two halves of R2 for that reason: it is
89//! the one moment when every width is known and no height is, which is exactly what measuring needs.
90//!
91//! R3 is the other: a child resolves against its parent's box, a scrolling parent's extent comes
92//! from where its children landed, and that extent is what its offset is clamped to. Extent affects
93//! only the clamp and never the parent's own box -- so a top-down layout sweep, a bottom-up extent
94//! sweep and a top-down scroll application resolve it in one pass each.
95//!
96//! Neither iterates to convergence. Every pass here runs exactly once.

173/// Every live element in dependency order, with what each one resolves against, what each one offers
174/// a placement that reads it, and everything resolution made of it.
175///
176/// The frame's one read of the tree, and what every pass indexes into. A trunk and an anchor are
177/// asked for on both axes and on four of the passes after them; what an element offers is asked for
178/// twice per element on each axis. Out of the world each time, every one of those is a lookup by
179/// entity -- resolved once to a position in the order, each is an index.
180///
181/// The columns are as long as the order and are read at the position an element sits at, so a pass
182/// that already knows where it is never asks a second time. They are kept between frames, which is
183/// what lets an element nothing wrote to keep the answer it already has.
184#[derive(Default)]
185pub(crate) struct Elements {
186    /// Every live element, ordered so that nothing resolves before what it depends on.
187    pub(crate) order: Vec<Leaf>,
188    /// Where each element sits in the order, by the index of its name. A slot may be stale -- one
189    /// left by a name that withered -- which is why a lookup checks the order holds the name it
190    /// asked for.
191    slots: Vec<u32>,
192    /// What each element hangs off, as a position in the order.
193    trunk: Vec<Option<usize>>,
194    /// What each element is anchored to, as a position in the order.
195    anchor: Vec<Option<usize>>,
196    /// What is grown directly under each element, as positions in the order: the children of the
197    /// element at `at` are `children[branches[at]..branches[at + 1]]`. One array for the whole tree
198    /// rather than one per element, and built with the order, so a pass that asks what is under an
199    /// element never asks the world.
200    branches: Vec<u32>,
201    children: Vec<u32>,
202    /// What each element declared that the passes after the axes read.
203    pub(crate) standing: Vec<Standing>,
204    /// The box, as far as the axes have resolved it: where the layout put the element, which is
205    /// what its children resolve against.
206    section: Vec<Section>,
207    /// Whether the element has a box worth reading yet. True from the start for one nothing has
208    /// written to, whose box is the one it settled at last frame; false for one being resolved
209    /// again, until an axis reaches it -- which is what answers a cycle's remainder with the
210    /// fallback rather than with a box that has not been computed.
211    resolved: Vec<bool>,
212    /// Whether the element has to be resolved again this frame.
213    ///
214    /// True where something it reads was written -- its own declarations, or those of what it hangs
215    /// off or is anchored to. False where nothing was, in which case the columns already hold what
216    /// it resolved to and the passes that only rewrite that have nothing to do.
217    dirty: Vec<bool>,
218    /// Whether any run stopped being stated this frame, which is the one thing that makes the
219    /// shaping cache worth sweeping.
220    restated: bool,
221    /// Whether anything extraction reads about the element moved this frame.
222    ///
223    /// Seeded from [`dirty`](Elements::dirty), because an element being resolved again may land
224    /// somewhere else, and from a [`restyled`](crate::tree::Tree::restyled) write, and set by R4
225    /// through R7 where what they wrote differs from what was held. An element it is false for is
226    /// drawn exactly as the backend already has it.
227    pub(crate) moved: Vec<bool>,
228    /// Whether R1 has to measure the element again: it was grown, or what it says was rewritten, or
229    /// every cell in the tree moved.
230    lettered: Vec<bool>,
231    /// Whether the element has to measure again, before R2m walks that up the trunks.
232    ///
233    /// [`dirty`](Elements::dirty) is most of it. The rest is an element something withered from,
234    /// which has one fewer thing to reach over and nothing left below it to say so.
235    measures: Vec<bool>,
236    /// What the element measured to, which is what [`content()`](crate::content) reads. R1 writes
237    /// the width -- max-content, free in a monospaced font -- and R2m the height it wrapped to at
238    /// the width R2a gave it, which is the whole of width-down and height-up.
239    intrinsic: Vec<Area>,
240    /// How far the element reaches below the top of what it is grown under, as R2m last found it
241    /// there, or `None` where its placement does not count toward that measure.
242    ///
243    /// What each element contributes to its trunk's [`reach`], held like any other answer so that a
244    /// trunk measuring again because one of its children moved asks the rest nothing. A child's
245    /// reach reads its own placement and the horizontal half of what it and its trunk and anchor
246    /// resolved to, and each of those that moves makes it dirty -- so an entry is found again
247    /// exactly where its element is, and a container of thousands with one child written pays for
248    /// one child.
249    reached: Vec<Option<f32>>,
250    /// The element's own grid, divided at the breakpoint in force.
251    tracks: Vec<Tracks>,
252    /// The character cell the element's own font and size make, as R1 measured it. What
253    /// [`letters`](crate::Source::letters) and a letter-pitched track are measured in; an element
254    /// that named no font and no size has none.
255    cell: Vec<Area>,
256    /// The element's run as R1 shaped it, where it has one: what R2m wraps, what a placement
257    /// reading a [`character`](crate::Anchor::character) of the element resolves against, and what
258    /// extraction draws. Shared with the shaping cache rather than copied out of it, and what tells
259    /// the cache the run is still stated.
260    pub(crate) composed: Vec<Option<Arc<Shaped>>>,
261    /// Where the layout put a stroke's two ends, as R2 settled them and before any scrolling
262    /// ancestor moved them. `None` on everything placed by a box.
263    ///
264    /// The box cannot stand in for it: a box is the rectangle around the two ends grown by half the
265    /// weight, and which of its two diagonals the stroke runs along is a fact the rectangle does not
266    /// carry. A stroke in motion is settled at the blend, so this is also what a retarget
267    /// snapshots.
268    spanned: Vec<Option<Stretched>>,
269    /// Where the element is on screen: its placed box less every scrolling ancestor's accumulated
270    /// offset. What drawing, clipping and hit-testing read.
271    ///
272    /// Deliberately apart from the placed box. A change to that means the layout moved a box and
273    /// its children have to follow; a change to this means only that the box moved under a scroll.
274    pub(crate) drawn: Vec<Section>,
275    /// Where a stroke's two ends landed: the spanned ends less the same offset the drawn box is.
276    pub(crate) stretched: Vec<Option<Stretched>>,
277    /// What a scrolling ancestor leaves visible of the element.
278    pub(crate) clip: Vec<Section>,
279    /// Where the element sits in the one stack.
280    pub(crate) rank: Vec<ResolvedElevation>,
281    /// What the three off-states resolved to over the element's whole ancestry.
282    pub(crate) inherited: Vec<Inherited>,
283    /// Whether anything the box stack is built from moved this frame: an element grown or withered,
284    /// or a drawn box, a clip, a rank or an inherited product that changed. What R8 waits on.
285    restack: bool,
286    /// Every position, front-most first: the order the box stack is read in. Sorted again only when
287    /// a rank moved, which is the only thing it is sorted on.
288    stacking: Vec<u32>,
289    /// Whether a rank moved this frame, or the order was built again.
290    reranked: bool,
291    /// Every element that withered since the order was last built, and what it drew. Read by
292    /// extraction, which has to let go of whatever it was holding for them.
293    pub(crate) gone: Vec<(Leaf, Chlorophyll)>,
294}

296impl Elements {
297    /// How many elements are live.
298    pub(crate) fn len(&self) -> usize {
299        self.order.len()
300    }
301
302    /// Where `leaf` sits, or `None` if it is not in the order.
303    fn at(&self, leaf: Leaf) -> Option<usize> {
304        let at = *self.slots.get(leaf.0.index_u32() as usize)? as usize;
305        (self.order.get(at) == Some(&leaf)).then_some(at)
306    }
307
308    /// The positions of everything grown directly under the element at `at`.
309    fn children(&self, at: usize) -> impl Iterator<Item = usize> + '_ {
310        self.children[self.branches[at] as usize..self.branches[at + 1] as usize]
311            .iter()
312            .map(|child| *child as usize)
313    }
314
315    /// Where the layout put `leaf`, which is what its children resolve against. A zero box for
316    /// anything resolution has not reached.
317    ///
318    /// Resolution reads a box by position, because it holds every element in order. A coast, a
319    /// sought region, a running motion and an app each name one element instead, so they ask this.
320    pub(crate) fn placed(&self, leaf: Leaf) -> Section {
321        self.at(leaf).map(|at| self.section[at]).unwrap_or_default()
322    }
323
324    /// Where `leaf` is on screen, which is what an app reads and what a hit test runs against.
325    pub(crate) fn drawn(&self, leaf: Leaf) -> Section {
326        self.at(leaf).map(|at| self.drawn[at]).unwrap_or_default()
327    }
328
329    /// What a scrolling ancestor leaves visible of `leaf`.
330    #[allow(unused)]
331    pub(crate) fn clip(&self, leaf: Leaf) -> Section {
332        self.at(leaf)
333            .map(|at| self.clip[at])
334            .unwrap_or_else(|| Clipped::unbounded().0)
335    }
336
337    /// Where `leaf` sits in the one stack, as R6 last resolved it.
338    #[allow(unused)]
339    pub(crate) fn rank(&self, leaf: Leaf) -> ResolvedElevation {
340        self.at(leaf).map(|at| self.rank[at]).unwrap_or_default()
341    }
342
343    /// What the three off-states resolved to over `leaf`'s whole ancestry, as R7 last computed it.
344    pub(crate) fn inherited(&self, leaf: Leaf) -> Inherited {
345        self.at(leaf)
346            .map(|at| self.inherited[at])
347            .unwrap_or_default()
348    }
349
350    /// The character cell of `leaf`'s own font, at its own size, as R1 measured it.
351    ///
352    /// Per element rather than per engine: an app registers as many fonts as it likes and each
353    /// element chooses, so `8.letters()` is eight cells of *that* element's font.
354    pub(crate) fn cell(&self, leaf: Leaf) -> Area {
355        self.at(leaf).map(|at| self.cell[at]).unwrap_or_default()
356    }
357
358    /// Where the layout put `leaf`'s two ends, before R4 moved them, or `None` if it is placed by
359    /// a box.
360    pub(crate) fn spanned(&self, leaf: Leaf) -> Option<Stretched> {
361        self.spanned[self.at(leaf)?]
362    }
363
364    /// Where `leaf`'s two ends landed, as R4 moved them, or `None` if it is placed by a box.
365    pub(crate) fn stretched(&self, leaf: Leaf) -> Option<Stretched> {
366        self.stretched[self.at(leaf)?]
367    }

370/// Steps 6 and 7. Declared state becomes resolved geometry and resolved products, for everything.
371pub(crate) fn run(grove: &mut Grove) {
372    let step = trace_span!("resolve", elements = Empty, dirty = Empty);
373    let resolving = step.enter();
374    // Taken off the grove so the passes can hold it while they write to the rest, and put back at
375    // the end of resolution: what it holds is what this frame settled, and what the next one starts
376    // from rather than reads again.
377    let mut elements = core::mem::take(&mut grove.elements);
378    read(&mut elements, grove);
379    // Forgotten the moment it is read, so a write made by a pass after this belongs to the frame
380    // that would resolve it.
381    grove.tree.taken();
382    step.record("elements", elements.len());
383    step.record(
384        "dirty",
385        elements.dirty.iter().filter(|dirty| **dirty).count(),
386    );
387    measure(grove, &mut elements);
388    // Every element now holds the run it states, so a run nothing holds is one nothing states. Only
389    // on a frame where a run stopped being stated, which is the only way the cache comes to hold
390    // one nothing wants.
391    if elements.restated {
392        grove.shaping.sweep();
393    }
394    axes(grove, &mut elements);
395    extent(grove, &elements);
396    scroll(grove, &mut elements);
397    clip(&mut elements);
398    rank(&mut elements);
399    // Resolution ends here. What settles after it is its own step, and is timed as one.
400    drop(resolving);
401    let _step = trace_span!("settle").entered();
402    inherit(&mut elements);
403    regions(grove, &mut elements);
404    grove.elements = elements;
405}

407/// R1. What an element's own font makes of it: its character cell, and the widest its content would
408/// like to be.
409///
410/// Ahead of every other pass, and reading no geometry at all, because neither answer has anything to
411/// do with where the element ended up. A monospaced run's max-content width is its longest line's
412/// character count times its cell, so the whole of the down-pass's input is available before the
413/// down-pass runs -- which is what leaves only the up-pass with anything to measure.
414fn measure(grove: &mut Grove, elements: &mut Elements) {
415    let _pass = trace_span!("measure").entered();
416    let Grove {
417        tree,
418        fonts,
419        shaping,
420        layout,
421        short,
422        ..
423    } = grove;
424    for at in 0..elements.order.len() {
425        // Nothing it reads was written, so it measures to what it measured to, which is what the
426        // column is already holding. What it reads is its own run and face and nothing else, so an
427        // element that only moved is one of these.
428        if !elements.lettered[at] {
429            continue;
430        }
431        let leaf = elements.order[at];
432        // No font and no size is no cell, and nothing measured in one. What such an element last
433        // measured to stands.
434        let Some(typeface) = tree.typeface(leaf) else {
435            continue;
436        };
437        let size = typeface.size.at(*layout, *short);
438        let cell = fonts.cell(typeface.font, size);
439        // The run, shaped, is kept beside the cell: it is what a placement reading a character of
440        // this element resolves against, and this is the one pass that shapes.
441        let composed = tree
442            .lettering(leaf)
443            .map(|value| shaping.shape(fonts, typeface.font, size, value).clone());
444        let width = composed
445            .as_ref()
446            .map(|shaped| shaped.max_content())
447            .unwrap_or_default();
448        elements.cell[at] = cell;
449        elements.composed[at] = composed;
450        // The height half is R2m's, and is written before anything reads it.
451        elements.intrinsic[at] = Area::new(width, 0.0);
452    }
453}

455/// R2a, R2m and R2b: the horizontal axis, then the measure it makes possible, then the vertical one.
456///
457/// An element with a placement in motion is resolved twice on each axis -- once for each endpoint,
458/// in the *same* context -- and the two answers are blended. That is what the resolver's purity
459/// buys: the endpoints are consistent with each other because they were asked at the same position
460/// in the same dependency order, against the same settled ancestors, and neither is remembered
461/// afterwards.
462fn axes(grove: &mut Grove, elements: &mut Elements) {
463    axis(grove, elements, Axis::Horizontal);
464    wrap(grove, elements);
465    axis(grove, elements, Axis::Vertical);
466}

468/// One axis of the whole tree, in dependency order, through the one pure resolver.
469fn axis(grove: &Grove, elements: &mut Elements, axis: Axis) {
470    let _pass = trace_span!("axis", vertical = (axis == Axis::Vertical)).entered();
471    let viewport = Section::new(Position::default(), grove.viewport);
472    for at in 0..elements.len() {
473        // R2m may have found a measure that moved under an element nothing was written to, between
474        // this axis and the last. The order puts what an element reads before it, so spreading that
475        // here reaches everything resolved against it.
476        elements.dirty[at] |= elements.trunk[at].is_some_and(|on| elements.dirty[on])
477            || elements.anchor[at].is_some_and(|on| elements.dirty[on]);
478        // Nothing it or anything it resolves against was written, so it resolves to the box it
479        // already holds. Its column keeps that box, so what reads it here reads the right one.
480        if !elements.dirty[at] {
481            continue;
482        }
483        let leaf = elements.order[at];
484        let context = context(elements, viewport, at, axis);
485        let (span, stretched) = geometry(grove, leaf, &context, axis);
486        // A stroke's ends are settled one axis at a time, into what it held: an element a measure
487        // reached between the two axes is resolved on the second alone, and keeps the first.
488        if let Some((from, to)) = stretched {
489            elements.spanned[at]
490                .get_or_insert_with(Stretched::default)
491                .set(axis, from, to);
492        }
493        let section = &mut elements.section[at];
494        match axis {
495            Axis::Horizontal => {
496                section.position.x = span.near;
497                section.area.width = span.extent();
498            }
499            Axis::Vertical => {
500                section.position.y = span.near;
501                section.area.height = span.extent();
502            }
503        }
504        elements.resolved[at] = true;
505    }
506}

508/// One axis of `leaf`, whichever of the two ways its placement is stated.
509///
510/// A box resolves to a span directly. A **trace** resolves to two positions, and the span is the
511/// distance between them grown by half the stroke's weight on each side -- which is what gives a
512/// rule, whose ends share a coordinate on one axis, a box on that axis at all. Both ends come back
513/// too, because the span cannot say which of its diagonals they are.
514fn geometry(
515    grove: &Grove,
516    leaf: Leaf,
517    context: &Context,
518    axis: Axis,
519) -> (Span, Option<(f32, f32)>) {
520    let (trace, stroke) = match grove.tree.placement(leaf) {
521        Some(Placement::Traced(trace, stroke)) => (trace, stroke),
522        Some(Placement::Boxed(location)) => {
523            return (span(grove, leaf, location, context, axis), None);
524        }
525        // Every live element is grown with a placement, so this is an element the order holds and
526        // the world does not -- which nothing that runs between the two can make.
527        None => return (span(grove, leaf, &Location::default(), context, axis), None),
528    };
529    let half = stroke.half();
530    let (from, to) = ends(grove, leaf, trace, context, axis);
531    (
532        Span {
533            near: from.min(to) - half,
534            far: from.max(to) + half,
535        },
536        Some((from, to)),
537    )
538}

540/// One axis of where `leaf`'s two ends currently are: what it declares, blended with the ends a
541/// motion left.
542///
543/// [`span`] for a trace. Each end blends on its own and the box is taken from the blended pair,
544/// rather than the two boxes blending: a stroke part way between a rising and a falling diagonal is
545/// a stroke, and a box that blended separately would not be the rectangle around it.
546fn ends(grove: &Grove, leaf: Leaf, trace: &Trace, context: &Context, axis: Axis) -> (f32, f32) {
547    let (from, to) = located(pinned_ends(trace, grove), context);
548    match grove.aspen.trace(leaf) {
549        Some((departed, at)) => {
550            let (left_from, left_to) = match departed {
551                Departed::Declared(trace) => located(pinned_ends(trace, grove), context),
552                Departed::Snapshot(stretched) => stretched.along(axis),
553            };
554            (blend(left_from, from, at), blend(left_to, to, at))
555        }
556        None => (from, to),
557    }
558}

560/// One axis of both of a pair of ends, through the resolver.
561fn located(ends: &Ends, context: &Context) -> (f32, f32) {
562    (locate(&ends.from, context), locate(&ends.to, context))
563}

565/// Which pair of ends a trace states, at the breakpoint in force. [`pinned`] for a trace.
566fn pinned_ends<'a>(trace: &'a Trace, grove: &Grove) -> &'a Ends {

570/// One axis of where `leaf` currently is: what it declares, blended with the endpoint a motion left.
571///
572/// The one place a placement becomes a span, so a measure and a layout are answering the same
573/// question -- an element in motion is measured where it *is* rather than where it is going.
574fn span(grove: &Grove, leaf: Leaf, location: &Location, context: &Context, axis: Axis) -> Span {
575    let target = resolve(pinned(location, grove, axis), context);
576    match grove.aspen.location(leaf) {
577        Some((departed, at)) => departure(departed, grove, context, axis).blend(target, at),
578        None => target,
579    }
580}

582/// How one axis of a placement is pinned down, at the breakpoint in force.
583///
584/// A lookup rather than arithmetic, which is why it is here and not in the resolver: picking a
585/// configuration out of a placement is not part of resolving one.
586fn pinned<'a>(location: &'a Location, grove: &Grove, axis: Axis) -> &'a Config {
587    let axes = location.axes(grove.layout, grove.short);
588    match axis {
589        Axis::Horizontal => &axes.horizontal,
590        Axis::Vertical => &axes.vertical,
591    }

595///
596/// A placement it left is resolved in the context the target was resolved in, so anything that
597/// moves one end moves both. A snapshot is already an answer: it is the box the element was blended
598/// to when it was retargeted, and it never corresponded to a placement that could be re-resolved.
599fn departure(

601    grove: &Grove,
602    context: &Context,

611/// R2m. How tall each element's contents turned out at the width R2a gave it.
612///
613/// Bottom-up, so everything inside an element is measured before the element asks. Two things are
614/// measured, and an element takes the greater of them, because both answer the one question
615/// [`content()`](crate::content) asks -- *how large is what is inside me*:
616///
617/// - a run of glyphs wraps at its own resolved width, and its lines times its cell is its height
618/// - anything with elements grown under it takes the furthest any of them reaches down
619///
620/// The second is resolved in the element's own space, with its vertical extent taken as **not yet
621/// known**, which is exactly what it is at this point in the frame. So a child that reads that
622/// extent -- `100.pct()`, a row of a grid, an anchor's edge -- contributes nothing to the measure
623/// and is given its real height by R2b like anything else. That is the correct reading rather than a
624/// limitation: a child sized to its trunk cannot also be what sizes it, and nothing is asked to
625/// converge.
626/// The two halves are separate walks because only one of them has an order. A run wraps at its own
627/// width and against its own font, so what an element shapes to reads nothing but the element --
628/// while what reaches below it reads the measures of everything under it, and so has to run after
629/// them.
630fn wrap(grove: &mut Grove, elements: &mut Elements) {
631    let _pass = trace_span!("wrap").entered();
632    // What has to measure again: what was written to, and everything above it, because what an
633    // element reaches over is what the elements under it resolved to. Up the order rather than down
634    // it -- a measure travels toward the trunk and stops there, where a box travels away from it.
635    for at in (0..elements.len()).rev() {
636        if let (true, Some(trunk)) = (elements.measures[at], elements.trunk[at]) {
637            elements.measures[trunk] = true;
638        }
639    }
640    let shaped = shaped(elements);
641    let _half = trace_span!("reach").entered();
642    for at in (0..elements.len()).rev() {
643        if !elements.measures[at] {
644            continue;
645        }
646        let height = shaped[at].max(reach(grove, elements, at));
647        if height != elements.intrinsic[at].height {
648            elements.intrinsic[at].height = height;
649            // The measure moved under an element nothing was written to, and a placement reading
650            // that measure has to be resolved against the new one. R2b runs after this and spreads
651            // it, which is why it is safe to find out here.
652            elements.dirty[at] = true;
653        }
654    }
655}

657/// How tall each element's own run turned out at the width R2a gave it, or zero where it says
658/// nothing.
659///
660/// In any order, because no element's answer is another's. The run is the one R1 left the element
661/// holding: an element measuring again because something under it moved says what it said last
662/// frame, and one that says something new was shaped for it by R1 this frame.
663fn shaped(elements: &Elements) -> Vec<f32> {
664    let _half = trace_span!("shaped").entered();
665    elements
666        .measures
667        .iter()
668        .zip(&elements.composed)
669        .zip(&elements.section)
670        .map(|((measures, run), section)| match (measures, run) {
671            (true, Some(run)) => run.measure(section.width()),
672            _ => 0.0,
673        })
674        .collect()
675}

677/// How far the elements grown under the element at `at` reach below its top edge.
678///
679/// Only the children that describe their own extent are counted. One that reads a vertical box --
680/// a percentage of this element, a row of its grid, an anchor's edge -- is asking how tall
681/// something else is, so it cannot be what decides how tall this is. See
682/// [`Config::measurable`](crate::placement::role::Config::measurable).
683///
684/// A child is asked only where it is dirty, and its answer kept. Every other child reaches exactly
685/// as far as it did when it last was, which is what [`reached`](Elements::reached) holds for it.
686fn reach(grove: &Grove, elements: &mut Elements, at: usize) -> f32 {
687    let mut reach: f32 = 0.0;
688    for index in elements.branches[at] as usize..elements.branches[at + 1] as usize {
689        let child_at = elements.children[index] as usize;
690        if elements.dirty[child_at] {
691            let child = elements.order[child_at];
692            let far = measurable(grove, child).then(|| {
693                let context = raised(elements, at, child_at);
694                geometry(grove, child, &context, Axis::Vertical).0.far
695            });
696            elements.reached[child_at] = far;
697        }
698        if let Some(far) = elements.reached[child_at] {
699            reach = reach.max(far);
700        }
701    }
702    reach
703}

705/// Whether `leaf`'s vertical placement describes its own extent, and so counts toward the measure
706/// of what it is grown under.
707///
708/// One question with two spellings, because a placement has two. A box asks it of its vertical
709/// configuration; a trace asks it of both of its ends, since either one reading a vertical box is
710/// enough to make the answer circular.
711fn measurable(grove: &Grove, leaf: Leaf) -> bool {
712    match grove.tree.placement(leaf) {
713        Some(Placement::Traced(trace, _)) => {
714            let ends = pinned_ends(trace, grove);
715            ends.from.measurable() && ends.to.measurable()
716        }
717        Some(Placement::Boxed(location)) => pinned(location, grove, Axis::Vertical).measurable(),
718        None => pinned(&Location::default(), grove, Axis::Vertical).measurable(),
719    }
720}

722/// What one child resolves its vertical axis against while its trunk is being measured.
723///
724/// The same [`Context`] R2b will build, with every vertical reading taken as zero: no box on this
725/// axis has resolved yet, which is the point of measuring. Every horizontal reading is real -- the
726/// child's own width included -- so a height stated in columns, read off a width, or held in
727/// proportion to its own still answers.
728fn raised<'a>(elements: &'a Elements, trunk: usize, child: usize) -> Context<'a> {
729    let offered = |at: usize| Basis {
730        section: flattened(elements.section[at]),
731        intrinsic: elements.intrinsic[at],
732        tracks: elements.tracks[at],
733        cell: elements.cell[at],
734        run: elements.composed[at].as_deref(),
735    };
736    Context {
737        axis: Axis::Vertical,
738        own: own(elements, child, Axis::Vertical),
739        trunk: offered(trunk),
740        anchor: match elements.anchor[child] {
741            Some(anchor) => offered(anchor),
742            None => Basis::default(),
743        },
744    }
745}

747/// R3. How far each region's content reaches, from where its children landed.
748///
749/// Bottom-up, so a subtree is measured before whatever contains it. Two things are deliberately not
750/// consulted: what is currently drawn, because content scrolled out of sight is exactly what an
751/// extent describes and has to remain reachable; and the offset, because measuring against it would
752/// make the extent depend on the clamp that depends on the extent.
753///
754/// A child that scrolls in its own right contributes its box and not its content -- what overflows
755/// inside it is its own to reach, and is already reachable there.
756///
757/// A **visible child that is simply far away is content**, and is counted. That is the answer
758/// `views.md` gives to the parking footgun, and it is deliberately not a guess about intent: if it
759/// is visible and out there it is reachable, which is coherent where the old behaviour was a
760/// surprise. What removes a child from the extent is the app saying so -- [`visible(false)`] takes
761/// it and its subtree out, and [`pinned`] takes out something that is inside the region without
762/// travelling with it.
763///
764/// [`visible(false)`]: crate::Place::visible
765/// [`pinned`]: crate::Place::pinned
766fn extent(grove: &mut Grove, elements: &Elements) {
767    let _pass = trace_span!("extent").entered();
768    // The far corner of everything under an element, in absolute coordinates. Absent where the
769    // element was skipped, which is what keeps a hidden subtree out of what contains it.
770    let mut reach: Vec<Option<Position>> = vec![None; elements.len()];
771    for at in (0..elements.len()).rev() {
772        let standing = &elements.standing[at];
773        // A hidden element is not content, and neither is anything under it: that is what makes
774        // hiding the whole answer for parking something out of the way, rather than half of one.
775        if !standing.visible {
776            continue;
777        }
778        let section = elements.section[at];
779        let mut far = Position::new(section.right(), section.bottom());
780        for child in elements.children(at) {
781            // The two ways an element grown inside a region is not part of its content, and each
782            // is left out here by the same one declaration that says the rest of what it means --
783            // which is what keeps the halves from disagreeing.
784            //
785            // A pinned child does not move with the content. A floating one moves with it but sits
786            // over the region rather than in it, so it is not content either: an overlay that
787            // invented room to scroll to is the scrollbar nobody ordered.
788            let held = &elements.standing[child];
789            if held.pinned || held.floats.is_some() {
790                continue;
791            }
792            let Some(child) = reach[child] else {
793                continue;
794            };
795            far = Position::new(far.x.max(child.x), far.y.max(child.y));
796        }
797        if let Some(scroll) = standing.scrolls {
798            grove
799                .tree
800                .set_extent(elements.order[at], reached(scroll, section, far));
801            far = Position::new(section.right(), section.bottom());
802        }
803        reach[at] = Some(far);
804    }
805}

807/// How far a region's content reaches, on each axis.
808///
809/// Three rules, and each of them is what stops a scrollbar nobody ordered:
810///
811/// - **only along a declared axis.** An axis the region does not scroll reads its own box and
812///   nothing else, so a child extending sideways out of a column that scrolls down is simply out of
813///   frame. Most accidental extent came from the axis nobody was scrolling.
814/// - **measured outward from the content origin, clamped at the near side.** A child at a negative
815///   offset creates no range to scroll *back* into: content above the origin is a layout mistake,
816///   and the previous behaviour turned it into a feature.
817/// - **never smaller than the region's own box**, so an empty region has a range of zero rather
818///   than a negative one.
819///
820fn reached(scroll: Scroll, section: Section, far: Position) -> Area {
821    let along = |axis: Axis, reach: f32, near: f32| {
822        let own = section.area.along(axis);
823        if !scroll.covers(axis) {
824            return own;
825        }
826        (reach - near).max(own)
827    };
828    Area::new(
829        along(Axis::Horizontal, far.x, section.left()),
830        along(Axis::Vertical, far.y, section.top()),
831    )
832}

834/// R4. Where each element is drawn: where the layout put it, less what its scrolling ancestors have
835/// moved.
836///
837/// A region's own box does not move under its own offset -- what moves is everything grown inside
838/// it. The offset is clamped here, against the extent R3 just measured, so a region whose content
839/// shrank under it comes back into range on the next frame rather than staying somewhere it can no
840/// longer reach.
841///
842/// The three ways a region is *asked* to move -- a coast still running from a release, a
843/// [`scroll`](crate::Grow::scroll) written this frame, and a
844/// [`Motion::Scroll`](crate::Motion::Scroll) part way through -- are answered first, here rather
845/// than where they were written, because all three need the extent and the extent is one pass old.
846fn scroll(grove: &mut Grove, elements: &mut Elements) {
847    let _pass = trace_span!("scroll", coasting = grove.coasting.len()).entered();
848    view::asked(grove, elements);
849    let mut accumulated: Vec<Position> = vec![Position::default(); elements.len()];
850    // What a *pinned* child of each element receives, which is the accumulation with its nearest
851    // scrolling ancestor left out of it.
852    let mut unpinned: Vec<Position> = vec![Position::default(); elements.len()];
853    for at in 0..elements.len() {
854        let placed = elements.section[at];
855        let trunk = elements.trunk[at];
856        let standing = elements.standing[at];
857        let inherited = trunk.map(|trunk| accumulated[trunk]).unwrap_or_default();
858        let outside = trunk.map(|trunk| unpinned[trunk]).unwrap_or_default();
859        // A pinned element does not receive its nearest scrolling ancestor's offset, and receives
860        // every offset outside that one: pinning is relative to the region the element sits in and
861        // says nothing about what contains that region.
862        let applied = match standing.pinned {
863            true => outside,
864            false => inherited,
865        };
866        let drawn = Section::new(
867            Position::new(placed.left() - applied.x, placed.top() - applied.y),
868            placed.area,
869        );
870        if drawn != elements.drawn[at] {
871            elements.drawn[at] = drawn;
872            elements.moved[at] = true;
873            elements.restack = true;
874        }
875        // A stroke's ends travel with its box, by the same offset, because they are the same
876        // geometry said two ways. A stroke nothing wrote to keeps the ends it settled at, and moves
877        // under the offset exactly as its box does.
878        if let Some(spanned) = elements.spanned[at] {
879            let stretched = Some(spanned.less(applied));
880            if stretched != elements.stretched[at] {
881                elements.stretched[at] = stretched;
882                elements.moved[at] = true;
883            }
884        }
885        let (carried, escaped) = match standing.scrolls {
886            Some(scroll) => {
887                let clamped = clamp(grove, elements.order[at], scroll, placed);
888                (
889                    Position::new(applied.x + clamped.x, applied.y + clamped.y),
890                    // A pinned child of this element is pinned to *this* region, so its offset is
891                    // the accumulation as it stood before this region's own.
892                    applied,
893                )
894            }
895            // Nothing here to be pinned against, so a pinned child of this element is pinned to
896            // whatever region contains it, exactly as a pinned sibling of this element would be.
897            None => (applied, outside),
898        };
899        accumulated[at] = carried;
900        unpinned[at] = escaped;
901    }
902}

904/// A region's offset, held to what it can actually reach.
905///
906/// An axis that was not declared does not scroll, so nothing can have moved along it -- and a
907/// region whose extent shrank under it is brought back into range here rather than left somewhere
908/// it can no longer get to.
909fn clamp(grove: &mut Grove, leaf: Leaf, scroll: Scroll, placed: Section) -> Position {
910    let offset = grove.tree.offset(leaf);
911    let extent = grove.tree.extent(leaf);
912    let mut clamped = Position::default();
913    for axis in Axis::BOTH {
914        if scroll.covers(axis) {
915            clamped = clamped.set(
916                axis,
917                offset
918                    .along(axis)
919                    .clamp(0.0, range(extent, placed.area, axis)),
920            );
921        }
922    }
923    if clamped != offset {
924        grove.tree.set_offset(leaf, clamped);
925    }
926    clamped
927}

929/// R5. What a scrolling ancestor leaves visible of each element.
930///
931/// A rect, and nothing else. A region does not clip itself, only what is grown inside it, and an
932/// element with no scrolling ancestor is clipped by nothing at all. Whether an element is *culled*
933/// is extraction's decision from this rect, and is never recorded on the element -- so there is no
934/// state saying "currently clipped away" for anything else, extent first among them, to read.
935fn clip(elements: &mut Elements) {
936    let _pass = trace_span!("clip").entered();
937    let unbounded = Clipped::unbounded().0;
938    let mut passed: Vec<Section> = vec![unbounded; elements.len()];
939    // What a *floating* child of each element is clipped to, which is the intersection with its
940    // nearest scrolling ancestor's own rect left out of it. The same second accumulation R4 carries
941    // for a pinned child, and for the same reason: both say "not part of this region", and both
942    // have to say it about the region the element is actually in rather than about all of them.
943    let mut escaped: Vec<Section> = vec![unbounded; elements.len()];
944    for at in 0..elements.len() {
945        let trunk = elements.trunk[at];
946        let standing = elements.standing[at];
947        let inherited = trunk.map(|trunk| passed[trunk]).unwrap_or(unbounded);
948        let outside = trunk.map(|trunk| escaped[trunk]).unwrap_or(unbounded);
949        // A floating element is positioned outside the region on purpose, so cutting it off at the
950        // region's edge would undo the placement that put it there. How far out it reaches is the
951        // element's own statement, because no one answer is right everywhere.
952        let applied = match standing.floats {
953            // Held by whatever holds the region it left.
954            Some(Escape::Region) => outside,
955            // Held by nothing, which extraction reads as the surface: a clip is never wider than
956            // what is being drawn on.
957            Some(Escape::Surface) => unbounded,
958            // Held by the element named, which is what that element passes down to what it holds.
959            Some(Escape::Within(named)) => match within(elements, &passed, at, named) {
960                Some(clip) => clip,
961                // Named something that is not above it, so it holds nothing. Falling back to the
962                // near answer rather than the far one: an element escapes no further than it was
963                // told to, and a mis-named ancestor is not permission to leave everything.
964                None => outside,
965            },
966            None => inherited,
967        };
968        if applied != elements.clip[at] {
969            elements.clip[at] = applied;
970            elements.moved[at] = true;
971            elements.restack = true;
972        }
973        let scrolls = standing.scrolls.is_some();
974        passed[at] = match scrolls {
975            true => applied.intersect(elements.drawn[at]),
976            false => applied,
977        };
978        escaped[at] = match scrolls {
979            true => applied,
980            false => outside,
981        };
982    }
983}

985/// What `named` leaves visible of what it holds, if it is above the element at `at` at all.
986///
987/// The walk is up the trunks from the element, so one that names something beside it rather than
988/// above it gets `None` and is answered as though it had named the region it is in. Naming the
989/// element rather than counting regions is what makes this survive a wrapper being added between
990/// the two, which a count would not.
991fn within(elements: &Elements, passed: &[Section], at: usize, named: Leaf) -> Option<Section> {
992    let named = elements.at(named)?;
993    let mut step = elements.trunk[at];
994    while let Some(above) = step {
995        // An ancestor resolves before what hangs off it, so one found here has already passed its
996        // own clip down and the read is never of a position the pass has yet to reach.
997        if above == named {
998            return Some(passed[above]);
999        }
1000        step = elements.trunk[above];
1001    }
1002    None
1003}

1005/// R6. Declared elevation accumulates down the tree, and allocation order settles what it leaves
1006/// equal.
1007///
1008/// One walk in the same dependency order the axes used, which puts every trunk before what hangs
1009/// off it -- so a trunk's rank is already this frame's when what hangs off it reads it. Nothing here
1010/// reads a box: where an element sits in the stack has nothing to do with where it sits on the
1011/// surface.
1012fn rank(elements: &mut Elements) {
1013    let _pass = trace_span!("rank").entered();
1014    for at in 0..elements.len() {
1015        let trunk = elements.trunk[at]
1016            .map(|trunk| elements.rank[trunk].stack)
1017            .unwrap_or_default();
1018        let standing = &elements.standing[at];
1019        let rank = ResolvedElevation {
1020            stack: standing.elevation.accumulate(trunk),
1021            growth: standing.growth,
1022        };
1023        if rank != elements.rank[at] {
1024            elements.rank[at] = rank;
1025            elements.moved[at] = true;
1026            elements.restack = true;
1027            elements.reranked = true;
1028        }
1029    }
1030}

1032/// R7. The three off-states, resolved over each element's whole ancestry.
1033///
1034/// One walk, in the same order the axes used, which puts every trunk before what hangs off it.
1035/// Nothing has a cascade to write: an element grown under a disabled trunk is disabled on its first
1036/// frame because the pass does not care when it arrived, and enabling that trunk leaves anything
1037/// disabled in its own right disabled because the product is over the whole ancestry rather than a
1038/// single bit that was overwritten on the way down.
1039fn inherit(elements: &mut Elements) {
1040    let _pass = trace_span!("inherit").entered();
1041    for at in 0..elements.len() {
1042        let trunk = elements.trunk[at]
1043            .map(|trunk| elements.inherited[trunk])
1044            .unwrap_or_default();
1045        let standing = &elements.standing[at];
1046        let product =
1047            Inherited::under(trunk, standing.visible, standing.opacity, standing.disabled);
1048        if product != elements.inherited[at] {
1049            elements.inherited[at] = product;
1050            elements.moved[at] = true;
1051            elements.restack = true;
1052        }
1053    }

1056/// R8. The box stack the next frame's dispatch reads.
1057///
1058/// Membership is universal: an element is here because it is there. What is left out is only what
1059/// is not there at all -- hidden, fully transparent, or clipped away by a region it sits inside.
1060/// `intangible` is not a way out of the stack; it is carried on the region and decides what may be
1061/// the top of it.
1062///
1063/// Built only on a frame where something it is built from moved. Every one of those is a column R4
1064/// through R7 compared as they wrote it, or the order itself being built again -- so a frame where
1065/// one hover fades, or nothing happens at all, keeps the stack the last one built.
1066fn regions(grove: &mut Grove, elements: &mut Elements) {
1067    if !elements.restack {
1068        return;
1069    }
1070    let _pass = trace_span!("regions").entered();
1071    // The order is total -- a resolved elevation carries allocation order as its tie-break -- so two
1072    // identical runs read the same element at the same point, and sorting without stability loses
1073    // nothing.
1074    if elements.reranked {
1075        let rank = &elements.rank;
1076        elements.stacking.clear();
1077        elements.stacking.extend(0..elements.len() as u32);
1078        elements
1079            .stacking
1080            .sort_unstable_by(|left, right| rank[*right as usize].cmp(&rank[*left as usize]));
1081    }
1082    grove
1083        .stack
1084        .settle(elements.stacking.iter().filter_map(|&at| {
1085            let at = at as usize;
1086            let inherited = elements.inherited[at];
1087            if !inherited.present() {
1088                return None;
1089            }
1090            let section = elements.drawn[at];
1091            let clip = elements.clip[at];
1092            if section.intersect(clip).is_empty() {
1093                return None;
1094            }
1095            let gestures = elements.standing[at].gestures;
1096            Some(Region {
1097                leaf: elements.order[at],
1098                section,
1099                clip,
1100                shape: gestures.shape,
1101                tangible: !gestures.intangible,
1102                receives: gestures.receives,
1103                disabled: inherited.disabled,
1104            })
1105        }));
1106}

1108/// Everything one axis of the element at `at` resolves against.
1109fn context<'a>(elements: &'a Elements, viewport: Section, at: usize, axis: Axis) -> Context<'a> {
1110    Context {
1111        axis,
1112        // Its box on this axis is the answer being computed, and its own grid divides it for its
1113        // children rather than for itself, so neither is readable here. Its box on the *other* axis
1114        // is readable exactly when that axis has already run, which is what [`own`] hands over.
1115        own: own(elements, at, axis),
1116        // A top-level element has no trunk, and fills the viewport instead.
1117        trunk: basis(elements, elements.trunk[at], viewport, axis),
1118        // A placement that reads an anchor it has not been given resolves against a zero box.
1119        anchor: basis(elements, elements.anchor[at], Section::default(), axis),
1120    }
1121}

1123/// What the element at `at` offers its own placement.
1124///
1125/// Its measured extent and its character cell on either axis, and its width on the vertical one:
1126/// the horizontal pass has run for the whole tree by then, so the width is settled where the
1127/// height is the answer being computed. That is what [`aspect`](crate::aspect) reads, and it is
1128/// offered flattened the way [`basis`] flattens a resolved box -- with nothing on the axis being
1129/// resolved -- so nothing about the box that is still open can be read back.
1130///
1131/// Nothing on the horizontal pass, where neither axis of it is known.
1132fn own<'a>(elements: &'a Elements, at: usize, axis: Axis) -> Basis<'a> {
1133    Basis {
1134        section: match axis {
1135            Axis::Horizontal => Section::default(),
1136            Axis::Vertical => flattened(elements.section[at]),
1137        },
1138        intrinsic: elements.intrinsic[at],
1139        tracks: Tracks::default(),
1140        cell: elements.cell[at],
1141        // Where its own characters stand is a question about a box that is still being solved.
1142        run: None,
1143    }
1144}

1146/// A box with its vertical half taken away: its left edge and its width, and nothing on the other
1147/// axis. What a box is worth to a reader while no height is known.

1150        Position::new(section.left(), 0.0),
1151        Area::new(section.width(), 0.0),

1155/// What the element at `at` offers a placement reading it, or `fallback` in place of a box when
1156/// there is no such element or it has not resolved yet.
1157///
1158/// **A resolved box offers no vertical reading on the horizontal axis.** R2a runs before any height
1159/// is known, so a box it offers is flattened to the horizontal -- which is what one held anyway when
1160/// every element was resolved every frame, and what it has to go on holding now that an element
1161/// nothing wrote to comes into the pass carrying the whole of last frame's box.
1162///
1163/// The fallback is not flattened, because it is not a resolved box: the viewport a top-level element
1164/// fills is as tall on this axis as on the other one.
1165fn basis<'a>(
1166    elements: &'a Elements,
1167    at: Option<usize>,
1168    fallback: Section,
1169    axis: Axis,
1170) -> Basis<'a> {
1171    let Some(at) = at else {
1172        return Basis {
1173            section: fallback,
1174            ..Basis::default()
1175        };
1176    };
1177    Basis {
1178        section: match (elements.resolved[at], axis) {
1179            (true, Axis::Horizontal) => flattened(elements.section[at]),
1180            (true, Axis::Vertical) => elements.section[at],
1181            (false, _) => fallback,
1182        },
1183        intrinsic: elements.intrinsic[at],
1184        tracks: elements.tracks[at],
1185        cell: elements.cell[at],
1186        run: elements.composed[at].as_deref(),
1187    }
1188}

1190/// The frame's one read of the tree: every live element, ordered so that nothing resolves before
1191/// what it depends on, with what it depends on and what it offers read out beside it.
1192///
1193/// An anchor may point anywhere -- a later sibling, a cousin, an element in another subtree -- so
1194/// this is ordered by dependency rather than by tree depth: an element resolves after its parent
1195/// *and* after whatever it anchors to.
1196///
1197/// A chain of anchors cannot close on itself, because one that would is refused where it is written.
1198/// A trunk and an anchor still can, between them: an element anchored to something grown under it
1199/// waits on a box that is waiting on its own. That is not the same contradiction -- both boxes
1200/// resolve, just not both against a settled other -- so the remainder is ordered by allocation order
1201/// and resolves against what its dependency last was. **Every live element is in the order**, which
1202/// is the property the passes downstream rely on: an element left out would have no box, no rank and
1203/// no place in the stack, and nothing would say so.
1204///
1205/// Each element is asked what it depends on exactly once here, and every position after that is
1206/// arithmetic on the answer.
1207///
1208/// Kept between frames and repaired rather than built again. The order is what the elements and the
1209/// edges between them make, and only growing, withering and anchoring change those -- so an ordinary
1210/// frame reads none of it. When it is built again, what every element already resolved to is
1211/// carried to wherever the element now sits, so building it again loses nothing but the elements
1212/// that went.
1213fn structure(elements: &mut Elements, grove: &Grove) {
1214    let _pass = trace_span!("structure").entered();
1215    let tree = &grove.tree;
1216    let leaves = tree.leaves();
1217    let count = leaves.len();
1218    // Where each element sits among the leaves, by the index of its name, which is dense: a lookup
1219    // is an index rather than a hash.
1220    let names = leaves
1221        .iter()
1222        .map(|leaf| leaf.0.index_u32() as usize + 1)
1223        .max()
1224        .unwrap_or_default();
1225    let mut among: Vec<u32> = vec![NOWHERE; names];
1226    for (at, leaf) in leaves.iter().enumerate() {
1227        among[leaf.0.index_u32() as usize] = at as u32;
1228    }
1229    let find = |leaf: Leaf| -> Option<usize> {
1230        let at = *among.get(leaf.0.index_u32() as usize)? as usize;
1231        (leaves.get(at) == Some(&leaf)).then_some(at)
1232    };
1233    // What each element waits on, and how many of those have yet to resolve. An element the leaves
1234    // do not hold is not live, since the leaves are what the world has grown, and a dependency on
1235    // something not live is no dependency at all.
1236    let mut depends: Vec<[Option<usize>; 2]> = Vec::with_capacity(count);
1237    let mut waiting: Vec<u8> = Vec::with_capacity(count);
1238    // Everything waiting on each element, as one run per element in a single array: an element
1239    // depends on at most two others, so the whole graph fits in one allocation rather than in a
1240    // vector per element.
1241    let mut runs: Vec<u32> = vec![0; count + 1];
1242    for &leaf in &leaves {
1243        let on = [tree.trunk(leaf), tree.anchor(leaf)].map(|on| on.and_then(find));
1244        let mut unresolved = 0;
1245        for at in on.into_iter().flatten() {
1246            unresolved += 1;
1247            runs[at + 1] += 1;
1248        }
1249        depends.push(on);
1250        waiting.push(unresolved);
1251    }
1252    for at in 0..count {
1253        runs[at + 1] += runs[at];
1254    }
1255    let mut filling = runs.clone();
1256    let mut dependents: Vec<u32> = vec![0; runs[count] as usize];
1257    for (at, on) in depends.iter().enumerate() {
1258        for &upon in on.iter().flatten() {
1259            dependents[filling[upon] as usize] = at as u32;
1260            filling[upon] += 1;
1261        }
1262    }
1263    // Kahn's, with the order under construction serving as its own queue.
1264    let mut order: Vec<usize> = (0..count).filter(|at| waiting[*at] == 0).collect();
1265    let mut next = 0;
1266    while next < order.len() {
1267        let at = order[next];
1268        next += 1;
1269        for &dependent in &dependents[runs[at] as usize..runs[at + 1] as usize] {
1270            let dependent = dependent as usize;
1271            waiting[dependent] -= 1;
1272            if waiting[dependent] == 0 {
1273                order.push(dependent);
1274            }
1275        }
1276    }
1277    if order.len() != count {
1278        order.extend((0..count).filter(|at| waiting[*at] != 0));
1279    }
1280    // Where each element ended up, which is what every position held below is in.
1281    let mut ranked: Vec<usize> = vec![0; count];
1282    for (position, &at) in order.iter().enumerate() {
1283        ranked[at] = position;
1284    }
1285    // Where each element sat in the order being replaced, which is where what it resolved to is
1286    // carried from. Whatever sat there and is not carried anywhere withered.
1287    let from: Vec<Option<usize>> = order.iter().map(|&at| elements.at(leaves[at])).collect();
1288    let mut carried = vec![false; elements.len()];
1289    for at in from.iter().flatten() {
1290        carried[*at] = true;
1291    }
1292    elements.gone.extend(
1293        (0..elements.len())
1294            .filter(|at| !carried[*at])
1295            .map(|at| (elements.order[at], elements.standing[at].chlorophyll)),
1296    );
1297    carry(&mut elements.section, &from, Section::default());
1298    carry(&mut elements.intrinsic, &from, Area::default());
1299    carry(&mut elements.reached, &from, None);
1300    carry(&mut elements.cell, &from, Area::default());
1301    carry(&mut elements.composed, &from, None);
1302    carry(&mut elements.spanned, &from, None);
1303    carry(&mut elements.drawn, &from, Section::default());
1304    carry(&mut elements.stretched, &from, None);
1305    carry(&mut elements.clip, &from, Clipped::unbounded().0);
1306    carry(&mut elements.rank, &from, ResolvedElevation::default());
1307    carry(&mut elements.inherited, &from, Inherited::default());
1308    // What an element declared is carried like what it resolved to. A grid is divided again by
1309    // `read` wherever the element is dirty, which an element just grown always is; its standing is
1310    // read here, and read again by `read` wherever it was restyled.
1311    carry(&mut elements.tracks, &from, Tracks::default());
1312    carry(&mut elements.standing, &from, Standing::default());
1313    elements.order.clear();
1314    elements.trunk.clear();
1315    elements.anchor.clear();
1316    elements.slots.clear();
1317    elements.slots.resize(names, NOWHERE);
1318    for (position, &at) in order.iter().enumerate() {
1319        let leaf = leaves[at];
1320        let [trunk, anchor] = depends[at];
1321        elements.slots[leaf.0.index_u32() as usize] = position as u32;
1322        elements.order.push(leaf);
1323        elements.trunk.push(trunk.map(|on| ranked[on]));
1324        elements.anchor.push(anchor.map(|on| ranked[on]));
1325        if from[position].is_none() {
1326            elements.standing[position] = tree.standing(leaf);
1327        }
1328    }
1329    // What is grown under each element, by position: counted, summed into where each element's run
1330    // starts, and filled.
1331    elements.branches.clear();
1332    elements.branches.resize(count + 1, 0);
1333    for trunk in elements.trunk.iter().flatten() {
1334        elements.branches[trunk + 1] += 1;
1335    }
1336    for at in 0..count {
1337        elements.branches[at + 1] += elements.branches[at];
1338    }
1339    let mut filling = elements.branches.clone();
1340    elements.children.clear();
1341    elements.children.resize(count, 0);
1342    for at in 0..count {
1343        if let Some(trunk) = elements.trunk[at] {
1344            elements.children[filling[trunk] as usize] = at as u32;
1345            filling[trunk] += 1;
1346        }
1347    }
1348    // Everything the stack is built from may have moved, since what is in it did.
1349    elements.restack = true;
1350    elements.reranked = true;
1351}

1353/// Rebuilds one column in the new order: each element's value carried from where it sat, and
1354/// `fresh` for one that was not in the order before.
1355fn carry<T: Clone>(column: &mut Vec<T>, from: &[Option<usize>], fresh: T) {
1356    let held = core::mem::take(column);
1357    column.extend(from.iter().map(|at| match at {
1358        Some(at) => held[*at].clone(),
1359        None => fresh.clone(),
1360    }));
1361}

1363/// What this frame has to resolve, and what it may leave alone.
1364///
1365/// An element resolves again if it was written to, or if what it hangs off or is anchored to does.
1366/// That closure is one walk of the order rather than a search, because the order already puts a
1367/// dependency before what depends on it. What was written is found by name and marked where it
1368/// sits, so the walk costs the order and the marking costs what was written.
1369///
1370/// An element that was restyled is read again and marked as moved, and resolves again only if
1371/// something it is placed by was written as well.
1372fn read(elements: &mut Elements, grove: &Grove) {
1373    let _pass = trace_span!("elements").entered();
1374    let written = grove.tree.written();
1375    elements.gone.clear();
1376    elements.restack = false;
1377    elements.reranked = false;
1378    if written.restructured {
1379        structure(elements, grove);
1380    }
1381    // What the restyled elements declared is read again where they sit.
1382    for &leaf in written.restyled {
1383        if let Some(at) = elements.at(leaf) {
1384            elements.standing[at] = grove.tree.standing(leaf);
1385        }
1386    }
1387    let count = elements.len();
1388    elements.restated = written.restated;
1389    elements.dirty.clear();
1390    elements.dirty.resize(count, written.all);
1391    elements.moved.clear();
1392    elements.moved.resize(count, false);
1393    elements.measures.clear();
1394    elements.measures.resize(count, false);
1395    elements.resolved.clear();
1396    elements.resolved.resize(count, false);
1397    elements.lettered.clear();
1398    elements.lettered.resize(count, written.all);
1399    if !written.all {
1400        for &leaf in written.lettered {
1401            if let Some(at) = elements.at(leaf) {
1402                elements.lettered[at] = true;
1403            }
1404        }
1405    }
1406    if !written.all {
1407        for &leaf in written.declared {
1408            if let Some(at) = elements.at(leaf) {
1409                elements.dirty[at] = true;
1410            }
1411        }
1412    }
1413    for &leaf in written.measures {
1414        if let Some(at) = elements.at(leaf) {
1415            elements.measures[at] = true;
1416        }
1417    }
1418    if written.repainted {
1419        elements.moved.fill(true);
1420    }
1421    for &leaf in written.restyled {
1422        if let Some(at) = elements.at(leaf) {
1423            elements.moved[at] = true;
1424        }
1425    }
1426    for at in 0..count {
1427        // A dependency the order could not put first is one a cycle left in the remainder, and it
1428        // has no answer yet. Resolving such an element is the same fallback the rest of resolution
1429        // gives it: it is answered against what its dependency last was, so it is answered again.
1430        let decided = |on: Option<usize>| on.is_some_and(|on| on >= at || elements.dirty[on]);
1431        let dirty =
1432            elements.dirty[at] || decided(elements.trunk[at]) || decided(elements.anchor[at]);
1433        elements.dirty[at] = dirty;
1434        elements.moved[at] |= dirty;
1435        elements.measures[at] |= dirty;
1436        // A clean element offers the box it settled at, and offers it from the start, because
1437        // nothing this frame is going to compute it again. One being resolved again offers nothing
1438        // until an axis reaches it, which is what it did when every element was resolved.
1439        elements.resolved[at] = !dirty;
1440        // The grid is divided at the breakpoint in force, so it is read again wherever the element
1441        // is -- a breakpoint that moved is every element written to, and nothing else can change a
1442        // division without writing the grid it divides.
1443        if dirty {
1444            elements.tracks[at] = grove
1445                .tree
1446                .grid(elements.order[at])
1447                .unwrap_or_default()
1448                .tracks(grove.layout, grove.short);
1449        }
1450    }
