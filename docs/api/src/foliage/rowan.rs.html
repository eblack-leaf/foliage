1//! Rowan -- resolution.
2//!
3//! # Rowan resolves. Elm decides what changed.
4//!
5//! Every pass runs in the same order over the same elements every frame, and each writes exactly one
6//! thing. What a pass may leave alone is an element **nothing it reads was written to**, whose
7//! answer is the one it already holds -- sitting in the column the pass would have written it to.
8//!
9//! That is not invalidation and nothing is ever marked stale. The tree records a write where the
10//! write happens ([`Tree::declared`](crate::tree::Tree::declared), which every declaration passes
11//! through), and [`read`] closes that over the dependencies before any pass runs. So an element
12//! resolves again if it was written to, if what it hangs off or is anchored to resolves again, or if
13//! a measure moved under it -- and if none of those happened, resolving it again would produce what
14//! it already has. A value here can be old. It cannot be wrong.
15//!
16//! What still runs over everything is the accumulations, R3 through R8: what they carry is a running
17//! product rather than an answer per element, so there is no position in them to start from. They
18//! record what they actually changed as they go, which is what extraction then states.
19//!
20//! The read itself is kept between frames and repaired where the tree was written -- growing,
21//! withering and anchoring are the only things that change the order, so an ordinary frame reads
22//! none of it.
23//!
24//! Nothing is re-uploaded on account of any of it, because extraction compares against a cached copy
25//! and sends only genuine differences.
26//!
27//! The passes each write exactly one thing, and nothing writes what another owns:
28//!
29//! | | Pass | Direction | Produces |
30//! |---|---|---|---|
31//! | R1 | measure | — | [`Cell`], and the max-content width half of [`Intrinsic`] |
32//! | R2a | horizontal | dependency order | the horizontal axis |
33//! | R2m | wrap | **bottom-up** | the measured-height half of [`Intrinsic`] |
34//! | R2b | vertical | dependency order | the vertical axis, and with it [`Placed`] |
35//! | R3 | extent | **bottom-up** | [`Extent`](crate::view::Extent): how far a region's content reaches |
36//! | R4 | scroll | top-down | [`Drawn`]: [`Placed`] less every scrolling ancestor's offset |
37//! | R5 | clip | top-down | [`Clipped`]: what a scrolling ancestor leaves visible |
38//! | R6 | rank | dependency order | `ResolvedElevation`: elevation accumulated, then tie-broken |
39//! | R7 | inherit | top-down | [`Inherited`]: the visible, opacity and disabled products |
40//! | R8 | regions | rank order | the box stack the next frame's dispatch reads |
41//!
42//! Both halves of R2 call the same pure resolver, once per axis. That is only safe because it is
43//! pure: there is no accumulated state for a second call to corrupt.
44//!
45//! R1, R2a and R2b resolve what was written to. R2m resolves that and everything above it, because
46//! what an element reaches over is what the elements under it resolved to -- a measure travels
47//! toward the trunk where a box travels away from it. A measure that moves under an element nothing
48//! wrote to makes that element resolve again, which is why R2m sits before R2b and not after it.
49//!
50//! # Every pass reads the order, not the world
51//!
52//! The passes ask the same questions of the same elements over and over: what an element hangs off,
53//! what it is anchored to, and what each of those offers a placement reading it. Asked of the world
54//! each time, every one of those is a lookup by entity -- and the arithmetic a pass does is small
55//! enough that the lookups, not the arithmetic, are what a frame costs.
56//!
57//! So the tree is read once, into [`Elements`]: every live element in dependency order, holding what
58//! it depends on as **positions in that order** rather than as names, and holding what it offers a
59//! placement beside it. From there every pass indexes -- the accumulations R3 through R7 carry are
60//! arrays the length of the order, and a trunk's contribution is `[..]` rather than a lookup on a
61//! map keyed by element.
62//!
63//! The measures R1 and R2m state are written there too, and reach the elements themselves in one
64//! [`scatter`] once both passes have run. So no pass writes a value another is about to read back
65//! out of the world, and during resolution the order is the only place a measure is held.
66//!
67//! Nothing about what is computed changes, and neither does the ordering that makes it correct.
68//!
69//! Two passes run the other way, and each is a cycle that turns out not to be vicious.
70//!
71//! R2m is one: wrapping makes a height depend on a width, and the width comes from the layout, so a
72//! box sized to its contents looks circular. It is not, because **width flows down and height flows
73//! up** -- a monospaced run's widest unwrapped line is free from its character count, so the
74//! down-pass needs nothing measured. R2m sits between the two halves of R2 for that reason: it is
75//! the one moment when every width is known and no height is, which is exactly what measuring needs.
76//!
77//! R3 is the other: a child resolves against its parent's box, a scrolling parent's extent comes
78//! from where its children landed, and that extent is what its offset is clamped to. Extent affects
79//! only the clamp and never the parent's own box -- so a top-down layout sweep, a bottom-up extent
80//! sweep and a top-down scroll application resolve it in one pass each.
81//!
82//! Neither iterates to convergence. Every pass here runs exactly once.

131/// What an element measured to, which is what [`content()`](crate::content) reads.
132///
133/// The two halves are written by different passes and mean different questions, which is the whole
134/// of width-down and height-up:
135///
136/// - **width** is max-content, written by R1 -- the widest the element would like to be, unwrapped.
137///   In a monospaced font that is a character count times a cell, so it is free and is available
138///   before any layout has happened.
139/// - **height** is measured, written by R2m -- what the element turned out to be at the width R2a
140///   gave it.
141#[derive(Component, Copy, Clone, Debug, Default, PartialEq)]
142pub(crate) struct Intrinsic(pub(crate) Area);

144/// An element's run of glyphs as R1 shaped it, which is what a placement reading a
145/// [`character`](crate::Anchor::character) of the element resolves against.
146///
147/// Held on the element the way its [`Cell`] is, and for the same reason: it is what the element
148/// offers a placement that reads it, so it is read into the order once and never looked up by a
149/// pass. Shared with the shaping cache rather than copied out of it, and absent on an element that
150/// says nothing.
151#[derive(Component, Clone, Debug, Default)]
152pub(crate) struct Composed(pub(crate) Option<Arc<Shaped>>);

154impl PartialEq for Composed {
155    /// The same run, not an equal one: two shapings of one value are one entry in the cache, so
156    /// what changed is whether the element was shaped again.
157    fn eq(&self, other: &Self) -> bool {
158        match (&self.0, &other.0) {
159            (Some(held), Some(other)) => Arc::ptr_eq(held, other),
160            (None, None) => true,
161            _ => false,
162        }
163    }
164}

166/// Every live element in dependency order, with what each one resolves against and what each one
167/// offers a placement that reads it.
168///
169/// The frame's one read of the tree, and what every pass indexes into. A trunk and an anchor are
170/// asked for on both axes and on four of the passes after them; what an element offers is asked for
171/// twice per element on each axis. Out of the world each time, every one of those is a lookup by
172/// entity -- resolved once to a position in the order, each is an index.
173///
174/// The columns are as long as the order and are read at the position an element sits at, so a pass
175/// that already knows where it is never asks a second time.
176#[derive(Default)]
177pub(crate) struct Elements {
178    /// Every live element, ordered so that nothing resolves before what it depends on.
179    order: Vec<Leaf>,
180    /// Where each element sits in the order.
181    index: HashMap<Leaf, usize>,
182    /// What each element hangs off, as a position in the order.
183    trunk: Vec<Option<usize>>,
184    /// What each element is anchored to, as a position in the order.
185    anchor: Vec<Option<usize>>,
186    /// The box, as far as the axes have resolved it.
187    section: Vec<Section>,
188    /// Whether the element has a box worth reading yet. True from the start for one nothing has
189    /// written to, whose box is the one it settled at last frame; false for one being resolved
190    /// again, until an axis reaches it -- which is what answers a cycle's remainder with the
191    /// fallback rather than with a box that has not been computed.
192    resolved: Vec<bool>,
193    /// Whether the element has to be resolved again this frame.
194    ///
195    /// True where something it reads was written -- its own declarations, or those of what it hangs
196    /// off or is anchored to. False where nothing was, in which case the columns already hold what
197    /// it resolved to and the passes that only rewrite that have nothing to do.
198    dirty: Vec<bool>,
199    /// Whether any run stopped being stated this frame, which is the one thing that makes the
200    /// shaping cache worth sweeping -- and, because a sweep drops what this frame did not state,
201    /// the one thing that makes every run worth shaping again.
202    restated: bool,
203    /// Whether anything extraction reads about the element moved this frame.
204    ///
205    /// Seeded from [`dirty`](Elements::dirty), because an element being resolved again may land
206    /// somewhere else, and set by R4 through R7 where what they wrote differs from what was held.
207    /// An element it is false for is drawn exactly as the backend already has it.
208    moved: Vec<bool>,
209    /// What the element draws, or [`Chlorophyll::None`] where it draws nothing.
210    chlorophyll: Vec<Chlorophyll>,
211    /// Whether the element has to measure again, before R2m walks that up the trunks.
212    ///
213    /// [`dirty`](Elements::dirty) is most of it. The rest is an element something withered from,
214    /// which has one fewer thing to reach over and nothing left below it to say so.
215    measures: Vec<bool>,
216    /// What the element measured to. R1 writes the width and R2m the height.
217    intrinsic: Vec<Area>,
218    /// The element's own grid, divided at the breakpoint in force.
219    tracks: Vec<Tracks>,
220    /// The element's character cell.
221    cell: Vec<Area>,
222    /// The element's run as R1 shaped it, where it has one.
223    composed: Vec<Option<Arc<Shaped>>>,
224}
225
226impl Elements {
227    /// How many elements are live.
228    fn len(&self) -> usize {
229        self.order.len()
230    }
231
232    /// Where `leaf` sits, or `None` if it is not live.
233    fn at(&self, leaf: Leaf) -> Option<usize> {
234        self.index.get(&leaf).copied()
235    }
236
237    /// The box `leaf` resolved to, or a zero one if it is not live.
238    ///
239    /// Resolution reads a box by position, because it holds every element in order. A coast, a
240    /// sought region and a running motion each name one element instead, so they ask the way an app
241    /// asks.
242    /// Every live element in the order resolution used, with what it draws and whether anything
243    /// extraction reads about it moved this frame.
244    pub(crate) fn drawing(&self) -> impl Iterator<Item = (Leaf, Chlorophyll, bool)> + '_ {
245        (0..self.len()).map(|at| (self.order[at], self.chlorophyll[at], self.moved[at]))
246    }
247
248    pub(crate) fn of(&self, leaf: Leaf) -> Section {
249        self.at(leaf).map(|at| self.section[at]).unwrap_or_default()
250    }
251}

253/// Steps 6 and 7. Declared state becomes resolved geometry and resolved products, for everything.
254pub(crate) fn run(grove: &mut Grove) {
255    let step = trace_span!("resolve", elements = Empty, dirty = Empty);
256    let resolving = step.enter();
257    // Taken off the grove so the passes can hold it while they write to the rest, and put back at
258    // the end of resolution: what it holds is what this frame settled, and what the next one starts
259    // from rather than reads again.
260    let mut elements = core::mem::take(&mut grove.elements);
261    read(&mut elements, grove);
262    // Forgotten the moment it is read, so a write made by a pass after this belongs to the frame
263    // that would resolve it.
264    grove.tree.taken();
265    step.record("elements", elements.len());
266    step.record(
267        "dirty",
268        elements.dirty.iter().filter(|dirty| **dirty).count(),
269    );
270    measure(grove, &mut elements);
271    let ends = axes(grove, &mut elements);
272    scatter(grove, &elements);
273    // Both of the passes that shape have run, so what is not held now is a run nothing states. Only
274    // on a frame that shaped every one of them, which is the frame after one stopped being stated:
275    // a sweep over a frame that shaped some of them would drop the rest.
276    if elements.restated {
277        grove.shaping.sweep();
278    }
279    extent(grove, &elements);
280    scroll(grove, &mut elements, &ends);
281    clip(grove, &mut elements);
282    rank(grove, &mut elements);
283    // Resolution ends here. What settles after it is its own step, and is timed as one.
284    drop(resolving);
285    let _step = trace_span!("settle").entered();
286    inherit(grove, &mut elements);
287    regions(grove, &elements);
288    grove.elements = elements;
289}

291/// The measures, written back to the elements themselves.
292///
293/// R1 and R2m state them into the order, because everything that reads them *during* resolution
294/// reads them there. This is the one write, after both passes that state them have run: what an
295/// element measured to is one value, and a frame never holds it in two places.
296fn scatter(grove: &mut Grove, elements: &Elements) {
297    let _pass = trace_span!("scatter").entered();
298    for at in 0..elements.len() {
299        let leaf = elements.order[at];
300        grove.tree.set_cell(leaf, elements.cell[at]);
301        grove.tree.set_intrinsic(leaf, elements.intrinsic[at]);
302        grove
303            .tree
304            .set_composed(leaf, Composed(elements.composed[at].clone()));
305    }
306}

308/// R1. What an element's own font makes of it: its character cell, and the widest its content would
309/// like to be.
310///
311/// Ahead of every other pass, and reading no geometry at all, because neither answer has anything to
312/// do with where the element ended up. A monospaced run's max-content width is its longest line's
313/// character count times its cell, so the whole of the down-pass's input is available before the
314/// down-pass runs -- which is what leaves only the up-pass with anything to measure.
315fn measure(grove: &mut Grove, elements: &mut Elements) {
316    let _pass = trace_span!("measure").entered();
317    let Grove {
318        tree,
319        fonts,
320        shaping,
321        layout,
322        short,
323        ..
324    } = grove;
325    for at in 0..elements.order.len() {
326        // Nothing it reads was written, so it measures to what it measured to, which is what the
327        // column was read out of the tree holding.
328        if !elements.dirty[at] {
329            continue;
330        }
331        let leaf = elements.order[at];
332        // No font and no size is no cell, and nothing measured in one. What such an element last
333        // measured to stands, which is what it was read out of the tree holding.
334        let Some(typeface) = tree.typeface(leaf) else {
335            continue;
336        };
337        let size = typeface.size.at(*layout, *short);
338        let cell = fonts.cell(typeface.font, size);
339        // The run, shaped, is kept beside the cell: it is what a placement reading a character of
340        // this element resolves against, and this is the one pass that shapes.
341        let composed = tree
342            .lettering(leaf)
343            .map(|value| shaping.shape(fonts, typeface.font, size, value).clone());
344        let width = composed
345            .as_ref()
346            .map(|shaped| shaped.max_content())
347            .unwrap_or_default();
348        elements.cell[at] = cell;
349        elements.composed[at] = composed;
350        // The height half is R2m's, and is written before anything reads it.
351        elements.intrinsic[at] = Area::new(width, 0.0);
352    }
353}

355/// R2a, R2m and R2b: the horizontal axis, then the measure it makes possible, then the vertical one.
356///
357/// An element with a placement in motion is resolved twice on each axis -- once for each endpoint,
358/// in the *same* context -- and the two answers are blended. That is what the resolver's purity
359/// buys: the endpoints are consistent with each other because they were asked at the same position
360/// in the same dependency order, against the same settled ancestors, and neither is remembered
361/// afterwards.
362fn axes(grove: &mut Grove, elements: &mut Elements) -> Vec<Option<Stretched>> {
363    let mut ends: Vec<Option<Stretched>> = vec![None; elements.len()];
364    axis(grove, elements, Axis::Horizontal, &mut ends);
365    wrap(grove, elements);
366    axis(grove, elements, Axis::Vertical, &mut ends);
367    ends
368}

370/// One axis of the whole tree, in dependency order, through the one pure resolver.
371fn axis(grove: &Grove, elements: &mut Elements, axis: Axis, ends: &mut [Option<Stretched>]) {
372    let _pass = trace_span!("axis", vertical = (axis == Axis::Vertical)).entered();
373    let viewport = Section::new(Position::default(), grove.viewport);
374    let fallback = Location::default();
375    for at in 0..elements.len() {
376        // R2m may have found a measure that moved under an element nothing was written to, between
377        // this axis and the last. The order puts what an element reads before it, so spreading that
378        // here reaches everything resolved against it.
379        elements.dirty[at] |= elements.trunk[at].is_some_and(|on| elements.dirty[on])
380            || elements.anchor[at].is_some_and(|on| elements.dirty[on]);
381        // Nothing it or anything it resolves against was written, so it resolves to the box it
382        // already holds. Its column keeps that box, so what reads it here reads the right one.
383        if !elements.dirty[at] {
384            continue;
385        }
386        let leaf = elements.order[at];
387        let context = context(elements, viewport, at, axis);
388        let (span, stretched) = geometry(grove, leaf, &fallback, &context, axis);
389        if let Some((from, to)) = stretched {
390            ends[at]
391                .get_or_insert_with(Stretched::default)
392                .set(axis, from, to);
393        }
394        let section = &mut elements.section[at];
395        match axis {
396            Axis::Horizontal => {
397                section.position.x = span.near;
398                section.area.width = span.extent();
399            }
400            Axis::Vertical => {
401                section.position.y = span.near;
402                section.area.height = span.extent();
403            }
404        }
405        elements.resolved[at] = true;
406    }
407}

409/// One axis of `leaf`, whichever of the two ways its placement is stated.
410///
411/// A box resolves to a span directly. A **trace** resolves to two positions, and the span is the
412/// distance between them grown by half the stroke's weight on each side -- which is what gives a
413/// rule, whose ends share a coordinate on one axis, a box on that axis at all. Both ends come back
414/// too, because the span cannot say which of its diagonals they are.
415fn geometry(
416    grove: &Grove,
417    leaf: Leaf,
418    fallback: &Location,
419    context: &Context,
420    axis: Axis,
421) -> (Span, Option<(f32, f32)>) {
422    let Some(trace) = grove.tree.trace(leaf) else {
423        return (span(grove, leaf, fallback, context, axis), None);
424    };
425    let half = grove.tree.stroke(leaf).unwrap_or_default().half();
426    let (from, to) = ends(grove, leaf, trace, context, axis);
427    (
428        Span {
429            near: from.min(to) - half,
430            far: from.max(to) + half,
431        },
432        Some((from, to)),
433    )
434}

436/// One axis of where `leaf`'s two ends currently are: what it declares, blended with the ends a
437/// motion left.
438///
439/// [`span`] for a trace. Each end blends on its own and the box is taken from the blended pair,
440/// rather than the two boxes blending: a stroke part way between a rising and a falling diagonal is
441/// a stroke, and a box that blended separately would not be the rectangle around it.
442fn ends(grove: &Grove, leaf: Leaf, trace: &Trace, context: &Context, axis: Axis) -> (f32, f32) {
443    let (from, to) = located(pinned_ends(trace, grove), context);
444    match grove.aspen.trace(leaf) {
445        Some((departed, at)) => {
446            let (left_from, left_to) = match departed {
447                Departed::Declared(trace) => located(pinned_ends(trace, grove), context),
448                Departed::Snapshot(stretched) => stretched.along(axis),
449            };
450            (blend(left_from, from, at), blend(left_to, to, at))
451        }
452        None => (from, to),
453    }
454}
455
456/// One axis of both of a pair of ends, through the resolver.
457fn located(ends: &Ends, context: &Context) -> (f32, f32) {
458    (locate(&ends.from, context), locate(&ends.to, context))
459}

466/// One axis of where `leaf` currently is: what it declares, blended with the endpoint a motion left.
467///
468/// The one place a placement becomes a span, so a measure and a layout are answering the same
469/// question -- an element in motion is measured where it *is* rather than where it is going.
470fn span(grove: &Grove, leaf: Leaf, fallback: &Location, context: &Context, axis: Axis) -> Span {
471    let location = grove.tree.location(leaf).unwrap_or(fallback);
472    let target = resolve(pinned(location, grove, axis), context);
473    match grove.aspen.location(leaf) {
474        Some((departed, at)) => departure(departed, grove, context, axis).blend(target, at),
475        None => target,
476    }
477}

479/// How one axis of a placement is pinned down, at the breakpoint in force.
480///
481/// A lookup rather than arithmetic, which is why it is here and not in the resolver: picking a
482/// configuration out of a placement is not part of resolving one.
483fn pinned<'a>(location: &'a Location, grove: &Grove, axis: Axis) -> &'a Config {
484    let axes = location.axes(grove.layout, grove.short);
485    match axis {
486        Axis::Horizontal => &axes.horizontal,
487        Axis::Vertical => &axes.vertical,
488    }
489}

491/// One axis of the endpoint a motion left.
492///
493/// A placement it left is resolved in the context the target was resolved in, so anything that
494/// moves one end moves both. A snapshot is already an answer: it is the box the element was blended
495/// to when it was retargeted, and it never corresponded to a placement that could be re-resolved.
496fn departure(
497    departed: &Departed<Location, Section>,
498    grove: &Grove,
499    context: &Context,
500    axis: Axis,
501) -> Span {
502    match departed {
503        Departed::Declared(location) => resolve(pinned(location, grove, axis), context),
504        Departed::Snapshot(section) => Span::of(*section, axis),
505    }
506}

508/// R2m. How tall each element's contents turned out at the width R2a gave it.
509///
510/// Bottom-up, so everything inside an element is measured before the element asks. Two things are
511/// measured, and an element takes the greater of them, because both answer the one question
512/// [`content()`](crate::content) asks -- *how large is what is inside me*:
513///
514/// - a run of glyphs wraps at its own resolved width, and its lines times its cell is its height
515/// - anything with elements grown under it takes the furthest any of them reaches down
516///
517/// The second is resolved in the element's own space, with its vertical extent taken as **not yet
518/// known**, which is exactly what it is at this point in the frame. So a child that reads that
519/// extent -- `100.pct()`, a row of a grid, an anchor's edge -- contributes nothing to the measure
520/// and is given its real height by R2b like anything else. That is the correct reading rather than a
521/// limitation: a child sized to its trunk cannot also be what sizes it, and nothing is asked to
522/// converge.
523/// The two halves are separate walks because only one of them has an order. A run wraps at its own
524/// width and against its own font, so what an element shapes to reads nothing but the element --
525/// while what reaches below it reads the measures of everything under it, and so has to run after
526/// them.
527fn wrap(grove: &mut Grove, elements: &mut Elements) {
528    let _pass = trace_span!("wrap").entered();
529    // What has to measure again: what was written to, and everything above it, because what an
530    // element reaches over is what the elements under it resolved to. Up the order rather than down
531    // it -- a measure travels toward the trunk and stops there, where a box travels away from it.
532    let mut measuring = elements.measures.clone();
533    for at in (0..elements.len()).rev() {
534        if let (true, Some(trunk)) = (measuring[at], elements.trunk[at]) {
535            measuring[trunk] = true;
536        }
537    }
538    let shaped = shaped(grove, elements, &measuring);
539    let _half = trace_span!("reach").entered();
540    let fallback = Location::default();
541    for at in (0..elements.len()).rev() {
542        if !measuring[at] {
543            continue;
544        }
545        let height = shaped[at].max(reach(grove, elements, &fallback, at));
546        if height != elements.intrinsic[at].height {
547            elements.intrinsic[at].height = height;
548            // The measure moved under an element nothing was written to, and a placement reading
549            // that measure has to be resolved against the new one. R2b runs after this and spreads
550            // it, which is why it is safe to find out here.
551            elements.dirty[at] = true;
552        }
553    }
554}

556/// How tall each element's own run turned out at the width R2a gave it.
557///
558/// In any order, because no element's answer is another's: this is the half of R2m that reaches into
559/// the world for a typeface and a run, and the only half that touches the shaping cache.
560///
561/// Shaping a run is what states that the run is still wanted, and the sweep drops what this frame did
562/// not state -- so on a frame that is going to sweep, every element is shaped whether or not it is
563/// measuring again. A frame where no run stopped being stated has nothing to sweep, and shapes only
564/// what it is measuring.
565fn shaped(grove: &mut Grove, elements: &Elements, measuring: &[bool]) -> Vec<f32> {
566    let _half = trace_span!("shaped").entered();
567    let mut shaped = vec![0.0; elements.len()];
568    for at in 0..elements.len() {
569        if !(measuring[at] || elements.restated) {
570            continue;
571        }
572        shaped[at] = wrapped(grove, elements.order[at], elements.section[at].width());
573    }
574    shaped
575}

577/// How tall `leaf`'s own run of glyphs is at `width`, or zero if it says nothing.
578fn wrapped(grove: &mut Grove, leaf: Leaf, width: f32) -> f32 {
579    let Grove {
580        tree,
581        fonts,
582        shaping,
583        layout,
584        short,
585        ..
586    } = grove;
587    let Some(typeface) = tree.typeface(leaf) else {
588        return 0.0;
589    };
590    let Some(value) = tree.lettering(leaf) else {
591        return 0.0;
592    };
593    let size = typeface.size.at(*layout, *short);
594    shaping
595        .shape(fonts, typeface.font, size, value)
596        .measure(width)
597}

599/// How far the elements grown under `leaf` reach below its top edge.
600///
601/// Only the children that describe their own extent are counted. One that reads a vertical box --
602/// a percentage of this element, a row of its grid, an anchor's edge -- is asking how tall
603/// something else is, so it cannot be what decides how tall this is. See
604/// [`Config::measurable`](crate::placement::role::Config::measurable).
605fn reach(grove: &Grove, elements: &Elements, fallback: &Location, at: usize) -> f32 {
606    let mut reach: f32 = 0.0;
607    for child in grove.tree.branched(elements.order[at]) {
608        let Some(child_at) = elements.at(child) else {
609            continue;
610        };
611        if !measurable(grove, child, fallback) {
612            continue;
613        }
614        let context = raised(elements, at, child_at);
615        reach = reach.max(
616            geometry(grove, child, fallback, &context, Axis::Vertical)
617                .0
618                .far,
619        );
620    }
621    reach
622}

624/// Whether `leaf`'s vertical placement describes its own extent, and so counts toward the measure
625/// of what it is grown under.
626///
627/// One question with two spellings, because a placement has two. A box asks it of its vertical
628/// configuration; a trace asks it of both of its ends, since either one reading a vertical box is
629/// enough to make the answer circular.
630fn measurable(grove: &Grove, leaf: Leaf, fallback: &Location) -> bool {
631    match grove.tree.trace(leaf) {
632        Some(trace) => {
633            let ends = pinned_ends(trace, grove);
634            ends.from.measurable() && ends.to.measurable()
635        }
636        None => pinned(
637            grove.tree.location(leaf).unwrap_or(fallback),
638            grove,
639            Axis::Vertical,
640        )
641        .measurable(),
642    }
643}

645/// What one child resolves its vertical axis against while its trunk is being measured.
646///
647/// The same [`Context`] R2b will build, with every vertical reading taken as zero: no box on this
648/// axis has resolved yet, which is the point of measuring. Every horizontal reading is real -- the
649/// child's own width included -- so a height stated in columns, read off a width, or held in
650/// proportion to its own still answers.
651fn raised<'a>(elements: &'a Elements, trunk: usize, child: usize) -> Context<'a> {
652    let offered = |at: usize| Basis {
653        section: flattened(elements.section[at]),
654        intrinsic: elements.intrinsic[at],
655        tracks: elements.tracks[at],
656        cell: elements.cell[at],
657        run: elements.composed[at].as_deref(),
658    };
659    Context {
660        axis: Axis::Vertical,
661        own: own(elements, child, Axis::Vertical),
662        trunk: offered(trunk),
663        anchor: match elements.anchor[child] {
664            Some(anchor) => offered(anchor),
665            None => Basis::default(),
666        },
667    }
668}

670/// R3. How far each region's content reaches, from where its children landed.
671///
672/// Bottom-up, so a subtree is measured before whatever contains it. Two things are deliberately not
673/// consulted: what is currently drawn, because content scrolled out of sight is exactly what an
674/// extent describes and has to remain reachable; and the offset, because measuring against it would
675/// make the extent depend on the clamp that depends on the extent.
676///
677/// A child that scrolls in its own right contributes its box and not its content -- what overflows
678/// inside it is its own to reach, and is already reachable there.
679///
680/// A **visible child that is simply far away is content**, and is counted. That is the answer
681/// `views.md` gives to the parking footgun, and it is deliberately not a guess about intent: if it
682/// is visible and out there it is reachable, which is coherent where the old behaviour was a
683/// surprise. What removes a child from the extent is the app saying so -- [`visible(false)`] takes
684/// it and its subtree out, and [`pinned`] takes out something that is inside the region without
685/// travelling with it.
686///
687/// [`visible(false)`]: crate::Place::visible
688/// [`pinned`]: crate::Place::pinned
689fn extent(grove: &mut Grove, elements: &Elements) {
690    let _pass = trace_span!("extent").entered();
691    // The far corner of everything under an element, in absolute coordinates. Absent where the
692    // element was skipped, which is what keeps a hidden subtree out of what contains it.
693    let mut reach: Vec<Option<Position>> = vec![None; elements.len()];
694    for at in (0..elements.len()).rev() {
695        let leaf = elements.order[at];
696        // A hidden element is not content, and neither is anything under it: that is what makes
697        // hiding the whole answer for parking something out of the way, rather than half of one.
698        if !grove.tree.visible(leaf).0 {
699            continue;
700        }
701        let section = elements.section[at];
702        let mut far = Position::new(section.right(), section.bottom());
703        for child in grove.tree.branched(leaf) {
704            // The two ways an element grown inside a region is not part of its content, and each
705            // is left out here by the same one declaration that says the rest of what it means --
706            // which is what keeps the halves from disagreeing.
707            //
708            // A pinned child does not move with the content. A floating one moves with it but sits
709            // over the region rather than in it, so it is not content either: an overlay that
710            // invented room to scroll to is the scrollbar nobody ordered.
711            if grove.tree.pinned(child) || grove.tree.floats(child).is_some() {
712                continue;
713            }
714            let Some(child) = elements.at(child).and_then(|child| reach[child]) else {
715                continue;
716            };
717            far = Position::new(far.x.max(child.x), far.y.max(child.y));
718        }
719        if let Some(scroll) = grove.tree.scrolls(leaf) {
720            grove.tree.set_extent(leaf, reached(scroll, section, far));
721            far = Position::new(section.right(), section.bottom());
722        }
723        reach[at] = Some(far);
724    }
725}

727/// How far a region's content reaches, on each axis.
728///
729/// Three rules, and each of them is what stops a scrollbar nobody ordered:
730///
731/// - **only along a declared axis.** An axis the region does not scroll reads its own box and
732///   nothing else, so a child extending sideways out of a column that scrolls down is simply out of
733///   frame. Most accidental extent came from the axis nobody was scrolling.
734/// - **measured outward from the content origin, clamped at the near side.** A child at a negative
735///   offset creates no range to scroll *back* into: content above the origin is a layout mistake,
736///   and the previous behaviour turned it into a feature.
737/// - **never smaller than the region's own box**, so an empty region has a range of zero rather
738///   than a negative one.
739///
740fn reached(scroll: Scroll, section: Section, far: Position) -> Area {
741    let along = |axis: Axis, reach: f32, near: f32| {
742        let own = section.area.along(axis);
743        if !scroll.covers(axis) {
744            return own;
745        }
746        (reach - near).max(own)
747    };
748    Area::new(
749        along(Axis::Horizontal, far.x, section.left()),
750        along(Axis::Vertical, far.y, section.top()),
751    )
752}

754/// R4. Where each element is drawn: where the layout put it, less what its scrolling ancestors have
755/// moved.
756///
757/// A region's own box does not move under its own offset -- what moves is everything grown inside
758/// it. The offset is clamped here, against the extent R3 just measured, so a region whose content
759/// shrank under it comes back into range on the next frame rather than staying somewhere it can no
760/// longer reach.
761///
762/// The three ways a region is *asked* to move -- a coast still running from a release, a
763/// [`scroll`](crate::Grow::scroll) written this frame, and a
764/// [`Motion::Scroll`](crate::Motion::Scroll) part way through -- are answered first, here rather
765/// than where they were written, because all three need the extent and the extent is one pass old.
766fn scroll(grove: &mut Grove, elements: &mut Elements, ends: &[Option<Stretched>]) {
767    let _pass = trace_span!("scroll", coasting = grove.coasting.len()).entered();
768    view::asked(grove, elements);
769    let mut accumulated: Vec<Position> = vec![Position::default(); elements.len()];
770    // What a *pinned* child of each element receives, which is the accumulation with its nearest
771    // scrolling ancestor left out of it.
772    let mut unpinned: Vec<Position> = vec![Position::default(); elements.len()];
773    for at in 0..elements.len() {
774        let leaf = elements.order[at];
775        let placed = elements.section[at];
776        let trunk = elements.trunk[at];
777        let inherited = trunk.map(|trunk| accumulated[trunk]).unwrap_or_default();
778        let outside = trunk.map(|trunk| unpinned[trunk]).unwrap_or_default();
779        // A pinned element does not receive its nearest scrolling ancestor's offset, and receives
780        // every offset outside that one: pinning is relative to the region the element sits in and
781        // says nothing about what contains that region.
782        let applied = match grove.tree.pinned(leaf) {
783            true => outside,
784            false => inherited,
785        };
786        let drawn = Section::new(
787            Position::new(placed.left() - applied.x, placed.top() - applied.y),
788            placed.area,
789        );
790        elements.moved[at] |= grove.tree.settle(leaf, placed, drawn);
791        // A stroke's ends travel with its box, by the same offset, because they are the same
792        // geometry said two ways. The ends this frame settled are written where the layout put
793        // them; a stroke nothing wrote to keeps what it settled at last frame, and moves under the
794        // offset exactly as its box does -- the same two writes `settle` makes for a box.
795        let spanned = match ends[at] {
796            Some(spanned) => {
797                grove.tree.set_spanned(leaf, spanned);
798                Some(spanned)
799            }
800            None => grove.tree.spanned(leaf),
801        };
802        if let Some(spanned) = spanned {
803            grove.tree.set_stretched(leaf, spanned.less(applied));
804        }
805        let (carried, escaped) = match grove.tree.scrolls(leaf) {
806            Some(scroll) => {
807                let clamped = clamp(grove, leaf, scroll, placed);
808                (
809                    Position::new(applied.x + clamped.x, applied.y + clamped.y),
810                    // A pinned child of this element is pinned to *this* region, so its offset is
811                    // the accumulation as it stood before this region's own.
812                    applied,
813                )
814            }
815            // Nothing here to be pinned against, so a pinned child of this element is pinned to
816            // whatever region contains it, exactly as a pinned sibling of this element would be.
817            None => (applied, outside),
818        };
819        accumulated[at] = carried;
820        unpinned[at] = escaped;
821    }
822}

824/// A region's offset, held to what it can actually reach.
825///
826/// An axis that was not declared does not scroll, so nothing can have moved along it -- and a
827/// region whose extent shrank under it is brought back into range here rather than left somewhere
828/// it can no longer get to.
829fn clamp(grove: &mut Grove, leaf: Leaf, scroll: Scroll, placed: Section) -> Position {
830    let offset = grove.tree.offset(leaf);
831    let extent = grove.tree.extent(leaf);
832    let mut clamped = Position::default();
833    for axis in Axis::BOTH {
834        if scroll.covers(axis) {
835            clamped = clamped.set(
836                axis,
837                offset
838                    .along(axis)
839                    .clamp(0.0, range(extent, placed.area, axis)),
840            );
841        }
842    }
843    if clamped != offset {
844        grove.tree.set_offset(leaf, clamped);
845    }
846    clamped
847}

849/// R5. What a scrolling ancestor leaves visible of each element.
850///
851/// A rect, and nothing else. A region does not clip itself, only what is grown inside it, and an
852/// element with no scrolling ancestor is clipped by nothing at all. Whether an element is *culled*
853/// is extraction's decision from this rect, and is never recorded on the element -- so there is no
854/// state saying "currently clipped away" for anything else, extent first among them, to read.
855fn clip(grove: &mut Grove, elements: &mut Elements) {
856    let _pass = trace_span!("clip").entered();
857    let unbounded = Clipped::unbounded().0;
858    let mut passed: Vec<Section> = vec![unbounded; elements.len()];
859    // What a *floating* child of each element is clipped to, which is the intersection with its
860    // nearest scrolling ancestor's own rect left out of it. The same second accumulation R4 carries
861    // for a pinned child, and for the same reason: both say "not part of this region", and both
862    // have to say it about the region the element is actually in rather than about all of them.
863    let mut escaped: Vec<Section> = vec![unbounded; elements.len()];
864    for at in 0..elements.len() {
865        let leaf = elements.order[at];
866        let trunk = elements.trunk[at];
867        let inherited = trunk.map(|trunk| passed[trunk]).unwrap_or(unbounded);
868        let outside = trunk.map(|trunk| escaped[trunk]).unwrap_or(unbounded);
869        // A floating element is positioned outside the region on purpose, so cutting it off at the
870        // region's edge would undo the placement that put it there. How far out it reaches is the
871        // element's own statement, because no one answer is right everywhere.
872        let applied = match grove.tree.floats(leaf) {
873            // Held by whatever holds the region it left.
874            Some(Escape::Region) => outside,
875            // Held by nothing, which extraction reads as the surface: a clip is never wider than
876            // what is being drawn on.
877            Some(Escape::Surface) => unbounded,
878            // Held by the element named, which is what that element passes down to what it holds.
879            Some(Escape::Within(named)) => match within(elements, &passed, at, named) {
880                Some(clip) => clip,
881                // Named something that is not above it, so it holds nothing. Falling back to the
882                // near answer rather than the far one: an element escapes no further than it was
883                // told to, and a mis-named ancestor is not permission to leave everything.
884                None => outside,
885            },
886            None => inherited,
887        };
888        elements.moved[at] |= grove.tree.set_clip(leaf, applied);
889        let scrolls = grove.tree.scrolls(leaf).is_some();
890        passed[at] = match scrolls {
891            true => applied.intersect(grove.tree.drawn(leaf)),
892            false => applied,
893        };
894        escaped[at] = match scrolls {
895            true => applied,
896            false => outside,
897        };
898    }
899}

901/// What `named` leaves visible of what it holds, if it is above `leaf` at all.
902///
903/// The walk is up the trunks from `leaf`, so an element that names something beside it rather than
904/// above it gets `None` and is answered as though it had named the region it is in. Naming the
905/// element rather than counting regions is what makes this survive a wrapper being added between
906/// the two, which a count would not.
907fn within(elements: &Elements, passed: &[Section], at: usize, named: Leaf) -> Option<Section> {
908    let named = elements.at(named)?;
909    let mut step = elements.trunk[at];
910    while let Some(above) = step {
911        // An ancestor resolves before what hangs off it, so one found here has already passed its
912        // own clip down and the read is never of a position the pass has yet to reach.
913        if above == named {
914            return Some(passed[above]);
915        }
916        step = elements.trunk[above];
917    }
918    None
919}

921/// R7. The three off-states, resolved over each element's whole ancestry.
922///
923/// One walk, in the same order the axes used, which puts every trunk before what hangs off it.
924/// Nothing has a cascade to write: an element grown under a disabled trunk is disabled on its first
925/// frame because the pass does not care when it arrived, and enabling that trunk leaves anything
926/// disabled in its own right disabled because the product is over the whole ancestry rather than a
927/// single bit that was overwritten on the way down.
928fn inherit(grove: &mut Grove, elements: &mut Elements) {
929    let _pass = trace_span!("inherit").entered();
930    let mut products: Vec<Inherited> = vec![Inherited::default(); elements.len()];
931    for at in 0..elements.len() {
932        let leaf = elements.order[at];
933        let trunk = elements.trunk[at]
934            .map(|trunk| products[trunk])
935            .unwrap_or_default();
936        let product = Inherited::under(
937            trunk,
938            grove.tree.visible(leaf),
939            grove.tree.opacity(leaf),
940            grove.tree.disabled(leaf),
941        );
942        products[at] = product;
943        elements.moved[at] |= grove.tree.set_inherited(leaf, product);
944    }
945}

947/// R8. The box stack the next frame's dispatch reads.
948///
949/// Membership is universal: an element is here because it is there. What is left out is only what
950/// is not there at all -- hidden, fully transparent, or clipped away by a region it sits inside.
951/// `intangible` is not a way out of the stack; it is carried on the region and decides what may be
952/// the top of it.
953fn regions(grove: &mut Grove, elements: &Elements) {
954    let _pass = trace_span!("regions").entered();
955    let mut ranked = Vec::with_capacity(elements.len());
956    for &leaf in &elements.order {
957        let inherited = grove.tree.inherited(leaf);
958        if !inherited.present() {
959            continue;
960        }
961        let section = grove.tree.drawn(leaf);
962        let clip = grove.tree.clip(leaf);
963        if section.intersect(clip).is_empty() {
964            continue;
965        }
966        let gestures = grove.tree.gestures(leaf);
967        ranked.push((
968            grove.tree.rank(leaf),
969            Region {
970                leaf,
971                section,
972                clip,
973                shape: gestures.shape,
974                tangible: !gestures.intangible,
975                receives: gestures.receives,
976                disabled: inherited.disabled,
977            },
978        ));
979    }
980    grove.stack.settle(ranked);
981}

983/// R6. Declared elevation accumulates down the tree, and allocation order settles what it leaves
984/// equal.
985///
986/// One walk in the same dependency order the axes used, which puts every trunk before what hangs
987/// off it. Nothing here reads a box: where an element sits in the stack has nothing to do with
988/// where it sits on the surface.
989fn rank(grove: &mut Grove, elements: &mut Elements) {
990    let _pass = trace_span!("rank").entered();
991    let mut stacks: Vec<i32> = vec![0; elements.len()];
992    for at in 0..elements.len() {
993        let leaf = elements.order[at];
994        let trunk = elements.trunk[at]
995            .map(|trunk| stacks[trunk])
996            .unwrap_or_default();
997        let stack = grove.tree.elevation(leaf).accumulate(trunk);
998        stacks[at] = stack;
999        elements.moved[at] |= grove.tree.set_rank(
1000            leaf,
1001            ResolvedElevation {
1002                stack,
1003                growth: grove.tree.growth(leaf).0,
1004            },
1005        );
1006    }
1007}

1009/// Everything one axis of the element at `at` resolves against.
1010fn context<'a>(elements: &'a Elements, viewport: Section, at: usize, axis: Axis) -> Context<'a> {
1011    Context {
1012        axis,
1013        // Its box on this axis is the answer being computed, and its own grid divides it for its
1014        // children rather than for itself, so neither is readable here. Its box on the *other* axis
1015        // is readable exactly when that axis has already run, which is what [`own`] hands over.
1016        own: own(elements, at, axis),
1017        // A top-level element has no trunk, and fills the viewport instead.
1018        trunk: basis(elements, elements.trunk[at], viewport, axis),
1019        // A placement that reads an anchor it has not been given resolves against a zero box.
1020        anchor: basis(elements, elements.anchor[at], Section::default(), axis),
1021    }
1022}

1024/// What the element at `at` offers its own placement.
1025///
1026/// Its measured extent and its character cell on either axis, and its width on the vertical one:
1027/// the horizontal pass has run for the whole tree by then, so the width is settled where the
1028/// height is the answer being computed. That is what [`aspect`](crate::aspect) reads, and it is
1029/// offered flattened the way [`basis`] flattens a resolved box -- with nothing on the axis being
1030/// resolved -- so nothing about the box that is still open can be read back.
1031///
1032/// Nothing on the horizontal pass, where neither axis of it is known.
1033fn own<'a>(elements: &'a Elements, at: usize, axis: Axis) -> Basis<'a> {
1034    Basis {
1035        section: match axis {
1036            Axis::Horizontal => Section::default(),
1037            Axis::Vertical => flattened(elements.section[at]),
1038        },
1039        intrinsic: elements.intrinsic[at],
1040        tracks: Tracks::default(),
1041        cell: elements.cell[at],
1042        // Where its own characters stand is a question about a box that is still being solved.
1043        run: None,
1044    }
1045}

1047/// A box with its vertical half taken away: its left edge and its width, and nothing on the other
1048/// axis. What a box is worth to a reader while no height is known.
1049fn flattened(section: Section) -> Section {
1050    Section::new(
1051        Position::new(section.left(), 0.0),
1052        Area::new(section.width(), 0.0),
1053    )
1054}

1056/// What the element at `at` offers a placement reading it, or `fallback` in place of a box when
1057/// there is no such element or it has not resolved yet.
1058///
1059/// **A resolved box offers no vertical reading on the horizontal axis.** R2a runs before any height
1060/// is known, so a box it offers is flattened to the horizontal -- which is what one held anyway when
1061/// every element was resolved every frame, and what it has to go on holding now that an element
1062/// nothing wrote to comes into the pass carrying the whole of last frame's box.
1063///
1064/// The fallback is not flattened, because it is not a resolved box: the viewport a top-level element
1065/// fills is as tall on this axis as on the other one.
1066fn basis<'a>(
1067    elements: &'a Elements,
1068    at: Option<usize>,
1069    fallback: Section,
1070    axis: Axis,
1071) -> Basis<'a> {
1072    let Some(at) = at else {
1073        return Basis {
1074            section: fallback,
1075            ..Basis::default()
1076        };
1077    };
1078    Basis {
1079        section: match (elements.resolved[at], axis) {
1080            (true, Axis::Horizontal) => flattened(elements.section[at]),
1081            (true, Axis::Vertical) => elements.section[at],
1082            (false, _) => fallback,
1083        },
1084        intrinsic: elements.intrinsic[at],
1085        tracks: elements.tracks[at],
1086        cell: elements.cell[at],
1087        run: elements.composed[at].as_deref(),
1088    }
1089}

1091/// The frame's one read of the tree: every live element, ordered so that nothing resolves before
1092/// what it depends on, with what it depends on and what it offers read out beside it.
1093///
1094/// An anchor may point anywhere -- a later sibling, a cousin, an element in another subtree -- so
1095/// this is ordered by dependency rather than by tree depth: an element resolves after its parent
1096/// *and* after whatever it anchors to.
1097///
1098/// A chain of anchors cannot close on itself, because one that would is refused where it is written.
1099/// A trunk and an anchor still can, between them: an element anchored to something grown under it
1100/// waits on a box that is waiting on its own. That is not the same contradiction -- both boxes
1101/// resolve, just not both against a settled other -- so the remainder is ordered by allocation order
1102/// and resolves against what its dependency last was. **Every live element is in the order**, which
1103/// is the property the passes downstream rely on: an element left out would have no box, no rank and
1104/// no place in the stack, and nothing would say so.
1105///
1106/// Each element is asked what it depends on exactly once here, and every position after that is
1107/// arithmetic on the answer.
1108///
1109/// Kept between frames and repaired rather than built again. The order is what the elements and the
1110/// edges between them make, and only growing, withering and anchoring change those -- so an ordinary
1111/// frame reads none of it, and rebuilds only the columns of the elements it is going to resolve.
1112fn structure(elements: &mut Elements, grove: &Grove) {
1113    let _pass = trace_span!("structure").entered();
1114    let tree = &grove.tree;
1115    let leaves = tree.leaves();
1116    let count = leaves.len();
1117    // Where each element sits among the leaves, and below -- once the order is known -- where it
1118    // sits in the order. Re-pointed rather than rebuilt, so a frame builds one map and not two.
1119    let mut index: HashMap<Leaf, usize> = HashMap::with_capacity(count);
1120    for (at, &leaf) in leaves.iter().enumerate() {
1121        index.insert(leaf, at);
1122    }
1123    // What each element waits on, and how many of those have yet to resolve. An element the leaves
1124    // do not hold is not live, since the leaves are what the world has grown, and a dependency on
1125    // something not live is no dependency at all.
1126    let mut depends: Vec<[Option<usize>; 2]> = Vec::with_capacity(count);
1127    let mut waiting: Vec<u8> = Vec::with_capacity(count);
1128    // Everything waiting on each element, as one run per element in a single array: an element
1129    // depends on at most two others, so the whole graph fits in one allocation rather than in a
1130    // vector per element.
1131    let mut runs: Vec<u32> = vec![0; count + 1];
1132    for &leaf in &leaves {
1133        let on = [tree.trunk(leaf), tree.anchor(leaf)]
1134            .map(|on| on.and_then(|on| index.get(&on).copied()));
1135        let mut unresolved = 0;
1136        for at in on.into_iter().flatten() {
1137            unresolved += 1;
1138            runs[at + 1] += 1;
1139        }
1140        depends.push(on);
1141        waiting.push(unresolved);
1142    }
1143    for at in 0..count {
1144        runs[at + 1] += runs[at];
1145    }
1146    let mut filling = runs.clone();
1147    let mut dependents: Vec<u32> = vec![0; runs[count] as usize];
1148    for (at, on) in depends.iter().enumerate() {
1149        for &upon in on.iter().flatten() {
1150            dependents[filling[upon] as usize] = at as u32;
1151            filling[upon] += 1;
1152        }
1153    }
1154    // Kahn's, with the order under construction serving as its own queue.
1155    let mut order: Vec<usize> = (0..count).filter(|at| waiting[*at] == 0).collect();
1156    let mut next = 0;
1157    while next < order.len() {
1158        let at = order[next];
1159        next += 1;
1160        for &dependent in &dependents[runs[at] as usize..runs[at + 1] as usize] {
1161            let dependent = dependent as usize;
1162            waiting[dependent] -= 1;
1163            if waiting[dependent] == 0 {
1164                order.push(dependent);
1165            }
1166        }
1167    }
1168    if order.len() != count {
1169        order.extend((0..count).filter(|at| waiting[*at] != 0));
1170    }
1171    // Where each element ended up, which is what every position held below is in.
1172    let mut ranked: Vec<usize> = vec![0; count];
1173    for (position, &at) in order.iter().enumerate() {
1174        ranked[at] = position;
1175    }
1176    for position in index.values_mut() {
1177        *position = ranked[*position];
1178    }
1179    // The positions all moved, so every column is read out of the tree again. What resolution
1180    // settled is on the elements themselves -- `scatter` and R4 put it there -- so this is a read of
1181    // last frame's answers into this frame's order, and not a loss of them.
1182    elements.order.clear();
1183    elements.trunk.clear();
1184    elements.anchor.clear();
1185    elements.section.clear();
1186    elements.intrinsic.clear();
1187    elements.cell.clear();
1188    elements.composed.clear();
1189    elements.chlorophyll.clear();
1190    elements.tracks.clear();
1191    elements.index = index;
1192    for &at in &order {
1193        let leaf = leaves[at];
1194        let [trunk, anchor] = depends[at];
1195        elements.order.push(leaf);
1196        elements.trunk.push(trunk.map(|on| ranked[on]));
1197        elements.anchor.push(anchor.map(|on| ranked[on]));
1198        elements.chlorophyll.push(tree.chlorophyll(leaf));
1199        elements.section.push(tree.placed(leaf));
1200        elements.intrinsic.push(tree.intrinsic(leaf));
1201        elements.cell.push(tree.cell(leaf));
1202        elements.composed.push(tree.composed(leaf).0);
1203        // Divided again here rather than left to `read`, which divides only what is dirty: an
1204        // element nothing wrote to keeps its grid, and its grid has to be at the position the
1205        // element now holds rather than the one it held before the order was built again.
1206        elements.tracks.push(
1207            tree.grid(leaf)
1208                .unwrap_or_default()
1209                .tracks(grove.layout, grove.short),
1210        );
1211    }
1212}

1214/// What this frame has to resolve, and what it may leave alone.
1215///
1216/// An element resolves again if it was written to, or if what it hangs off or is anchored to does.
1217/// That closure is one walk of the order rather than a search, because the order already puts a
1218/// dependency before what depends on it.
1219///
1220/// Where most of the tree was written to, working out what to leave alone costs more than resolving
1221/// it does: a lookup for every element, three columns for the passes to read, and a skip that almost
1222/// never takes. Past a quarter it is cheaper to resolve everything, and the whole of the closure
1223/// falls away with one branch.
1224fn read(elements: &mut Elements, grove: &Grove) {
1225    let _pass = trace_span!("elements").entered();
1226    let written = grove.tree.written();
1227    if written.restructured {
1228        structure(elements, grove);
1229    }
1230    let count = elements.order.len();
1231    let all = written.all || written.declared.len() * 4 >= count;
1232    elements.restated = written.restated;
1233    elements.dirty.clear();
1234    elements.measures.clear();
1235    elements.resolved.clear();
1236    elements.moved.clear();
1237    for at in 0..count {
1238        let leaf = elements.order[at];
1239        // A dependency the order could not put first is one a cycle left in the remainder, and it
1240        // has no answer yet. Resolving such an element is the same fallback the rest of resolution
1241        // gives it: it is answered against what its dependency last was, so it is answered again.
1242        let decided = |on: Option<usize>| {
1243            on.is_some_and(|on| elements.dirty.get(on).copied().unwrap_or(true))
1244        };
1245        let dirty = all
1246            || written.declared.contains(&leaf)
1247            || decided(elements.trunk[at])
1248            || decided(elements.anchor[at]);
1249        elements.dirty.push(dirty);
1250        elements.moved.push(dirty);
1251        elements
1252            .measures
1253            .push(dirty || written.measures.contains(&leaf));
1254        // A clean element offers the box it settled at, and offers it from the start, because
1255        // nothing this frame is going to compute it again. One being resolved again offers nothing
1256        // until an axis reaches it, which is what it did when every element was resolved.
1257        elements.resolved.push(!dirty);
1258        // The grid is divided at the breakpoint in force, so it is read again wherever the element
1259        // is -- a breakpoint that moved is every element written to, and nothing else can change a
1260        // division without writing the grid it divides. A frame that built the order again has
1261        // already divided every grid into it.
1262        if dirty && !written.restructured {
1263            elements.tracks[at] = grove
1264                .tree
1265                .grid(leaf)
1266                .unwrap_or_default()
1267                .tracks(grove.layout, grove.short);
1268        }
1269    }
1270}
