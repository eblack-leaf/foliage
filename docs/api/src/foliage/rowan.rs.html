1//! Rowan -- resolution.
2//!
3//! # Rowan resolves. Elm decides what changed.
4//!
5//! Every pass runs in the same order over the same elements every frame, and each writes exactly one
6//! thing. What a pass may leave alone is an element **nothing it reads was written to**, whose
7//! answer is the one it already holds -- sitting in the column the pass would have written it to.
8//!
9//! That is not invalidation and nothing is ever marked stale. The tree records a write where the
10//! write happens ([`Tree::declared`](crate::tree::Tree::declared), which every declaration passes
11//! through), and [`read`] closes that over the dependencies before any pass runs. So an element
12//! resolves again if it was written to, if what it hangs off or is anchored to resolves again, or if
13//! a measure moved under it -- and if none of those happened, resolving it again would produce what
14//! it already has. A value here can be old. It cannot be wrong.
15//!
16//! A write that moves nothing is recorded apart from one that can
17//! ([`Tree::restyled`](crate::tree::Tree::restyled)): a fill, a rounding, a tint or a shape is read
18//! by extraction alone, and whether an element is shown, how opaque, whether disabled and how far
19//! forward are read by the passes below that run over every element anyway. Such an element is read
20//! again and drawn again, and nothing is placed again on its account.
21//!
22//! The accumulations, R3 through R7, carry a running product down the trunks (or up them, for R3)
23//! rather than an answer per element, so what each element passes on is held too, beside what it
24//! resolved to. An element is visited where something it reads moved: it was written to, restyled or
25//! grown, or what it hangs off passes it something new -- and what it passes on is handed to what is
26//! under it only where that changed. They record what they actually changed as they go, which is
27//! what extraction then states -- and R8, the box stack, is built again only on a frame where one of
28//! them changed something it is built from.
29//!
30//! No pass walks the order to find what it has to do. What each visits is marked, a bit per
31//! position ([`Positions`]), and the walk goes from one mark to the next: a frame that wrote nothing
32//! walks a few thousand empty words, where it once walked every element, and an element left alone
33//! -- hidden, or only sitting there -- costs nothing on any frame that does not reach it.
34//!
35//! The read itself is kept between frames and repaired where the tree was written -- growing,
36//! withering and anchoring are the only things that change the order, so an ordinary frame reads
37//! none of it.
38//!
39//! Nothing is re-uploaded on account of any of it, because extraction compares against a cached copy
40//! and sends only genuine differences.
41//!
42//! The passes each write exactly one thing, and nothing writes what another owns:
43//!
44//! | | Pass | Direction | Produces |
45//! |---|---|---|---|
46//! | R1 | measure | — | the character cell, and the run each element is drawn from |
47//! | R1m | across | **bottom-up** | the max-content width half of the intrinsic size |
48//! | R2a | horizontal | dependency order | the horizontal axis |
49//! | R2m | wrap | **bottom-up** | the measured-height half of the intrinsic size |
50//! | R2b | vertical | dependency order | the vertical axis, and with it the placed box |
51//! | R3 | extent | **bottom-up** | [`Extent`](crate::view::Extent): how far a region's content reaches |
52//! | R4 | scroll | top-down | the drawn box: the placed box less every scrolling ancestor's offset, and moved by every shift over it |
53//! | R5 | clip | top-down | the clip: what a scrolling ancestor leaves visible |
54//! | R6 | rank | dependency order | `ResolvedElevation`: elevation accumulated, then tie-broken |
55//! | R7 | inherit | top-down | [`Inherited`]: the visible, opacity and disabled products |
56//! | R8 | regions | rank order | the box stack the next frame's dispatch reads |
57//!
58//! Both halves of R2 call the same pure resolver, once per axis. That is only safe because it is
59//! pure: there is no accumulated state for a second call to corrupt.
60//!
61//! R2a and R2b resolve what was written to, and R1 only what says something new -- a run rewritten,
62//! an element grown, a breakpoint or a face that changed every cell. R1m and R2m measure what was
63//! written to and everything above it, because what an element reaches over is what the elements
64//! under it resolved to -- a measure travels toward the trunk where a box travels away from it. R2m
65//! also measures what is only being resolved again against something written, since a box that
66//! comes out another width may wrap to another height; R1m does not, since nothing it reads is
67//! anyone else's box. A measure that moves under an element nothing wrote to makes that element
68//! resolve again, which is why each measure sits before the axis it is read on and not after it. And
69//! an element measuring again because one of its children moved asks that child alone: how far each
70//! of the others reaches is held from when it last resolved, which is the answer asking would give.
71//!
72//! # Every pass reads the order, not the tree
73//!
74//! The passes ask the same questions of the same elements over and over: what an element hangs off,
75//! what it is anchored to, what is grown under it, and what each of those offers a placement reading
76//! it. Asked of the tree each time, every one of those is a lookup by name -- and the arithmetic a
77//! pass does is small enough that the lookups, not the arithmetic, are what a frame costs.
78//!
79//! So the tree is read once, into [`Elements`]: every live element in dependency order, holding what
80//! it depends on as **positions in that order** rather than as names, and holding what it offers a
81//! placement beside it. From there every pass indexes -- what the accumulations R3 through R7 carry
82//! is held in columns the length of the order, and a trunk's contribution is `[..]` rather than a
83//! lookup on a map keyed by element.
84//!
85//! **What resolution produces is held there and nowhere else.** The placed and drawn boxes, the
86//! measures, the clip, the rank and the inherited products are columns of the order, kept between
87//! frames and read by position -- by extraction, which walks the same order -- or by name through
88//! [`Elements`]'s accessors, by anything that asks about one element. None of it is written back
89//! into the tree, so no pass pays to store a value per element per frame that the next pass would
90//! have to look up again.
91//!
92//! Nothing about what is computed changes, and neither does the ordering that makes it correct.
93//!
94//! Three passes run the other way, and each is a cycle that turns out not to be vicious.
95//!
96//! R1m and R2m are two of them, and the same one on each axis: a box sized to its contents is sized
97//! by boxes resolved against it. Neither is circular, because a child that reads its trunk's extent
98//! on the axis being measured is not counted toward it -- and what is left is measured bottom-up
99//! before that axis is laid out at all. R1m runs before R2a, when no width is known; R2m between the
100//! two halves of R2, the one moment when every width is known and no height is. The order matters
101//! for wrapping, which makes a height depend on a width: **width flows down and height flows up** --
102//! a monospaced run's widest unwrapped line is free from its character count, so a run's width needs
103//! no wrapping measured, and its height is measured at the width R2a gave it.
104//!
105//! R3 is the third: a child resolves against its parent's box, a scrolling parent's extent comes
106//! from where its children landed, and that extent is what its offset is clamped to. Extent affects
107//! only the clamp and never the parent's own box -- so a top-down layout sweep, a bottom-up extent
108//! sweep and a top-down scroll application resolve it in one pass each.
109//!
110//! None of them iterates to convergence. Every pass here runs exactly once.

144/// Every live element in dependency order, with what each one resolves against, what each one offers
145/// a placement that reads it, and everything resolution made of it.
146///
147/// The frame's one read of the tree, and what every pass indexes into. A trunk and an anchor are
148/// asked for on both axes and on four of the passes after them; what an element offers is asked for
149/// twice per element on each axis. Out of the tree each time, every one of those is a lookup by
150/// name -- resolved once to a position in the order, each is an index.
151///
152/// What the order is made of -- what each element hangs off, what is under it, what every pass
153/// visits -- is held by position, since that is what a walk goes by. What resolution made of each
154/// element is held by its slot, the index of its name, which is where the tree holds what it
155/// declared: so an order made again, or repaired for what was grown and what withered, moves none of
156/// it, and an element new to the order has only its own slot to clear. The columns are kept between
157/// frames, which is what lets an element nothing wrote to keep the answer it already has.
158#[derive(Default)]

379impl Elements {
380    /// How many elements are live.
381    pub(crate) fn len(&self) -> usize {
382        self.order.len()
383    }
384
385    /// Where `leaf` sits, or `None` if it is not in the order.
386    fn at(&self, leaf: Leaf) -> Option<usize> {
387        let at = *self.sits.get(leaf.slot())? as usize;
388        (self.order.get(at) == Some(&leaf)).then_some(at)
389    }
390
391    /// Where what the element at `at` hangs off sits, if it hangs off anything.
392    fn trunk(&self, at: usize) -> Option<usize> {
393        position(self.trunk[at])
394    }
395
396    /// Where what the element at `at` is anchored to sits, if it is anchored to anything.
397    fn anchor(&self, at: usize) -> Option<usize> {
398        position(self.anchor[at])
399    }
400
401    /// The slot of the element at `at`: where what resolution made of it is held.
402    fn slot(&self, at: usize) -> usize {
403        self.order[at].slot()
404    }
405
406    /// The slot of `leaf`, or `None` if it is not in the order.
407    fn held(&self, leaf: Leaf) -> Option<usize> {
408        self.at(leaf).map(|_| leaf.slot())
409    }
410
411    /// The positions of everything grown directly under the element at `at`.
412    fn children(&self, at: usize) -> impl Iterator<Item = usize> + '_ {
413        self.children[self.branches[at] as usize..self.branches[at + 1] as usize]
414            .iter()
415            .map(|child| *child as usize)
416    }
417
418    /// Marks in `marks` everything resolved against the element at `at` that comes after it in the
419    /// order -- what is grown under it, and what is anchored to it -- which is everything a walk
420    /// still to reach them will visit. One that comes before it is a cycle's remainder, which every
421    /// pass visits anyway.
422    fn dependents(&self, at: usize, marks: &mut Positions) {
423        let anchored = &self.anchored[self.anchoring[at] as usize..self.anchoring[at + 1] as usize];
424        for dependent in self
425            .children(at)
426            .chain(anchored.iter().map(|on| *on as usize))
427        {
428            if dependent > at {
429                marks.set(dependent);
430            }
431        }
432    }
433
434    /// Nothing marked, as long as the order, with what `seeds` mark and what every pass visits on
435    /// every frame marked: where a pass that walks the order starts from.
436    fn visiting(&self, seeds: &[&Positions], every: &[&[u32]]) -> Positions {
437        let mut marks = Positions::default();
438        marks.reset(self.len());
439        for seed in seeds {
440            marks.add(seed);
441        }
442        for at in every.iter().copied().flatten().chain(&self.forward) {
443            marks.set(*at as usize);
444        }
445        marks
446    }
447
448    /// Where the layout put `leaf`, which is what its children resolve against. A zero box for
449    /// anything resolution has not reached.
450    ///
451    /// Resolution reads a box where it goes, because it holds every element in order. A coast, a
452    /// sought region, a running motion and an app each name one element instead, so they ask this.
453    pub(crate) fn placed(&self, leaf: Leaf) -> Section {
454        self.held(leaf)
455            .map(|slot| self.section[slot])
456            .unwrap_or_default()
457    }
458
459    /// Where `leaf` is on screen, which is what an app reads and what a hit test runs against.
460    pub(crate) fn drawn(&self, leaf: Leaf) -> Section {
461        self.held(leaf)
462            .map(|slot| self.drawn[slot])
463            .unwrap_or_default()

532/// Positions in the order, a bit each: what a pass has to visit, walked from one mark to the next.
533///
534/// What lets a pass cost what it visits rather than what is there. A position left unmarked is a
535/// sixty-fourth of a word looked at, so a walk over an order of three hundred thousand elements with
536/// nothing marked reads under five thousand words -- and a walk forward that marks a position ahead
537/// of it, as a trunk marks what hangs off it, reaches that position in the same walk.
538#[derive(Clone, Default)]
539pub(crate) struct Positions {
540    words: Vec<u64>,
541}
542
543impl Positions {
544    /// Nothing marked, over `len` positions.
545    fn reset(&mut self, len: usize) {
546        self.words.clear();
547        self.words.resize(len.div_ceil(64), 0);
548    }
549
550    /// Every one of `len` positions marked.
551    pub(crate) fn fill(&mut self, len: usize) {
552        self.words.clear();
553        self.words.resize(len / 64, u64::MAX);
554        if !len.is_multiple_of(64) {
555            self.words.push((1 << (len % 64)) - 1);
556        }
557    }
558
559    /// What `other` marks, and nothing else.
560    pub(crate) fn copy_from(&mut self, other: &Positions) {
561        self.words.clear();
562        self.words.extend_from_slice(&other.words);
563    }
564
565    /// Whether `at` is marked. A position past the end is not.
566    pub(crate) fn get(&self, at: usize) -> bool {
567        self.words
568            .get(at / 64)
569            .is_some_and(|word| (word >> (at % 64)) & 1 == 1)
570    }
571
572    fn set(&mut self, at: usize) {
573        self.words[at / 64] |= 1 << (at % 64);
574    }
575
576    fn unset(&mut self, at: usize) {
577        self.words[at / 64] &= !(1 << (at % 64));
578    }
579
580    /// Marks everything `other` marks, as far as both reach.
581    fn add(&mut self, other: &Positions) {
582        for (word, theirs) in self.words.iter_mut().zip(&other.words) {
583            *word |= theirs;
584        }
585    }
586
587    /// How many positions are marked.
588    pub(crate) fn count(&self) -> usize {
589        self.words
590            .iter()
591            .map(|word| word.count_ones() as usize)
592            .sum()
593    }
594
595    /// The first marked position at or after `from`.
596    fn next(&self, from: usize) -> Option<usize> {
597        let mut index = from / 64;
598        let mut word = *self.words.get(index)? & (u64::MAX << (from % 64));
599        loop {
600            if word != 0 {
601                return Some(index * 64 + word.trailing_zeros() as usize);
602            }
603            index += 1;
604            word = *self.words.get(index)?;
605        }
606    }
607
608    /// The last marked position before `end`.
609    fn last_before(&self, end: usize) -> Option<usize> {
610        let last = end.min(self.words.len() * 64).checked_sub(1)?;
611        let mut index = last / 64;
612        let mut word = self.words[index] & (u64::MAX >> (63 - last % 64));
613        loop {
614            if word != 0 {
615                return Some(index * 64 + 63 - word.leading_zeros() as usize);
616            }
617            index = index.checked_sub(1)?;
618            word = self.words[index];
619        }
620    }
621
622    /// Every marked position, first to last.
623    pub(crate) fn iter(&self) -> impl Iterator<Item = usize> + '_ {
624        self.words.iter().enumerate().flat_map(|(index, &word)| {
625            core::iter::successors((word != 0).then_some(word), |word| {
626                let rest = word & (word - 1);
627                (rest != 0).then_some(rest)
628            })
629            .map(move |word| index * 64 + word.trailing_zeros() as usize)
630        })
631    }
632}

634/// Steps 6 and 7. Declared state becomes resolved geometry and resolved products, for everything.
635pub(crate) fn run(grove: &mut Grove) {
636    let step = trace_span!("resolve", elements = Empty, dirty = Empty);
637    let resolving = step.enter();
638    // Taken off the grove so the passes can hold it while they write to the rest, and put back at
639    // the end of resolution: what it holds is what this frame settled, and what the next one starts
640    // from rather than reads again.
641    let mut elements = core::mem::take(&mut grove.elements);
642    read(&mut elements, grove);
643    // Forgotten the moment it is read, so a write made by a pass after this belongs to the frame
644    // that would resolve it.
645    grove.tree.taken();
646    step.record("elements", elements.len());
647    step.record("dirty", elements.dirty.count());
648    measure(grove, &mut elements);
649    // Every element now holds the run it states, so a run nothing holds is one nothing states. Only
650    // on a frame where a run stopped being stated, which is the only way the cache comes to hold
651    // one nothing wants.
652    if elements.restated {
653        grove.shaping.sweep();
654    }
655    axes(grove, &mut elements);
656    extent(grove, &mut elements);
657    scroll(grove, &mut elements);
658    clip(&grove.tree, &mut elements);
659    rank(&grove.tree, &mut elements);
660    // Resolution ends here. What settles after it is its own step, and is timed as one.
661    drop(resolving);
662    let _step = trace_span!("settle").entered();
663    inherit(&grove.tree, &mut elements);
664    regions(grove, &mut elements);
665    grove.elements = elements;
666}

668/// R1. What an element's own font makes of it: its character cell, and its run shaped in it.
669///
670/// Ahead of every other pass, and reading no geometry at all, because neither answer has anything to
671/// do with where the element ended up. A monospaced run's max-content width is its longest line's
672/// character count times its cell, so what a run asks of the down-pass is known before the
673/// down-pass runs -- R1m reads it off the run left here.
674fn measure(grove: &mut Grove, elements: &mut Elements) {
675    let _pass = trace_span!("measure").entered();
676    let Grove {
677        tree,
678        fonts,
679        shaping,
680        layout,
681        short,
682        ..
683    } = grove;
684    // An element left unmarked measures to what it measured to, which is what the column is already
685    // holding: what it reads is its own run and face and nothing else, so one that only moved is
686    // one of these.
687    let lettered = core::mem::take(&mut elements.lettered);
688    for at in lettered.iter() {
689        let leaf = elements.order[at];
690        // No font and no size is no cell, and nothing measured in one. What such an element last
691        // measured to stands.
692        let Some(typeface) = tree.typeface(leaf) else {
693            continue;
694        };
695        let size = typeface.size.at(*layout, *short);
696        let cell = fonts.cell(typeface.font, size);
697        // The run, shaped, is kept beside the cell: it is what a placement reading a character of
698        // this element resolves against, and this is the one pass that shapes.
699        // A masked run is shaped as its dots, so the value itself is never a key in the shaping
700        // cache, and nothing drawn from here can say it.
701        let masked = tree.masked(leaf);
702        let composed = tree.lettering(leaf).map(|value| match masked {
703            true => shaping
704                .shape(fonts, typeface.font, size, &crate::text_input::dots(value))
705                .clone(),
706            false => shaping.shape(fonts, typeface.font, size, value).clone(),
707        });
708        elements.cell[leaf.slot()] = cell;
709        // Both halves of what it measures to are read off this, by R1m and R2m, which write them
710        // before anything reads either.
711        elements.composed[leaf.slot()] = composed;
712    }
713    elements.lettered = lettered;
714}

716/// R1m, R2a, R2m and R2b: the measure across, the horizontal axis, then the measure down it makes
717/// possible, then the vertical axis.
718///
719/// An element with a placement in motion is resolved twice on each axis -- once for each endpoint,
720/// in the *same* context -- and the two answers are blended. That is what the resolver's purity
721/// buys: the endpoints are consistent with each other because they were asked at the same position
722/// in the same dependency order, against the same settled ancestors, and neither is remembered
723/// afterwards.
724fn axes(grove: &mut Grove, elements: &mut Elements) {
725    across(grove, elements);
726    axis(grove, elements, Axis::Horizontal);
727    wrap(grove, elements);
728    axis(grove, elements, Axis::Vertical);
729}

731/// One axis of the whole tree, in dependency order, through the one pure resolver.
732fn axis(grove: &Grove, elements: &mut Elements, axis: Axis) {
733    let _pass = trace_span!("axis", vertical = (axis == Axis::Vertical)).entered();
734    let viewport = Section::new(Position::default(), grove.viewport);
735    // What is to be resolved again, and what is resolved against something that may have moved --
736    // marked as the walk finds it, ahead of where the walk is, since the order puts it there.
737    let mut visit = elements.visiting(&[&elements.dirty], &[]);
738    let mut offered = Offered::default();
739    let mut from = 0;
740    while let Some(at) = visit.next(from) {
741        from = at + 1;
742        // A measure may have moved under an element nothing was written to, before this axis: R1m's
743        // before this one, R2m's before the vertical. The order puts what an element reads before
744        // it, so spreading that here reaches everything resolved against it -- where what it reads
745        // changed: a box that moved, or a measure that moved and that it reads.
746        let follows = |on: Option<usize>, against: Against| {
747            on.is_some_and(|on| {
748                elements.answers.get(on)
749                    || (elements.remeasured.get(on)
750                        && reads_content(grove, elements.order[at], against, axis))
751            })
752        };
753        if follows(elements.trunk(at), Against::Trunk)
754            || follows(elements.anchor(at), Against::Anchor)
755        {
756            elements.dirty.set(at);
757        }
758        // Nothing it or anything it resolves against was written, so it resolves to the box it
759        // already holds. Its column keeps that box, so what reads it here reads the right one.
760        if !elements.dirty.get(at) {
761            continue;
762        }
763        // Laid out across again, it may come out another width -- and wrap to another height, or
764        // reach somewhere else below it -- so it is measured down again in R2m. Almost all of it
765        // already was; what R1m's spreading reached here was not.
766        if axis == Axis::Horizontal {
767            elements.measures.set(at);
768        }
769        let leaf = elements.order[at];
770        let slot = leaf.slot();
771        let placement = grove.tree.placement(leaf);
772        if axis == Axis::Horizontal {
773            elements.upright[slot] = measurable(grove, placement, Axis::Vertical);
774        }
775        let context = context(grove, elements, viewport, at, axis, &mut offered);
776        let (span, stretched) = geometry(grove, leaf, placement, &context, axis);
777        // A stroke's ends are settled one axis at a time, into what it held: an element a measure
778        // reached between the two axes is resolved on the second alone, and keeps the first.
779        if let Some((from, to)) = stretched {
780            elements.spanned[slot]
781                .get_or_insert_with(Stretched::default)
782                .set(axis, from, to);
783        }
784        let section = &mut elements.section[slot];
785        let landed = match axis {
786            Axis::Horizontal => {
787                let landed = (section.position.x, section.area.width) == (span.near, span.extent());
788                section.position.x = span.near;
789                section.area.width = span.extent();
790                landed
791            }
792            Axis::Vertical => {
793                let landed =
794                    (section.position.y, section.area.height) == (span.near, span.extent());
795                section.position.y = span.near;
796                section.area.height = span.extent();
797                landed
798            }
799        };
800        if !landed {
801            elements.answers.set(at);
802        }
803        elements.unresolved.unset(at);
804        offered.resolved(at);
805        // What it offers may be different, so what is resolved against it is looked at -- unless
806        // it was resolving again from the start, when everything resolved against it already is.
807        if !elements.closed.get(at) && (elements.answers.get(at) || elements.remeasured.get(at)) {
808            elements.dependents(at, &mut visit);
809        }
810    }
811}

813/// One axis of `leaf`, whichever of the two ways its placement is stated.
814///
815/// A box resolves to a span directly. A **trace** resolves to two positions, and the span is the
816/// distance between them grown by half the stroke's weight on each side -- which is what gives a
817/// rule, whose ends share a coordinate on one axis, a box on that axis at all. Both ends come back
818/// too, because the span cannot say which of its diagonals they are.
819fn geometry(
820    grove: &Grove,
821    leaf: Leaf,
822    placement: Option<Placement>,
823    context: &Context,
824    axis: Axis,
825) -> (Span, Option<(f32, f32)>) {
826    let (trace, stroke) = match placement {
827        Some(Placement::Traced(trace, stroke)) => (trace, stroke),
828        Some(Placement::Boxed(location)) => {
829            return (span(grove, leaf, location, context, axis), None);
830        }
831        // Every live element is grown with a placement, so this is an element the order holds and
832        // the tree does not -- which nothing that runs between the two can make.
833        None => return (span(grove, leaf, &Location::default(), context, axis), None),
834    };
835    let half = stroke.half();
836    let (from, to) = ends(grove, leaf, trace, context, axis);
837    (
838        Span {
839            near: from.min(to) - half,
840            far: from.max(to) + half,
841        },
842        Some((from, to)),
843    )
844}

846/// One axis of where `leaf`'s two ends currently are: what it declares, blended with the ends a
847/// motion left.
848///
849/// [`span`] for a trace. Each end blends on its own and the box is taken from the blended pair,
850/// rather than the two boxes blending: a stroke part way between a rising and a falling diagonal is
851/// a stroke, and a box that blended separately would not be the rectangle around it.
852fn ends(grove: &Grove, leaf: Leaf, trace: &Trace, context: &Context, axis: Axis) -> (f32, f32) {
853    let (from, to) = located(pinned_ends(trace, grove), context);
854    match grove.aspen.trace(leaf) {
855        Some((departed, at)) => {
856            let (left_from, left_to) = match departed {
857                Departed::Declared(trace) => located(pinned_ends(trace, grove), context),
858                Departed::Snapshot(stretched) => stretched.along(axis),
859            };
860            (blend(left_from, from, at), blend(left_to, to, at))
861        }
862        None => (from, to),
863    }
864}

867fn located(ends: &Ends, context: &Context) -> (f32, f32) {
868    (locate(&ends.from, context), locate(&ends.to, context))
869}

917/// R1m. How wide each element's contents would like to be, before any width is laid out.
918///
919/// R2m across, and the reason [`content()`](crate::content) asks the same question on both axes --
920/// *how large is what is inside me*. Bottom-up, so everything inside an element is measured before
921/// the element asks, and an element takes the wider of two things:
922///
923/// - its run's max-content, its widest line unwrapped, which R1 left it holding
924/// - how far right anything grown under it reaches, from its own left edge
925///
926/// The second is resolved with no horizontal box known at all, which is exactly what there is at
927/// this point in the frame. So a child that reads one -- `100.pct()`, a column of a grid, an edge of
928/// its trunk or of an anchor, a place in a run -- contributes nothing to the measure and is given its
929/// real width by R2a like anything else; a child that describes its own extent, in pixels, in
930/// letters or by its own content, is what is measured. A width that moved marks the element written,
931/// and R2a spreads it to everything resolved against it.
932///
933/// What has to measure again is what was written to itself, and everything above it -- not what
934/// is only being resolved again against something written, which R2m measures as well. Nothing
935/// this measure reads is anyone else's box, so a subtree under a box that moved measures across to
936/// what it did; see [`touched`](Elements::touched).
937fn across(grove: &Grove, elements: &mut Elements) {
938    let _pass = trace_span!("across").entered();
939    if !elements.across {
940        return;
941    }
942    // Up the order, so everything under an element is measured before it is -- and each one marks
943    // what it hangs off, which the walk reaches after it.
944    let mut from = elements.len();
945    while let Some(at) = elements.measures_across.last_before(from) {
946        from = at;
947        if let Some(trunk) = elements.trunk(at) {
948            elements.measures_across.set(trunk);
949        }
950        let slot = elements.slot(at);
951        let run = elements.composed[slot]
952            .as_ref()
953            .map_or(0.0, |run| run.max_content());
954        let width = run.max(spread(grove, elements, at));
955        if width != elements.intrinsic[slot].width {
956            elements.intrinsic[slot].width = width;
957            // Ahead of R2a, which resolves it and what reads it against the new measure -- and
958            // below every trunk it reaches, each of which asks it again on the way up.
959            elements.dirty.set(at);
960            elements.remeasured.set(at);
961            elements.touched.set(at);
962        }
963    }
964}

966/// How far right the elements grown under the element at `at` reach from its left edge.
967///
968/// [`reach`] across: only a child that describes its own extent is counted, and a child is asked
969/// only where it was [`touched`](Elements::touched) -- every other one reaches exactly as far as it
970/// did when it last was, which is what [`spread`](Elements::spread) holds for it.
971fn spread(grove: &Grove, elements: &mut Elements, at: usize) -> f32 {
972    let mut spread: f32 = 0.0;
973    let divided = tracks(grove, elements, at);
974    for index in elements.branches[at] as usize..elements.branches[at + 1] as usize {
975        let child_at = elements.children[index] as usize;
976        let child = elements.order[child_at];
977        if elements.touched.get(child_at) {
978            let placement = grove.tree.placement(child);
979            let far = measurable(grove, placement, Axis::Horizontal).then(|| {
980                let context = unlaid(grove, elements, (at, divided), child_at);
981                geometry(grove, child, placement, &context, Axis::Horizontal)
982                    .0
983                    .far
984            });
985            elements.spread[child.slot()] = far;
986        }
987        if let Some(far) = elements.spread[child.slot()] {
988            spread = spread.max(far);
989        }
990    }
991    spread
992}

994/// What one child resolves its horizontal axis against while its trunk is being measured across.
995///
996/// The same [`Context`] R2a will build, with every box taken as not laid out yet -- which none is,
997/// and which a counted child never reads. What is real is what R1 and the measure below the trunk
998/// already answered: every cell, and the child's own intrinsic width, so a width in letters or of
999/// the child's own content still answers. The trunk's left edge is the origin, so what comes back
1000/// is how far right of it the child reaches.
1001///
1002/// The trunk comes with its grid already divided, since every child of it asks.
1003fn unlaid<'a>(
1004    grove: &Grove,
1005    elements: &'a Elements,
1006    (trunk, divided): (usize, Tracks),
1007    child: usize,
1008) -> Context<'a> {
1009    let offered = |at: usize, tracks: Tracks| {
1010        let slot = elements.slot(at);
1011        Basis {
1012            section: Section::default(),
1013            intrinsic: elements.intrinsic[slot],
1014            tracks,
1015            cell: elements.cell[slot],
1016            run: None,
1017        }
1018    };
1019    Context {
1020        axis: Axis::Horizontal,
1021        own: own(elements, child, Axis::Horizontal),
1022        trunk: offered(trunk, divided),
1023        anchor: match elements.anchor(child) {
1024            Some(anchor) => offered(anchor, tracks(grove, elements, anchor)),
1025            None => Basis::default(),
1026        },
1027    }

1030/// R2m. How tall each element's contents turned out at the width R2a gave it.
1031///
1032/// Bottom-up, so everything inside an element is measured before the element asks. Two things are
1033/// measured, and an element takes the greater of them, because both answer the one question
1034/// [`content()`](crate::content) asks -- *how large is what is inside me*:
1035///
1036/// - a run of glyphs wraps at its own resolved width, and its lines times its cell is its height
1037/// - anything with elements grown under it takes the furthest any of them reaches down
1038///
1039/// The second is resolved in the element's own space, with its vertical extent taken as **not yet
1040/// known**, which is exactly what it is at this point in the frame. So a child that reads that
1041/// extent -- `100.pct()`, a row of a grid, an anchor's edge -- contributes nothing to the measure
1042/// and is given its real height by R2b like anything else. That is the correct reading rather than a
1043/// limitation: a child sized to its trunk cannot also be what sizes it, and nothing is asked to
1044/// converge. [`across`] is the same reading on the other axis, taken before any width is known.
1045///
1046/// Both halves are taken in the one walk up the order. What reaches below an element reads the
1047/// measures of everything under it, so it has to come after them -- and a run wraps at its own width
1048/// and against its own font, reading nothing but its element, so it can be measured wherever the
1049/// walk finds it. The run is the one R1 left the element holding: an element measuring again
1050/// because something under it moved says what it said last frame, and one that says something new
1051/// was shaped for it by R1 this frame.
1052fn wrap(grove: &mut Grove, elements: &mut Elements) {
1053    let _pass = trace_span!("wrap").entered();
1054    // What has to measure again: what was written to, and everything above it, because what an
1055    // element reaches over is what the elements under it resolved to. Up the order rather than down
1056    // it -- a measure travels toward the trunk and stops there, where a box travels away from it --
1057    // so each element marks what it hangs off, which the walk reaches after it.
1058    let mut from = elements.len();
1059    while let Some(at) = elements.measures.last_before(from) {
1060        from = at;
1061        if let Some(trunk) = elements.trunk(at) {
1062            elements.measures.set(trunk);
1063        }
1064        let slot = elements.slot(at);
1065        let shaped = elements.composed[slot]
1066            .as_ref()
1067            .map_or(0.0, |run| run.measure(elements.section[slot].width()));
1068        let height = shaped.max(reach(grove, elements, at));
1069        if height != elements.intrinsic[slot].height {
1070            elements.intrinsic[slot].height = height;
1071            // The measure moved under an element nothing was written to, and a placement reading
1072            // that measure has to be resolved against the new one. R2b runs after this and spreads
1073            // it, which is why it is safe to find out here.
1074            elements.dirty.set(at);
1075            elements.remeasured.set(at);
1076        }
1077    }
1078}

1080/// How far the elements grown under the element at `at` reach below its top edge.
1081///
1082/// Only the children that describe their own extent are counted. One that reads a vertical box --
1083/// a percentage of this element, a row of its grid, an anchor's edge -- is asking how tall
1084/// something else is, so it cannot be what decides how tall this is. See
1085/// [`Config::measurable`](crate::placement::role::Config::measurable).
1086///
1087/// A child is asked only where it is dirty, and its answer kept. Every other child reaches exactly
1088/// as far as it did when it last was, which is what [`reached`](Elements::reached) holds for it.
1089/// Whether a child counts at all is what R2a left in [`upright`](Elements::upright), so one that
1090/// does not is passed over without its placement being asked for.
1091fn reach(grove: &Grove, elements: &mut Elements, at: usize) -> f32 {
1092    let mut reach: f32 = 0.0;
1093    let divided = tracks(grove, elements, at);
1094    for index in elements.branches[at] as usize..elements.branches[at + 1] as usize {
1095        let child_at = elements.children[index] as usize;
1096        let child = elements.order[child_at];
1097        if elements.dirty.get(child_at) {
1098            let far = elements.upright[child.slot()].then(|| {
1099                let context = raised(grove, elements, (at, divided), child_at);
1100                let placement = grove.tree.placement(child);
1101                geometry(grove, child, placement, &context, Axis::Vertical)
1102                    .0
1103                    .far
1104            });
1105            elements.reached[child.slot()] = far;
1106        }
1107        if let Some(far) = elements.reached[child.slot()] {
1108            reach = reach.max(far);
1109        }
1110    }
1111    reach
1112}

1186/// R3. How far each region's content reaches, from where its children landed.
1187///
1188/// Bottom-up, so a subtree is measured before whatever contains it. Two things are deliberately not
1189/// consulted: what is currently drawn, because content scrolled out of sight is exactly what an
1190/// extent describes and has to remain reachable; and the offset, because measuring against it would
1191/// make the extent depend on the clamp that depends on the extent.
1192///
1193/// A child that scrolls in its own right contributes its box and not its content -- what overflows
1194/// inside it is its own to reach, and is already reachable there.
1195///
1196/// A **visible child that is simply far away is content**, and is counted. That is the answer
1197/// `views.md` gives to the parking footgun, and it is deliberately not a guess about intent: if it
1198/// is visible and out there it is reachable, which is coherent where the old behaviour was a
1199/// surprise. What removes a child from the extent is the app saying so -- [`visible(false)`] takes
1200/// it and its subtree out, and [`pinned`] takes out something that is inside the region without
1201/// travelling with it.
1202///
1203/// What an element reaches to is held, so a walk up the order visits what may reach somewhere else
1204/// -- what was resolved again, shown or hidden, or lost something under it -- and what hangs over
1205/// one whose reach moved.
1206///
1207/// [`visible(false)`]: crate::Place::visible
1208/// [`pinned`]: crate::Place::pinned
1209fn extent(grove: &mut Grove, elements: &mut Elements) {
1210    let _pass = trace_span!("extent").entered();
1211    let mut visit = elements.visiting(
1212        &[
1213            &elements.dirty,
1214            &elements.restyled,
1215            &elements.measures,
1216            &elements.fresh,
1217        ],
1218        &[],
1219    );
1220    // A child that came to be pinned or to float, or stopped, came to count toward what it hangs
1221    // off or stopped, whether or not it reaches anywhere else.
1222    if elements.rescoped {
1223        for at in elements.restyled.iter() {
1224            if let Some(trunk) = elements.trunk(at) {
1225                visit.set(trunk);
1226            }
1227        }
1228    }
1229    let mut from = elements.len();
1230    while let Some(at) = visit.last_before(from) {
1231        from = at;
1232        let leaf = elements.order[at];
1233        let slot = leaf.slot();
1234        let standing = grove.tree.standing(leaf);
1235        let (visible, scrolls) = (standing.visible(), standing.scrolls());
1236        // A hidden element is not content, and neither is anything under it: that is what makes
1237        // hiding the whole answer for parking something out of the way, rather than half of one.
1238        // It reaches nowhere, which is what keeps a hidden subtree out of what contains it.
1239        let extends = visible.then(|| {
1240            let section = elements.section[slot];
1241            let mut far = Position::new(section.right(), section.bottom());
1242            for child in elements.children(at) {
1243                // Pinned or floating, and so not content. See [`aside`](Elements::aside).
1244                if elements.aside.get(child) {
1245                    continue;
1246                }
1247                let Some(child) = elements.extends[elements.slot(child)] else {
1248                    continue;
1249                };
1250                far = Position::new(far.x.max(child.x), far.y.max(child.y));
1251            }
1252            match scrolls {
1253                Some(scroll) => {
1254                    grove.tree.set_extent(leaf, reached(scroll, section, far));
1255                    Position::new(section.right(), section.bottom())
1256                }
1257                None => far,
1258            }
1259        });
1260        if extends != elements.extends[slot] {
1261            elements.extends[slot] = extends;
1262            if let Some(trunk) = elements.trunk(at) {
1263                visit.set(trunk);
1264            }
1265        }
1266    }
1267}

1269/// How far a region's content reaches, on each axis.
1270///
1271/// Three rules, and each of them is what stops a scrollbar nobody ordered:
1272///
1273/// - **only along a declared axis.** An axis the region does not scroll reads its own box and
1274///   nothing else, so a child extending sideways out of a column that scrolls down is simply out of
1275///   frame. Most accidental extent came from the axis nobody was scrolling.
1276/// - **measured outward from the content origin, clamped at the near side.** A child at a negative
1277///   offset creates no range to scroll *back* into: content above the origin is a layout mistake,
1278///   and the previous behaviour turned it into a feature.
1279/// - **never smaller than the region's own box**, so an empty region has a range of zero rather
1280///   than a negative one.
1281///
1282fn reached(scroll: Scroll, section: Section, far: Position) -> Area {
1283    let along = |axis: Axis, reach: f32, near: f32| {
1284        let own = section.area.along(axis);
1285        if !scroll.covers(axis) {
1286            return own;
1287        }
1288        (reach - near).max(own)
1289    };
1290    Area::new(
1291        along(Axis::Horizontal, far.x, section.left()),
1292        along(Axis::Vertical, far.y, section.top()),
1293    )
1294}

1296/// R4. Where each element is drawn: where the layout put it, less what its scrolling ancestors have
1297/// moved, and moved by whatever shift it and they were given.
1298///
1299/// A region's own box does not move under its own offset -- what moves is everything grown inside
1300/// it. The offset is clamped here, against the extent R3 just measured, so a region whose content
1301/// shrank under it comes back into range on the next frame rather than staying somewhere it can no
1302/// longer reach.
1303///
1304/// The three ways a region is *asked* to move -- a coast still running from a release, a
1305/// [`scroll`](crate::Grow::scroll) written this frame, and a
1306/// [`Motion::Scroll`](crate::Motion::Scroll) part way through -- are answered first, here rather
1307/// than where they were written, because all three need the extent and the extent is one pass old.
1308///
1309/// What each element passes on is held, so the walk visits what was resolved again or restyled,
1310/// every region -- since what one scrolled to is never written to it -- and what hangs off an element
1311/// that passes on something new.
1312fn scroll(grove: &mut Grove, elements: &mut Elements) {
1313    let _pass = trace_span!("scroll", coasting = grove.coasting.len()).entered();
1314    view::asked(grove, elements);
1315    let mut visit = elements.visiting(
1316        &[&elements.dirty, &elements.restyled, &elements.fresh],
1317        &[&elements.scrolling],
1318    );
1319    let mut from = 0;
1320    while let Some(at) = visit.next(from) {
1321        from = at + 1;
1322        let leaf = elements.order[at];
1323        let slot = leaf.slot();
1324        let placed = elements.section[slot];
1325        let trunk = elements.trunk(at).map(|trunk| elements.slot(trunk));
1326        let standing = grove.tree.standing(leaf);
1327        let (shift, pinned, scrolls) = (standing.shift(), standing.pinned(), standing.scrolls());
1328        // A shift moves the element and everything grown under it, pinned or not, so it comes off
1329        // both accumulations -- the other way to an offset, which moves content toward the near
1330        // edge.
1331        let shifted = |by: Position| Position::new(by.x - shift.x, by.y - shift.y);
1332        let inherited = shifted(
1333            trunk
1334                .map(|trunk| elements.accumulated[trunk])
1335                .unwrap_or_default(),
1336        );
1337        // What a *pinned* element receives, which is the accumulation with its nearest scrolling
1338        // ancestor left out of it.
1339        let outside = shifted(
1340            trunk
1341                .map(|trunk| elements.unpinned[trunk])
1342                .unwrap_or_default(),
1343        );
1344        // A pinned element does not receive its nearest scrolling ancestor's offset, and receives
1345        // every offset outside that one: pinning is relative to the region the element sits in and
1346        // says nothing about what contains that region.
1347        let applied = match pinned {
1348            true => outside,
1349            false => inherited,
1350        };
1351        let drawn = Section::new(
1352            Position::new(placed.left() - applied.x, placed.top() - applied.y),
1353            placed.area,
1354        );
1355        if drawn != elements.drawn[slot] {
1356            elements.drawn[slot] = drawn;
1357            elements.moved.set(at);
1358            elements.restack = true;
1359        }
1360        // A stroke's ends travel with its box, by the same offset, because they are the same
1361        // geometry said two ways. A stroke nothing wrote to keeps the ends it settled at, and moves
1362        // under the offset exactly as its box does.
1363        if let Some(spanned) = elements.spanned[slot] {
1364            let stretched = Some(spanned.less(applied));
1365            if stretched != elements.stretched[slot] {
1366                elements.stretched[slot] = stretched;
1367                elements.moved.set(at);
1368            }
1369        }
1370        let (carried, escaped) = match scrolls {
1371            Some(scroll) => {
1372                let clamped = clamp(grove, leaf, scroll, placed);
1373                (
1374                    Position::new(applied.x + clamped.x, applied.y + clamped.y),
1375                    // A pinned child of this element is pinned to *this* region, so its offset is
1376                    // the accumulation as it stood before this region's own.
1377                    applied,
1378                )
1379            }
1380            // Nothing here to be pinned against, so a pinned child of this element is pinned to
1381            // whatever region contains it, exactly as a pinned sibling of this element would be.
1382            None => (applied, outside),
1383        };
1384        if (carried, escaped) != (elements.accumulated[slot], elements.unpinned[slot]) {
1385            elements.accumulated[slot] = carried;
1386            elements.unpinned[slot] = escaped;
1387            for child in elements.children(at) {
1388                visit.set(child);
1389            }
1390        }
1391    }
1392}

1394/// A region's offset, held to what it can actually reach.
1395///
1396/// An axis that was not declared does not scroll, so nothing can have moved along it -- and a
1397/// region whose extent shrank under it is brought back into range here rather than left somewhere
1398/// it can no longer get to.
1399fn clamp(grove: &mut Grove, leaf: Leaf, scroll: Scroll, placed: Section) -> Position {
1400    let offset = grove.tree.offset(leaf);
1401    let extent = grove.tree.extent(leaf);
1402    let mut clamped = Position::default();
1403    for axis in Axis::BOTH {
1404        if scroll.covers(axis) {
1405            clamped = clamped.set(
1406                axis,
1407                offset
1408                    .along(axis)
1409                    .clamp(0.0, range(extent, placed.area, axis)),
1410            );
1411        }
1412    }
1413    if clamped != offset {
1414        grove.tree.set_offset(leaf, clamped);
1415    }
1416    clamped
1417}

1419/// R5. What a scrolling ancestor leaves visible of each element.
1420///
1421/// A rect, and nothing else. A region does not clip itself, only what is grown inside it, and an
1422/// element with no scrolling ancestor is clipped by nothing at all. Whether an element is *culled*
1423/// is extraction's decision from this rect, and is never recorded on the element -- so there is no
1424/// state saying "currently clipped away" for anything else, extent first among them, to read.
1425///
1426/// What each element passes on is held. A clip reads no box but a region's own, and nothing it reads
1427/// is restyled, so the walk visits what is new, every region and every element floating out to one
1428/// it names, and what hangs off an element that passes on something new.
1429fn clip(tree: &Tree, elements: &mut Elements) {
1430    let _pass = trace_span!("clip").entered();
1431    let unbounded = Clipped::unbounded().0;
1432    let restyled = match elements.rescoped {
1433        true => &elements.restyled,
1434        false => &Positions::default(),
1435    };
1436    let mut visit = elements.visiting(
1437        &[&elements.fresh, restyled],
1438        &[&elements.scrolling, &elements.within],
1439    );
1440    let mut from = 0;
1441    while let Some(at) = visit.next(from) {
1442        from = at + 1;
1443        let leaf = elements.order[at];
1444        let slot = leaf.slot();
1445        let trunk = elements.trunk(at).map(|trunk| elements.slot(trunk));
1446        let standing = tree.standing(leaf);
1447        let inherited = trunk
1448            .map(|trunk| elements.passed[trunk])
1449            .unwrap_or(unbounded);
1450        // What a *floating* element is clipped to, which is the intersection with its nearest
1451        // scrolling ancestor's own rect left out of it. The same second accumulation R4 carries
1452        // for a pinned child, and for the same reason: both say "not part of this region", and both
1453        // have to say it about the region the element is actually in rather than about all of them.
1454        let outside = trunk
1455            .map(|trunk| elements.escaped[trunk])
1456            .unwrap_or(unbounded);
1457        // A floating element is positioned outside the region on purpose, so cutting it off at the
1458        // region's edge would undo the placement that put it there. How far out it reaches is the
1459        // element's own statement, because no one answer is right everywhere.
1460        let applied = match standing.floats() {
1461            // Held by whatever holds the region it left.
1462            Some(Escape::Region) => outside,
1463            // Held by nothing, which extraction reads as the surface: a clip is never wider than
1464            // what is being drawn on.
1465            Some(Escape::Surface) => unbounded,
1466            // Held by the element named, which is what that element passes down to what it holds.
1467            Some(Escape::Within(named)) => match within(elements, at, named) {
1468                Some(clip) => clip,
1469                // Named something that is not above it, so it holds nothing. Falling back to the
1470                // near answer rather than the far one: an element escapes no further than it was
1471                // told to, and a mis-named ancestor is not permission to leave everything.
1472                None => outside,
1473            },
1474            None => inherited,
1475        };
1476        if applied != elements.clip[slot] {
1477            elements.clip[slot] = applied;
1478            elements.moved.set(at);
1479            elements.restack = true;
1480        }
1481        let scrolls = standing.scrolls().is_some();
1482        let passed = match scrolls {
1483            true => applied.intersect(elements.drawn[slot]),
1484            false => applied,
1485        };
1486        let escaped = match scrolls {
1487            true => applied,
1488            false => outside,
1489        };
1490        if (passed, escaped) != (elements.passed[slot], elements.escaped[slot]) {
1491            elements.passed[slot] = passed;
1492            elements.escaped[slot] = escaped;
1493            for child in elements.children(at) {
1494                visit.set(child);
1495            }
1496        }
1497    }
1498}

1500/// What `named` leaves visible of what it holds, if it is above the element at `at` at all.
1501///
1502/// The walk is up the trunks from the element, so one that names something beside it rather than
1503/// above it gets `None` and is answered as though it had named the region it is in. Naming the
1504/// element rather than counting regions is what makes this survive a wrapper being added between
1505/// the two, which a count would not.
1506fn within(elements: &Elements, at: usize, named: Leaf) -> Option<Section> {
1507    let named = elements.at(named)?;
1508    let mut step = elements.trunk(at);
1509    while let Some(above) = step {
1510        // An ancestor resolves before what hangs off it, so one found here has already passed its
1511        // own clip down and the read is never of a position the pass has yet to reach.
1512        if above == named {
1513            return Some(elements.passed[elements.slot(above)]);
1514        }
1515        step = elements.trunk(above);
1516    }
1517    None
1518}

1520/// R6. Declared elevation accumulates down the tree, and allocation order settles what it leaves
1521/// equal.
1522///
1523/// One walk in the same dependency order the axes used, which puts every trunk before what hangs
1524/// off it -- so a trunk's rank is already this frame's when what hangs off it reads it. Nothing here
1525/// reads a box: where an element sits in the stack has nothing to do with where it sits on the
1526/// surface. What is visited is what is new or restyled, and what hangs off an element whose rank
1527/// moved.
1528fn rank(tree: &Tree, elements: &mut Elements) {
1529    let _pass = trace_span!("rank").entered();
1530    let mut visit = elements.visiting(&[&elements.fresh, &elements.restyled], &[]);
1531    let mut from = 0;
1532    while let Some(at) = visit.next(from) {
1533        from = at + 1;
1534        let trunk = elements
1535            .trunk(at)
1536            .map(|trunk| elements.rank[elements.slot(trunk)].stack)
1537            .unwrap_or_default();
1538        let leaf = elements.order[at];
1539        let standing = tree.standing(leaf);
1540        let rank = ResolvedElevation {
1541            stack: standing.elevation().accumulate(trunk),
1542            growth: standing.growth(),
1543        };
1544        if rank != elements.rank[leaf.slot()] {
1545            elements.rank[leaf.slot()] = rank;
1546            elements.moved.set(at);
1547            elements.restack = true;
1548            // What the stack is sorted on moved, where the element is in it at all.
1549            elements.reranked |= !standing.gestures().intangible;
1550            for child in elements.children(at) {
1551                visit.set(child);
1552            }
1553        }
1554    }
1555}

1557/// R7. The three off-states, resolved over each element's whole ancestry.
1558///
1559/// One walk, in the same order the axes used, which puts every trunk before what hangs off it.
1560/// Nothing has a cascade to write: an element grown under a disabled trunk is disabled on its first
1561/// frame because the pass does not care when it arrived, and enabling that trunk leaves anything
1562/// disabled in its own right disabled because the product is over the whole ancestry rather than a
1563/// single bit that was overwritten on the way down.
1564///
1565/// What is visited is what is new or restyled, and what hangs off an element whose product moved --
1566/// so hiding a subtree visits all of it once, on the frame it is hidden, and none of it after.
1567fn inherit(tree: &Tree, elements: &mut Elements) {
1568    let _pass = trace_span!("inherit").entered();
1569    let mut visit = elements.visiting(&[&elements.fresh, &elements.restyled], &[]);
1570    let mut from = 0;
1571    while let Some(at) = visit.next(from) {
1572        from = at + 1;
1573        let trunk = elements
1574            .trunk(at)
1575            .map(|trunk| elements.inherited[elements.slot(trunk)])
1576            .unwrap_or_default();
1577        let leaf = elements.order[at];
1578        let standing = tree.standing(leaf);
1579        let product = Inherited::under(
1580            trunk,
1581            standing.visible(),
1582            standing.opacity(),
1583            standing.disabled(),
1584        );
1585        if product != elements.inherited[leaf.slot()] {
1586            elements.inherited[leaf.slot()] = product;
1587            elements.moved.set(at);
1588            elements.restack = true;
1589            for child in elements.children(at) {
1590                visit.set(child);
1591            }
1592        }
1593    }
1594}

1596/// R8. The box stack the next frame's dispatch reads.
1597///
1598/// Membership is universal: an element is here because it is there. What is left out is what is
1599/// not there at all -- hidden, fully transparent, or clipped away by a region it sits inside -- and
1600/// what is `intangible`. The one read of the stack is its top, the front-most tangible element at a
1601/// point, and a gesture passes through an intangible one to whatever is beneath it: holding it
1602/// would change no answer the stack gives, and would make the stack the size of everything drawn
1603/// rather than of what can be pressed.
1604///
1605/// Built only on a frame where something it is built from moved. Every one of those is a column R4
1606/// through R7 compared as they wrote it, or the order itself being built again -- so a frame where
1607/// one hover fades, or nothing happens at all, keeps the stack the last one built.
1608fn regions(grove: &mut Grove, elements: &mut Elements) {
1609    if !elements.restack {
1610        return;
1611    }
1612    let _pass = trace_span!("regions").entered();
1613    // The order is total -- a resolved elevation carries allocation order as its tie-break -- so two
1614    // identical runs read the same element at the same point, and sorting without stability loses
1615    // nothing. What is sorted is what the order was made holding, every tangible position.
1616    if elements.reranked {
1617        let Elements {
1618            rank,
1619            order,
1620            stacking,
1621            ..
1622        } = elements;
1623        let rank = |at: &u32| rank[order[*at as usize].slot()];
1624        stacking.sort_unstable_by_key(|at| core::cmp::Reverse(rank(at)));
1625    }
1626    let Grove { tree, stack, .. } = grove;
1627    stack.settle(elements.stacking.iter().filter_map(|&at| {
1628        let leaf = elements.order[at as usize];
1629        let slot = leaf.slot();
1630        let gestures = tree.standing(leaf).gestures();
1631        let inherited = elements.inherited[slot];
1632        if !inherited.present() {
1633            return None;
1634        }
1635        let section = elements.drawn[slot];
1636        let clip = elements.clip[slot];
1637        if section.intersect(clip).is_empty() {
1638            return None;
1639        }
1640        Some(Region {
1641            leaf,
1642            section,
1643            clip,
1644            shape: gestures.shape,
1645            receives: gestures.receives,
1646            disabled: inherited.disabled,
1647        })
1648    }));
1649}

1651/// Everything one axis of the element at `at` resolves against.
1652fn context<'a>(
1653    grove: &Grove,
1654    elements: &'a Elements,
1655    viewport: Section,
1656    at: usize,
1657    axis: Axis,
1658    offered: &mut Offered,
1659) -> Context<'a> {
1660    let (trunk, anchor) = (elements.trunk(at), elements.anchor(at));
1661    Context {
1662        axis,
1663        // Its box on this axis is the answer being computed, and its own grid divides it for its
1664        // children rather than for itself, so neither is readable here. Its box on the *other* axis
1665        // is readable exactly when that axis has already run, which is what [`own`] hands over.
1666        own: own(elements, at, axis),
1667        // A top-level element has no trunk, and fills the viewport instead.
1668        trunk: match trunk {
1669            Some(trunk) => offered.basis(grove, elements, trunk, viewport, axis),
1670            None => basis(elements, None, viewport, axis, Tracks::default()),
1671        },
1672        // A placement that reads an anchor it has not been given resolves against a zero box.
1673        anchor: basis(
1674            elements,
1675            anchor,
1676            Section::default(),
1677            axis,
1678            anchor.map_or_else(Tracks::default, |anchor| tracks(grove, elements, anchor)),
1679        ),
1680    }
1681}

1683/// What the element at `at` offers its own placement.
1684///
1685/// Its measured extent and its character cell on either axis, and its width on the vertical one:
1686/// the horizontal pass has run for the whole tree by then, so the width is settled where the
1687/// height is the answer being computed. That is what [`aspect`](crate::aspect) reads, and it is
1688/// offered flattened the way [`basis`] flattens a resolved box -- with nothing on the axis being
1689/// resolved -- so nothing about the box that is still open can be read back.
1690///
1691/// Nothing on the horizontal pass, where neither axis of it is known.
1692fn own<'a>(elements: &'a Elements, at: usize, axis: Axis) -> Basis<'a> {
1693    let slot = elements.slot(at);
1694    Basis {
1695        section: match axis {
1696            Axis::Horizontal => Section::default(),
1697            Axis::Vertical => flattened(elements.section[slot]),
1698        },
1699        intrinsic: elements.intrinsic[slot],
1700        tracks: Tracks::default(),
1701        cell: elements.cell[slot],
1702        // Where its own characters stand is a question about a box that is still being solved.
1703        run: None,
1704    }
1705}

1707/// A box with its vertical half taken away: its left edge and its width, and nothing on the other
1708/// axis. What a box is worth to a reader while no height is known.
1709fn flattened(section: Section) -> Section {
1710    Section::new(
1711        Position::new(section.left(), 0.0),
1712        Area::new(section.width(), 0.0),
1713    )
1714}

1716/// What the element at `at` offers a placement reading it, or `fallback` in place of a box when
1717/// there is no such element or it has not resolved yet.
1718///
1719/// **A resolved box offers no vertical reading on the horizontal axis.** R2a runs before any height
1720/// is known, so a box it offers is flattened to the horizontal -- which is what one held anyway when
1721/// every element was resolved every frame, and what it has to go on holding now that an element
1722/// nothing wrote to comes into the pass carrying the whole of last frame's box.
1723///
1724/// The fallback is not flattened, because it is not a resolved box: the viewport a top-level element
1725/// fills is as tall on this axis as on the other one.
1726fn basis<'a>(
1727    elements: &'a Elements,
1728    at: Option<usize>,
1729    fallback: Section,
1730    axis: Axis,
1731    tracks: Tracks,
1732) -> Basis<'a> {
1733    let Some(at) = at else {
1734        return Basis {
1735            section: fallback,
1736            ..Basis::default()
1737        };
1738    };
1739    let slot = elements.slot(at);
1740    Basis {
1741        section: match (elements.unresolved.get(at), axis) {
1742            (false, Axis::Horizontal) => flattened(elements.section[slot]),
1743            (false, Axis::Vertical) => elements.section[slot],
1744            (true, _) => fallback,
1745        },
1746        intrinsic: elements.intrinsic[slot],
1747        tracks,
1748        cell: elements.cell[slot],
1749        run: elements.composed[slot].as_deref(),
1750    }
1751}

1753/// What the trunk the last element resolved against offers, held for the next element to ask.
1754///
1755/// Siblings sit together in the order and each asks the same trunk the same thing -- and nothing a
1756/// trunk offers moves once the walk is past it, so what was read for one serves the rest. The one
1757/// trunk the walk has yet to reach, a cycle's remainder, is let go of when the walk resolves it.
1758#[derive(Default)]
1759struct Offered {
1760    held: Option<(usize, Section, Area, Tracks, Area)>,
1761}
1762
1763impl Offered {
1764    fn basis<'a>(
1765        &mut self,
1766        grove: &Grove,
1767        elements: &'a Elements,
1768        trunk: usize,
1769        viewport: Section,
1770        axis: Axis,
1771    ) -> Basis<'a> {
1772        let (section, intrinsic, tracks, cell) = match self.held {
1773            Some((held, section, intrinsic, tracks, cell)) if held == trunk => {
1774                (section, intrinsic, tracks, cell)
1775            }
1776            _ => {
1777                let basis = basis(
1778                    elements,
1779                    Some(trunk),
1780                    viewport,
1781                    axis,
1782                    tracks(grove, elements, trunk),
1783                );
1784                self.held = Some((
1785                    trunk,
1786                    basis.section,
1787                    basis.intrinsic,
1788                    basis.tracks,
1789                    basis.cell,
1790                ));
1791                (basis.section, basis.intrinsic, basis.tracks, basis.cell)
1792            }
1793        };
1794        Basis {
1795            section,
1796            intrinsic,
1797            tracks,
1798            cell,
1799            run: elements.composed[elements.slot(trunk)].as_deref(),
1800        }
1801    }
1802
1803    /// The walk resolved the element at `at`, so what it offers may be different.
1804    fn resolved(&mut self, at: usize) {
1805        if self.held.is_some_and(|(held, ..)| held == at) {
1806            self.held = None;
1807        }
1808    }
1809}

1820/// The frame's one read of the tree: every live element, ordered so that nothing resolves before
1821/// what it depends on, with what it depends on and what it offers read out beside it.
1822///
1823/// An anchor may point anywhere -- a later sibling, a cousin, an element in another subtree -- so
1824/// this is ordered by dependency rather than by tree depth: an element resolves after its parent
1825/// *and* after whatever it anchors to.
1826///
1827/// A chain of anchors cannot close on itself, because one that would is refused where it is written.
1828/// A trunk and an anchor still can, between them: an element anchored to something grown under it
1829/// waits on a box that is waiting on its own. That is not the same contradiction -- both boxes
1830/// resolve, just not both against a settled other -- so the remainder is ordered by allocation order
1831/// and resolves against what its dependency last was. **Every live element is in the order**, which
1832/// is the property the passes downstream rely on: an element left out would have no box, no rank and
1833/// no place in the stack, and nothing would say so.
1834///
1835/// Each element is asked what it depends on exactly once here, and every position after that is
1836/// arithmetic on the answer.
1837///
1838/// Kept between frames and repaired rather than built again. The order is what the elements and the
1839/// edges between them make, and only growing, withering and anchoring change those -- so an ordinary
1840/// frame reads none of it. When it is built again, what every element already resolved to stays
1841/// where it is held, by slot, so building it again loses nothing but the elements that went.
1842fn structure(elements: &mut Elements, grove: &Grove) {
1843    let _pass = trace_span!("structure").entered();
1844    let tree = &grove.tree;
1845    let leaves = tree.leaves();
1846    let count = leaves.len();
1847    // Where each element sits among the leaves, by the index of its name, which is dense: a lookup
1848    // is an index rather than a hash.
1849    let names = leaves
1850        .iter()
1851        .map(|leaf| leaf.slot() + 1)
1852        .max()
1853        .unwrap_or_default();
1854    let mut among: Vec<u32> = vec![NOWHERE; names];
1855    for (at, leaf) in leaves.iter().enumerate() {
1856        among[leaf.slot()] = at as u32;
1857    }
1858    let find = |leaf: Leaf| -> Option<usize> {
1859        let at = *among.get(leaf.slot())? as usize;
1860        (leaves.get(at) == Some(&leaf)).then_some(at)
1861    };
1862    // What each element waits on, and how many of those have yet to resolve. An element the leaves
1863    // do not hold is not live, since the leaves are what the tree has grown, and a dependency on
1864    // something not live is no dependency at all.
1865    let mut depends: Vec<[Option<usize>; 2]> = Vec::with_capacity(count);
1866    let mut waiting: Vec<u8> = Vec::with_capacity(count);
1867    // Everything waiting on each element, as one run per element in a single array: an element
1868    // depends on at most two others, so the whole graph fits in one allocation rather than in a
1869    // vector per element.
1870    let mut runs: Vec<u32> = vec![0; count + 1];
1871    elements.waits = false;
1872    for &leaf in &leaves {
1873        let declared = [tree.trunk(leaf), tree.anchor(leaf)];
1874        let on = declared.map(|on| on.and_then(find));
1875        elements.waits |= declared[1].is_some() && on[1].is_none();
1876        let mut unresolved = 0;
1877        for at in on.into_iter().flatten() {
1878            unresolved += 1;
1879            runs[at + 1] += 1;
1880        }
1881        depends.push(on);
1882        waiting.push(unresolved);
1883    }
1884    for at in 0..count {
1885        runs[at + 1] += runs[at];
1886    }
1887    let mut filling = runs.clone();
1888    let mut dependents: Vec<u32> = vec![0; runs[count] as usize];
1889    for (at, on) in depends.iter().enumerate() {
1890        for &upon in on.iter().flatten() {
1891            dependents[filling[upon] as usize] = at as u32;
1892            filling[upon] += 1;
1893        }
1894    }
1895    // Kahn's, with the order under construction serving as its own queue.
1896    let mut order: Vec<usize> = (0..count).filter(|at| waiting[*at] == 0).collect();
1897    let mut next = 0;
1898    while next < order.len() {
1899        let at = order[next];
1900        next += 1;
1901        for &dependent in &dependents[runs[at] as usize..runs[at + 1] as usize] {
1902            let dependent = dependent as usize;
1903            waiting[dependent] -= 1;
1904            if waiting[dependent] == 0 {
1905                order.push(dependent);
1906            }
1907        }
1908    }
1909    if order.len() != count {
1910        order.extend((0..count).filter(|at| waiting[*at] != 0));
1911    }
1912    // Where each element ended up, which is what every position held below is in.
1913    let mut ranked: Vec<usize> = vec![0; count];
1914    for (position, &at) in order.iter().enumerate() {
1915        ranked[at] = position;
1916    }
1917    let placed = order
1918        .iter()
1919        .map(|&at| {
1920            let [trunk, anchor] = depends[at];
1921            Placed {
1922                leaf: leaves[at],
1923                trunk: trunk.map(|on| ranked[on]),
1924                anchor: anchor.map(|on| ranked[on]),
1925                from: elements.at(leaves[at]),
1926            }
1927        })
1928        .collect();
1929    settle(elements, grove, placed, names, false);
1930}

1932/// One element's place in an order being made: what it is, the positions of what it hangs off and
1933/// what it is anchored to, and where it sat in the order being replaced.
1934struct Placed {
1935    leaf: Leaf,
1936    trunk: Option<usize>,
1937    anchor: Option<usize>,
1938    from: Option<usize>,
1939}

1941/// The order repaired for what was grown and what withered since it was made, rather than made
1942/// again: what withered is taken out, and what was grown is placed after everything already there,
1943/// in the order it was grown. Reports whether it could be, having changed nothing where it could
1944/// not.
1945///
1946/// Everything [`structure`] makes the order from is read here too, but only of what changed: what
1947/// stays keeps its place relative to the rest, so what it depends on is still before it, and is
1948/// carried without a lookup. What is grown depends on what it was grown under, which was grown
1949/// before it, and on an anchor -- which has to be placed already. One that is not, or an order whose
1950/// anchors point forward, is left to [`structure`], which places everything from scratch.
1951fn patch(elements: &mut Elements, grove: &Grove, written: &Written) -> bool {
1952    let _pass = trace_span!("patch").entered();
1953    let tree = &grove.tree;
1954    let held = elements.len();
1955    let mut kept = vec![true; held];
1956    for &(leaf, _) in written.withered {
1957        if let Some(at) = elements.at(leaf) {
1958            kept[at] = false;
1959        }
1960    }
1961    let mut moved: Vec<u32> = vec![NOWHERE; held];
1962    let mut placed: Vec<Placed> = Vec::with_capacity(held + written.grown.len());
1963    for at in 0..held {
1964        if !kept[at] {
1965            continue;
1966        }
1967        // Earlier in the order than the element itself, or this is an order a cycle left a
1968        // remainder in, which only building it again answers.
1969        let earlier = |on: Option<usize>| match on {
1970            Some(on) if on < at => Ok((moved[on] != NOWHERE).then_some(moved[on] as usize)),
1971            Some(_) => Err(()),
1972            None => Ok(None),
1973        };
1974        let (Ok(trunk), Ok(anchor)) = (earlier(elements.trunk(at)), earlier(elements.anchor(at)))
1975        else {
1976            return false;
1977        };
1978        moved[at] = placed.len() as u32;
1979        placed.push(Placed {
1980            leaf: elements.order[at],
1981            trunk,
1982            anchor,
1983            from: Some(at),
1984        });
1985    }
1986    let names = written
1987        .grown
1988        .iter()
1989        .map(|leaf| leaf.slot() + 1)
1990        .max()
1991        .unwrap_or_default()
1992        .max(elements.sits.len());
1993    // Where each element grown this frame was placed, by the index of its name.
1994    let placing = trace_span!("grown").entered();
1995    let mut grown: Vec<u32> = vec![NOWHERE; names];
1996    for &leaf in written.grown {
1997        if !tree.is_live(leaf) || elements.at(leaf).is_some() {
1998            continue;
1999        }
2000        let find = |on: Leaf| match elements.at(on) {
2001            Some(at) => (moved[at] != NOWHERE).then_some(moved[at] as usize),
2002            None => grown
2003                .get(on.slot())
2004                .filter(|at| **at != NOWHERE && placed[**at as usize].leaf == on)
2005                .map(|at| *at as usize),
2006        };
2007        let trunk = match tree.trunk(leaf) {
2008            Some(on) => match find(on) {
2009                Some(at) => Some(at),
2010                None => return false,
2011            },
2012            None => None,
2013        };
2014        let anchor = match tree.anchor(leaf) {
2015            Some(on) => match find(on) {
2016                Some(at) => Some(at),
2017                None => return false,
2018            },
2019            None => None,
2020        };
2021        grown[leaf.slot()] = placed.len() as u32;
2022        placed.push(Placed {
2023            leaf,
2024            trunk,
2025            anchor,
2026            from: None,
2027        });
2028    }
2029    drop(placing);
2030    settle(elements, grove, placed, names, true);
2031    true
2032}

2034/// Makes `placed` the order: what is grown under each element found again, and what every pass
2035/// visits. `names` is one past the largest slot of any element placed.
2036///
2037/// Nothing any element resolved to moves, since it is held by slot: an element new to the order has
2038/// its slot cleared of whatever withered from it, and everything else keeps what it holds.
2039/// `repaired` says the order was repaired rather than made again -- what stays is in the order it
2040/// was, with what is new after it -- so only what was grown passes on anything new, where an order
2041/// made again may hang anything off anything.
2042fn settle(
2043    elements: &mut Elements,
2044    grove: &Grove,
2045    placed: Vec<Placed>,
2046    names: usize,
2047    repaired: bool,
2048) {
2049    let _pass = trace_span!("order").entered();
2050    let tree = &grove.tree;
2051    let count = placed.len();
2052    match repaired {
2053        true => {
2054            elements.fresh.reset(count);
2055            for (position, placed) in placed.iter().enumerate() {
2056                if placed.from.is_none() {
2057                    elements.fresh.set(position);
2058                }
2059            }
2060        }
2061        false => elements.fresh.fill(count),
2062    }
2063    // A slot past what the columns held is new to them, and already holds what an element starts
2064    // from. One before it held something that withered.
2065    let held = elements.section.len();
2066    columns(elements, &Lengthen(names));
2067    for placed in &placed {
2068        let slot = placed.leaf.slot();
2069        if placed.from.is_none() && slot < held {
2070            columns(elements, &Clear(slot));
2071        }
2072    }
2073    elements.order.clear();
2074    elements.trunk.clear();
2075    elements.anchor.clear();
2076    elements.sits.clear();
2077    elements.sits.resize(names, NOWHERE);
2078    for (position, placed) in placed.iter().enumerate() {
2079        elements.sits[placed.leaf.slot()] = position as u32;
2080        elements.order.push(placed.leaf);
2081        elements
2082            .trunk
2083            .push(placed.trunk.map_or(NOWHERE, |on| on as u32));
2084        elements
2085            .anchor
2086            .push(placed.anchor.map_or(NOWHERE, |on| on as u32));
2087    }
2088    // What is grown under each element, by position: counted, summed into where each element's run
2089    // starts, and filled.
2090    elements.branches.clear();
2091    elements.branches.resize(count + 1, 0);
2092    for trunk in elements.trunk.iter().filter_map(|&on| position(on)) {
2093        elements.branches[trunk + 1] += 1;
2094    }
2095    for at in 0..count {
2096        elements.branches[at + 1] += elements.branches[at];
2097    }
2098    let mut filling = elements.branches.clone();
2099    elements.children.clear();
2100    elements.children.resize(count, 0);
2101    for at in 0..count {
2102        if let Some(trunk) = elements.trunk(at) {
2103            elements.children[filling[trunk] as usize] = at as u32;
2104            filling[trunk] += 1;
2105        }
2106    }
2107    // What is anchored to each element, the same way.
2108    elements.anchoring.clear();
2109    elements.anchoring.resize(count + 1, 0);
2110    for anchor in elements.anchor.iter().filter_map(|&on| position(on)) {
2111        elements.anchoring[anchor + 1] += 1;
2112    }
2113    for at in 0..count {
2114        elements.anchoring[at + 1] += elements.anchoring[at];
2115    }
2116    let mut filling = elements.anchoring.clone();
2117    elements.anchored.clear();
2118    elements
2119        .anchored
2120        .resize(elements.anchoring[count] as usize, 0);
2121    for at in 0..count {
2122        if let Some(anchor) = elements.anchor(at) {
2123            elements.anchored[filling[anchor] as usize] = at as u32;
2124            filling[anchor] += 1;
2125        }
2126    }
2127    // What every pass visits whatever was written, and what the stack is sorted from.
2128    elements.forward.clear();
2129    elements.stacking.clear();
2130    for at in 0..count {
2131        let ahead = |on: Option<usize>| on.is_some_and(|on| on >= at);
2132        if ahead(elements.trunk(at)) || ahead(elements.anchor(at)) {
2133            elements.forward.push(at as u32);
2134        }
2135        if !tree.standing(elements.order[at]).gestures().intangible {
2136            elements.stacking.push(at as u32);
2137        }

2217/// What this frame has to resolve, and what it may leave alone.
2218///
2219/// An element resolves again if it was written to, or if what it hangs off or is anchored to does.
2220/// That closure is one walk of the order rather than a search, because the order already puts a
2221/// dependency before what depends on it -- and the walk goes from mark to mark, each element
2222/// resolving again marking what is resolved against it. What was written is found by name and
2223/// marked where it sits, so the walk costs what resolves again and the marking costs what was
2224/// written.
2225///
2226/// An element that was restyled is read again and marked as moved, and resolves again only if
2227/// something it is placed by was written as well.
2228fn read(elements: &mut Elements, grove: &Grove) {
2229    let _pass = trace_span!("elements").entered();
2230    let written = grove.tree.written();
2231    // What withered from the order, and what it drew: what extraction lets go of. Found before the
2232    // order is repaired, while it still says where each sat -- an element grown and withered between
2233    // two frames was never in it, and has nothing drawn to let go of.
2234    let mut gone = core::mem::take(&mut elements.gone);
2235    gone.clear();
2236    gone.extend(
2237        written
2238            .withered
2239            .iter()
2240            .filter(|(leaf, _)| elements.at(*leaf).is_some()),
2241    );
2242    // What each held stays in its slot until something is grown there, which is harmless for a
2243    // value and not for a run: the shaping cache keeps a run for as long as anything holds it.
2244    for &(leaf, _) in &gone {
2245        elements.composed[leaf.slot()] = None;
2246    }
2247    elements.gone = gone;
2248    elements.restack = false;
2249    elements.reranked = false;
2250    // Nothing is new unless the order is made or repaired below, which marks what is.
2251    elements.fresh.reset(0);
2252    if written.restructured
2253        && (written.reordered || elements.waits || !patch(elements, grove, &written))
2254    {
2255        structure(elements, grove);
2256    }
2257    let count = elements.len();
2258    elements.restyled.reset(count);
2259    for &leaf in written.restyled {
2260        if let Some(at) = elements.at(leaf) {
2261            elements.restyled.set(at);
2262        }
2263    }
2264    // An element that came to scroll, or stopped, is restyled, and is a region or is not one from
2265    // here on.
2266    elements.rescoped = written.rescoped;
2267    if written.rescoped {
2268        scopes(elements, &grove.tree);
2269    }
2270    elements.restated = written.restated;
2271    if written.all {
2272        elements.fresh.fill(count);
2273    }
2274    let marked = |marks: &mut Positions, leaves: &crate::leaf::Leaves| {
2275        for &leaf in leaves {
2276            if let Some(at) = elements.at(leaf) {
2277                marks.set(at);
2278            }
2279        }
2280    };
2281    let mut dirty = Positions::default();
2282    let mut lettered = Positions::default();
2283    match written.all {
2284        true => {
2285            dirty.fill(count);
2286            lettered.fill(count);
2287        }
2288        false => {
2289            dirty.reset(count);
2290            lettered.reset(count);
2291            marked(&mut lettered, written.lettered);
2292            marked(&mut dirty, written.declared);
2293        }
2294    }
2295    let mut measures = Positions::default();
2296    measures.reset(count);
2297    marked(&mut measures, written.measures);
2298    let mut touched = Positions::default();
2299    if written.across {
2300        touched.fill(count);
2301    } else {
2302        touched.reset(count);
2303        marked(&mut touched, written.declared);
2304    }
2305    elements.dirty = dirty;
2306    elements.lettered = lettered;
2307    elements.measures = measures;
2308    match written.repainted {
2309        true => elements.moved.fill(count),
2310        false => elements.moved.reset(count),
2311    }
2312    elements.moved.add(&elements.restyled);
2313    elements.answers.reset(count);
2314    elements.remeasured.reset(count);
2315    // What R1m reads, taken before the closure below spreads anything: what was written to each
2316    // element itself, and with it what something went from. Everything, where what every measure
2317    // across reads changed; where only the viewport moved, it changed nothing a measure reads, and
2318    // what was written is what was. Nothing at all, and nothing is filled in, where nothing was
2319    // written and nothing went.
2320    elements.across =
2321        written.across || !written.declared.is_empty() || !written.measures.is_empty();
2322    if elements.across {
2323        elements.measures_across.copy_from(&touched);
2324        elements.measures_across.add(&elements.measures);
2325        elements.touched = touched;
2326    }
2327    // A dependency the order could not put first is one a cycle left in the remainder, and it has
2328    // no answer yet. Resolving such an element is the same fallback the rest of resolution gives
2329    // it: it is answered against what its dependency last was, so it is answered again.
2330    if !written.all {
2331        let mut dirty = core::mem::take(&mut elements.dirty);
2332        for &at in &elements.forward {
2333            dirty.set(at as usize);
2334        }
2335        let mut from = 0;
2336        while let Some(at) = dirty.next(from) {
2337            from = at + 1;
2338            elements.dependents(at, &mut dirty);
2339        }
2340        elements.dirty = dirty;
2341    }
2342    elements.answers.add(&elements.dirty);
2343    elements.moved.add(&elements.dirty);
2344    elements.measures.add(&elements.dirty);
2345    // A clean element offers the box it settled at, and offers it from the start, because nothing
2346    // this frame is going to compute it again. One being resolved again offers nothing until an
2347    // axis reaches it, which is what it did when every element was resolved.
2348    elements.unresolved.copy_from(&elements.dirty);
2349    elements.closed.copy_from(&elements.dirty);
2350}
