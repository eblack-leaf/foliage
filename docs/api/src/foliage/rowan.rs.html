1//! Rowan -- resolution.
2//!
3//! # Rowan resolves. Elm decides what changed.
4//!
5//! Every pass runs in the same order over the same elements every frame, and each writes exactly one
6//! thing. What a pass may leave alone is an element **nothing it reads was written to**, whose
7//! answer is the one it already holds -- sitting in the column the pass would have written it to.
8//!
9//! That is not invalidation and nothing is ever marked stale. The tree records a write where the
10//! write happens ([`Tree::declared`](crate::tree::Tree::declared), which every declaration passes
11//! through), and [`read`] closes that over the dependencies before any pass runs. So an element
12//! resolves again if it was written to, if what it hangs off or is anchored to resolves again, or if
13//! a measure moved under it -- and if none of those happened, resolving it again would produce what
14//! it already has. A value here can be old. It cannot be wrong.
15//!
16//! What still runs over everything is the accumulations, R3 through R8: what they carry is a running
17//! product rather than an answer per element, so there is no position in them to start from. They
18//! record what they actually changed as they go, which is what extraction then states.
19//!
20//! The read itself is kept between frames and repaired where the tree was written -- growing,
21//! withering and anchoring are the only things that change the order, so an ordinary frame reads
22//! none of it.
23//!
24//! Nothing is re-uploaded on account of any of it, because extraction compares against a cached copy
25//! and sends only genuine differences.
26//!
27//! The passes each write exactly one thing, and nothing writes what another owns:
28//!
29//! | | Pass | Direction | Produces |
30//! |---|---|---|---|
31//! | R1 | measure | — | [`Cell`], and the max-content width half of [`Intrinsic`] |
32//! | R2a | horizontal | dependency order | the horizontal axis |
33//! | R2m | wrap | **bottom-up** | the measured-height half of [`Intrinsic`] |
34//! | R2b | vertical | dependency order | the vertical axis, and with it [`Placed`] |
35//! | R3 | extent | **bottom-up** | [`Extent`](crate::view::Extent): how far a region's content reaches |
36//! | R4 | scroll | top-down | [`Drawn`]: [`Placed`] less every scrolling ancestor's offset |
37//! | R5 | clip | top-down | [`Clipped`]: what a scrolling ancestor leaves visible |
38//! | R6 | rank | dependency order | `ResolvedElevation`: elevation accumulated, then tie-broken |
39//! | R7 | inherit | top-down | [`Inherited`]: the visible, opacity and disabled products |
40//! | R8 | regions | rank order | the box stack the next frame's dispatch reads |
41//!
42//! Both halves of R2 call the same pure resolver, once per axis. That is only safe because it is
43//! pure: there is no accumulated state for a second call to corrupt.
44//!
45//! R1, R2a and R2b resolve what was written to. R2m resolves that and everything above it, because
46//! what an element reaches over is what the elements under it resolved to -- a measure travels
47//! toward the trunk where a box travels away from it. A measure that moves under an element nothing
48//! wrote to makes that element resolve again, which is why R2m sits before R2b and not after it.
49//!
50//! # Every pass reads the order, not the world
51//!
52//! The passes ask the same questions of the same elements over and over: what an element hangs off,
53//! what it is anchored to, and what each of those offers a placement reading it. Asked of the world
54//! each time, every one of those is a lookup by entity -- and the arithmetic a pass does is small
55//! enough that the lookups, not the arithmetic, are what a frame costs.
56//!
57//! So the tree is read once, into [`Elements`]: every live element in dependency order, holding what
58//! it depends on as **positions in that order** rather than as names, and holding what it offers a
59//! placement beside it. From there every pass indexes -- the accumulations R3 through R7 carry are
60//! arrays the length of the order, and a trunk's contribution is `[..]` rather than a lookup on a
61//! map keyed by element.
62//!
63//! The measures R1 and R2m state are written there too, and reach the elements themselves in one
64//! [`scatter`] once both passes have run. So no pass writes a value another is about to read back
65//! out of the world, and during resolution the order is the only place a measure is held.
66//!
67//! Nothing about what is computed changes, and neither does the ordering that makes it correct.
68//!
69//! Two passes run the other way, and each is a cycle that turns out not to be vicious.
70//!
71//! R2m is one: wrapping makes a height depend on a width, and the width comes from the layout, so a
72//! box sized to its contents looks circular. It is not, because **width flows down and height flows
73//! up** -- a monospaced run's widest unwrapped line is free from its character count, so the
74//! down-pass needs nothing measured. R2m sits between the two halves of R2 for that reason: it is
75//! the one moment when every width is known and no height is, which is exactly what measuring needs.
76//!
77//! R3 is the other: a child resolves against its parent's box, a scrolling parent's extent comes
78//! from where its children landed, and that extent is what its offset is clamped to. Extent affects
79//! only the clamp and never the parent's own box -- so a top-down layout sweep, a bottom-up extent
80//! sweep and a top-down scroll application resolve it in one pass each.
81//!
82//! Neither iterates to convergence. Every pass here runs exactly once.

128/// What an element measured to, which is what [`content()`](crate::content) reads.
129///
130/// The two halves are written by different passes and mean different questions, which is the whole
131/// of width-down and height-up:
132///
133/// - **width** is max-content, written by R1 -- the widest the element would like to be, unwrapped.
134///   In a monospaced font that is a character count times a cell, so it is free and is available
135///   before any layout has happened.
136/// - **height** is measured, written by R2m -- what the element turned out to be at the width R2a
137///   gave it.
138#[derive(Component, Copy, Clone, Debug, Default, PartialEq)]
139pub(crate) struct Intrinsic(pub(crate) Area);

141/// Every live element in dependency order, with what each one resolves against and what each one
142/// offers a placement that reads it.
143///
144/// The frame's one read of the tree, and what every pass indexes into. A trunk and an anchor are
145/// asked for on both axes and on four of the passes after them; what an element offers is asked for
146/// twice per element on each axis. Out of the world each time, every one of those is a lookup by
147/// entity -- resolved once to a position in the order, each is an index.
148///
149/// The columns are as long as the order and are read at the position an element sits at, so a pass
150/// that already knows where it is never asks a second time.
151#[derive(Default)]
152pub(crate) struct Elements {
153    /// Every live element, ordered so that nothing resolves before what it depends on.
154    order: Vec<Leaf>,
155    /// Where each element sits in the order.
156    index: HashMap<Leaf, usize>,
157    /// What each element hangs off, as a position in the order.
158    trunk: Vec<Option<usize>>,
159    /// What each element is anchored to, as a position in the order.
160    anchor: Vec<Option<usize>>,
161    /// The box, as far as the axes have resolved it.
162    section: Vec<Section>,
163    /// Whether the element has a box worth reading yet. True from the start for one nothing has
164    /// written to, whose box is the one it settled at last frame; false for one being resolved
165    /// again, until an axis reaches it -- which is what answers a cycle's remainder with the
166    /// fallback rather than with a box that has not been computed.
167    resolved: Vec<bool>,
168    /// Whether the element has to be resolved again this frame.
169    ///
170    /// True where something it reads was written -- its own declarations, or those of what it hangs
171    /// off or is anchored to. False where nothing was, in which case the columns already hold what
172    /// it resolved to and the passes that only rewrite that have nothing to do.
173    dirty: Vec<bool>,
174    /// Whether any run stopped being stated this frame, which is the one thing that makes the
175    /// shaping cache worth sweeping -- and, because a sweep drops what this frame did not state,
176    /// the one thing that makes every run worth shaping again.
177    restated: bool,
178    /// Whether anything extraction reads about the element moved this frame.
179    ///
180    /// Seeded from [`dirty`](Elements::dirty), because an element being resolved again may land
181    /// somewhere else, and set by R4 through R7 where what they wrote differs from what was held.
182    /// An element it is false for is drawn exactly as the backend already has it.
183    moved: Vec<bool>,
184    /// What the element draws, or [`Chlorophyll::None`] where it draws nothing.
185    chlorophyll: Vec<Chlorophyll>,
186    /// Whether the element has to measure again, before R2m walks that up the trunks.
187    ///
188    /// [`dirty`](Elements::dirty) is most of it. The rest is an element something withered from,
189    /// which has one fewer thing to reach over and nothing left below it to say so.
190    measures: Vec<bool>,
191    /// What the element measured to. R1 writes the width and R2m the height.
192    intrinsic: Vec<Area>,
193    /// The element's own grid, divided at the breakpoint in force.
194    tracks: Vec<Tracks>,
195    /// The element's character cell.
196    cell: Vec<Area>,
197}
198
199impl Elements {
200    /// How many elements are live.
201    fn len(&self) -> usize {
202        self.order.len()
203    }
204
205    /// Where `leaf` sits, or `None` if it is not live.
206    fn at(&self, leaf: Leaf) -> Option<usize> {
207        self.index.get(&leaf).copied()
208    }
209
210    /// The box `leaf` resolved to, or a zero one if it is not live.
211    ///
212    /// Resolution reads a box by position, because it holds every element in order. A coast, a
213    /// sought region and a running motion each name one element instead, so they ask the way an app
214    /// asks.
215    /// Every live element in the order resolution used, with what it draws and whether anything
216    /// extraction reads about it moved this frame.
217    pub(crate) fn drawing(&self) -> impl Iterator<Item = (Leaf, Chlorophyll, bool)> + '_ {
218        (0..self.len()).map(|at| (self.order[at], self.chlorophyll[at], self.moved[at]))
219    }
220
221    pub(crate) fn of(&self, leaf: Leaf) -> Section {
222        self.at(leaf).map(|at| self.section[at]).unwrap_or_default()
223    }
224}

226/// Steps 6 and 7. Declared state becomes resolved geometry and resolved products, for everything.
227pub(crate) fn run(grove: &mut Grove) {
228    let step = trace_span!("resolve", elements = Empty, dirty = Empty);
229    let resolving = step.enter();
230    // Taken off the grove so the passes can hold it while they write to the rest, and put back at
231    // the end of resolution: what it holds is what this frame settled, and what the next one starts
232    // from rather than reads again.
233    let mut elements = core::mem::take(&mut grove.elements);
234    read(&mut elements, grove);
235    // Forgotten the moment it is read, so a write made by a pass after this belongs to the frame
236    // that would resolve it.
237    grove.tree.taken();
238    step.record("elements", elements.len());
239    step.record(
240        "dirty",
241        elements.dirty.iter().filter(|dirty| **dirty).count(),
242    );
243    measure(grove, &mut elements);
244    let ends = axes(grove, &mut elements);
245    scatter(grove, &elements);
246    // Both of the passes that shape have run, so what is not held now is a run nothing states. Only
247    // on a frame that shaped every one of them, which is the frame after one stopped being stated:
248    // a sweep over a frame that shaped some of them would drop the rest.
249    if elements.restated {
250        grove.shaping.sweep();
251    }
252    extent(grove, &elements);
253    scroll(grove, &mut elements, &ends);
254    clip(grove, &mut elements);
255    rank(grove, &mut elements);
256    // Resolution ends here. What settles after it is its own step, and is timed as one.
257    drop(resolving);
258    let _step = trace_span!("settle").entered();
259    inherit(grove, &mut elements);
260    regions(grove, &elements);
261    grove.elements = elements;
262}

264/// The measures, written back to the elements themselves.
265///
266/// R1 and R2m state them into the order, because everything that reads them *during* resolution
267/// reads them there. This is the one write, after both passes that state them have run: what an
268/// element measured to is one value, and a frame never holds it in two places.
269fn scatter(grove: &mut Grove, elements: &Elements) {
270    let _pass = trace_span!("scatter").entered();
271    for at in 0..elements.len() {
272        let leaf = elements.order[at];
273        grove.tree.set_cell(leaf, elements.cell[at]);
274        grove.tree.set_intrinsic(leaf, elements.intrinsic[at]);
275    }
276}

278/// R1. What an element's own font makes of it: its character cell, and the widest its content would
279/// like to be.
280///
281/// Ahead of every other pass, and reading no geometry at all, because neither answer has anything to
282/// do with where the element ended up. A monospaced run's max-content width is its longest line's
283/// character count times its cell, so the whole of the down-pass's input is available before the
284/// down-pass runs -- which is what leaves only the up-pass with anything to measure.
285fn measure(grove: &mut Grove, elements: &mut Elements) {
286    let _pass = trace_span!("measure").entered();
287    let Grove {
288        tree,
289        fonts,
290        shaping,
291        layout,
292        short,
293        ..
294    } = grove;
295    for at in 0..elements.order.len() {
296        // Nothing it reads was written, so it measures to what it measured to, which is what the
297        // column was read out of the tree holding.
298        if !elements.dirty[at] {
299            continue;
300        }
301        let leaf = elements.order[at];
302        // No font and no size is no cell, and nothing measured in one. What such an element last
303        // measured to stands, which is what it was read out of the tree holding.
304        let Some(typeface) = tree.typeface(leaf) else {
305            continue;
306        };
307        let size = typeface.size.at(*layout, *short);
308        let cell = fonts.cell(typeface.font, size);
309        let width = match tree.lettering(leaf) {
310            Some(value) => shaping
311                .shape(fonts, typeface.font, size, value)
312                .max_content(),
313            None => 0.0,
314        };
315        elements.cell[at] = cell;
316        // The height half is R2m's, and is written before anything reads it.
317        elements.intrinsic[at] = Area::new(width, 0.0);
318    }
319}

321/// R2a, R2m and R2b: the horizontal axis, then the measure it makes possible, then the vertical one.
322///
323/// An element with a placement in motion is resolved twice on each axis -- once for each endpoint,
324/// in the *same* context -- and the two answers are blended. That is what the resolver's purity
325/// buys: the endpoints are consistent with each other because they were asked at the same position
326/// in the same dependency order, against the same settled ancestors, and neither is remembered
327/// afterwards.
328fn axes(grove: &mut Grove, elements: &mut Elements) -> Vec<Option<Stretched>> {
329    let mut ends: Vec<Option<Stretched>> = vec![None; elements.len()];
330    axis(grove, elements, Axis::Horizontal, &mut ends);
331    wrap(grove, elements);
332    axis(grove, elements, Axis::Vertical, &mut ends);
333    ends
334}

336/// One axis of the whole tree, in dependency order, through the one pure resolver.
337fn axis(grove: &Grove, elements: &mut Elements, axis: Axis, ends: &mut [Option<Stretched>]) {
338    let _pass = trace_span!("axis", vertical = (axis == Axis::Vertical)).entered();
339    let viewport = Section::new(Position::default(), grove.viewport);
340    let fallback = Location::default();
341    for at in 0..elements.len() {
342        // R2m may have found a measure that moved under an element nothing was written to, between
343        // this axis and the last. The order puts what an element reads before it, so spreading that
344        // here reaches everything resolved against it.
345        elements.dirty[at] |= elements.trunk[at].is_some_and(|on| elements.dirty[on])
346            || elements.anchor[at].is_some_and(|on| elements.dirty[on]);
347        // Nothing it or anything it resolves against was written, so it resolves to the box it
348        // already holds. Its column keeps that box, so what reads it here reads the right one.
349        if !elements.dirty[at] {
350            continue;
351        }
352        let leaf = elements.order[at];
353        let context = context(elements, viewport, at, axis);
354        let (span, stretched) = geometry(grove, leaf, &fallback, &context, axis);
355        if let Some((from, to)) = stretched {
356            ends[at]
357                .get_or_insert_with(Stretched::default)
358                .set(axis, from, to);
359        }
360        let section = &mut elements.section[at];
361        match axis {
362            Axis::Horizontal => {
363                section.position.x = span.near;
364                section.area.width = span.extent();
365            }
366            Axis::Vertical => {
367                section.position.y = span.near;
368                section.area.height = span.extent();
369            }
370        }
371        elements.resolved[at] = true;
372    }
373}

375/// One axis of `leaf`, whichever of the two ways its placement is stated.
376///
377/// A box resolves to a span directly. A **trace** resolves to two positions, and the span is the
378/// distance between them grown by half the stroke's weight on each side -- which is what gives a
379/// rule, whose ends share a coordinate on one axis, a box on that axis at all. Both ends come back
380/// too, because the span cannot say which of its diagonals they are.
381fn geometry(
382    grove: &Grove,
383    leaf: Leaf,
384    fallback: &Location,
385    context: &Context,
386    axis: Axis,
387) -> (Span, Option<(f32, f32)>) {
388    let Some(traced) = grove.tree.traced(leaf) else {
389        return (span(grove, leaf, fallback, context, axis), None);
390    };
391    let half = grove.tree.stroke(leaf).unwrap_or_default().half();
392    let (from, to) = (locate(&traced.from, context), locate(&traced.to, context));
393    (
394        Span {
395            near: from.min(to) - half,
396            far: from.max(to) + half,
397        },
398        Some((from, to)),
399    )
400}

402/// One axis of where `leaf` currently is: what it declares, blended with the endpoint a motion left.
403///
404/// The one place a placement becomes a span, so a measure and a layout are answering the same
405/// question -- an element in motion is measured where it *is* rather than where it is going.
406fn span(grove: &Grove, leaf: Leaf, fallback: &Location, context: &Context, axis: Axis) -> Span {
407    let location = grove.tree.location(leaf).unwrap_or(fallback);
408    let target = resolve(pinned(location, grove, axis), context);
409    match grove.aspen.location(leaf) {
410        Some((departed, at)) => departure(departed, grove, context, axis).blend(target, at),
411        None => target,
412    }
413}

415/// How one axis of a placement is pinned down, at the breakpoint in force.
416///
417/// A lookup rather than arithmetic, which is why it is here and not in the resolver: picking a
418/// configuration out of a placement is not part of resolving one.
419fn pinned<'a>(location: &'a Location, grove: &Grove, axis: Axis) -> &'a Config {
420    let axes = location.axes(grove.layout, grove.short);
421    match axis {
422        Axis::Horizontal => &axes.horizontal,
423        Axis::Vertical => &axes.vertical,
424    }
425}

427/// One axis of the endpoint a motion left.
428///
429/// A placement it left is resolved in the context the target was resolved in, so anything that
430/// moves one end moves both. A snapshot is already an answer: it is the box the element was blended
431/// to when it was retargeted, and it never corresponded to a placement that could be re-resolved.
432fn departure(
433    departed: &Departed<Location, Section>,
434    grove: &Grove,
435    context: &Context,
436    axis: Axis,
437) -> Span {
438    match departed {
439        Departed::Declared(location) => resolve(pinned(location, grove, axis), context),
440        Departed::Snapshot(section) => Span::of(*section, axis),
441    }
442}

444/// R2m. How tall each element's contents turned out at the width R2a gave it.
445///
446/// Bottom-up, so everything inside an element is measured before the element asks. Two things are
447/// measured, and an element takes the greater of them, because both answer the one question
448/// [`content()`](crate::content) asks -- *how large is what is inside me*:
449///
450/// - a run of glyphs wraps at its own resolved width, and its lines times its cell is its height
451/// - anything with elements grown under it takes the furthest any of them reaches down
452///
453/// The second is resolved in the element's own space, with its vertical extent taken as **not yet
454/// known**, which is exactly what it is at this point in the frame. So a child that reads that
455/// extent -- `100.pct()`, a row of a grid, an anchor's edge -- contributes nothing to the measure
456/// and is given its real height by R2b like anything else. That is the correct reading rather than a
457/// limitation: a child sized to its trunk cannot also be what sizes it, and nothing is asked to
458/// converge.
459/// The two halves are separate walks because only one of them has an order. A run wraps at its own
460/// width and against its own font, so what an element shapes to reads nothing but the element --
461/// while what reaches below it reads the measures of everything under it, and so has to run after
462/// them.
463fn wrap(grove: &mut Grove, elements: &mut Elements) {
464    let _pass = trace_span!("wrap").entered();
465    // What has to measure again: what was written to, and everything above it, because what an
466    // element reaches over is what the elements under it resolved to. Up the order rather than down
467    // it -- a measure travels toward the trunk and stops there, where a box travels away from it.
468    let mut measuring = elements.measures.clone();
469    for at in (0..elements.len()).rev() {
470        if let (true, Some(trunk)) = (measuring[at], elements.trunk[at]) {
471            measuring[trunk] = true;
472        }
473    }
474    let shaped = shaped(grove, elements, &measuring);
475    let _half = trace_span!("reach").entered();
476    let fallback = Location::default();
477    for at in (0..elements.len()).rev() {
478        if !measuring[at] {
479            continue;
480        }
481        let height = shaped[at].max(reach(grove, elements, &fallback, at));
482        if height != elements.intrinsic[at].height {
483            elements.intrinsic[at].height = height;
484            // The measure moved under an element nothing was written to, and a placement reading
485            // that measure has to be resolved against the new one. R2b runs after this and spreads
486            // it, which is why it is safe to find out here.
487            elements.dirty[at] = true;
488        }
489    }
490}

492/// How tall each element's own run turned out at the width R2a gave it.
493///
494/// In any order, because no element's answer is another's: this is the half of R2m that reaches into
495/// the world for a typeface and a run, and the only half that touches the shaping cache.
496///
497/// Shaping a run is what states that the run is still wanted, and the sweep drops what this frame did
498/// not state -- so on a frame that is going to sweep, every element is shaped whether or not it is
499/// measuring again. A frame where no run stopped being stated has nothing to sweep, and shapes only
500/// what it is measuring.
501fn shaped(grove: &mut Grove, elements: &Elements, measuring: &[bool]) -> Vec<f32> {
502    let _half = trace_span!("shaped").entered();
503    let mut shaped = vec![0.0; elements.len()];
504    for at in 0..elements.len() {
505        if !(measuring[at] || elements.restated) {
506            continue;
507        }
508        shaped[at] = wrapped(grove, elements.order[at], elements.section[at].width());
509    }
510    shaped
511}

513/// How tall `leaf`'s own run of glyphs is at `width`, or zero if it says nothing.
514fn wrapped(grove: &mut Grove, leaf: Leaf, width: f32) -> f32 {
515    let Grove {
516        tree,
517        fonts,
518        shaping,
519        layout,
520        short,
521        ..
522    } = grove;
523    let Some(typeface) = tree.typeface(leaf) else {
524        return 0.0;
525    };
526    let Some(value) = tree.lettering(leaf) else {
527        return 0.0;
528    };
529    let size = typeface.size.at(*layout, *short);
530    shaping
531        .shape(fonts, typeface.font, size, value)
532        .measure(width)
533}

535/// How far the elements grown under `leaf` reach below its top edge.
536///
537/// Only the children that describe their own extent are counted. One that reads a vertical box --
538/// a percentage of this element, a row of its grid, an anchor's edge -- is asking how tall
539/// something else is, so it cannot be what decides how tall this is. See
540/// [`Config::measurable`](crate::placement::role::Config::measurable).
541fn reach(grove: &Grove, elements: &Elements, fallback: &Location, at: usize) -> f32 {
542    let mut reach: f32 = 0.0;
543    for child in grove.tree.branched(elements.order[at]) {
544        let Some(child_at) = elements.at(child) else {
545            continue;
546        };
547        if !measurable(grove, child, fallback) {
548            continue;
549        }
550        let context = raised(elements, at, child_at);
551        reach = reach.max(
552            geometry(grove, child, fallback, &context, Axis::Vertical)
553                .0
554                .far,
555        );
556    }
557    reach
558}

560/// Whether `leaf`'s vertical placement describes its own extent, and so counts toward the measure
561/// of what it is grown under.
562///
563/// One question with two spellings, because a placement has two. A box asks it of its vertical
564/// configuration; a trace asks it of both of its ends, since either one reading a vertical box is
565/// enough to make the answer circular.
566fn measurable(grove: &Grove, leaf: Leaf, fallback: &Location) -> bool {
567    match grove.tree.traced(leaf) {
568        Some(traced) => traced.from.measurable() && traced.to.measurable(),
569        None => pinned(
570            grove.tree.location(leaf).unwrap_or(fallback),
571            grove,
572            Axis::Vertical,
573        )
574        .measurable(),
575    }
576}

578/// What one child resolves its vertical axis against while its trunk is being measured.
579///
580/// The same [`Context`] R2b will build, with every vertical reading taken as zero: no box on this
581/// axis has resolved yet, which is the point of measuring. Every horizontal reading is real, so a
582/// height stated in columns or read off a width still answers.
583fn raised(elements: &Elements, trunk: usize, child: usize) -> Context {
584    let flattened = |at: usize| {
585        let section = elements.section[at];
586        Basis {
587            section: Section::new(
588                Position::new(section.left(), 0.0),
589                Area::new(section.width(), 0.0),
590            ),
591            intrinsic: elements.intrinsic[at],
592            tracks: elements.tracks[at],
593            cell: elements.cell[at],
594        }
595    };
596    Context {
597        axis: Axis::Vertical,
598        own: Basis {
599            section: Section::default(),
600            intrinsic: elements.intrinsic[child],
601            tracks: Tracks::default(),
602            cell: elements.cell[child],
603        },
604        trunk: flattened(trunk),
605        anchor: match elements.anchor[child] {
606            Some(anchor) => flattened(anchor),
607            None => Basis::default(),
608        },
609    }
610}

612/// R3. How far each region's content reaches, from where its children landed.
613///
614/// Bottom-up, so a subtree is measured before whatever contains it. Two things are deliberately not
615/// consulted: what is currently drawn, because content scrolled out of sight is exactly what an
616/// extent describes and has to remain reachable; and the offset, because measuring against it would
617/// make the extent depend on the clamp that depends on the extent.
618///
619/// A child that scrolls in its own right contributes its box and not its content -- what overflows
620/// inside it is its own to reach, and is already reachable there.
621///
622/// A **visible child that is simply far away is content**, and is counted. That is the answer
623/// `views.md` gives to the parking footgun, and it is deliberately not a guess about intent: if it
624/// is visible and out there it is reachable, which is coherent where the old behaviour was a
625/// surprise. What removes a child from the extent is the app saying so -- [`visible(false)`] takes
626/// it and its subtree out, and [`pinned`] takes out something that is inside the region without
627/// travelling with it.
628///
629/// [`visible(false)`]: crate::Place::visible
630/// [`pinned`]: crate::Place::pinned
631fn extent(grove: &mut Grove, elements: &Elements) {
632    let _pass = trace_span!("extent").entered();
633    // The far corner of everything under an element, in absolute coordinates. Absent where the
634    // element was skipped, which is what keeps a hidden subtree out of what contains it.
635    let mut reach: Vec<Option<Position>> = vec![None; elements.len()];
636    for at in (0..elements.len()).rev() {
637        let leaf = elements.order[at];
638        // A hidden element is not content, and neither is anything under it: that is what makes
639        // hiding the whole answer for parking something out of the way, rather than half of one.
640        if !grove.tree.visible(leaf).0 {
641            continue;
642        }
643        let section = elements.section[at];
644        let mut far = Position::new(section.right(), section.bottom());
645        for child in grove.tree.branched(leaf) {
646            // The two ways an element grown inside a region is not part of its content, and each
647            // is left out here by the same one declaration that says the rest of what it means --
648            // which is what keeps the halves from disagreeing.
649            //
650            // A pinned child does not move with the content. A floating one moves with it but sits
651            // over the region rather than in it, so it is not content either: an overlay that
652            // invented room to scroll to is the scrollbar nobody ordered.
653            if grove.tree.pinned(child) || grove.tree.floats(child).is_some() {
654                continue;
655            }
656            let Some(child) = elements.at(child).and_then(|child| reach[child]) else {
657                continue;
658            };
659            far = Position::new(far.x.max(child.x), far.y.max(child.y));
660        }
661        if let Some(scroll) = grove.tree.scrolls(leaf) {
662            grove.tree.set_extent(leaf, reached(scroll, section, far));
663            far = Position::new(section.right(), section.bottom());
664        }
665        reach[at] = Some(far);
666    }
667}
668
669/// How far a region's content reaches, on each axis.
670///
671/// Three rules, and each of them is what stops a scrollbar nobody ordered:
672///
673/// - **only along a declared axis.** An axis the region does not scroll reads its own box and
674///   nothing else, so a child extending sideways out of a column that scrolls down is simply out of
675///   frame. Most accidental extent came from the axis nobody was scrolling.
676/// - **measured outward from the content origin, clamped at the near side.** A child at a negative
677///   offset creates no range to scroll *back* into: content above the origin is a layout mistake,
678///   and the previous behaviour turned it into a feature.
679/// - **never smaller than the region's own box**, so an empty region has a range of zero rather
680///   than a negative one.
681///
682fn reached(scroll: Scroll, section: Section, far: Position) -> Area {
683    let along = |axis: Axis, reach: f32, near: f32| {
684        let own = section.area.along(axis);
685        if !scroll.covers(axis) {
686            return own;
687        }
688        (reach - near).max(own)
689    };
690    Area::new(
691        along(Axis::Horizontal, far.x, section.left()),
692        along(Axis::Vertical, far.y, section.top()),
693    )
694}

696/// R4. Where each element is drawn: where the layout put it, less what its scrolling ancestors have
697/// moved.
698///
699/// A region's own box does not move under its own offset -- what moves is everything grown inside
700/// it. The offset is clamped here, against the extent R3 just measured, so a region whose content
701/// shrank under it comes back into range on the next frame rather than staying somewhere it can no
702/// longer reach.
703///
704/// The three ways a region is *asked* to move -- a coast still running from a release, a
705/// [`scroll`](crate::Grow::scroll) written this frame, and a
706/// [`Motion::Scroll`](crate::Motion::Scroll) part way through -- are answered first, here rather
707/// than where they were written, because all three need the extent and the extent is one pass old.
708fn scroll(grove: &mut Grove, elements: &mut Elements, ends: &[Option<Stretched>]) {
709    let _pass = trace_span!("scroll", coasting = grove.coasting.len()).entered();
710    view::asked(grove, elements);
711    let mut accumulated: Vec<Position> = vec![Position::default(); elements.len()];
712    // What a *pinned* child of each element receives, which is the accumulation with its nearest
713    // scrolling ancestor left out of it.
714    let mut unpinned: Vec<Position> = vec![Position::default(); elements.len()];
715    for at in 0..elements.len() {
716        let leaf = elements.order[at];
717        let placed = elements.section[at];
718        let trunk = elements.trunk[at];
719        let inherited = trunk.map(|trunk| accumulated[trunk]).unwrap_or_default();
720        let outside = trunk.map(|trunk| unpinned[trunk]).unwrap_or_default();
721        // A pinned element does not receive its nearest scrolling ancestor's offset, and receives
722        // every offset outside that one: pinning is relative to the region the element sits in and
723        // says nothing about what contains that region.
724        let applied = match grove.tree.pinned(leaf) {
725            true => outside,
726            false => inherited,
727        };
728        let drawn = Section::new(
729            Position::new(placed.left() - applied.x, placed.top() - applied.y),
730            placed.area,
731        );
732        elements.moved[at] |= grove.tree.settle(leaf, placed, drawn);
733        // A stroke's ends travel with its box, by the same offset, because they are the same
734        // geometry said two ways.
735        if let Some(stretched) = &ends[at] {
736            grove.tree.set_stretched(leaf, stretched.less(applied));
737        }
738        let (carried, escaped) = match grove.tree.scrolls(leaf) {
739            Some(scroll) => {
740                let clamped = clamp(grove, leaf, scroll, placed);
741                (
742                    Position::new(applied.x + clamped.x, applied.y + clamped.y),
743                    // A pinned child of this element is pinned to *this* region, so its offset is
744                    // the accumulation as it stood before this region's own.
745                    applied,
746                )
747            }
748            // Nothing here to be pinned against, so a pinned child of this element is pinned to
749            // whatever region contains it, exactly as a pinned sibling of this element would be.
750            None => (applied, outside),
751        };
752        accumulated[at] = carried;
753        unpinned[at] = escaped;
754    }
755}
756
757/// A region's offset, held to what it can actually reach.
758///
759/// An axis that was not declared does not scroll, so nothing can have moved along it -- and a
760/// region whose extent shrank under it is brought back into range here rather than left somewhere
761/// it can no longer get to.
762fn clamp(grove: &mut Grove, leaf: Leaf, scroll: Scroll, placed: Section) -> Position {
763    let offset = grove.tree.offset(leaf);
764    let extent = grove.tree.extent(leaf);
765    let mut clamped = Position::default();
766    for axis in Axis::BOTH {
767        if scroll.covers(axis) {
768            clamped = clamped.set(
769                axis,
770                offset
771                    .along(axis)
772                    .clamp(0.0, range(extent, placed.area, axis)),
773            );
774        }
775    }
776    if clamped != offset {
777        grove.tree.set_offset(leaf, clamped);
778    }
779    clamped
780}

782/// R5. What a scrolling ancestor leaves visible of each element.
783///
784/// A rect, and nothing else. A region does not clip itself, only what is grown inside it, and an
785/// element with no scrolling ancestor is clipped by nothing at all. Whether an element is *culled*
786/// is extraction's decision from this rect, and is never recorded on the element -- so there is no
787/// state saying "currently clipped away" for anything else, extent first among them, to read.
788fn clip(grove: &mut Grove, elements: &mut Elements) {
789    let _pass = trace_span!("clip").entered();
790    let unbounded = Clipped::unbounded().0;
791    let mut passed: Vec<Section> = vec![unbounded; elements.len()];
792    // What a *floating* child of each element is clipped to, which is the intersection with its
793    // nearest scrolling ancestor's own rect left out of it. The same second accumulation R4 carries
794    // for a pinned child, and for the same reason: both say "not part of this region", and both
795    // have to say it about the region the element is actually in rather than about all of them.
796    let mut escaped: Vec<Section> = vec![unbounded; elements.len()];
797    for at in 0..elements.len() {
798        let leaf = elements.order[at];
799        let trunk = elements.trunk[at];
800        let inherited = trunk.map(|trunk| passed[trunk]).unwrap_or(unbounded);
801        let outside = trunk.map(|trunk| escaped[trunk]).unwrap_or(unbounded);
802        // A floating element is positioned outside the region on purpose, so cutting it off at the
803        // region's edge would undo the placement that put it there. How far out it reaches is the
804        // element's own statement, because no one answer is right everywhere.
805        let applied = match grove.tree.floats(leaf) {
806            // Held by whatever holds the region it left.
807            Some(Escape::Region) => outside,
808            // Held by nothing, which extraction reads as the surface: a clip is never wider than
809            // what is being drawn on.
810            Some(Escape::Surface) => unbounded,
811            // Held by the element named, which is what that element passes down to what it holds.
812            Some(Escape::Within(named)) => match within(elements, &passed, at, named) {
813                Some(clip) => clip,
814                // Named something that is not above it, so it holds nothing. Falling back to the
815                // near answer rather than the far one: an element escapes no further than it was
816                // told to, and a mis-named ancestor is not permission to leave everything.
817                None => outside,
818            },
819            None => inherited,
820        };
821        elements.moved[at] |= grove.tree.set_clip(leaf, applied);
822        let scrolls = grove.tree.scrolls(leaf).is_some();
823        passed[at] = match scrolls {
824            true => applied.intersect(grove.tree.drawn(leaf)),
825            false => applied,
826        };
827        escaped[at] = match scrolls {
828            true => applied,
829            false => outside,
830        };
831    }
832}
833
834/// What `named` leaves visible of what it holds, if it is above `leaf` at all.
835///
836/// The walk is up the trunks from `leaf`, so an element that names something beside it rather than
837/// above it gets `None` and is answered as though it had named the region it is in. Naming the
838/// element rather than counting regions is what makes this survive a wrapper being added between
839/// the two, which a count would not.
840fn within(elements: &Elements, passed: &[Section], at: usize, named: Leaf) -> Option<Section> {
841    let named = elements.at(named)?;
842    let mut step = elements.trunk[at];
843    while let Some(above) = step {
844        // An ancestor resolves before what hangs off it, so one found here has already passed its
845        // own clip down and the read is never of a position the pass has yet to reach.
846        if above == named {
847            return Some(passed[above]);
848        }
849        step = elements.trunk[above];
850    }
851    None
852}

854/// R7. The three off-states, resolved over each element's whole ancestry.
855///
856/// One walk, in the same order the axes used, which puts every trunk before what hangs off it.
857/// Nothing has a cascade to write: an element grown under a disabled trunk is disabled on its first
858/// frame because the pass does not care when it arrived, and enabling that trunk leaves anything
859/// disabled in its own right disabled because the product is over the whole ancestry rather than a
860/// single bit that was overwritten on the way down.
861fn inherit(grove: &mut Grove, elements: &mut Elements) {
862    let _pass = trace_span!("inherit").entered();
863    let mut products: Vec<Inherited> = vec![Inherited::default(); elements.len()];
864    for at in 0..elements.len() {
865        let leaf = elements.order[at];
866        let trunk = elements.trunk[at]
867            .map(|trunk| products[trunk])
868            .unwrap_or_default();
869        let product = Inherited::under(
870            trunk,
871            grove.tree.visible(leaf),
872            grove.tree.opacity(leaf),
873            grove.tree.disabled(leaf),
874        );
875        products[at] = product;
876        elements.moved[at] |= grove.tree.set_inherited(leaf, product);
877    }
878}

880/// R8. The box stack the next frame's dispatch reads.
881///
882/// Membership is universal: an element is here because it is there. What is left out is only what
883/// is not there at all -- hidden, fully transparent, or clipped away by a region it sits inside.
884/// `intangible` is not a way out of the stack; it is carried on the region and decides what may be
885/// the top of it.
886fn regions(grove: &mut Grove, elements: &Elements) {
887    let _pass = trace_span!("regions").entered();
888    let mut ranked = Vec::with_capacity(elements.len());
889    for &leaf in &elements.order {
890        let inherited = grove.tree.inherited(leaf);
891        if !inherited.present() {
892            continue;
893        }
894        let section = grove.tree.drawn(leaf);
895        let clip = grove.tree.clip(leaf);
896        if section.intersect(clip).is_empty() {
897            continue;
898        }
899        let gestures = grove.tree.gestures(leaf);
900        ranked.push((
901            grove.tree.rank(leaf),
902            Region {
903                leaf,
904                section,
905                clip,
906                shape: gestures.shape,
907                tangible: !gestures.intangible,
908                receives: gestures.receives,
909                disabled: inherited.disabled,
910            },
911        ));
912    }
913    grove.stack.settle(ranked);
914}

916/// R6. Declared elevation accumulates down the tree, and allocation order settles what it leaves
917/// equal.
918///
919/// One walk in the same dependency order the axes used, which puts every trunk before what hangs
920/// off it. Nothing here reads a box: where an element sits in the stack has nothing to do with
921/// where it sits on the surface.
922fn rank(grove: &mut Grove, elements: &mut Elements) {
923    let _pass = trace_span!("rank").entered();
924    let mut stacks: Vec<i32> = vec![0; elements.len()];
925    for at in 0..elements.len() {
926        let leaf = elements.order[at];
927        let trunk = elements.trunk[at]
928            .map(|trunk| stacks[trunk])
929            .unwrap_or_default();
930        let stack = grove.tree.elevation(leaf).accumulate(trunk);
931        stacks[at] = stack;
932        elements.moved[at] |= grove.tree.set_rank(
933            leaf,
934            ResolvedElevation {
935                stack,
936                growth: grove.tree.growth(leaf).0,
937            },
938        );
939    }
940}

942/// Everything one axis of the element at `at` resolves against.
943fn context(elements: &Elements, viewport: Section, at: usize, axis: Axis) -> Context {
944    Context {
945        axis,
946        // Its box is the answer being computed, and its own grid divides it for its children
947        // rather than for itself, so neither is readable here.
948        own: Basis {
949            section: Section::default(),
950            intrinsic: elements.intrinsic[at],
951            tracks: Tracks::default(),
952            cell: elements.cell[at],
953        },
954        // A top-level element has no trunk, and fills the viewport instead.
955        trunk: basis(elements, elements.trunk[at], viewport, axis),
956        // A placement that reads an anchor it has not been given resolves against a zero box.
957        anchor: basis(elements, elements.anchor[at], Section::default(), axis),
958    }
959}

961/// What the element at `at` offers a placement reading it, or `fallback` in place of a box when
962/// there is no such element or it has not resolved yet.
963///
964/// **A resolved box offers no vertical reading on the horizontal axis.** R2a runs before any height
965/// is known, so a box it offers is flattened to the horizontal -- which is what one held anyway when
966/// every element was resolved every frame, and what it has to go on holding now that an element
967/// nothing wrote to comes into the pass carrying the whole of last frame's box.
968///
969/// The fallback is not flattened, because it is not a resolved box: the viewport a top-level element
970/// fills is as tall on this axis as on the other one.
971fn basis(elements: &Elements, at: Option<usize>, fallback: Section, axis: Axis) -> Basis {
972    let Some(at) = at else {
973        return Basis {
974            section: fallback,
975            ..Basis::default()
976        };
977    };
978    Basis {
979        section: match (elements.resolved[at], axis) {
980            (true, Axis::Horizontal) => {
981                let section = elements.section[at];
982                Section::new(
983                    Position::new(section.left(), 0.0),
984                    Area::new(section.width(), 0.0),
985                )
986            }
987            (true, Axis::Vertical) => elements.section[at],
988            (false, _) => fallback,
989        },
990        intrinsic: elements.intrinsic[at],
991        tracks: elements.tracks[at],
992        cell: elements.cell[at],
993    }
994}

996/// The frame's one read of the tree: every live element, ordered so that nothing resolves before
997/// what it depends on, with what it depends on and what it offers read out beside it.
998///
999/// An anchor may point anywhere -- a later sibling, a cousin, an element in another subtree -- so
1000/// this is ordered by dependency rather than by tree depth: an element resolves after its parent
1001/// *and* after whatever it anchors to.
1002///
1003/// A chain of anchors cannot close on itself, because one that would is refused where it is written.
1004/// A trunk and an anchor still can, between them: an element anchored to something grown under it
1005/// waits on a box that is waiting on its own. That is not the same contradiction -- both boxes
1006/// resolve, just not both against a settled other -- so the remainder is ordered by allocation order
1007/// and resolves against what its dependency last was. **Every live element is in the order**, which
1008/// is the property the passes downstream rely on: an element left out would have no box, no rank and
1009/// no place in the stack, and nothing would say so.
1010///
1011/// Each element is asked what it depends on exactly once here, and every position after that is
1012/// arithmetic on the answer.
1013///
1014/// Kept between frames and repaired rather than built again. The order is what the elements and the
1015/// edges between them make, and only growing, withering and anchoring change those -- so an ordinary
1016/// frame reads none of it, and rebuilds only the columns of the elements it is going to resolve.
1017fn structure(elements: &mut Elements, grove: &Grove) {
1018    let _pass = trace_span!("structure").entered();
1019    let tree = &grove.tree;
1020    let leaves = tree.leaves();
1021    let count = leaves.len();
1022    // Where each element sits among the leaves, and below -- once the order is known -- where it
1023    // sits in the order. Re-pointed rather than rebuilt, so a frame builds one map and not two.
1024    let mut index: HashMap<Leaf, usize> = HashMap::with_capacity(count);
1025    for (at, &leaf) in leaves.iter().enumerate() {
1026        index.insert(leaf, at);
1027    }
1028    // What each element waits on, and how many of those have yet to resolve. An element the leaves
1029    // do not hold is not live, since the leaves are what the world has grown, and a dependency on
1030    // something not live is no dependency at all.
1031    let mut depends: Vec<[Option<usize>; 2]> = Vec::with_capacity(count);
1032    let mut waiting: Vec<u8> = Vec::with_capacity(count);
1033    // Everything waiting on each element, as one run per element in a single array: an element
1034    // depends on at most two others, so the whole graph fits in one allocation rather than in a
1035    // vector per element.
1036    let mut runs: Vec<u32> = vec![0; count + 1];
1037    for &leaf in &leaves {
1038        let on = [tree.trunk(leaf), tree.anchor(leaf)]
1039            .map(|on| on.and_then(|on| index.get(&on).copied()));
1040        let mut unresolved = 0;
1041        for at in on.into_iter().flatten() {
1042            unresolved += 1;
1043            runs[at + 1] += 1;
1044        }
1045        depends.push(on);
1046        waiting.push(unresolved);
1047    }
1048    for at in 0..count {
1049        runs[at + 1] += runs[at];
1050    }
1051    let mut filling = runs.clone();
1052    let mut dependents: Vec<u32> = vec![0; runs[count] as usize];
1053    for (at, on) in depends.iter().enumerate() {
1054        for &upon in on.iter().flatten() {
1055            dependents[filling[upon] as usize] = at as u32;
1056            filling[upon] += 1;
1057        }
1058    }
1059    // Kahn's, with the order under construction serving as its own queue.
1060    let mut order: Vec<usize> = (0..count).filter(|at| waiting[*at] == 0).collect();
1061    let mut next = 0;
1062    while next < order.len() {
1063        let at = order[next];
1064        next += 1;
1065        for &dependent in &dependents[runs[at] as usize..runs[at + 1] as usize] {
1066            let dependent = dependent as usize;
1067            waiting[dependent] -= 1;
1068            if waiting[dependent] == 0 {
1069                order.push(dependent);
1070            }
1071        }
1072    }
1073    if order.len() != count {
1074        order.extend((0..count).filter(|at| waiting[*at] != 0));
1075    }
1076    // Where each element ended up, which is what every position held below is in.
1077    let mut ranked: Vec<usize> = vec![0; count];
1078    for (position, &at) in order.iter().enumerate() {
1079        ranked[at] = position;
1080    }
1081    for position in index.values_mut() {
1082        *position = ranked[*position];
1083    }
1084    // The positions all moved, so every column is read out of the tree again. What resolution
1085    // settled is on the elements themselves -- `scatter` and R4 put it there -- so this is a read of
1086    // last frame's answers into this frame's order, and not a loss of them.
1087    elements.order.clear();
1088    elements.trunk.clear();
1089    elements.anchor.clear();
1090    elements.section.clear();
1091    elements.intrinsic.clear();
1092    elements.cell.clear();
1093    elements.chlorophyll.clear();
1094    elements.index = index;
1095    for &at in &order {
1096        let leaf = leaves[at];
1097        let [trunk, anchor] = depends[at];
1098        elements.order.push(leaf);
1099        elements.trunk.push(trunk.map(|on| ranked[on]));
1100        elements.anchor.push(anchor.map(|on| ranked[on]));
1101        elements.chlorophyll.push(tree.chlorophyll(leaf));
1102        elements.section.push(tree.placed(leaf));
1103        elements.intrinsic.push(tree.intrinsic(leaf));
1104        elements.cell.push(tree.cell(leaf));
1105    }
1106    elements.tracks.resize(count, Tracks::default());
1107    elements.tracks.truncate(count);
1108}
1109
1110/// What this frame has to resolve, and what it may leave alone.
1111///
1112/// An element resolves again if it was written to, or if what it hangs off or is anchored to does.
1113/// That closure is one walk of the order rather than a search, because the order already puts a
1114/// dependency before what depends on it.
1115///
1116/// Where most of the tree was written to, working out what to leave alone costs more than resolving
1117/// it does: a lookup for every element, three columns for the passes to read, and a skip that almost
1118/// never takes. Past a quarter it is cheaper to resolve everything, and the whole of the closure
1119/// falls away with one branch.
1120fn read(elements: &mut Elements, grove: &Grove) {
1121    let _pass = trace_span!("elements").entered();
1122    let written = grove.tree.written();
1123    if written.restructured {
1124        structure(elements, grove);
1125    }
1126    let count = elements.order.len();
1127    let all = written.all || written.declared.len() * 4 >= count;
1128    elements.restated = written.restated;
1129    elements.dirty.clear();
1130    elements.measures.clear();
1131    elements.resolved.clear();
1132    elements.moved.clear();
1133    for at in 0..count {
1134        let leaf = elements.order[at];
1135        // A dependency the order could not put first is one a cycle left in the remainder, and it
1136        // has no answer yet. Resolving such an element is the same fallback the rest of resolution
1137        // gives it: it is answered against what its dependency last was, so it is answered again.
1138        let decided = |on: Option<usize>| {
1139            on.is_some_and(|on| elements.dirty.get(on).copied().unwrap_or(true))
1140        };
1141        let dirty = all
1142            || written.declared.contains(&leaf)
1143            || decided(elements.trunk[at])
1144            || decided(elements.anchor[at]);
1145        elements.dirty.push(dirty);
1146        elements.moved.push(dirty);
1147        elements
1148            .measures
1149            .push(dirty || written.measures.contains(&leaf));
1150        // A clean element offers the box it settled at, and offers it from the start, because
1151        // nothing this frame is going to compute it again. One being resolved again offers nothing
1152        // until an axis reaches it, which is what it did when every element was resolved.
1153        elements.resolved.push(!dirty);
1154        // The grid is divided at the breakpoint in force, so it is read again wherever the element
1155        // is -- a breakpoint that moved is every element written to, and nothing else can change a
1156        // division without writing the grid it divides.
1157        if dirty {
1158            elements.tracks[at] = grove
1159                .tree
1160                .grid(leaf)
1161                .unwrap_or_default()
1162                .tracks(grove.layout, grove.short);
1163        }
1164    }
1165}
