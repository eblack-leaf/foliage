1//! Elm -- change extraction.
2//!
3//! # Rowan recomputes. Elm decides what changed.
4//!
5//! Step 8, and the reason recomputing everything costs nothing downstream. Every renderer keeps what
6//! the backend is holding and compares this frame's resolved values against it, so an element that
7//! did not change costs one comparison and no upload.
8//!
9//! The cache is *what the backend holds*, not what the element last was. That is what makes a
10//! skipped frame unable to lose a change: there is no flag to miss, only a value that still differs
11//! at the next comparison. It is also a contract on the backend, which has to apply every batch it
12//! is handed -- a dropped batch leaves the cache claiming something the backend does not have, and
13//! nothing afterwards will correct it.
14//!
15//! # What is compared is not always what is uploaded
16//!
17//! A [`Panel`](crate::Panel) and a [`Polygon`](crate::Polygon) are described entirely in logical
18//! pixels, so one value is both what is compared here and what the vertex buffer holds. The other
19//! four are not, and each for the same reason: turning what the element declares into what the GPU
20//! draws needs the display's density, and the density stops at the backend
21//! ([`Ginkgo`](crate::ginkgo)).
22//!
23//! | | declares | the backend derives |
24//! |---|---|---|
25//! | [`Text`](crate::Text) | cells and characters | the cut ink, snapped to device pixels |
26//! | [`Line`](crate::Line) | two ends and a weight | four corners, axis-aligned ones snapped |
27//! | [`Icon`](crate::Icon) | a box and a field | the sheet rect, and the field's screen-space range |
28//! | [`Image`](crate::Image) | a box and a plate | which texture to bind |
29//!
30//! So extraction is written in logical pixels throughout and compares logical values, and the
31//! derivation happens once per written instance rather than once per frame.
32//!
33//! # What is not looked at
34//!
35//! An element resolution did not move is not visited: what the backend holds for it is what it
36//! should go on holding. So what the backend is told to let go of is said outright, and there are
37//! exactly two ways to earn it -- an element that moved and is not painted any more (hidden, culled,
38//! or drawing an asset that has not arrived), and an element that withered, which resolution
39//! reports when it builds the order again. A frame that moves nothing does nothing here.

61/// Which renderer an element carries, and so which instances it is gathered into.
62///
63/// Decided when the element is described and never afterwards: what an element draws is part of
64/// what it is, and one that is to draw something else is a different element. Nothing writes this
65/// -- there is no op that can, and the only place it is set is where the element is grown.
66///
67/// Extraction walks the tree once and routes on this, so a further renderer costs a variant rather
68/// than a pass over everything. It is the *only* thing that says what an element is: a set of
69/// declarations that happens to look like a panel is not a panel.
70#[derive(Copy, Clone, Debug, Default, PartialEq, Eq)]
71pub(crate) enum Chlorophyll {
72    /// Nothing. Carrying no renderer is the whole of what makes an element a [`Stem`](crate::Stem).
73    #[default]
74    None,
75    /// A filled rectangle.
76    Panel,
77    /// A run of monospaced glyphs.
78    Text,
79    /// A filled regular polygon.
80    Polygon,
81    /// A straight stroke between two points.
82    Line,
83    /// A vector mark, from a distance field.
84    Icon,
85    /// A picture, fitted into its box.
86    Image,
87}

138/// What the backend is holding, one set per renderer.
139#[derive(Default)]
140pub(crate) struct Elm {
141    pub(crate) panels: Instances<PanelInstance>,
142    pub(crate) polygons: Instances<PolygonInstance>,
143    pub(crate) lines: Instances<LineInstance>,
144    pub(crate) icons: Instances<IconInstance>,
145    pub(crate) images: Instances<ImageInstance>,
146    /// Pictures whose pixels were replaced since the last batch, in name order and each once.
147    ///
148    /// The one change to what is drawn that no instance can state: an image's instance names its
149    /// picture rather than holding it, so new pixels under the same name, at the same shape, leave
150    /// every instance drawing them exactly as it was. Said here instead, so the backend replaces
151    /// whatever it holds under the name.
152    pub(crate) refilled: Vec<Plate>,
153    pub(crate) texts: Runs,
154    /// Where one run's glyphs are gathered before they are compared against what is held. Kept
155    /// between frames for its capacity, and reused by every run in turn: a frame that changes
156    /// nothing must not allocate.
157    glyphs: Vec<Glyph>,
158    /// Whether the backend was let go of, so the next extraction has nothing to compare against and
159    /// states every element rather than only what moved.
160    recut: bool,
161}
162
163impl Elm {
164    /// How much this frame's batch moves, across every renderer. Reported to the trace, and the one
165    /// number that says whether an unchanged frame really cost nothing.
166    pub(crate) fn moved(&self) -> (usize, usize) {
167        let written = self.panels.written.len()
168            + self.polygons.written.len()
169            + self.lines.written.len()
170            + self.icons.written.len()
171            + self.images.written.len()
172            + self.texts.written.len();
173        let withdrawn = self.panels.withdrawn.len()
174            + self.polygons.withdrawn.len()
175            + self.lines.withdrawn.len()
176            + self.icons.withdrawn.len()
177            + self.images.withdrawn.len()
178            + self.texts.withdrawn.len();
179        (written, withdrawn)
180    }
181
182    /// Opens an extraction on every renderer, dropping what the last one reported.
183    fn open(&mut self) {
184        self.panels.open();
185        self.polygons.open();
186        self.lines.open();
187        self.icons.open();
188        self.images.open();
189        self.texts.open();
190    }
191
192    /// Closes an extraction on every renderer.
193    fn close(&mut self) {
194        self.panels.close();
195        self.polygons.close();
196        self.lines.close();
197        self.icons.close();
198        self.images.close();
199        self.texts.close();
200    }
201
202    /// Lets go of whatever the backend holds for `leaf`, in the renderer it draws with.
203    fn withdraw(&mut self, chlorophyll: Chlorophyll, leaf: Leaf) {
204        let key = Key::from(leaf);
205        match chlorophyll {
206            Chlorophyll::None => {}
207            Chlorophyll::Panel => self.panels.withdraw(key),
208            Chlorophyll::Polygon => self.polygons.withdraw(key),
209            Chlorophyll::Line => self.lines.withdraw(key),
210            Chlorophyll::Icon => self.icons.withdraw(key),
211            Chlorophyll::Image => self.images.withdraw(key),
212            Chlorophyll::Text => self.texts.withdraw(key),
213        }
214    }
215
216    /// Drops everything the backend is held to, so the next extraction writes the tree entire.
217    ///
218    /// Two things invalidate a comparison against what the backend holds, and both are facts about
219    /// the backend rather than about any element:
220    ///
221    /// - **The density changed.** The backend's copy is in device pixels and this one is not, so a
222    ///   display whose density changed leaves every derived instance -- a cut glyph, a snapped
223    ///   stroke, a field's screen-space range -- correct against a density that is gone, while the
224    ///   logical values they came from are unchanged and compare equal forever. The backend is kept,
225    ///   so it lets go of what it holds in the same breath ([`Ash::recut`](crate::ash::Ash::recut)),
226    ///   or an element that stopped being drawn in the frame this lands in would go on being drawn:
227    ///   with nothing held here for it, nothing would name it to be let go of.
228    /// - **The backend was rebuilt.** A platform that took its surface back and gave another one --
229    ///   an Android activity leaving the foreground and returning -- leaves a cache describing
230    ///   buffers that no longer exist. Every value would compare equal and nothing would be
231    ///   uploaded, against renderers holding nothing.
232    ///
233    /// Total rather than per renderer, because neither the density nor the device is any
234    /// renderer's.
235    ///
236    /// The next extraction states every element rather than only what moved, because after this
237    /// there is nothing held for anything to have moved against.
238    pub(crate) fn recut(&mut self) {
239        self.recut = true;
240        self.panels.forget();
241        self.polygons.forget();
242        self.lines.forget();
243        self.icons.forget();
244        self.images.forget();
245        self.texts.forget();
246    }
247}

249/// One glyph of a run: the cell it occupies, which character occupies it, and what it is filled
250/// with.
251///
252/// The cell is in logical pixels and already offset by the run's own box, because where a character
253/// lands is what wrapping decided and wrapping is the engine's. Where the *ink* sits inside that
254/// cell is not here: that is the rasteriser's, which is the only thing that knows what shape it made
255/// and at what density it made it.
256///
257/// The colour is per glyph because a [`tint`](crate::Grow::tint) is a fill over a range of the run's
258/// own index space. A run with no tints resolves the same colour for every one of them, which costs
259/// the comparison it would have cost anyway.
260#[derive(Copy, Clone, Debug, PartialEq)]
261pub(crate) struct Glyph {
262    pub(crate) cell: Section,
263    pub(crate) character: char,
264    pub(crate) color: Color,
265}
266
267/// The runs, and every glyph of each.
268///
269/// Deliberately not an [`Instances`]: a run is **one** entry in the one stack whose renderer holds
270/// many things under it, and that is the whole difference. What is diffed here is the run entire --
271/// its glyphs, its face, its rank and its clip -- because a run's glyphs move, refill and restack
272/// together, and finding which of them changed would cost more than rewriting the run.
273#[derive(Default)]
274pub(crate) struct Runs {
275    held: Named<Key, Run>,
276    /// Runs the backend holds at something other than what is now wanted, or does not hold at all.
277    /// Keys rather than values: what the backend is to apply is what is held for them, which it
278    /// reads back at [`run`](Runs::run).
279    pub(crate) written: Vec<Key>,
280    /// Runs the backend holds and should not, in a stable order.
281    pub(crate) withdrawn: Vec<Key>,
282}
283
284/// One run, as the backend is to hold it.
285pub(crate) struct Run {
286    /// Every glyph that leaves ink, in reading order. A space advances the wrap and is not one.
287    pub(crate) glyphs: Vec<Glyph>,
288    /// Which face the glyphs are cut from, and at what size. The backend rasterises against these,
289    /// so they are part of what the run is rather than of how it was measured.
290    pub(crate) font: Font,
291    pub(crate) size: u32,
292    pub(crate) rank: ResolvedElevation,
293    pub(crate) clip: Section,
294}
295
296impl Runs {
297    /// Opens an extraction, dropping what the last one reported.
298    fn open(&mut self) {
299        self.written.clear();
300        self.withdrawn.clear();
301    }
302
303    /// Takes one run as it now stands, and reports it written if the backend is holding it
304    /// otherwise.
305    fn want(
306        &mut self,
307        key: Key,
308        rank: ResolvedElevation,
309        clip: Section,
310        font: Font,
311        size: u32,
312        glyphs: &[Glyph],
313    ) {
314        match self.held.get_mut(&key) {
315            Some(held) => {
316                if held.font == font
317                    && held.size == size
318                    && held.rank == rank
319                    && held.clip == clip
320                    && held.glyphs == glyphs
321                {
322                    return;
323                }
324                held.font = font;
325                held.size = size;
326                held.rank = rank;
327                held.clip = clip;
328                // Rewritten in place, so a run that changed costs its own glyphs and no allocation.
329                held.glyphs.clear();
330                held.glyphs.extend_from_slice(glyphs);
331            }
332            None => {
333                self.held.insert(
334                    key,
335                    Run {
336                        glyphs: glyphs.to_vec(),
337                        font,
338                        size,
339                        rank,
340                        clip,
341                    },
342                );
343            }
344        }
345        self.written.push(key);
346    }
347
348    /// Lets go of a run, if the backend is holding one.
349    fn withdraw(&mut self, key: Key) {
350        if self.held.remove(&key).is_some() {
351            self.withdrawn.push(key);
352        }
353    }
354
355    /// Closes the extraction.
356    fn close(&mut self) {
357        // Two identical runs have to extract identically, whatever order what went was found in.
358        self.withdrawn.sort();
359    }
360
361    /// Drops what the backend is held to. See [`Elm::recut`].
362    fn forget(&mut self) {
363        self.held.clear();
364    }
365
366    /// What is held for one run, which is what the backend is to be holding for it.
367    pub(crate) fn run(&self, key: Key) -> Option<&Run> {
368        self.held.get(&key)
369    }
370
371    /// Every run held, which is every run the backend is to be holding: the whole of what the frame
372    /// draws in glyphs.
373    pub(crate) fn keys(&self) -> impl Iterator<Item = Key> + '_ {
374        self.held.keys().copied()
375    }
376}

378/// What one instance is held under.
379///
380/// A plain number, and deliberately not a [`Leaf`]. An element is one of these -- its name's own
381/// bits -- and so is a glyph inside a run, so a renderer whose element draws *many* things keeps its
382/// own [`Instances`] under its own numbering and hands the one stack a single entry. Nothing about
383/// holding, diffing or uploading has to know which of the two it is looking at.
384#[derive(Copy, Clone, PartialEq, Eq, Hash, PartialOrd, Ord, Debug)]
385pub(crate) struct Key(pub(crate) u64);
386
387impl From<Leaf> for Key {
388    fn from(leaf: Leaf) -> Self {
389        Self(leaf.id())
390    }
391}
392
393impl Key {
394    /// The index of the name it is the bits of, which is its low half: dense, since an index that
395    /// went is the next one handed out.
396    fn index(self) -> usize {
397        self.0 as u32 as usize
398    }
399}

401/// What is held for each key, in a slot per name's index rather than in a hash table.
402///
403/// The indices in use are dense, so the table is as long as the most names live at once. A lookup
404/// is an index rather than a hash -- and a walk over the order, which is mostly the order things
405/// were grown in, walks the table nearly in step rather than all over it. A slot holds the whole
406/// key, so a name grown into an index something withered from is never taken for it.
407pub(crate) struct Table<V> {
408    slots: Vec<Option<(Key, V)>>,
409    len: usize,
410}
411
412impl<V> Default for Table<V> {
413    fn default() -> Self {
414        Self {
415            slots: Vec::new(),
416            len: 0,
417        }
418    }
419}
420
421impl<V> Table<V> {
422    pub(crate) fn get(&self, key: Key) -> Option<&V> {
423        match self.slots.get(key.index())? {
424            Some((held, value)) if *held == key => Some(value),
425            _ => None,
426        }
427    }
428
429    pub(crate) fn get_mut(&mut self, key: Key) -> Option<&mut V> {
430        match self.slots.get_mut(key.index())? {
431            Some((held, value)) if *held == key => Some(value),
432            _ => None,
433        }
434    }
435
436    /// Holds `value` under `key`, and hands back what another name was holding in its slot: one
437    /// that withered with nothing yet said about it, whose index `key` was grown into. The caller
438    /// lets that go as it would anything withdrawn.
439    pub(crate) fn insert(&mut self, key: Key, value: V) -> Option<(Key, V)> {
440        let at = key.index();
441        if at >= self.slots.len() {
442            self.slots.resize_with(at + 1, || None);
443        }
444        match self.slots[at].replace((key, value)) {
445            None => {
446                self.len += 1;
447                None
448            }
449            Some((held, _)) if held == key => None,
450            displaced => displaced,
451        }
452    }
453
454    pub(crate) fn remove(&mut self, key: Key) -> Option<V> {
455        let slot = self.slots.get_mut(key.index())?;
456        if !slot.as_ref().is_some_and(|(held, _)| *held == key) {
457            return None;
458        }
459        self.len -= 1;
460        slot.take().map(|(_, value)| value)
461    }
462
463    pub(crate) fn clear(&mut self) {
464        self.slots.clear();
465        self.len = 0;
466    }
467
468    pub(crate) fn len(&self) -> usize {
469        self.len
470    }
471}

473/// One renderer's instances: what the backend holds, and the difference the last extraction found.
474///
475/// Generic over the instance, because what a renderer sends is the renderer's own business. This
476/// owns the comparison and knows nothing about what is being compared.
477///
478/// The rank is the one thing every renderer has in common, so it is carried here rather than
479/// inside each renderer's instance: where an element sits in the one stack is a fact about the
480/// element, not about what it happens to draw, and the backend needs it in a different form from
481/// the one the resolver produced. Keeping it out is also what leaves an instance free to be
482/// exactly the bytes a vertex buffer takes, for the renderers whose instance is those bytes.
483pub(crate) struct Instances<I> {
484    held: Table<Held<I>>,
485    /// Instances the backend does not hold, or holds at a different value or rank.
486    pub(crate) written: Vec<Stacked<I>>,
487    /// Instances the backend holds and should not, in a stable order.
488    pub(crate) withdrawn: Vec<Key>,
489}
490
491/// One instance, where in the one stack it is to be drawn, and what it is clipped to.
492///
493/// The clip is beside the instance rather than inside it for the same reason the rank is: it is not
494/// the renderer's data. It says where the backend is allowed to paint, which is a property of the
495/// region the element sits in, and the backend applies it to the pass rather than to the panel.
496#[derive(Copy, Clone, Debug)]
497pub(crate) struct Stacked<I> {
498    pub(crate) key: Key,
499    pub(crate) rank: ResolvedElevation,
500    pub(crate) clip: Section,
501    pub(crate) instance: I,
502}
503
504/// One instance the backend holds.
505struct Held<I> {
506    instance: I,
507    rank: ResolvedElevation,
508    clip: Section,
509}
510
511impl<I> Default for Instances<I> {
512    fn default() -> Self {
513        Self {
514            held: Table::default(),
515            written: Vec::new(),
516            withdrawn: Vec::new(),
517        }
518    }
519}
520
521impl<I: Copy + PartialEq> Instances<I> {
522    /// Opens an extraction, dropping what the last one reported.
523    fn open(&mut self) {
524        self.written.clear();
525        self.withdrawn.clear();
526    }
527
528    /// States one instance as it now stands -- at the rank it resolved to and inside the clip it
529    /// resolved under -- and reports it written if the backend is holding it otherwise.
530    ///
531    /// The holding is updated in place, so a frame that rewrites an instance allocates nothing, and
532    /// one that states it at what is already held writes nothing.
533    fn want(&mut self, key: impl Into<Key>, rank: ResolvedElevation, clip: Section, instance: I) {
534        let key = key.into();
535        match self.held.get_mut(key) {
536            Some(held) => {
537                if held.instance == instance && held.rank == rank && held.clip == clip {
538                    return;
539                }
540                held.instance = instance;
541                held.rank = rank;
542                held.clip = clip;
543            }
544            None => {
545                let held = Held {
546                    instance,
547                    rank,
548                    clip,
549                };
550                if let Some((displaced, _)) = self.held.insert(key, held) {
551                    self.withdrawn.push(displaced);
552                }
553            }
554        }
555        self.written.push(Stacked {
556            key,
557            rank,
558            clip,
559            instance,
560        });
561    }
562
563    /// Lets go of an instance, if the backend is holding one.
564    fn withdraw(&mut self, key: Key) {
565        if self.held.remove(key).is_some() {
566            self.withdrawn.push(key);
567        }
568    }
569
570    /// Closes the extraction.
571    fn close(&mut self) {
572        // Two identical runs have to extract identically, whatever order what went was found in.
573        self.withdrawn.sort();
574    }
575
576    /// Drops what the backend is held to. See [`Elm::recut`].
577    fn forget(&mut self) {
578        self.held.clear();
579    }
580
581    /// How many instances the backend is holding.
582    #[allow(unused)]
583    pub(crate) fn len(&self) -> usize {
584        self.held.len()
585    }
586
587    /// What the backend is holding for `key`.
588    #[allow(unused)]
589    pub(crate) fn holding(&self, key: impl Into<Key>) -> Option<I> {
590        self.held.get(key.into()).map(|held| held.instance)
591    }
592}

594/// Step 8. Resolved state becomes instances, and only where it differs from what is already drawn.
595pub(crate) fn run(grove: &mut Grove) {
596    let step = trace_span!(
597        "extract",
598        written = Empty,
599        withdrawn = Empty,
600        glyphs = Empty,
601        kept = Empty
602    );
603    let _entered = step.enter();
604    grove.elm.open();
605    // Every name filled since the last batch, handed over whether or not anything draws it: the
606    // backend knows which it holds, and this does not. Swapped rather than moved, so both lists keep
607    // their capacity.
608    core::mem::swap(&mut grove.elm.refilled, &mut grove.plates.refilled);
609    grove.plates.refilled.clear();
610    grove.elm.refilled.sort_unstable();
611    grove.elm.refilled.dedup();
612    // Detached for the walk so that gathering a run's glyphs -- which reads the shaping cache -- and
613    // handing them over -- which writes what is held -- are not the same borrow. It goes back below,
614    // with whatever capacity the widest run this frame gave it.
615    let mut glyphs = core::mem::take(&mut grove.elm.glyphs);
616    // Taken off the grove for the walk, and put back below. Resolution left it holding the order it
617    // used, what each element settled at, and what moved, which is what decides how much of this
618    // there is to do.
619    let elements = core::mem::take(&mut grove.elements);
620    let mut total = 0;
621    // Nothing is held to compare against, so nothing can be said to be unchanged.
622    let recut = core::mem::take(&mut grove.elm.recut);
623    // Whatever the backend held for an element that withered, it holds for nothing now.
624    for &(leaf, chlorophyll) in &elements.gone {
625        grove.elm.withdraw(chlorophyll, leaf);
626    }
627    let surface = Section::new(Position::default(), grove.viewport);
628    // An element nothing extraction reads about moved is held by the backend as it should go on
629    // being held, and there is nothing to say: the walk is over what moved, unless nothing is held.
630    let mut moved = Positions::default();
631    match recut {
632        true => moved.fill(elements.len()),
633        false => moved.copy_from(&elements.moved),
634    }
635    let kept = elements.len() - moved.count();
636    for at in moved.iter() {
637        let chlorophyll = grove.tree.standing(elements.order[at]).chlorophyll();
638        // Carrying no renderer is the whole of what makes an element a stem.
639        if chlorophyll == Chlorophyll::None {
640            continue;
641        }
642        let stated = match painted(&elements, at, surface) {
643            Some(painted) => {
644                let drawing = Drawing {
645                    elements: &elements,
646                    at,
647                    painted,
648                };
649                state(grove, &mut glyphs, drawing, chlorophyll, &mut total)
650            }
651            None => false,
652        };
653        // Moved, and not drawn: hidden, culled, or drawing something that has not arrived. What
654        // the backend was holding for it has to go.
655        if !stated {
656            grove.elm.withdraw(chlorophyll, elements.order[at]);
657        }
658    }
659    grove.elm.glyphs = glyphs;
660    grove.elements = elements;
661    step.record("kept", kept);
662    grove.elm.close();
663    let (written, withdrawn) = grove.elm.moved();
664    step.record("written", written);
665    step.record("withdrawn", withdrawn);
666    step.record("glyphs", total);
667}

669/// One element being drawn: where it sits in the order resolution left, and what of it is painted.
670struct Drawing<'a> {
671    elements: &'a Elements,
672    at: usize,
673    painted: Painted,
674}
675
676/// States what one element draws, reporting whether it draws anything at all.
677///
678/// `false` for an element whose renderer has nothing to draw yet -- a mark whose field has not
679/// arrived, a picture whose pixels have not -- which is absent from the batch rather than held as
680/// blank.
681fn state(
682    grove: &mut Grove,
683    glyphs: &mut Vec<Glyph>,
684    drawing: Drawing,
685    chlorophyll: Chlorophyll,
686    total: &mut usize,
687) -> bool {
688    let Drawing {
689        elements,
690        at,
691        painted,
692    } = drawing;
693    let leaf = elements.order[at];
694    let slot = leaf.slot();
695    let rank = elements.rank[slot];
696    match chlorophyll {
697        // Answered by the caller: carrying no renderer is the whole of what makes an element a stem.
698        Chlorophyll::None => false,
699        Chlorophyll::Panel => {
700            // Grown together and by nothing else, so a panel always has one.
701            let Some(pigment) = grove.tree.panel_pigment(leaf) else {
702                return false;
703            };
704            // The outline is filled as a fill is, against the scheme the frame is drawn in, and
705            // faded with the panel. It has no motion of its own, so there is no blend to read.
706            let outline = pigment.outline;
707            let instance = PanelInstance::new(
708                painted.section,
709                tint(grove, leaf, pigment.fill).faded(painted.opacity),
710                pigment.rounding,
711                outline.fill.color(&grove.scheme).faded(painted.opacity),
712                outline.width,
713            );
714            grove.elm.panels.want(leaf, rank, painted.clip, instance);
715            true
716        }
717        Chlorophyll::Polygon => {
718            let Some(pigment) = grove.tree.polygon_pigment(leaf) else {
719                return false;
720            };
721            // The shape is read plainly, with no blend applied here: a shape blends to a shape,
722            // so a motion moving one writes it back over the declaration every frame and what
723            // the element holds is already where the motion has reached.
724            let instance = PolygonInstance::new(
725                painted.section,
726                tint(grove, leaf, pigment.fill).faded(painted.opacity),
727                pigment.shape,
728            );
729            grove.elm.polygons.want(leaf, rank, painted.clip, instance);
730            true
731        }
732        // A stroke's ends are resolved geometry in their own right, settled beside the box the way
733        // the drawn box is: the box is the rectangle around them grown by half the weight, and
734        // which of its two diagonals the stroke runs along is not something a rectangle can say.
735        Chlorophyll::Line => {
736            let (Some(pigment), Some(stretched), Some(stroke)) = (
737                grove.tree.line_pigment(leaf),
738                elements.stretched[slot],
739                grove.tree.stroke(leaf),
740            ) else {
741                return false;
742            };
743            let instance = LineInstance {
744                from: stretched.from,
745                to: stretched.to,
746                color: tint(grove, leaf, pigment.fill).faded(painted.opacity),
747                weight: stroke.weight,
748                cap: pigment.cap,
749            };
750            grove.elm.lines.want(leaf, rank, painted.clip, instance);
751            true
752        }
753        Chlorophyll::Icon => {
754            let Some(pigment) = grove.tree.icon_pigment(leaf) else {
755                return false;
756            };
757            // A field that has not arrived draws nothing and occupies its box, exactly as a
758            // picture with no pixels does. Absent from the batch rather than held as blank: the
759            // sheet cuts a mark when the batch names one, so an instance written before the
760            // field landed would be a mark nothing ever asked the sheet for again.
761            if grove.fields.mark(pigment.field).is_none() {
762                return false;
763            }
764            let instance = IconInstance {
765                // Square, because a distance field is: the mark sits in the largest square its
766                // box holds rather than stretching to the box's own ratio.
767                section: squared(painted.section),
768                color: tint(grove, leaf, pigment.fill).faded(painted.opacity),
769                field: pigment.field,
770            };
771            grove.elm.icons.want(leaf, rank, painted.clip, instance);
772            true
773        }
774        Chlorophyll::Image => {
775            let Some(pigment) = grove.tree.image_pigment(leaf) else {
776                return false;
777            };
778            // A plate whose pixels have not arrived draws nothing and occupies its box. It is
779            // absent from the batch rather than held as blank, so the frame the pixels land is
780            // the frame it appears, with nothing to undo.
781            let Some(picture) = grove.plates.size(pigment.plate) else {
782                return false;
783            };
784            let (section, crop) = fitted(painted.section, picture, pigment.fit);
785            let instance = ImageInstance {
786                section,
787                crop,
788                radii: pigment.rounding.radii(section),
789                opacity: painted.opacity,
790                plate: pigment.plate,
791            };
792            grove.elm.images.want(leaf, rank, painted.clip, instance);
793            true
794        }
795        // A run's box, fill, rank and clip resolve exactly as a panel's do. What is different is
796        // that it draws *many* things at one rank: it is one entry in the one stack, and its
797        // renderer holds its glyphs under its own numbering -- which is what a [`Key`] is a
798        // number rather than a [`Leaf`] for.
799        Chlorophyll::Text => {
800            // Grown together and by nothing else, so a run always has both.
801            let (Some(pigment), Some(typeface)) =
802                (grove.tree.text_pigment(leaf), grove.tree.typeface(leaf))
803            else {
804                return false;
805            };
806            let color = tint(grove, leaf, pigment.fill).faded(painted.opacity);
807            let size = typeface.size.at(grove.layout, grove.short);
808            // The run R1 left the element holding, which is what it was measured and wrapped as.
809            let Some(shaped) = elements.composed[slot].as_deref() else {
810                return false;
811            };
812            let tints = grove.tree.tints(leaf);
813            let origin = painted.section.position;
814            let cell = shaped.cell();
815            glyphs.clear();
816            // Wrapped at the width the run resolved to, which is the width it was measured at.
817            shaped.place(painted.section.width(), |character, index, at| {
818                glyphs.push(Glyph {
819                    cell: Section::new(origin.moved(at), cell),
820                    character,
821                    // The run's own fill, unless a tint claims this character. Resolved here
822                    // because this is where a fill becomes a colour, which is the same reason
823                    // the run's own is.
824                    color: match tints.and_then(|tints| tints.over(index)) {
825                        Some(fill) => fill.color(&grove.scheme).faded(painted.opacity),
826                        None => color,
827                    },
828                });
829            });
830            *total += glyphs.len();
831            grove
832                .elm
833                .texts
834                .want(leaf.into(), rank, painted.clip, typeface.font, size, glyphs);
835            true
836        }
837    }
838}

840/// Where an element is painted, and inside what.
841struct Painted {
842    section: Section,
843    clip: Section,
844    opacity: f32,
845}
846
847/// What is painted of the element at `at`, or `None` if nothing is.
848///
849/// Hidden is the app's intent and culled is this pass's decision, taken here from the clip rect and
850/// recorded nowhere: an element scrolled out of its region is absent from the batch and unchanged in
851/// every other respect, so scrolling back to it needs nothing to be undone.
852fn painted(elements: &Elements, at: usize, surface: Section) -> Option<Painted> {
853    let slot = elements.order[at].slot();
854    let inherited = elements.inherited[slot];
855    let section = elements.drawn[slot];
856    // What a scrolling ancestor leaves visible, never wider than the surface: a clip is what the
857    // backend scissors the pass to, and nothing outside the surface is painted whatever the rect
858    // says.
859    let clip = elements.clip[slot].intersect(surface);
860    if !inherited.visible || section.intersect(clip).is_empty() {
861        return None;
862    }
863    Some(Painted {
864        section,
865        clip,
866        opacity: inherited.opacity,
867    })
868}

870/// The largest square `section` holds, centred in it.
871fn squared(section: Section) -> Section {
872    let side = section.width().min(section.height());
873    Section::new(
874        Position::new(
875            section.left() + (section.width() - side) / 2.0,
876            section.top() + (section.height() - side) / 2.0,
877        ),
878        Area::new(side, side),
879    )
880}

882/// The box a picture is drawn into, and what part of it is shown.
883///
884/// One of the two moves, never both: fitting inside the box changes the box and shows the whole
885/// picture, and filling the box keeps the box and shows part of the picture. Stretching does
886/// neither and is the only one that distorts.
887fn fitted(section: Section, picture: Area, fit: Fit) -> (Section, [f32; 4]) {
888    const WHOLE: [f32; 4] = [0.0, 0.0, 1.0, 1.0];
889    if picture.width <= 0.0 || picture.height <= 0.0 || section.is_empty() {
890        return (section, WHOLE);
891    }
892    let picture_ratio = picture.width / picture.height;
893    let box_ratio = section.width() / section.height();
894    match fit {
895        Fit::Stretch => (section, WHOLE),
896        Fit::Aspect => {
897            let area = match box_ratio > picture_ratio {
898                true => Area::new(section.height() * picture_ratio, section.height()),
899                false => Area::new(section.width(), section.width() / picture_ratio),
900            };
901            let position = Position::new(
902                section.left() + (section.width() - area.width) / 2.0,
903                section.top() + (section.height() - area.height) / 2.0,
904            );
905            (Section::new(position, area), WHOLE)
906        }
907        Fit::Crop => {
908            let (width, height) = match box_ratio > picture_ratio {
909                true => (1.0, picture_ratio / box_ratio),
910                false => (box_ratio / picture_ratio, 1.0),
911            };
912            (
913                section,
914                [(1.0 - width) / 2.0, (1.0 - height) / 2.0, width, height],
915            )
916        }
917    }
918}

920/// What a fill currently paints as.
921///
922/// A blend of two fills is a color rather than a fill, so a motion on one is applied here -- where a
923/// fill becomes a color -- and not written onto the element. Both ends are read against the same
924/// scheme at the same instant, so a repaint mid-motion moves whichever of them is a role.
925fn tint(grove: &Grove, leaf: Leaf, fill: Fill) -> Color {
926    let target = fill.color(&grove.scheme);
927    match grove.aspen.fill(leaf) {
928        Some((Departed::Declared(fill), at)) => fill.color(&grove.scheme).blend(target, at),
929        Some((Departed::Snapshot(color), at)) => color.blend(target, at),
930        None => target,
931    }
