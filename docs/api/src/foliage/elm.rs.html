1//! Elm -- change extraction.
2//!
3//! # Rowan recomputes. Elm decides what changed.
4//!
5//! Step 8, and the reason recomputing everything costs nothing downstream. Every renderer keeps what
6//! the backend is holding and compares this frame's resolved values against it, so an element that
7//! did not change costs one comparison and no upload.
8//!
9//! The cache is *what the backend holds*, not what the element last was. That is what makes a
10//! skipped frame unable to lose a change: there is no flag to miss, only a value that still differs
11//! at the next comparison. It is also a contract on the backend, which has to apply every batch it
12//! is handed -- a dropped batch leaves the cache claiming something the backend does not have, and
13//! nothing afterwards will correct it.
14//!
15//! # What is compared is not always what is uploaded
16//!
17//! A [`Panel`](crate::Panel) and a [`Polygon`](crate::Polygon) are described entirely in logical
18//! pixels, so one value is both what is compared here and what the vertex buffer holds. The other
19//! four are not, and each for the same reason: turning what the element declares into what the GPU
20//! draws needs the display's density, and the density stops at the backend
21//! ([`Ginkgo`](crate::ginkgo)).
22//!
23//! | | declares | the backend derives |
24//! |---|---|---|
25//! | [`Text`](crate::Text) | cells and characters | the cut ink, snapped to device pixels |
26//! | [`Line`](crate::Line) | two ends and a weight | four corners, axis-aligned ones snapped |
27//! | [`Icon`](crate::Icon) | a box and a field | the sheet rect, and the field's screen-space range |
28//! | [`Image`](crate::Image) | a box and a plate | which texture to bind |
29//!
30//! So extraction is written in logical pixels throughout and compares logical values, and the
31//! derivation happens once per written instance rather than once per frame.
32//!
33//! # What is not looked at
34//!
35//! An element resolution did not move is not visited: what the backend holds for it is what it
36//! should go on holding. So what the backend is told to let go of is said outright, and there are
37//! exactly two ways to earn it -- an element that moved and is not painted any more (hidden, culled,
38//! or drawing an asset that has not arrived), and an element that withered, which resolution
39//! reports when it builds the order again. A frame that moves nothing does nothing here.

62/// Which renderer an element carries, and so which instances it is gathered into.
63///
64/// Decided when the element is described and never afterwards: what an element draws is part of
65/// what it is, and one that is to draw something else is a different element. Nothing writes this
66/// -- there is no op that can, and the only place it is set is where the element is grown.
67///
68/// Extraction walks the tree once and routes on this, so a further renderer costs a variant rather
69/// than a pass over everything. It is the *only* thing that says what an element is: a set of
70/// declarations that happens to look like a panel is not a panel.
71#[derive(Copy, Clone, Debug, Default, PartialEq, Eq)]
72pub(crate) enum Chlorophyll {
73    /// Nothing. Carrying no renderer is the whole of what makes an element a [`Stem`](crate::Stem).
74    #[default]
75    None,
76    /// A filled rectangle.
77    Panel,
78    /// A run of monospaced glyphs.
79    Text,
80    /// A filled regular polygon.
81    Polygon,
82    /// A straight stroke between two points.
83    Line,
84    /// A vector mark, from a distance field.
85    Icon,
86    /// A picture, fitted into its box.
87    Image,
88}

142    pub(crate) panels: Instances<PanelInstance>,
143    pub(crate) polygons: Instances<PolygonInstance>,
144    pub(crate) lines: Instances<LineInstance>,
145    pub(crate) icons: Instances<IconInstance>,

154    pub(crate) texts: Runs,

170/// One picture drawn apart: what its instances carry as their rank's
171/// [`layer`](ResolvedElevation::layer), how opaque it is laid onto everything else, and where in the
172/// stack it is laid -- the rank of the element that opened it.
173#[derive(Copy, Clone, Debug, PartialEq)]
174pub(crate) struct Layered {
175    pub(crate) layer: u32,
176    pub(crate) opacity: f32,
177    pub(crate) rank: ResolvedElevation,
178}
179
180impl Elm {
181    /// How much this frame's batch moves, across every renderer. Reported to the trace, and the one
182    /// number that says whether an unchanged frame really cost nothing.
183    pub(crate) fn moved(&self) -> (usize, usize) {
184        let written = self.panels.written.len()
185            + self.polygons.written.len()
186            + self.lines.written.len()
187            + self.icons.written.len()
188            + self.images.written.len()
189            + self.texts.written.len();
190        let withdrawn = self.panels.withdrawn.len()
191            + self.polygons.withdrawn.len()
192            + self.lines.withdrawn.len()
193            + self.icons.withdrawn.len()
194            + self.images.withdrawn.len()
195            + self.texts.withdrawn.len();
196        (written, withdrawn)
197    }
198
199    /// Opens an extraction on every renderer, dropping what the last one reported.
200    fn open(&mut self) {
201        self.relayered = false;
202        self.panels.open();
203        self.polygons.open();
204        self.lines.open();
205        self.icons.open();
206        self.images.open();
207        self.texts.open();
208    }
209
210    /// Closes an extraction on every renderer.
211    fn close(&mut self) {
212        self.panels.close();
213        self.polygons.close();
214        self.lines.close();
215        self.icons.close();
216        self.images.close();
217        self.texts.close();
218    }
219
220    /// States the picture the element in slot `slot` opens, or that it opens none.
221    fn layer(&mut self, slot: usize, opens: Option<(f32, ResolvedElevation)>) {
222        let layer = slot as u32 + 1;
223        let at = self.layers.binary_search_by_key(&layer, |held| held.layer);
224        match (at, opens) {
225            (Ok(at), Some((opacity, rank))) => {
226                let stated = Layered {
227                    layer,
228                    opacity,
229                    rank,
230                };
231                if self.layers[at] != stated {
232                    self.layers[at] = stated;
233                    self.relayered = true;
234                }
235            }
236            (Err(at), Some((opacity, rank))) => {
237                self.layers.insert(
238                    at,
239                    Layered {
240                        layer,
241                        opacity,
242                        rank,
243                    },
244                );
245                self.relayered = true;
246            }
247            (Ok(at), None) => {
248                self.layers.remove(at);
249                self.relayered = true;
250            }
251            (Err(_), None) => {}
252        }
253    }
254
255    /// Lets go of whatever the backend holds for `leaf`, in the renderer it draws with.
256    fn withdraw(&mut self, chlorophyll: Chlorophyll, leaf: Leaf) {
257        let key = Key::from(leaf);
258        match chlorophyll {
259            Chlorophyll::None => {}
260            Chlorophyll::Panel => self.panels.withdraw(key),
261            Chlorophyll::Polygon => self.polygons.withdraw(key),
262            Chlorophyll::Line => self.lines.withdraw(key),
263            Chlorophyll::Icon => self.icons.withdraw(key),
264            Chlorophyll::Image => self.images.withdraw(key),
265            Chlorophyll::Text => self.texts.withdraw(key),
266        }
267    }
268
269    /// Drops everything the backend is held to, so the next extraction writes the tree entire.
270    ///
271    /// Two things invalidate a comparison against what the backend holds, and both are facts about
272    /// the backend rather than about any element:
273    ///
274    /// - **The density changed.** The backend's copy is in device pixels and this one is not, so a
275    ///   display whose density changed leaves every derived instance -- a cut glyph, a snapped
276    ///   stroke, a field's screen-space range -- correct against a density that is gone, while the
277    ///   logical values they came from are unchanged and compare equal forever. The backend is kept,
278    ///   so it lets go of what it holds in the same breath ([`Ash::recut`](crate::ash::Ash::recut)),
279    ///   or an element that stopped being drawn in the frame this lands in would go on being drawn:
280    ///   with nothing held here for it, nothing would name it to be let go of.
281    /// - **The backend was rebuilt.** A platform that took its surface back and gave another one --
282    ///   an Android activity leaving the foreground and returning -- leaves a cache describing
283    ///   buffers that no longer exist. Every value would compare equal and nothing would be
284    ///   uploaded, against renderers holding nothing.
285    ///
286    /// Total rather than per renderer, because neither the density nor the device is any
287    /// renderer's.
288    ///
289    /// The next extraction states every element rather than only what moved, because after this
290    /// there is nothing held for anything to have moved against.
291    pub(crate) fn recut(&mut self) {
292        self.recut = true;
293        self.panels.forget();
294        self.polygons.forget();
295        self.lines.forget();
296        self.icons.forget();
297        self.images.forget();
298        self.texts.forget();
299    }
300}

302/// One glyph of a run: the cell it occupies, which character occupies it, and what it is filled
303/// with.
304///
305/// The cell is in logical pixels and already offset by the run's own box, because where a character
306/// lands is what wrapping decided and wrapping is the engine's. Where the *ink* sits inside that
307/// cell is not here: that is the rasteriser's, which is the only thing that knows what shape it made
308/// and at what density it made it.
309///
310/// The colour is per glyph because a [`tint`](crate::Grow::tint) is a fill over a range of the run's
311/// own index space. A run with no tints resolves the same colour for every one of them, which costs
312/// the comparison it would have cost anyway.
313#[derive(Copy, Clone, Debug, PartialEq)]
314pub(crate) struct Glyph {
315    pub(crate) cell: Section,
316    pub(crate) character: char,
317    pub(crate) color: Color,
318}

320/// The runs, and every glyph of each.
321///
322/// Deliberately not an [`Instances`]: a run is **one** entry in the one stack whose renderer holds
323/// many things under it, and that is the whole difference. What is diffed here is the run entire --
324/// its glyphs, its face, its rank and its clip -- because a run's glyphs move, refill and restack
325/// together, and finding which of them changed would cost more than rewriting the run.
326#[derive(Default)]
327pub(crate) struct Runs {
328    held: Named<Key, Run>,
329    /// Runs the backend holds at something other than what is now wanted, or does not hold at all.
330    /// Keys rather than values: what the backend is to apply is what is held for them, which it
331    /// reads back at [`run`](Runs::run).
332    pub(crate) written: Vec<Key>,
333    /// Runs the backend holds and should not, in a stable order.
334    pub(crate) withdrawn: Vec<Key>,
335}
336
337/// One run, as the backend is to hold it.
338pub(crate) struct Run {
339    /// Every glyph that leaves ink, in reading order. A space advances the wrap and is not one.
340    pub(crate) glyphs: Vec<Glyph>,
341    /// Which face the glyphs are cut from, and at what size. The backend rasterises against these,
342    /// so they are part of what the run is rather than of how it was measured.
343    pub(crate) font: Font,
344    pub(crate) size: u32,
345    pub(crate) rank: ResolvedElevation,
346    pub(crate) clip: Section,
347    /// How the run is turned and scaled where it is drawn, glyphs and all.
348    pub(crate) pose: Affine,
349}
350
351impl Runs {
352    /// Opens an extraction, dropping what the last one reported.
353    fn open(&mut self) {
354        self.written.clear();
355        self.withdrawn.clear();
356    }
357
358    /// Takes one run as it now stands, and reports it written if the backend is holding it
359    /// otherwise.
360    ///
361    /// Each part of a run is stated separately because each is compared separately, against what is
362    /// held, without building a run to compare.
363    #[allow(clippy::too_many_arguments)]
364    fn want(
365        &mut self,
366        key: Key,
367        rank: ResolvedElevation,
368        clip: Section,
369        font: Font,
370        size: u32,
371        glyphs: &[Glyph],
372        pose: Affine,
373    ) {
374        match self.held.get_mut(&key) {
375            Some(held) => {
376                if held.font == font
377                    && held.size == size
378                    && held.rank == rank
379                    && held.clip == clip
380                    && held.pose == pose
381                    && held.glyphs == glyphs
382                {
383                    return;
384                }
385                held.font = font;
386                held.size = size;
387                held.rank = rank;
388                held.clip = clip;
389                held.pose = pose;
390                // Rewritten in place, so a run that changed costs its own glyphs and no allocation.
391                held.glyphs.clear();
392                held.glyphs.extend_from_slice(glyphs);
393            }
394            None => {
395                self.held.insert(
396                    key,
397                    Run {
398                        glyphs: glyphs.to_vec(),
399                        font,
400                        size,
401                        rank,
402                        clip,
403                        pose,
404                    },
405                );
406            }
407        }
408        self.written.push(key);
409    }
410
411    /// Lets go of a run, if the backend is holding one.
412    fn withdraw(&mut self, key: Key) {
413        if self.held.remove(&key).is_some() {
414            self.withdrawn.push(key);
415        }
416    }
417
418    /// Closes the extraction.
419    fn close(&mut self) {
420        // Two identical runs have to extract identically, whatever order what went was found in.
421        self.withdrawn.sort();
422    }
423
424    /// Drops what the backend is held to. See [`Elm::recut`].
425    fn forget(&mut self) {
426        self.held.clear();
427    }
428
429    /// What is held for one run, which is what the backend is to be holding for it.
430    pub(crate) fn run(&self, key: Key) -> Option<&Run> {
431        self.held.get(&key)
432    }
433
434    /// Every run held, which is every run the backend is to be holding: the whole of what the frame
435    /// draws in glyphs.
436    pub(crate) fn keys(&self) -> impl Iterator<Item = Key> + '_ {
437        self.held.keys().copied()
438    }
439}

441/// What one instance is held under.
442///
443/// A plain number, and deliberately not a [`Leaf`]. An element is one of these -- its name's own
444/// bits -- and so is a glyph inside a run, so a renderer whose element draws *many* things keeps its
445/// own [`Instances`] under its own numbering and hands the one stack a single entry. Nothing about
446/// holding, diffing or uploading has to know which of the two it is looking at.
447#[derive(Copy, Clone, PartialEq, Eq, Hash, PartialOrd, Ord, Debug)]
448pub(crate) struct Key(pub(crate) u64);
449
450impl From<Leaf> for Key {
451    fn from(leaf: Leaf) -> Self {
452        Self(leaf.id())
453    }
454}

456impl Key {
457    /// The index of the name it is the bits of, which is its low half: dense, since an index that
458    /// went is the next one handed out.
459    fn index(self) -> usize {
460        self.0 as u32 as usize
461    }
462}

464/// What is held for each key, in a slot per name's index rather than in a hash table.
465///
466/// The indices in use are dense, so the table is as long as the most names live at once. A lookup
467/// is an index rather than a hash -- and a walk over the order, which is mostly the order things
468/// were grown in, walks the table nearly in step rather than all over it. A slot holds the whole
469/// key, so a name grown into an index something withered from is never taken for it.
470pub(crate) struct Table<V> {
471    slots: Vec<Option<(Key, V)>>,
472    len: usize,
473}
474
475impl<V> Default for Table<V> {
476    fn default() -> Self {
477        Self {
478            slots: Vec::new(),
479            len: 0,
480        }
481    }
482}
483
484impl<V> Table<V> {
485    pub(crate) fn get(&self, key: Key) -> Option<&V> {
486        match self.slots.get(key.index())? {
487            Some((held, value)) if *held == key => Some(value),
488            _ => None,
489        }
490    }
491
492    pub(crate) fn get_mut(&mut self, key: Key) -> Option<&mut V> {
493        match self.slots.get_mut(key.index())? {
494            Some((held, value)) if *held == key => Some(value),
495            _ => None,
496        }
497    }
498
499    /// Holds `value` under `key`, and hands back what another name was holding in its slot: one
500    /// that withered with nothing yet said about it, whose index `key` was grown into. The caller
501    /// lets that go as it would anything withdrawn.
502    pub(crate) fn insert(&mut self, key: Key, value: V) -> Option<(Key, V)> {
503        let at = key.index();
504        if at >= self.slots.len() {
505            self.slots.resize_with(at + 1, || None);
506        }
507        match self.slots[at].replace((key, value)) {
508            None => {
509                self.len += 1;
510                None
511            }
512            Some((held, _)) if held == key => None,
513            displaced => displaced,
514        }
515    }
516
517    pub(crate) fn remove(&mut self, key: Key) -> Option<V> {
518        let slot = self.slots.get_mut(key.index())?;
519        if !slot.as_ref().is_some_and(|(held, _)| *held == key) {
520            return None;
521        }
522        self.len -= 1;
523        slot.take().map(|(_, value)| value)
524    }
525
526    pub(crate) fn clear(&mut self) {
527        self.slots.clear();
528        self.len = 0;
529    }
530
531    pub(crate) fn len(&self) -> usize {
532        self.len
533    }
534}

536/// One renderer's instances: what the backend holds, and the difference the last extraction found.
537///
538/// Generic over the instance, because what a renderer sends is the renderer's own business. This
539/// owns the comparison and knows nothing about what is being compared.
540///
541/// The rank is the one thing every renderer has in common, so it is carried here rather than
542/// inside each renderer's instance: where an element sits in the one stack is a fact about the
543/// element, not about what it happens to draw, and the backend needs it in a different form from
544/// the one the resolver produced. Keeping it out is also what leaves an instance free to be
545/// exactly the bytes a vertex buffer takes, for the renderers whose instance is those bytes.
546pub(crate) struct Instances<I> {
547    held: Table<Held<I>>,
548    /// Instances the backend does not hold, or holds at a different value or rank.
549    pub(crate) written: Vec<Stacked<I>>,
550    /// Instances the backend holds and should not, in a stable order.
551    pub(crate) withdrawn: Vec<Key>,
552}
553
554/// One instance, where in the one stack it is to be drawn, and what it is clipped to.
555///
556/// The clip is beside the instance rather than inside it for the same reason the rank is: it is not
557/// the renderer's data. It says where the backend is allowed to paint, which is a property of the
558/// region the element sits in, and the backend applies it to the pass rather than to the panel.
559#[derive(Copy, Clone, Debug)]
560pub(crate) struct Stacked<I> {
561    pub(crate) key: Key,
562    pub(crate) rank: ResolvedElevation,
563    pub(crate) clip: Section,
564    pub(crate) instance: I,
565}
566
567/// One instance the backend holds.
568struct Held<I> {
569    instance: I,
570    rank: ResolvedElevation,
571    clip: Section,
572}
573
574impl<I> Default for Instances<I> {
575    fn default() -> Self {
576        Self {
577            held: Table::default(),
578            written: Vec::new(),
579            withdrawn: Vec::new(),
580        }
581    }
582}
583
584impl<I: Copy + PartialEq> Instances<I> {
585    /// Opens an extraction, dropping what the last one reported.
586    fn open(&mut self) {
587        self.written.clear();
588        self.withdrawn.clear();
589    }
590
591    /// States one instance as it now stands -- at the rank it resolved to and inside the clip it
592    /// resolved under -- and reports it written if the backend is holding it otherwise.
593    ///
594    /// The holding is updated in place, so a frame that rewrites an instance allocates nothing, and
595    /// one that states it at what is already held writes nothing.
596    fn want(&mut self, key: impl Into<Key>, rank: ResolvedElevation, clip: Section, instance: I) {
597        let key = key.into();
598        match self.held.get_mut(key) {
599            Some(held) => {
600                if held.instance == instance && held.rank == rank && held.clip == clip {
601                    return;
602                }
603                held.instance = instance;
604                held.rank = rank;
605                held.clip = clip;
606            }
607            None => {
608                let held = Held {
609                    instance,
610                    rank,
611                    clip,
612                };
613                if let Some((displaced, _)) = self.held.insert(key, held) {
614                    self.withdrawn.push(displaced);
615                }
616            }
617        }
618        self.written.push(Stacked {
619            key,
620            rank,
621            clip,
622            instance,
623        });
624    }
625
626    /// Lets go of an instance, if the backend is holding one.
627    fn withdraw(&mut self, key: Key) {
628        if self.held.remove(key).is_some() {
629            self.withdrawn.push(key);
630        }
631    }
632
633    /// Closes the extraction.
634    fn close(&mut self) {
635        // Two identical runs have to extract identically, whatever order what went was found in.
636        self.withdrawn.sort();
637    }
638
639    /// Drops what the backend is held to. See [`Elm::recut`].
640    fn forget(&mut self) {
641        self.held.clear();
642    }
643
644    /// How many instances the backend is holding.
645    #[allow(unused)]
646    pub(crate) fn len(&self) -> usize {
647        self.held.len()
648    }
649
650    /// What the backend is holding for `key`.
651    #[allow(unused)]
652    pub(crate) fn holding(&self, key: impl Into<Key>) -> Option<I> {
653        self.held.get(key.into()).map(|held| held.instance)
654    }
655}

657/// Step 8. Resolved state becomes instances, and only where it differs from what is already drawn.
658pub(crate) fn run(grove: &mut Grove) {
659    let step = trace_span!(
660        "extract",
661        written = Empty,
662        withdrawn = Empty,
663        glyphs = Empty,
664        kept = Empty
665    );
666    let _entered = step.enter();
667    grove.elm.open();
668    // Every name filled since the last batch, handed over whether or not anything draws it: the
669    // backend knows which it holds, and this does not. Swapped rather than moved, so both lists keep
670    // their capacity.
671    core::mem::swap(&mut grove.elm.refilled, &mut grove.plates.refilled);
672    grove.plates.refilled.clear();
673    grove.elm.refilled.sort_unstable();
674    grove.elm.refilled.dedup();
675    // Detached for the walk so that gathering a run's glyphs -- which reads the shaping cache -- and
676    // handing them over -- which writes what is held -- are not the same borrow. It goes back below,
677    // with whatever capacity the widest run this frame gave it.
678    let mut glyphs = core::mem::take(&mut grove.elm.glyphs);
679    // Taken off the grove for the walk, and put back below. Resolution left it holding the order it
680    // used, what each element settled at, and what moved, which is what decides how much of this
681    // there is to do.
682    let elements = core::mem::take(&mut grove.elements);
683    let mut total = 0;
684    // Nothing is held to compare against, so nothing can be said to be unchanged -- the pictures
685    // included, which are handed over whole.
686    let recut = core::mem::take(&mut grove.elm.recut);
687    grove.elm.relayered |= recut;
688    // Whatever the backend held for an element that withered, it holds for nothing now -- and a
689    // picture it opened is not drawn.
690    for &(leaf, chlorophyll) in &elements.gone {
691        grove.elm.withdraw(chlorophyll, leaf);
692        grove.elm.layer(leaf.slot(), None);
693    }
694    let surface = Section::new(Position::default(), grove.viewport);
695    // An element nothing extraction reads about moved is held by the backend as it should go on
696    // being held, and there is nothing to say: the walk is over what moved, unless nothing is held.
697    let mut moved = Positions::default();
698    match recut {
699        true => moved.fill(elements.len()),
700        false => moved.copy_from(&elements.moved),
701    }
702    let kept = elements.len() - moved.count();
703    for at in moved.iter() {
704        let leaf = elements.order[at];
705        // Whether it opens a picture is asked of every element that moved, stems included: a stem
706        // is the usual thing a card is grown in. Not of whether it is culled, since what is drawn
707        // into it may be on screen where its own box is not.
708        let inherited = elements.inherited[leaf.slot()];
709        grove.elm.layer(
710            leaf.slot(),
711            (inherited.visible && inherited.opens(leaf.slot()))
712                .then(|| (inherited.opacity, elements.rank[leaf.slot()])),
713        );
714        let chlorophyll = grove.tree.standing(leaf).chlorophyll();
715        // Carrying no renderer is the whole of what makes an element a stem.
716        if chlorophyll == Chlorophyll::None {
717            continue;
718        }
719        let stated = match painted(&elements, at, surface) {
720            Some(painted) => {
721                let drawing = Drawing {
722                    elements: &elements,
723                    at,
724                    painted,
725                };
726                state(grove, &mut glyphs, drawing, chlorophyll, &mut total)
727            }
728            None => false,
729        };
730        // Moved, and not drawn: hidden, culled, or drawing something that has not arrived. What
731        // the backend was holding for it has to go.
732        if !stated {
733            grove.elm.withdraw(chlorophyll, elements.order[at]);
734        }
735    }
736    grove.elm.glyphs = glyphs;
737    grove.elements = elements;
738    step.record("kept", kept);
739    grove.elm.close();
740    let (written, withdrawn) = grove.elm.moved();
741    step.record("written", written);
742    step.record("withdrawn", withdrawn);
743    step.record("glyphs", total);
744}

746/// One element being drawn: where it sits in the order resolution left, and what of it is painted.
747struct Drawing<'a> {
748    elements: &'a Elements,
749    at: usize,
750    painted: Painted,
751}
752
753/// States what one element draws, reporting whether it draws anything at all.
754///
755/// `false` for an element whose renderer has nothing to draw yet -- a mark whose field has not
756/// arrived, a picture whose pixels have not -- which is absent from the batch rather than held as
757/// blank.
758fn state(
759    grove: &mut Grove,
760    glyphs: &mut Vec<Glyph>,
761    drawing: Drawing,
762    chlorophyll: Chlorophyll,
763    total: &mut usize,
764) -> bool {
765    let Drawing {
766        elements,
767        at,
768        painted,
769    } = drawing;
770    let leaf = elements.order[at];
771    let slot = leaf.slot();
772    // Where it is in the stack, and which picture it is drawn into.
773    let rank = ResolvedElevation {
774        layer: painted.layer,
775        ..elements.rank[slot]
776    };
777    match chlorophyll {
778        // Answered by the caller: carrying no renderer is the whole of what makes an element a stem.
779        Chlorophyll::None => false,
780        Chlorophyll::Panel => {
781            // Grown together and by nothing else, so a panel always has one.
782            let Some(pigment) = grove.tree.panel_pigment(leaf) else {
783                return false;
784            };
785            // The outline is filled as a fill is, against the scheme the frame is drawn in, and
786            // faded with the panel. It has no motion of its own, so there is no blend to read.
787            let outline = pigment.outline;
788            let instance = PanelInstance {
789                pose: painted.posed,
790                ..PanelInstance::new(
791                    painted.section,
792                    tint(grove, leaf, pigment.fill).faded(painted.opacity),
793                    pigment.rounding,
794                    outline.fill.color(&grove.scheme).faded(painted.opacity),
795                    outline.width,
796                )
797            };
798            grove.elm.panels.want(leaf, rank, painted.clip, instance);
799            true
800        }
801        Chlorophyll::Polygon => {
802            let Some(pigment) = grove.tree.polygon_pigment(leaf) else {
803                return false;
804            };
805            // The shape is read plainly, with no blend applied here: a shape blends to a shape,
806            // so a motion moving one writes it back over the declaration every frame and what
807            // the element holds is already where the motion has reached.
808            let instance = PolygonInstance {
809                pose: painted.posed,
810                ..PolygonInstance::new(
811                    painted.section,
812                    tint(grove, leaf, pigment.fill).faded(painted.opacity),
813                    pigment.shape,
814                )
815            };
816            grove.elm.polygons.want(leaf, rank, painted.clip, instance);
817            true
818        }
819        // A stroke's ends are resolved geometry in their own right, settled beside the box the way
820        // the drawn box is: the box is the rectangle around them grown by half the weight, and
821        // which of its two diagonals the stroke runs along is not something a rectangle can say.
822        Chlorophyll::Line => {
823            let (Some(pigment), Some(stretched), Some(stroke)) = (
824                grove.tree.line_pigment(leaf),
825                elements.stretched[slot],
826                grove.tree.stroke(leaf),
827            ) else {
828                return false;
829            };
830            let instance = LineInstance {
831                from: stretched.from,
832                to: stretched.to,
833                color: tint(grove, leaf, pigment.fill).faded(painted.opacity),
834                weight: stroke.weight,
835                cap: pigment.cap,
836                pose: painted.posed,
837            };
838            grove.elm.lines.want(leaf, rank, painted.clip, instance);
839            true
840        }
841        Chlorophyll::Icon => {
842            let Some(pigment) = grove.tree.icon_pigment(leaf) else {
843                return false;
844            };
845            // A field that has not arrived draws nothing and occupies its box, exactly as a
846            // picture with no pixels does. Absent from the batch rather than held as blank: the
847            // sheet cuts a mark when the batch names one, so an instance written before the
848            // field landed would be a mark nothing ever asked the sheet for again.
849            if grove.fields.mark(pigment.field).is_none() {
850                return false;
851            }
852            let instance = IconInstance {
853                // Square, because a distance field is: the mark sits in the largest square its
854                // box holds rather than stretching to the box's own ratio.
855                section: squared(painted.section),
856                color: tint(grove, leaf, pigment.fill).faded(painted.opacity),
857                field: pigment.field,
858                pose: painted.posed,
859            };
860            grove.elm.icons.want(leaf, rank, painted.clip, instance);
861            true
862        }
863        Chlorophyll::Image => {
864            let Some(pigment) = grove.tree.image_pigment(leaf) else {
865                return false;
866            };
867            // A plate whose pixels have not arrived draws nothing and occupies its box. It is
868            // absent from the batch rather than held as blank, so the frame the pixels land is
869            // the frame it appears, with nothing to undo.
870            let Some(picture) = grove.plates.size(pigment.plate) else {
871                return false;
872            };
873            let (section, crop) = fitted(painted.section, picture, pigment.fit);
874            let instance = ImageInstance {
875                section,
876                crop,
877                radii: pigment.rounding.radii(section),
878                opacity: painted.opacity,
879                plate: pigment.plate,
880                pose: painted.posed,
881            };
882            grove.elm.images.want(leaf, rank, painted.clip, instance);
883            true
884        }
885        // A run's box, fill, rank and clip resolve exactly as a panel's do. What is different is
886        // that it draws *many* things at one rank: it is one entry in the one stack, and its
887        // renderer holds its glyphs under its own numbering -- which is what a [`Key`] is a
888        // number rather than a [`Leaf`] for.
889        Chlorophyll::Text => {
890            // Grown together and by nothing else, so a run always has both.
891            let (Some(pigment), Some(typeface)) =
892                (grove.tree.text_pigment(leaf), grove.tree.typeface(leaf))
893            else {
894                return false;
895            };
896            let color = tint(grove, leaf, pigment.fill).faded(painted.opacity);
897            let size = typeface.size.at(grove.layout, grove.short);
898            // The run R1 left the element holding, which is what it was measured and wrapped as.
899            let Some(shaped) = elements.composed[slot].as_deref() else {
900                return false;
901            };
902            let tints = grove.tree.tints(leaf);
903            let origin = painted.section.position;
904            let cell = shaped.cell();
905            glyphs.clear();
906            // Wrapped at the width the run resolved to, which is the width it was measured at.
907            shaped.place(painted.section.width(), |character, index, at| {
908                glyphs.push(Glyph {
909                    cell: Section::new(origin.moved(at), cell),
910                    character,
911                    // The run's own fill, unless a tint claims this character. Resolved here
912                    // because this is where a fill becomes a colour, which is the same reason
913                    // the run's own is.
914                    color: match tints.and_then(|tints| tints.over(index)) {
915                        Some(fill) => fill.color(&grove.scheme).faded(painted.opacity),
916                        None => color,
917                    },
918                });
919            });
920            *total += glyphs.len();
921            grove.elm.texts.want(
922                leaf.into(),
923                rank,
924                painted.clip,
925                typeface.font,
926                size,
927                glyphs,
928                painted.posed,
929            );
930            true
931        }
932    }
933}

935/// Where an element is painted, and inside what.
936struct Painted {
937    section: Section,
938    clip: Section,
939    /// How opaque it is drawn: into its picture, where it is drawn into one, and onto the window
940    /// otherwise.
941    opacity: f32,
942    layer: u32,
943    /// How it is turned and scaled where it is drawn.
944    posed: Affine,
945}
946
947/// What is painted of the element at `at`, or `None` if nothing is.
948///
949/// Hidden is the app's intent and culled is this pass's decision, taken here from the clip rect and
950/// recorded nowhere: an element scrolled out of its region is absent from the batch and unchanged in
951/// every other respect, so scrolling back to it needs nothing to be undone.
952fn painted(elements: &Elements, at: usize, surface: Section) -> Option<Painted> {
953    let slot = elements.order[at].slot();
954    let inherited = elements.inherited[slot];
955    let section = elements.drawn[slot];
956    // What a scrolling ancestor leaves visible, never wider than the surface: a clip is what the
957    // backend scissors the pass to, and nothing outside the surface is painted whatever the rect
958    // says.
959    let clip = elements.clip[slot].intersect(surface);
960    // Culled by where it lands once turned and scaled, which may be on screen where its upright box
961    // is not.
962    let posed = elements.posed[slot];
963    if !inherited.visible || posed.bounds(section).intersect(clip).is_empty() {
964        return None;
965    }
966    Some(Painted {
967        section,
968        clip,
969        opacity: inherited.drawn,
970        layer: inherited.layer,
971        posed,
972    })
973}

975/// The largest square `section` holds, centred in it.
976fn squared(section: Section) -> Section {
977    let side = section.width().min(section.height());
978    Section::new(
979        Position::new(
980            section.left() + (section.width() - side) / 2.0,
981            section.top() + (section.height() - side) / 2.0,
982        ),
983        Area::new(side, side),
984    )
985}

987/// The box a picture is drawn into, and what part of it is shown.
988///
989/// One of the two moves, never both: fitting inside the box changes the box and shows the whole
990/// picture, and filling the box keeps the box and shows part of the picture. Stretching does
991/// neither and is the only one that distorts.
992fn fitted(section: Section, picture: Area, fit: Fit) -> (Section, [f32; 4]) {
993    const WHOLE: [f32; 4] = [0.0, 0.0, 1.0, 1.0];
994    if picture.width <= 0.0 || picture.height <= 0.0 || section.is_empty() {
995        return (section, WHOLE);
996    }
997    let picture_ratio = picture.width / picture.height;
998    let box_ratio = section.width() / section.height();
999    match fit {
1000        Fit::Stretch => (section, WHOLE),
1001        Fit::Aspect => {
1002            let area = match box_ratio > picture_ratio {
1003                true => Area::new(section.height() * picture_ratio, section.height()),
1004                false => Area::new(section.width(), section.width() / picture_ratio),
1005            };
1006            let position = Position::new(
1007                section.left() + (section.width() - area.width) / 2.0,
1008                section.top() + (section.height() - area.height) / 2.0,
1009            );
1010            (Section::new(position, area), WHOLE)
1011        }
1012        Fit::Crop => {
1013            let (width, height) = match box_ratio > picture_ratio {
1014                true => (1.0, picture_ratio / box_ratio),
1015                false => (box_ratio / picture_ratio, 1.0),
1016            };
1017            (
1018                section,
1019                [(1.0 - width) / 2.0, (1.0 - height) / 2.0, width, height],
1020            )
1021        }
1022    }
1023}

1025/// What a fill currently paints as.
1026///
1027/// A blend of two fills is a color rather than a fill, so a motion on one is applied here -- where a
1028/// fill becomes a color -- and not written onto the element. Both ends are read against the same
1029/// scheme at the same instant, so a repaint mid-motion moves whichever of them is a role.
1030fn tint(grove: &Grove, leaf: Leaf, fill: Fill) -> Color {
1031    let target = fill.color(&grove.scheme);
1032    match grove.aspen.fill(leaf) {
1033        Some((Departed::Declared(fill), at)) => fill.color(&grove.scheme).blend(target, at),
1034        Some((Departed::Snapshot(color), at)) => color.blend(target, at),
1035        None => target,
1036    }
