1//! Ash -- the render backend.
2//!
3//! Step 9. What [`Elm`](crate::elm) decided had changed becomes what the GPU is holding, and what
4//! the GPU is holding becomes a frame.
5//!
6//! # The batch is a contract
7//!
8//! `Elm`'s cache is *what the backend holds*. Every batch it produces has to be applied, because a
9//! batch that is dropped leaves that cache claiming something the GPU does not have and nothing
10//! afterwards will disagree with it. So absorbing a batch is separate from painting one: absorbing
11//! is unconditional and happens in the same breath as the extraction that produced it, and a paint
12//! that cannot acquire a surface loses a picture rather than a change.
13//!
14//! # This is where the density lives
15//!
16//! Everything above this line is written in logical pixels. Four of the six renderers cannot build
17//! what the GPU draws without knowing how large a device pixel is -- a glyph is cut at a density, a
18//! stroke's axis-aligned edges are snapped to whole ones, a mark's distance range is converted into
19//! a screen-space one, a picture is uploaded at its own resolution -- so each takes what extraction
20//! declared and derives the instance here. That is what keeps `Ginkgo`'s line honest: the scale
21//! factor is applied below it and nowhere above.
22//!
23//! # The stack is shared
24//!
25//! There is one stack, across every renderer, ordered back to front by rank -- which is what alpha
26//! blending requires. It is walked here, and a renderer holds no opinion about it: each keeps its
27//! own slots sorted by rank, and this merges them.
28//!
29//! Two things come out of that one walk, and they must come out of the same one. Each instance is
30//! given a **depth** from its position in it, so the depth test holds the order for fragments the
31//! draw order alone would not, and a repaint of the same content lands on the same result. And the
32//! walk is cut into **spans**: maximal runs sharing a renderer, a clip, and a binding. A run of one
33//! renderer's slots is contiguous in that renderer's buffer, because the merge meets them in slot
34//! order, so a span is one draw of one range.
35//!
36//! The binding is in that cut because a picture is one texture each: two images at neighbouring
37//! ranks are two spans, and everything else in the engine binds one thing or nothing and so never
38//! cuts on it.
39//!
40//! Clipping is applied to the pass as a scissor rather than carried in an instance and tested per
41//! fragment, so it costs nothing per element and every renderer has it without a line of shader.
42//!
43//! # Some of it is drawn apart
44//!
45//! An instance whose rank names a [layer](crate::elevation::ResolvedElevation::layer) that is open
46//! this frame is taken out of the window's walk and walked into that layer's instead, in the same
47//! order. The layer itself stands in the window's walk at the rank of the element that opened it,
48//! and is laid down there ([`layer`]). So something drawn together is drawn at its own place in the
49//! stack, whole, and nothing grown elsewhere comes between its parts while it fades.

82///
83/// The whole of the geometry every renderer here draws over: a rounded corner is a distance field
84/// and a glyph is a sample of a sheet, so neither has anything to carve into a mesh. One constant
85/// rather than one per renderer, because two quads that disagreed would be two renderers whose
86/// instances mean subtly different things.

88    [0.0, 0.0],
89    [1.0, 0.0],
90    [0.0, 1.0],
91    [1.0, 0.0],
92    [1.0, 1.0],
93    [0.0, 1.0],

121/// One run of the stack: which renderer draws it, what it is scissored to, what it binds, and which
122/// of that renderer's slots it covers.
123#[derive(Copy, Clone, Debug)]
124struct Span {
125    renderer: Renderer,
126    clip: Section,
127    group: u32,
128    from: u32,
129    to: u32,
130}

132/// One instance's place in the stack.
133#[derive(Copy, Clone, Debug, PartialEq, Eq, PartialOrd, Ord)]
134struct Slot {
135    /// First, because this is what the stack is ordered by. A rank is total, so the sort leaves no
136    /// tie and two identical runs draw identically.
137    rank: ResolvedElevation,
138    renderer: Renderer,
139    slot: u32,
140}

151    /// A picture drawn apart, laid down whole. Its slot is its index among this frame's pictures.

236    /// Takes this frame's batches and puts them on the GPU.
237    ///
238    /// Runs once for every extraction, and reads what extraction produced without consuming it: a
239    /// batch is a statement of what the backend should be holding, so applying one twice reaches
240    /// the same holding as applying it once. What must not happen is applying one zero times.
241    ///
242    /// `fonts`, `fields` and `plates` are here and not in the batch for one reason: what a face, a
243    /// distance field or a decoded picture *becomes* at this display's density is the only part
244    /// that has to be re-answered when the display changes, and it is the part extraction cannot
245    /// state.
246    pub(crate) fn absorb(
247        &mut self,
248        elm: &Elm,
249        fonts: &Fonts,
250        fields: &Fields,
251        plates: &Plates,
252        ginkgo: &Ginkgo,
253    ) {
254        let span = trace_span!("absorb", written = Empty, withdrawn = Empty, glyphs = Empty);
255        let _entered = span.enter();
256        let (written, withdrawn) = elm.moved();
257        span.record("written", written);
258        span.record("withdrawn", withdrawn);
259        let scale = ginkgo.scale();
260        for wanted in &elm.panels.written {
261            self.panels
262                .instances
263                .write(wanted.key, wanted.rank, wanted.clip, 0, wanted.instance);
264        }
265        for key in &elm.panels.withdrawn {
266            self.panels.instances.withdraw(*key);
267        }
268        for wanted in &elm.polygons.written {
269            self.polygons
270                .instances
271                .write(wanted.key, wanted.rank, wanted.clip, 0, wanted.instance);
272        }
273        for key in &elm.polygons.withdrawn {
274            self.polygons.instances.withdraw(*key);
275        }
276        for wanted in &elm.lines.written {
277            self.lines.instances.write(
278                wanted.key,
279                wanted.rank,
280                wanted.clip,
281                0,
282                LineQuad::new(wanted.instance, scale),
283            );
284        }
285        for key in &elm.lines.withdrawn {
286            self.lines.instances.withdraw(*key);
287        }
288        for wanted in &elm.icons.written {
289            // Packing on first sight, so a mark costs one upload for the life of the program and a
290            // frame that draws one already packed touches no texture.
291            let packed = self.sheet.place(fields, ginkgo, wanted.instance.field);
292            self.icons.instances.write(
293                wanted.key,
294                wanted.rank,
295                wanted.clip,
296                0,
297                MarkQuad::new(wanted.instance, packed, scale),
298            );
299        }
300        for key in &elm.icons.withdrawn {
301            self.icons.instances.withdraw(*key);
302        }
303        // New pixels under a name already held. Every instance drawing it may be exactly what it
304        // was -- the same box, the same crop -- so nothing below would reach it, and the texture is
305        // replaced here or never. One that is not held is left for the first instance to want it.
306        for &plate in &elm.refilled {
307            if self.pictures.binding(plate).is_some() {
308                self.upload(plates, ginkgo, plate);
309            }
310        }
311        for wanted in &elm.images.written {
312            if self.pictures.binding(wanted.instance.plate).is_none() {
313                self.upload(plates, ginkgo, wanted.instance.plate);
314            }
315            self.images.instances.write(
316                wanted.key,
317                wanted.rank,
318                wanted.clip,
319                // The one renderer whose binding is per instance, so the one that puts anything
320                // but zero here.
321                wanted.instance.plate.0,
322                PictureQuad {
323                    section: wanted.instance.section,
324                    crop: wanted.instance.crop,
325                    radii: wanted.instance.radii,
326                    opacity: wanted.instance.opacity,
327                    pose: wanted.instance.pose,
328                },
329            );
330        }
331        for key in &elm.images.withdrawn {
332            self.images.instances.withdraw(*key);
333        }
334        // Taken whole rather than a run at a time, because a sheet that runs out of room is cut again
335        // from every run the frame draws -- which is more than this batch names.
336        self.texts.absorb(&elm.texts, fonts, ginkgo);
337        let device = ginkgo.device();
338        let queue = ginkgo.queue();
339        self.panels.instances.flush(device, queue);
340        self.polygons.instances.flush(device, queue);
341        self.lines.instances.flush(device, queue);
342        self.icons.instances.flush(device, queue);
343        self.images.instances.flush(device, queue);
344        self.texts.flush(device, queue);
345        span.record("glyphs", self.texts.len());
346        // Every one of them, and not the first that says so: a walk skipped because another
347        // renderer answered first would leave that one's new slots without a depth.
348        let disturbed = [
349            self.panels.instances.disturbed(),
350            self.polygons.instances.disturbed(),
351            self.lines.instances.disturbed(),
352            self.icons.instances.disturbed(),
353            self.images.instances.disturbed(),
354            self.texts.disturbed(),
355        ];
356        // Where the pictures stand moved, or which there are: the stack is walked again. Only how
357        // opaque each is moved, which is every frame of a fade: what each is laid down with is
358        // rewritten and nothing else.
359        let mut restack = disturbed.into_iter().any(|moved| moved);
360        if elm.relayered {
361            let placed = |layers: &[Layered]| -> Vec<(u32, ResolvedElevation)> {
362                layers
363                    .iter()
364                    .map(|layered| (layered.layer, layered.rank))
365                    .collect()
366            };
367            restack |= placed(&self.composites) != placed(&elm.layers);
368            self.composites.clone_from(&elm.layers);
369            for (laid, layered) in self.laid.iter_mut().zip(&self.composites) {
370                laid.opacity = layered.opacity;
371            }
372        }
373        if restack {
374            self.restack(ginkgo);
375        } else if elm.relayered
376            || self.layers.canvases(ginkgo, self.laid.len()).len() < self.laid.len()
377        {
378            // What each is laid down with moved, or the window changed size under them.
379            self.layers.hold(ginkgo, &self.laid);
380        }
381    }

383    /// Lets go of everything the renderers hold, for the next batch to state all of it again.
384    ///
385    /// This side of [`Elm::recut`](crate::elm::Elm::recut), for a backend that is kept rather than
386    /// built again -- which is a display whose density changed. That drops the cache of what is
387    /// held here, so the next extraction states every element it finds drawn, and names nothing to
388    /// be let go of: an element that stopped being drawn in the same frame has nothing held for it
389    /// there to withdraw. So what is held here goes too, and the next batch is the whole of what is
390    /// drawn.
391    ///
392    /// And the glyph atlas with it, because every cut on it was rasterised at the density that went.
393    /// A mark's field and a picture's pixels are stated in their own texels and are kept.
394    pub(crate) fn recut(&mut self) {
395        self.composites.clear();
396        self.panels.instances.forget();
397        self.polygons.instances.forget();
398        self.lines.instances.forget();
399        self.icons.instances.forget();
400        self.images.instances.forget();
401        self.texts.forget();
402    }

404    /// Puts a picture's pixels on the GPU as they now stand, replacing whatever was held under its
405    /// name. Called the first time an instance wants a picture, and again whenever its pixels are
406    /// replaced while it is held.
407    fn upload(&mut self, plates: &Plates, ginkgo: &Ginkgo, plate: Plate) {
408        let Some(picture) = plates.picture(plate) else {
409            return;
410        };
411        self.pictures.upload(
412            ginkgo,
413            plate,
414            &picture.pixels,
415            (picture.size.width as u32, picture.size.height as u32),
416        );
417    }

419    /// Walks the one stack: gives every instance its depth, and cuts the draw into spans.
420    ///
421    /// Runs only when something in it moved -- a slot appeared, went, changed rank, or changed what
422    /// it is clipped to or what it binds. A frame that only recoloured what was already there
423    /// leaves the stack as it was, and this does not run.
424    fn restack(&mut self, ginkgo: &Ginkgo) {
425        let _span = trace_span!("restack").entered();
426        self.stack.clear();
427        let gather = |ranks: &[ResolvedElevation], renderer: Renderer, stack: &mut Vec<Slot>| {
428            stack.extend(ranks.iter().enumerate().map(|(slot, rank)| Slot {
429                rank: *rank,
430                renderer,
431                slot: slot as u32,
432            }));
433        };
434        gather(
435            self.panels.instances.ranks(),
436            Renderer::Panel,
437            &mut self.stack,
438        );
439        gather(
440            self.polygons.instances.ranks(),
441            Renderer::Polygon,
442            &mut self.stack,
443        );
444        gather(
445            self.lines.instances.ranks(),
446            Renderer::Line,
447            &mut self.stack,
448        );
449        gather(
450            self.icons.instances.ranks(),
451            Renderer::Icon,
452            &mut self.stack,
453        );
454        gather(
455            self.images.instances.ranks(),
456            Renderer::Image,
457            &mut self.stack,
458        );
459        // A run contributes one entry however many characters it has, which is what keeps this the
460        // size of the tree rather than the size of the text on it.
461        gather(self.texts.ranks(), Renderer::Text, &mut self.stack);
462        // Each picture stands where the element that opened it does.
463        self.stack.extend(
464            self.composites
465                .iter()
466                .enumerate()
467                .map(|(index, layered)| Slot {
468                    rank: layered.rank,
469                    renderer: Renderer::Layer,
470                    slot: index as u32,
471                }),
472        );
473        self.stack.sort_unstable();
474        let total = self.stack.len();
475        self.spans.clear();
476        self.layered.iter_mut().for_each(Vec::clear);
477        self.layered.resize_with(self.composites.len(), Vec::new);
478        self.laid.clear();
479        self.laid.extend(self.composites.iter().map(|layered| Laid {
480            opacity: layered.opacity,
481            depth: 0.0,
482        }));
483        // How far down each walk has come: the window's first, then each picture's. A picture has a
484        // depth attachment of its own, so its walk counts from the back like the window's does.
485        let mut positions = vec![0_usize; self.composites.len() + 1];
486        // What was drawn into each picture reaches, which is all of it there is to lay down.
487        let mut reaches: Vec<Option<Section>> = vec![None; self.composites.len()];
488        for entry in &self.stack {
489            // Into the picture its rank names, where that picture is open; onto the window where it
490            // is not, which an instance whose picture closed this frame and has not been rewritten
491            // yet still names.
492            let into = match entry.renderer {
493                Renderer::Layer => 0,
494                _ => self
495                    .composites
496                    .binary_search_by_key(&entry.rank.layer, |layered| layered.layer)
497                    .map_or(0, |at| at + 1),
498            };
499            let depth = Depth::of(positions[into], total);
500            positions[into] += 1;
501            let (clip, group) = match entry.renderer {
502                Renderer::Panel => {
503                    self.panels.instances.set_depth(entry.slot, depth);
504                    (self.panels.instances.clip(entry.slot), 0)
505                }
506                Renderer::Polygon => {
507                    self.polygons.instances.set_depth(entry.slot, depth);
508                    (self.polygons.instances.clip(entry.slot), 0)
509                }
510                Renderer::Line => {
511                    self.lines.instances.set_depth(entry.slot, depth);
512                    (self.lines.instances.clip(entry.slot), 0)
513                }
514                Renderer::Icon => {
515                    self.icons.instances.set_depth(entry.slot, depth);
516                    (self.icons.instances.clip(entry.slot), 0)
517                }
518                Renderer::Image => {
519                    self.images.instances.set_depth(entry.slot, depth);
520                    (
521                        self.images.instances.clip(entry.slot),
522                        self.images.instances.group(entry.slot),
523                    )
524                }
525                Renderer::Text => {
526                    self.texts.set_depth(entry.slot, depth);
527                    (self.texts.clip(entry.slot), 0)
528                }
529                // Scissored to what was drawn into it, which is only known once the walk is over.
530                Renderer::Layer => {
531                    self.laid[entry.slot as usize].depth = depth;
532                    (Section::default(), entry.slot)
533                }
534            };
535            let spans = match into {
536                0 => &mut self.spans,
537                picture => {
538                    let reach = &mut reaches[picture - 1];
539                    *reach = Some(reach.map_or(clip, |reach| around(reach, clip)));
540                    &mut self.layered[picture - 1]
541                }
542            };
543            match spans.last_mut() {
544                Some(span)
545                    if span.renderer == entry.renderer
546                        && span.clip == clip
547                        && span.group == group
548                        && span.to == entry.slot =>
549                {
550                    span.to = entry.slot + 1;
551                }
552                _ => spans.push(Span {
553                    renderer: entry.renderer,
554                    clip,
555                    group,
556                    from: entry.slot,
557                    to: entry.slot + 1,
558                }),
559            }
560        }
561        for span in &mut self.spans {
562            if span.renderer == Renderer::Layer {
563                span.clip = reaches[span.group as usize].unwrap_or_default();
564            }
565        }
566        self.layers.hold(ginkgo, &self.laid);
567        let queue = ginkgo.queue();
568        self.panels.instances.flush_depths(queue);
569        self.polygons.instances.flush_depths(queue);
570        self.lines.instances.flush_depths(queue);
571        self.icons.instances.flush_depths(queue);
572        self.images.instances.flush_depths(queue);
573        self.texts.flush_depths(queue);
574    }

576    /// Step 9. Paints what is held.
577    ///
578    /// `clear` is what the surface is cleared to. Nothing of the engine's own sits behind the tree,
579    /// so it is the app's own ground -- whatever [`Palette::Surface`](crate::Palette::Surface)
580    /// currently resolves to.
581    pub(crate) fn draw(&self, ginkgo: &Ginkgo, clear: Color) {
582        let _span = trace_span!(
583            "draw",
584            instances = self.stack.len(),
585            spans = self.spans.len()
586        )
587        .entered();
588        let canvases = self.layers.canvases(ginkgo, self.laid.len());
589        let targets: Vec<_> = canvases.iter().map(|canvas| canvas.target()).collect();
590        ginkgo.draw(
591            clear,
592            &targets,
593            |index, pass| self.paint(ginkgo, pass, &self.layered[index], false),
594            // A picture with nothing to lay down -- the window changed size and no frame has made
595            // pictures at the new one yet -- is left out for the frame rather than laid down stale.
596            |pass| self.paint(ginkgo, pass, &self.spans, !targets.is_empty()),
597        );
598    }

600    /// Draws `spans` into a pass, laying pictures down where they stand if `laying`.
601    fn paint(
602        &self,
603        ginkgo: &Ginkgo,
604        pass: &mut wgpu::RenderPass<'_>,
605        spans: &[Span],
606        laying: bool,
607    ) {
608        for span in spans {
609            let (left, top, width, height) = ginkgo.scissor(span.clip);
610            // A region scrolled entirely off the surface has nothing to paint, and a zero-sized
611            // scissor is not a way of saying so.
612            if width == 0 || height == 0 {
613                continue;
614            }
615            pass.set_scissor_rect(left, top, width, height);
616            let range = span.from..span.to;
617            match span.renderer {
618                Renderer::Panel => self.panels.draw(pass, range, None),
619                Renderer::Polygon => self.polygons.draw(pass, range, None),
620                Renderer::Line => self.lines.draw(pass, range, None),
621                Renderer::Icon => self.icons.draw(pass, range, Some(self.sheet.binding())),
622                // A picture whose texture is not held yet is skipped rather than drawn against
623                // someone else's: it appears on the frame its pixels arrive.
624                Renderer::Image => {
625                    if let Some(binding) = self.pictures.binding(crate::image::Plate(span.group)) {
626                        self.images.draw(pass, range, Some(binding));
627                    }
628                }
629                Renderer::Text => self.texts.draw(pass, range),
630                Renderer::Layer => {
631                    if laying {
632                        self.layers.draw(pass, span.group as usize);
633                    }
634                }
635            }
636        }
637    }
638}

640/// The smallest section holding both.
641fn around(one: Section, other: Section) -> Section {
642    Section::from_edges(
643        one.left().min(other.left()),
644        one.top().min(other.top()),
645        one.right().max(other.right()),
646        one.bottom().max(other.bottom()),
647    )
648}
