11/// Exactly what a frame may read of an element.
12///
13/// Exhaustive by construction: if it is not here, an app cannot see it. Everything an app can
14/// declare is here, because a value you can set and cannot read back is a value you have to keep a
15/// copy of.
16#[derive(Copy, Clone, PartialEq, Eq, Hash, Debug)]
17#[non_exhaustive]
18pub enum Vein {
19    /// The elements branched directly off this one.
20    Branches,
21    /// The element this one was branched off, if any.
22    Trunk,
23    /// Where the layout put the element, before any scrolling moved it.
24    ///
25    /// What a containing view's extent is measured from, and what to read when the question is
26    /// where content sits rather than where it currently appears.
27    Placed,
28    /// The element's box less every scrolling ancestor's offset: where it is on screen, which is
29    /// what was drawn and what a hit test runs against.
30    ///
31    /// The two differ only inside a view that has been scrolled.
32    Drawn,
33    /// The one other element this one's placement may read, if it has been given one.
34    Anchor,
35    /// How far in front of its trunk the element was told to sit.
36    ///
37    /// What was declared, not where it ended up: the resolved value accumulates its whole ancestry
38    /// and carries a tie-break, and neither is a number an app has any use for.
39    Elevation,
40    /// What the element is filled with, if it is something with a fill: the role it declared, or
41    /// the color it named outright.
42    ///
43    /// What was declared, not what it currently paints as. A role's color is the
44    /// [`Scheme`](crate::Scheme)'s answer and is resolved at extraction, so there is no resolved
45    /// color held anywhere for this to report.
46    Color,
47    /// Where a stroke's two ends landed, which is what [`Drawn`](Vein::Drawn) cannot say.
48    ///
49    /// A box is the rectangle around them grown by half the weight, and a rectangle has two
50    /// diagonals -- so the box says how much room the stroke takes and this says where it runs.
51    /// `None` on anything placed by a box.
52    ///
53    /// Resolved rather than declared, on the same terms as `Drawn`: the two ends as the layout
54    /// answered them and scrolling moved them, not the grammar they were written in.
55    Ends,
56    /// How thick a stroke is drawn, in logical pixels. `None` on anything that is not a stroke.
57    Weight,
58    /// How a stroke's ends are finished.
59    Cap,
60    /// What a regular polygon looks like: its sides, its rounding and its rotation.
61    ///
62    /// While a [`Motion::Polygon`](crate::Motion::Polygon) is running this is where it has reached,
63    /// because a blend of two shapes is a shape and is written back over the declaration -- the same
64    /// standing [`Opacity`](Vein::Opacity) has.
65    Shape,
66    /// Which registered mark an icon draws.
67    Mark,
68    /// Which registered picture an image draws.
69    ///
70    /// The name only. Whether its pixels have arrived is not readable and is deliberately not a
71    /// question an app has to ask: an element drawing a picture that has not loaded occupies its box
72    /// and draws nothing, and appears when the pixels do.
73    Picture,
74    /// How an image's pixels are fitted into its box.
75    Fit,
76    /// How the element's corners are rounded, if it is something with corners.
77    Rounding,
78    /// What the element says, if it is a run of glyphs.
79    ///
80    /// What was written, not how it wrapped: where the lines fell is a function of the box the
81    /// layout gave it, and the box is [`Drawn`](Vein::Drawn).
82    Text,
83    /// What a [`TextInput`](crate::TextInput) has selected, in characters of its value.
84    ///
85    /// Empty where nothing is selected, and its one end is then where the caret is -- so a caret
86    /// and a selection are one read rather than two that could disagree.
87    /// `None` on anything that is not a field.
88    Selection,
89    /// Whether the app has hidden the element.
90    ///
91    /// What was declared of this element, not the product over its ancestry: an element inside a
92    /// hidden subtree reads visible, because that is what it says about itself and what showing its
93    /// ancestor again would leave it as.
94    Visible,
95    /// How opaque the element was told to be, on the same terms as [`Visible`](Vein::Visible).
96    ///
97    /// While a [`Motion::Opacity`](crate::Motion::Opacity) is running this is where it has reached,
98    /// because a blend of two numbers is a number and is written back over the declaration. That is
99    /// what is on screen, which is what a read is for.
100    Opacity,
101    /// Whether the element was disabled in its own right, on the same terms as
102    /// [`Visible`](Vein::Visible).
103    Disabled,
104    /// How far a scrolling region has been moved from its content's origin, in logical pixels.
105    ///
106    /// The same unit it is written in, so reading it back after a
107    /// [`scroll`](crate::Grow::scroll) returns the pixels it settled at. `None` on anything that
108    /// does not scroll: an element with no scrolling axis has no offset, rather than an offset of
109    /// zero it can never leave.
110    Offset,
111    /// How far a scrolling region's content reaches, from its own near edges.
112    ///
113    /// What a scrollbar's thumb is a fraction of. An axis the region does not scroll reads the
114    /// region's own box, which is the same statement as having no extent on it.
115    Extent,
116    /// How far through its range a scrolling region sits, per axis, in `0.0..=1.0`.
117    ///
118    /// Derived from the two above rather than held, and read-only for that reason: pixels are the
119    /// one unit an offset is written in. A region with nowhere to go reads zero on that axis.
120    Progress,
121}

123/// What a [`Vein`] draws out.
124#[derive(Clone, PartialEq, Debug)]
125#[non_exhaustive]
126pub enum Sap {
127    /// A set of elements, in the order the tree holds them. What [`Branches`](Vein::Branches)
128    /// answers.
129    Leaves(Vec<Leaf>),
130    /// One element, or none where there is nothing to name. What [`Trunk`](Vein::Trunk) and
131    /// [`Anchor`](Vein::Anchor) answer.
132    Leaf(Option<Leaf>),
133    /// A box. What [`Placed`](Vein::Placed) and [`Drawn`](Vein::Drawn) answer.
134    Section(Section),
135    /// Logical pixels, like every other coordinate.
136    Position(Position),
137    /// An extent, in logical pixels.
138    Area(Area),
139    /// A fraction on each axis, in `0.0..=1.0`. Held apart from a [`Position`](Sap::Position) even
140    /// though it is the same pair of numbers, so a read cannot quietly take a fraction for pixels.
141    Progress(Position),
142    /// How far in front of its trunk an element was told to sit.
143    Elevation(Elevation),
144    /// What an element is filled with: the role it declared, or the color it named outright.
145    Color(Fill),
146    /// The radius bracket on each of the four corners.
147    Rounding(Corners),
148    /// A stroke's two ends, in the order they were written.
149    Ends(Position, Position),
150    /// A stroke's thickness, in logical pixels.
151    Weight(f32),
152    /// How a stroke's ends are finished.
153    Cap(Cap),
154    /// A regular polygon's sides, rounding and rotation.
155    Shape(Shape),
156    /// Which registered mark an icon draws.
157    Mark(Field),
158    /// Which registered picture an image draws.
159    Picture(Plate),
160    /// How an image's pixels are fitted into its box.
161    Fit(Fit),
162    /// What a run of glyphs says.
163    Text(String),
164    /// A span of a value, in characters. Empty means a caret at its own position.
165    Selection(core::ops::Range<usize>),
166    /// Whether the app has hidden the element.
167    Visible(bool),
168    /// How opaque the element was told to be, in `0.0..=1.0`.
169    Opacity(f32),
170    /// Whether the element was disabled in its own right.
171    Disabled(bool),
172}
