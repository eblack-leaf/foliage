1//! Interaction -- hit-testing, gestures, and focus.
2//!
3//! # Two questions, not one
4//!
5//! 1. **What is at this point?** Geometry, answered for every element, always. That is
6//!    [`stack`], and it is where the law of this module lives.
7//! 2. **Who receives this gesture?** Intent, answered only for elements that asked. That is
8//!    [`interactive`](crate::Place::interactive), and it is one bit.
9//!
10//! Answering both with one mechanism is what made decoration steal taps, because the only way to
11//! stop it stealing them was to take it out of the geometry -- which is the same geometry a drag
12//! needs to find its scrolling region.
13//!
14//! # Gestures are claimed, not declared
15//!
16//! Nothing at spawn time knows what a gesture will turn out to mean. A drag beginning on a slider
17//! inside a scrolling column belongs to the slider if it moves along the slider and to the column
18//! if it moves down.
19//!
20//! So a gesture opens **unclaimed**. The target it landed on holds it while it resolves; if it
21//! resolves to a drag the target does not take, the target yields and it passes to the nearest
22//! scrolling ancestor. Contention runs up the tree and never sideways -- a target contends only
23//! with the things containing it, because targeting has already picked one element over every other
24//! one at that point.
25//!
26//! A **tap** is what a gesture that ended without ever resolving to a drag emits. Nothing is
27//! cancelled and nothing is retracted, because nothing was issued early: the threshold is not a
28//! rule about taking a click back, it is the point at which the kind of the gesture becomes known.
29//!
30//! # A press that was held
31//!
32//! That threshold is a distance, and a distance alone cannot tell a gesture that is sitting still
33//! from one that has not moved yet. So resolving has a second way out: held past [`Hold::after`],
34//! reported as a gesture fact of its own.
35//!
36//! ```text
37//! opened ──▶ resolving ──▶ claimed ──▶ ended
38//!                └──────▶ held ──▶ claimed ──▶ ended
39//! ```
40//!
41//! It is general -- context menus, reorder handles and press-and-hold affordances all want it -- and
42//! it is what lets an element scroll like any other and still take a drag, by declaring no drag at
43//! all and claiming one only out of a hold.
44

65/// What an element declared about gestures.
66///
67/// Two of these state what cannot be derived from anything else, and the other two are the shape of
68/// the element as a hand meets it rather than as it is drawn. What is *not* here is any prediction
69/// of what a gesture will mean: that is claimed at the time, from the gesture itself.
70#[derive(Component, Copy, Clone, Debug, Default, PartialEq)]
71pub(crate) struct Gestures {
72    /// Declared [`interactive`](crate::Place::interactive): this element receives.
73    pub(crate) receives: bool,
74    /// Declared [`intangible`](crate::Place::intangible): a gesture over it reaches what is
75    /// beneath.
76    pub(crate) intangible: bool,
77    /// Which drags the element takes. Absent, it takes none -- so it holds a gesture only until
78    /// that gesture becomes a drag, and then yields.
79    pub(crate) drags: Option<Axes>,
80    pub(crate) shape: Shape,
81}

93/// How far a gesture travels before it is claimed as a drag, per axis, in logical pixels.
94///
95/// The two axes compete at different scales, so one number is too eager for one and too reluctant
96/// for the other. On touch, scrolling down is the dominant gesture and wants an eager claim; a
97/// claim across contends with it and wants a larger threshold, or every attempt to scroll steals
98/// into a carousel.
99///
100/// A **global tuning value, not a per-element flag**. This is input feel, and input feel that
101/// varies element to element is what makes an app feel unpredictable. Set it once, before the
102/// engine runs:
103///
104/// ```no_run
105/// # use foliage::{Claim, Foliage};
106/// let mut foliage = Foliage::new();
107/// foliage.tune(Claim {
108///     horizontal: 18.0,
109///     vertical: 8.0,
110/// });
111/// ```
112///
113/// Callers wanting the two the same set them the same.
114#[derive(Copy, Clone, Debug, PartialEq)]
115pub struct Claim {
116    /// How far across before a drag is claimed as a drag across.
117    pub horizontal: f32,
118    /// How far down before a drag is claimed as a drag down.
119    pub vertical: f32,
120}
121
122impl Default for Claim {
123    fn default() -> Self {
124        Self {
125            horizontal: 16.0,
126            vertical: 8.0,
127        }
128    }
129}
130
131impl Claim {
132    /// Which axis this travel has claimed, or `None` while the gesture could still be a tap.
133    ///
134    /// A tie goes down, because down is the gesture a hand makes without meaning anything by it.
135    fn claimed(&self, travel: Position) -> Option<Axis> {
136        let (across, down) = (travel.x.abs(), travel.y.abs());
137        if down >= self.vertical && down >= across {
138            return Some(Axis::Vertical);
139        }
140        if across >= self.horizontal && across > down {
141            return Some(Axis::Horizontal);
142        }
143        None
144    }
145}

147/// How long a press is held before it is a hold rather than a gesture still deciding.
148///
149/// The lifecycle's other threshold is a distance, so on its own it leaves a gesture that is sitting
150/// still indistinguishable from one that has not moved yet. Touch is where that shows: dragging to
151/// scroll and dragging to select are the same motion, and what separates them on both platforms is
152/// that a plain drag scrolls and selection begins from a press that was **held**.
153///
154/// A **global tuning value, not a per-element flag**, for the reason [`Claim`] is one. Set it once,
155/// before the engine runs:
156///
157/// ```no_run
158/// # use core::time::Duration;
159/// # use foliage::{Foliage, Hold};
160/// let mut foliage = Foliage::new();
161/// foliage.tune(Hold {
162///     after: Duration::from_millis(400),
163/// });
164/// ```
165///
166/// Not something an element opts into. A hold is part of what a gesture can turn out to be, so it is
167/// reported to whatever the press landed on and that element decides whether it means anything --
168/// which is the same footing a tap is on.
169#[derive(Copy, Clone, Debug, PartialEq, Eq)]
170pub struct Hold {
171    /// How long the press is down, without having become a drag, before it is reported as held.
172    pub after: Duration,
173}
174
175impl Default for Hold {
176    fn default() -> Self {
177        Self {
178            after: Duration::from_millis(500),
179        }
180    }
181}

183/// What a drag has done, as the element holding it reads it.
184///
185/// `delta` is this frame's movement and nothing else, so an element following a pointer adds it and
186/// an element reading an absolute position takes `current`. The travel spent deciding the gesture
187/// was a drag at all is not in any `delta`: it is the distance the claim cost, and paying it out
188/// afterwards would make everything that claims start with a jump.
189#[derive(Copy, Clone, Debug, PartialEq)]
190pub struct Drag {
191    /// Where the gesture began.
192    pub start: Position,
193    /// Where the pointer is now.
194    pub current: Position,
195    /// How far it moved this frame.
196    pub delta: Position,
197}

199/// How far back a release velocity is measured.
200///
201/// A release lands in one frame, and that frame on its own is a poor sample of the gesture that
202/// ended in it: a hand slows as it lifts, a pointer reports nothing at all in the frame the button
203/// came up, and a flick can put the whole of its movement into the frame before. Measured over one
204/// frame, all three read as a hand that stopped -- and with a minimum speed to clear, reading low is
205/// not a coast that starts slow, it is a coast that never starts.
206///
207/// So the speed handed on is the mean over the last of the gesture rather than the last frame of it.
208/// Long enough that a frame or two of nothing does not throw a fling away, short enough that a hand
209/// which came to rest before lifting still reads as stopped.
210///
211/// Not a tuning value: it is how the measurement is taken, not a statement about how a coast feels.
212/// [`Momentum`](crate::Momentum) is the half of momentum an app sets.
213const WINDOW: Duration = Duration::from_millis(100);

215/// The gesture in progress.
216pub(crate) struct Gesture {
217    /// Where it began, which is where its tap would be.
218    at: Position,
219    /// Where the pointer is now.
220    to: Position,
221    /// The element receiving it, while one is. Cleared when a target yields, so nothing that has
222    /// let go of a gesture hears any more about it.
223    target: Option<Leaf>,
224    /// The scrolling ancestors of wherever it landed, innermost first. Fixed at the press: where a
225    /// gesture lands is where it looks for a region, whatever it passes over afterwards.
226    chain: Vec<Leaf>,
227    stage: Stage,
228    /// When the press landed, on the engine's own clock.
229    ///
230    /// What a hold is measured from, so what it measures is time the gesture has been open rather
231    /// than time anything moved -- a hand that drifted a few pixels and stopped is still resolving,
232    /// and is still on its way to a hold.
233    since: Duration,
234    /// What the gesture did over the last [`WINDOW`], oldest first, which is what a release velocity
235    /// is measured from.
236    ///
237    /// One entry per frame the gesture has been open in, each carrying the interval it stands for,
238    /// so the mean is over time rather than over a count of frames. It holds the movement that was
239    /// actually *applied*, so the travel spent claiming the gesture is out of it here for the same
240    /// reason it is out of every `delta`.
241    recent: VecDeque<Sample>,
242}
243
244/// One frame's share of a gesture: how long the frame stood for, and how far it moved in it.
245struct Sample {
246    span: Duration,
247    travel: Position,
248}
249
250impl Gesture {
251    /// Opens this frame's sample and drops what has fallen out of the window.
252    fn open(&mut self, span: Duration) {
253        // A frame that took no time is no interval to measure a speed over, so it opens nothing and
254        // whatever moves in it belongs to the sample already running. The first sample is pushed
255        // whatever its span, so a gesture always has somewhere to put its movement.
256        if span.is_zero() && !self.recent.is_empty() {
257            return;
258        }
259        self.recent.push_back(Sample {
260            span,
261            travel: Position::default(),
262        });
263        // What is kept is the shortest run of frames that still reaches back a whole window, so a
264        // window's worth is always covered and never much more. The last sample is never dropped:
265        // where one frame is longer than the window, that frame is the whole measurement.
266        let mut covered = self.covered();
267        while let Some(oldest) = self.recent.front() {
268            let without = covered - oldest.span;
269            if without < WINDOW {
270                break;
271            }
272            covered = without;
273            self.recent.pop_front();
274        }
275    }
276
277    /// Adds movement to the frame being measured.
278    fn record(&mut self, delta: Position) {
279        if let Some(sample) = self.recent.back_mut() {
280            sample.travel = sample.travel.moved(delta);
281        }
282    }
283
284    /// How much time the samples reach back over.
285    fn covered(&self) -> Duration {
286        self.recent.iter().map(|sample| sample.span).sum()
287    }
288
289    /// The mean velocity of the pointer over the window, in logical pixels per second, or `None`
290    /// where no time has passed to measure one over.
291    fn velocity(&self) -> Option<Position> {
292        let covered = self.covered().as_secs_f32();
293        if covered <= 0.0 {
294            return None;
295        }
296        let travel = self
297            .recent
298            .iter()
299            .fold(Position::default(), |sum, sample| sum.moved(sample.travel));
300        Some(Position::new(travel.x / covered, travel.y / covered))
301    }
302
303    /// Whether this gesture could still become a hold.
304    ///
305    /// F9's question about a press that is not moving. A hold is the one thing that happens to a
306    /// gesture with nothing arriving to make it happen, so the frames that would notice it are owed
307    /// while this is true.
308    ///
309    /// A gesture that landed on nothing which receives is not one of them. A hold is a fact reported
310    /// to whoever is holding the gesture, and where nobody is, there is nothing for it to be a fact
311    /// about -- so such a press stays resolving and ends as the tap it would always have been.
312    fn awaiting_hold(&self) -> bool {
313        matches!(self.stage, Stage::Resolving) && self.target.is_some()
314    }
315}

317/// Where the gesture has reached, and with it who is holding it.
318enum Stage {
319    /// Opened and not yet a drag. The target holds it, and a release now is a tap.
320    Resolving,
321    /// Down past [`Hold::after`] without having become a drag. The target still holds it, and a
322    /// release now is not a tap -- the press has already turned into something else.
323    Held,
324    /// A drag the target took, because it declared [`drags`](crate::Place::drags) on this axis or
325    /// because it took the hold this drag came out of.
326    Target,
327    /// A drag a scrolling region took. The index only ever moves outward.
328    Region { index: usize, axis: Axis },
329    /// A drag on an axis nothing in the chain scrolls. Nothing moves, and nothing will.
330    Nobody,
331}

333/// Step 2. The frame's input, resolved against what the last frame drew.
334pub(crate) fn dispatch(grove: &mut Grove) {
335    let step = trace_span!("dispatch", inputs = Empty, stack = grove.stack.len());
336    let _entered = step.enter();
337    let pending = core::mem::take(&mut grove.incoming.pending);
338    step.record("inputs", pending.len());
339    // Every frame an open gesture lives through is one the window is measured across, so a frame
340    // opens a sample whether or not anything arrives in it: a frame nothing happened in is a hand
341    // that held still, and it counts against the mean exactly as much as one that moved.
342    let span = grove.clock.delta();
343    if let Some(gesture) = grove.incoming.gesture.as_mut() {
344        gesture.open(span);
345    }
346    // Read before this frame's input, because by the time any of that arrived the press had already
347    // been down this long. A hold is the transition nothing arrives to make.
348    holding(grove);
349    for input in pending {
350        match input {
351            Input::Pressed(at) => pressed(grove, at),
352            Input::Moved(to) => moved(grove, to),
353            Input::Released(at) => released(grove, at),
354            Input::Cancelled => close(grove, false),
355            Input::Wheeled { at, delta } => wheeled(grove, at, delta),
356            Input::Keyed(key) => keyed(grove, key),
357            Input::Modifiers(modifiers) => grove.incoming.modifiers = modifiers,
358        }
359    }
360}

362/// The second way out of resolving: a press that has been down long enough to be a statement of its
363/// own.
364///
365/// Read at the top of every frame an open gesture lives through, against the one clock the frame
366/// shares. Every other transition is an event -- a move that crossed a threshold, a release, a
367/// cancel -- and this is the one that is a duration, so there is nothing to answer it but the frame
368/// itself.
369///
370/// Reported and then done with: the gesture leaves resolving, so it is reported once however long
371/// the press goes on.
372fn holding(grove: &mut Grove) {
373    let (elapsed, after) = (grove.clock.elapsed(), grove.hold.after);
374    let Some(gesture) = grove.incoming.gesture.as_mut() else {
375        return;
376    };
377    if !gesture.awaiting_hold() || elapsed.saturating_sub(gesture.since) < after {
378        return;
379    }
380    let Some(target) = gesture.target else {
381        return;
382    };
383    let at = gesture.at;
384    gesture.stage = Stage::Held;
385    grove.drift.held.insert(target, at);
386    debug!(leaf = target.id(), "held");
387}

389/// A keystroke, delivered to whatever it is about.
390///
391/// `Tab` and `Escape` are focus's own and are answered wherever focus is, including nowhere --
392/// which is what makes keyboard navigation work on a page with no field on it at all. Everything
393/// else goes to whatever holds focus, and what an element makes of a key is that element's: this
394/// pass knows which keys steer focus and nothing else about any of them.
395///
396/// A key arriving with focus nowhere is carried with no target rather than dropped. It reaches no
397/// element -- there is none to reach -- and is reported to the app itself, which is where a chord
398/// that is about the whole page belongs.
399///
400/// Queued rather than applied, so a keystroke is drained in arrival order beside every other change
401/// and what it produces is reported on F7's own terms.
402fn keyed(grove: &mut Grove, key: Key) {
403    let stroke = Keystroke {
404        key,
405        modifiers: grove.incoming.modifiers,
406    };
407    if key == Key::Tab {
408        grove.queue.push(Op::Focus(match stroke.modifiers.shift {
409            true => Intent::Previous,
410            false => Intent::Next,
411        }));
412        debug!(shift = stroke.modifiers.shift, "tabbed");
413        return;
414    }
415    if key == Key::Escape {
416        grove.queue.push(Op::Focus(Intent::Away));
417        debug!("escaped");
418        return;
419    }
420    grove.queue.push(Op::Keyed {
421        target: grove.focus.held(),
422        stroke,
423    });
424}

426/// The one read of the stack, and everything that follows from it.
427fn pressed(grove: &mut Grove, at: Position) {
428    // A press arriving with a gesture still open ends that one first. It was not released, so it
429    // earned no tap.
430    close(grove, false);
431    let mut gesture = Gesture {
432        at,
433        to: at,
434        target: None,
435        chain: Vec::new(),
436        stage: Stage::Resolving,
437        since: grove.clock.elapsed(),
438        recent: VecDeque::new(),
439    };
440    // Opened here rather than at the top of the next dispatch, because a flick can press, move and
441    // release inside one frame and that movement has to land somewhere.
442    gesture.open(grove.clock.delta());
443    if let Some(region) = grove.stack.top(at) {
444        if region.disabled {
445            // Swallowed. A disabled element is present and inert: it takes nothing itself, and it
446            // does not pass the gesture on to what is behind it or to a region containing it.
447            debug!(leaf = region.leaf.id(), "gesture swallowed");
448        } else {
449            gesture.chain = chain(grove, region.leaf);
450            // Taking hold of something still coasting stops it where the hand met it. A coast is
451            // the reader's own last gesture carrying on, so catching it is how it is meant to end.
452            let caught = gesture.chain.iter().fold(false, |caught, &region| {
453                grove.coasting.stop(region) || caught
454            });
455            if caught {
456                // And the press is spent on the catch. What is under the hand hears nothing of it,
457                // or stopping a moving list would also be a press on whatever it happened to stop
458                // over -- which is the one thing a reader reaching for it did not mean. The gesture
459                // stays open and keeps its chain, so a drag out of the catch scrolls as any other.
460                debug!(leaf = region.leaf.id(), "coast caught");
461            } else if region.receives {
462                gesture.target = Some(region.leaf);
463                grove.drift.engaged.insert(region.leaf);
464                debug!(leaf = region.leaf.id(), "engaged");
465            }
466        }
467    }
468    grove.incoming.gesture = Some(gesture);
469}

471fn moved(grove: &mut Grove, to: Position) {
472    let Some(mut gesture) = grove.incoming.gesture.take() else {
473        return;
474    };
475    let delta = gesture.to.to(to);
476    gesture.to = to;
477    match gesture.stage {
478        Stage::Resolving => match grove.claim.claimed(gesture.at.to(to)) {
479            Some(axis) => claim(grove, &mut gesture, axis),
480            // Still short of both thresholds, so this is still a gesture that could end as a tap.
481            None => {
482                grove.incoming.gesture = Some(gesture);
483                return;
484            }
485        },
486        Stage::Held => claim_hold(grove, &mut gesture),
487        Stage::Target | Stage::Region { .. } | Stage::Nobody => {}
488    }
489    gesture.record(delta);
490    apply(grove, &mut gesture, delta);
491    grove.incoming.gesture = Some(gesture);
492}

494fn released(grove: &mut Grove, at: Position) {
495    // The last of the movement, which can itself be what claims the gesture: a flick can carry one
496    // move and a release and nothing else.
497    moved(grove, at);
498    close(grove, true);
499}

501/// The drag out of a hold, which belongs to whoever took the hold.
502///
503/// Not a second claim, and not one the thresholds have anything left to decide: the hold already
504/// settled that this gesture is not a tap and that this element is the one holding it, so the first
505/// movement out of it is the drag, however far it went and whichever way. An element that takes no
506/// drags at all still takes this one -- which is what lets it scroll like anything else and select
507/// from a press that was held.
508fn claim_hold(grove: &mut Grove, gesture: &mut Gesture) {
509    let Some(target) = gesture.target else {
510        return;
511    };
512    gesture.stage = Stage::Target;
513    grove.drift.drag_started.insert(target);
514    debug!(leaf = target.id(), "drag claimed");
515}

517/// The gesture has become a drag. Who takes it is settled here, once.
518fn claim(grove: &mut Grove, gesture: &mut Gesture, axis: Axis) {
519    if let Some(target) = gesture.target {
520        if grove
521            .tree
522            .gestures(target)
523            .drags
524            .is_some_and(|axes| axes.covers(axis))
525        {
526            gesture.stage = Stage::Target;
527            grove.drift.drag_started.insert(target);
528            debug!(leaf = target.id(), ?axis, "drag claimed");
529            return;
530        }
531        // The target takes no drag on this axis, so it yields. It is no longer holding the gesture
532        // -- which is what makes a button inside a scrolling list behave: press it and it holds,
533        // drag and it lets go, so the list scrolls and the button gets no tap.
534        grove.drift.disengaged.insert(target);
535        debug!(leaf = target.id(), ?axis, "target yielded");
536        gesture.target = None;
537    }
538    gesture.stage = match scrolling(grove, &gesture.chain, 0, axis) {
539        Some(index) => Stage::Region { index, axis },
540        None => Stage::Nobody,
541    };
542}

544/// This frame's movement, delivered to whoever is holding the gesture.
545fn apply(grove: &mut Grove, gesture: &mut Gesture, delta: Position) {
546    match gesture.stage {
547        Stage::Resolving | Stage::Held | Stage::Nobody => {}
548        Stage::Target => {
549            let Some(target) = gesture.target else {
550                return;
551            };
552            grove.drift.dragged(
553                target,
554                Drag {
555                    start: gesture.at,
556                    current: gesture.to,
557                    delta,
558                },
559            );
560        }
561        Stage::Region { index, axis } => {
562            // Content moves against the pointer: dragging toward the near edge carries the content
563            // that way, which is the region moving further into its own extent.
564            let wanted = -delta.along(axis);
565            // A move that went nowhere on this axis is not a region declining to move: nothing was
566            // asked of it. Reading it as a refusal is what would hand the claim outward on the
567            // release itself, which re-delivers the last position and so always has a delta of
568            // zero -- and the region that ends up holding the gesture is the region that is handed
569            // the coast.
570            if wanted == 0.0 {
571                return;
572            }
573            let mut index = index;
574            loop {
575                if scroll(grove, gesture.chain[index], axis, wanted) != 0.0 {
576                    break;
577                }
578                // This one can no longer consume, so it yields and the claim passes outward. The
579                // outermost region keeps it and moves nothing: a claim never travels back inward,
580                // or a drag would hand itself between regions every time it reversed.
581                match outward(grove, &gesture.chain, index, axis) {
582                    Some(outward) => {
583                        debug!(
584                            from = gesture.chain[index].id(),
585                            to = gesture.chain[outward].id(),
586                            "scroll handed outward"
587                        );
588                        index = outward;
589                    }
590                    None => break,
591                }
592            }
593            gesture.stage = Stage::Region { index, axis };
594        }
595    }
596}

598/// Ends the open gesture, taking the tap it earned if it earned one and handing on the speed it
599/// ended with.
600fn close(grove: &mut Grove, released: bool) {
601    let Some(gesture) = grove.incoming.gesture.take() else {
602        return;
603    };
604    if released {
605        launch(grove, &gesture);
606    }
607    let Some(target) = gesture.target else {
608        // A tap that reached nothing that receives takes focus off whatever held it. That is not a
609        // rule about dismissing: it is the same rule as below, reading that what was tapped cannot
610        // hold focus -- so nothing does.
611        if released && matches!(gesture.stage, Stage::Resolving) {
612            focus::moved(grove, Intent::Away);
613        }
614        return;
615    };
616    // A tap is what a gesture that ended without ever resolving to a drag emits. A gesture that
617    // became a drag is not a tap that was taken back; it was never a tap. Neither is one that was
618    // held: a press reported as a hold has already stopped being a gesture that could end as a tap,
619    // so it moves no caret and takes no focus either.
620    if released && matches!(gesture.stage, Stage::Resolving) {
621        grove.drift.clicked.insert(target, gesture.at);
622        // Focus goes to what was tapped. There is no second declaration deciding it: `interactive`
623        // is already the statement that an element takes input, and focus already rests only on
624        // what said that -- so a target of a tap is by definition somewhere focus can be.
625        //
626        // Applied rather than queued, because it is decided here. That leaves focus final before
627        // the drain, so anything following it is an ordinary write on the ordinary path, and an app
628        // moving focus elsewhere from `clicked` is drained afterwards and still wins.
629        focus::moved(grove, Intent::To(target));
630        debug!(leaf = target.id(), "tapped");
631    }
632    grove.drift.disengaged.insert(target);
633}

635/// Hands the region that was holding the gesture its release velocity, and stops there.
636///
637/// This is the whole of interaction's part in momentum. The decay, the clamp against the extent and
638/// whether reaching an end chains outward or absorbs are the region's, and are `views.md`'s.
639///
640/// Only a gesture a *region* was holding leaves one. A target that took the drag owns whatever it
641/// was doing with it and coasts it itself if it wants to; a gesture that ended still resolving is a
642/// tap and has no speed to speak of. A hand that came to rest before lifting leaves no speed either:
643/// the frames it rested for are in the [`WINDOW`] and are what bring the mean down, which is what
644/// makes holding still before lifting stop the list rather than fling it.
645fn launch(grove: &mut Grove, gesture: &Gesture) {
646    let Stage::Region { index, axis } = gesture.stage else {
647        return;
648    };
649    let Some(velocity) = gesture.velocity() else {
650        return;
651    };
652    // Content moves against the pointer, so the offset's velocity is the pointer's reversed --
653    // the same sign the drag itself was applied with.
654    let speed = -velocity.along(axis);
655    // Reported whether or not it turns out to be enough to coast on, because a fling that did not
656    // fling is exactly the question this answers.
657    debug!(
658        leaf = gesture.chain[index].id(),
659        ?axis,
660        speed,
661        over = gesture.covered().as_secs_f32(),
662        frames = gesture.recent.len(),
663        "released"
664    );
665    view::launch(grove, gesture.chain[index], axis, speed);
666}

668/// A wheel notch: no gesture, no claim, no lifecycle. It moves what is under it, and it is over.
669fn wheeled(grove: &mut Grove, at: Position, delta: Position) {
670    let Some(region) = grove.stack.top(at) else {
671        return;
672    };
673    if region.disabled {
674        return;
675    }
676    let axis = if delta.x.abs() > delta.y.abs() {
677        Axis::Horizontal
678    } else {
679        Axis::Vertical
680    };
681    let chain = chain(grove, region.leaf);
682    let wanted = -delta.along(axis);
683    let mut next = scrolling(grove, &chain, 0, axis);
684    while let Some(index) = next {
685        if scroll(grove, chain[index], axis, wanted) != 0.0 {
686            break;
687        }
688        next = outward(grove, &chain, index, axis);
689    }
690}

692/// Where the pointer is, while `leaf` is the one holding the open drag.
693///
694/// The gesture itself rather than the moves it reported. A pointer held still produces no event at
695/// all, so an element with something to do for as long as a drag is *somewhere* -- selecting toward
696/// a point past its own edge -- has nothing to read in a frame that reported nothing. This is what
697/// it reads instead, and it is the same answer in a frame that moved.
698pub(crate) fn dragging(grove: &Grove, leaf: Leaf) -> Option<Position> {
699    let gesture = grove.incoming.gesture.as_ref()?;
700    (gesture.target == Some(leaf) && matches!(gesture.stage, Stage::Target)).then_some(gesture.to)
701}

703/// The scrolling ancestors of `from`, itself included, innermost first.
704///
705/// Targethood is not consulted. A drag anywhere inside a region must scroll it -- on touch that is
706/// the only way to scroll at all -- and that has to work on plain decoration, which asked for
707/// nothing. So scrolling is structural, and it is not the reason anything opts in.
708pub(crate) fn chain(grove: &Grove, from: Leaf) -> Vec<Leaf> {
709    let mut chain = Vec::new();
710    let mut step = Some(from);
711    while let Some(leaf) = step {
712        if grove.tree.scrolls(leaf).is_some() {
713            chain.push(leaf);
714        }
715        step = grove.tree.trunk(leaf);
716    }
717    chain
718}
719
720/// The first element of `chain` at or after `from` that scrolls `axis`.
721fn scrolling(grove: &Grove, chain: &[Leaf], from: usize, axis: Axis) -> Option<usize> {
722    chain
723        .iter()
724        .enumerate()
725        .skip(from)
726        .find_map(|(index, leaf)| {
727            grove
728                .tree
729                .scrolls(*leaf)
730                .is_some_and(|scroll| scroll.covers(axis))
731                .then_some(index)
732        })
733}

735/// Where a gesture goes when the region at `index` can consume no more of it, or `None` where it
736/// stops there.
737///
738/// Chaining is the default and is what lets a drag inside a list keep moving the page once the list
739/// is done. A region that declared [`contain`](crate::Scroll::contain) on this axis owns its
740/// gesture outright and is where the walk ends -- reaching its bottom and having the whole page
741/// lurch is the bug the declaration exists to prevent.
742///
743/// The same question for a drag and for a coast, asked of the same region at the same place in its
744/// own extent, because there is only one answer to it.
745pub(crate) fn outward(grove: &Grove, chain: &[Leaf], index: usize, axis: Axis) -> Option<usize> {
746    if grove
747        .tree
748        .scrolls(chain[index])
749        .is_some_and(|scroll| scroll.absorbs(axis))
750    {
751        return None;
752    }
753    scrolling(grove, chain, index + 1, axis)
754}
755
756/// Moves a region by as much of `wanted` as it can still take, and reports how much that was.
757fn scroll(grove: &mut Grove, leaf: Leaf, axis: Axis, wanted: f32) -> f32 {
758    let range = range(grove.tree.extent(leaf), grove.tree.placed(leaf).area, axis);
759    let offset = grove.tree.offset(leaf);
760    let taken = consumable(offset.along(axis), range, wanted);
761    if taken == 0.0 {
762        return 0.0;
763    }
764    // The region moved, which makes this a write to where it sits: it ends a coast still running on
765    // this axis, and cancels a motion moving the same region (F8). The reader wins over both.
766    grove.coasting.halt(leaf, axis);
767    if grove.aspen.cancel(leaf, Property::Scroll) {
768        debug!(leaf = leaf.id(), "tween cancelled");
769    }
770    grove
771        .tree
772        .set_offset(leaf, offset.set(axis, offset.along(axis) + taken));
773    taken
774}
