1//! TextInput -- an editable run, and the first [`Frond`](crate::frond): a leaf that is divided.
2//!
3//! # What a field is made of
4//!
5//! Everything else foliage grows is one element. A field is six, because the parts move
6//! independently of each other and each is already something the engine draws:
7//!
8//! | | Part | Is |
9//! |---|---|---|
10//! | | `run` | the value, as an ordinary [`Text`](crate::Text) |
11//! | | `hint` | the placeholder, shown only while the value is empty |
12//! | | `caret` | a [`Panel`](crate::Panel) [`CARET`] wide, shown only while the field holds focus |
13//! | | `head`, `body`, `tail` | the selection: [`Panel`](crate::Panel)s behind the run, one per part of a span that crosses lines |
14//!
15//! The app names the field and nothing else. Every verb and every read is addressed to it, and the
16//! parts are grown, placed and hidden from here -- so a field is one [`Leaf`] to hold, and what it
17//! is made of is not a surface to keep in step with.
18//!
19//! # The caret is placed in the ordinary grammar
20//!
21//! A caret at character `n` is `anchor().left() + anchor().character(n)` across and
22//! `anchor().top() + anchor().character(n)` down, against the run. That is the whole of the
23//! geometry: no pass measures a caret, because [`character`](crate::Anchor::character) resolves an
24//! index to the cell the run wrapped that character into, and it moves when the run moves because
25//! an anchor does. It is exact on the frame the run wraps differently, because it is read off the
26//! wrap rather than off where the caret was last seen.
27//!
28//! A selection is the span between two of those. On one line it is one box; across lines it is
29//! three -- the rest of the first line, every whole line between, and the start of the last -- and
30//! which of the three are drawn is the one thing decided here rather than by the layout, against the
31//! width the run was last drawn at.
32//!
33//! The run is drawn in front of all of them. A caret sits on the boundary between two character
34//! cells and is as wide as it needs to be seen, so a caret drawn over the run would take a bite out
35//! of the glyph it stands before -- at a small size, a quarter of it.
36//!
37//! # The field is a scrolling region
38//!
39//! A [`TextInput`] is one line, as wide as its own value, inside a box that clips it and scrolls
40//! across. A [`TextArea`] wraps at its box and scrolls down. Either is a region, so it is declared as
41//! one -- which is also what makes the caret stay in view: every edit asks the field to
42//! [`show`](crate::ScrollTo::show) the caret, and R4 answers it against the extent the same frame
43//! measured.

80/// An editable run of glyphs.
81///
82/// One line. What it holds is a value, a placeholder shown while that value is empty, and a caret
83/// with a selection behind it -- and the app holds one [`Leaf`] for the whole of it:
84///
85/// ```no_run
86/// # use foliage::{Boxed, FontSize, Location, Palette, Place, Source, TextInput, left, top};
87/// TextInput::new()
88///     .value("")
89///     .placeholder("Search")
90///     .color(Palette::Ink)
91///     .font_size(FontSize::new().xs(14))
92///     .at(Location::new().xs(
93///         left(0.px()).right(100.pct()),
94///         top(0.px()).height(32.px()),
95///     ));
96/// ```
97///
98/// It draws no border and no ground of its own. A field is a run and a caret inside whatever box an
99/// app puts it in, and a chrome the engine drew would be one more thing to talk an app out of.
100///
101/// A tap puts the caret where it landed and takes focus -- the second because focus goes to
102/// whatever a tap lands on, which a field is by virtue of receiving at all. An app that wants focus
103/// somewhere else writes [`focus`](crate::Grow::focus) from [`clicked`](crate::Pollen::clicked) and
104/// wins, because the tap settled focus a frame before the app is handed it.
105///
106/// A drag across a field **scrolls its value**, because a field declares no drags and so is left
107/// to the region it is. Selecting is a press that was [`held`](crate::Pollen::held) and then
108/// dragged: the two motions are identical until the hold separates them, which is the only thing
109/// that can.
110///
111/// What it types is reported as [`edited`](crate::Pollen::edited), and an `Enter` as
112/// [`submitted`](crate::Pollen::submitted).
113///
114/// Its value is what [`text`](crate::Grow::text) rewrites and [`Vein::Text`](crate::Vein::Text)
115/// reads, and what [`color`](crate::Grow::color) refills -- moved with a
116/// [`Motion::Color`](crate::Motion::Color) or a [`Motion::Palette`](crate::Motion::Palette) like
117/// any other fill, and read back as [`Vein::Color`](crate::Vein::Color). The placeholder, the
118/// caret and the selection keep the fills they were grown with.
119///
120/// It answers the clipboard itself: `Ctrl+C` and `Ctrl+X` put the selected span on it and `Ctrl+V`
121/// asks for what is there, which lands **in a later frame** because what a clipboard holds is the
122/// host's to say. A paste is reported as [`edited`](crate::Pollen::edited) like anything else the
123/// person at the keyboard did, so an app hears it where it hears the typing.
124///
125/// On a platform with a soft keyboard it raises the [`keypad`](TextInput::keypad) it named
126/// whenever it holds focus, and nothing declares that beyond being a field.
127///
128/// A value of more than one line is a [`TextArea`].
129#[derive(Clone, Debug)]
130pub struct TextInput {
131    pub(crate) placement: Placement,
132    pub(crate) value: String,
133    pub(crate) placeholder: String,
134    pub(crate) fill: Fill,
135    pub(crate) hint: Fill,
136    pub(crate) caret: Fill,
137    pub(crate) selection: Fill,
138    pub(crate) keypad: Keypad,
139}

141/// An editable run of glyphs that wraps.
142///
143/// A [`TextInput`] with as many lines as its value takes: the run wraps at the box's width exactly
144/// as a [`Text`](crate::Text) does, and the field scrolls **down** rather than across to keep the
145/// caret in view.
146///
147/// ```no_run
148/// # use foliage::{Boxed, FontSize, Location, Palette, Place, Source, TextArea, left, top};
149/// TextArea::new()
150///     .placeholder("Notes")
151///     .color(Palette::Ink)
152///     .font_size(FontSize::new().xs(14))
153///     .at(Location::new().xs(
154///         left(0.px()).right(100.pct()),
155///         top(0.px()).height(160.px()),
156///     ));
157/// ```
158///
159/// Where the two differ is what the keys that are about lines mean. `Enter` puts a newline in the
160/// value where a field would submit, and `Ctrl+Enter` is what submits. `Up` and `Down` move the
161/// caret by a line, and `Home` and `End` go to the ends of the line the caret is on rather than of
162/// the whole value -- the line as it wrapped, which is the line a reader sees. A newline that comes
163/// in on the clipboard is kept, where a field drops it.
164///
165/// Everything else -- the placeholder, the fills, the clipboard, the keypad, what a tap and a hold
166/// do, and what it reports -- is as it is on a [`TextInput`], and it is read with the same
167/// [`Vein::Text`](crate::Vein::Text) and [`Vein::Selection`](crate::Vein::Selection).
168#[derive(Clone, Debug)]
169pub struct TextArea {
170    pub(crate) placement: Placement,
171    pub(crate) value: String,
172    pub(crate) placeholder: String,
173    pub(crate) fill: Fill,
174    pub(crate) hint: Fill,
175    pub(crate) caret: Fill,
176    pub(crate) selection: Fill,
177    pub(crate) keypad: Keypad,
178}

180/// The builders a field and an area share, which are all of them: the two are the same thing to
181/// describe and differ only in what they do with a line.
182macro_rules! field {
183    ($seed:ident, $lines:expr) => {
184        impl Default for $seed {
185            fn default() -> Self {
186                Self::new()
187            }
188        }
189
190        impl $seed {
191            /// An empty one, read in [`Palette::Ink`] with an [`Palette::Accent`] caret.
192            pub fn new() -> Self {
193                Self {
194                    placement: Placement::default(),
195                    value: String::new(),
196                    placeholder: String::new(),
197                    fill: Fill::Role(Palette::Ink),
198                    hint: Fill::Role(Palette::Muted),
199                    caret: Fill::Role(Palette::Accent),
200                    selection: Fill::Role(Palette::Muted),
201                    keypad: Keypad::Text,
202                }
203            }
204
205            /// What the field starts out saying.
206            pub fn value(mut self, value: impl Into<String>) -> Self {
207                self.value = value.into();
208                self
209            }
210
211            /// What is read in the field's place while it says nothing.
212            ///
213            /// Drawn in [`hint`](Self::hint) rather than in the value's own fill, and never part of
214            /// the value: it is absent from [`Vein::Text`](crate::Vein::Text) and a field showing
215            /// one is empty.
216            pub fn placeholder(mut self, placeholder: impl Into<String>) -> Self {
217                self.placeholder = placeholder.into();
218                self
219            }
220
221            /// What the value is filled with.
222            pub fn color(mut self, fill: impl Into<Fill>) -> Self {
223                self.fill = fill.into();
224                self
225            }
226
227            /// What the placeholder is filled with.
228            pub fn hint(mut self, fill: impl Into<Fill>) -> Self {
229                self.hint = fill.into();
230                self
231            }
232
233            /// What the caret is filled with.
234            pub fn caret(mut self, fill: impl Into<Fill>) -> Self {
235                self.caret = fill.into();
236                self
237            }
238
239            /// What is drawn behind a selected span.
240            pub fn selection(mut self, fill: impl Into<Fill>) -> Self {
241                self.selection = fill.into();
242                self
243            }
244
245            /// Which soft keyboard the field raises while it holds focus.
246            ///
247            /// A hint about what is easy to type and not a rule about what the field takes: a
248            /// [`Keypad::Number`] field can still be pasted a word into, so what a value is allowed
249            /// to be is the app's to check either way. Ignored where the platform raises no
250            /// keyboard of its own.
251            pub fn keypad(mut self, keypad: Keypad) -> Self {
252                self.keypad = keypad;
253                self
254            }
255        }
256
257        impl Places for $seed {
258            fn placement(&mut self) -> &mut Placement {
259                &mut self.placement
260            }
261        }
262
263        impl Boxed for $seed {}
264
265        impl Buds for $seed {
266            fn bud(mut self, at: Caller) -> Bud {
267                let lines: Lines = $lines;
268                // A field is measured in characters throughout -- its caret, its selection and its
269                // own value -- so it carries a typeface whether or not one was named, exactly as a
270                // run does.
271                self.placement.typeface.get_or_insert_default();
272                // Declared here rather than left to the app, because both are what make a field a
273                // field rather than a preference about one. It receives, so a gesture can reach it
274                // and focus can rest on it -- which is what makes a tap focus it, since that is
275                // where focus goes for anything that receives; and it is a region along the axis
276                // its value grows on, which is what clips a value larger than its box and what the
277                // caret is kept in view by.
278                //
279                // It declares no drags. A drag across a field is then the region's, and the region
280                // is the field, so the value moves under its box; selection comes out of a hold,
281                // which claims a drag whatever an element declared.
282                self.placement.manner.gestures.receives = true;
283                let axes = lines.axes();
284                self.placement.manner.scrolls = Some(Scrolls(Scroll::new(axes).contain(axes)));
285                Bud {
286                    chlorophyll: Chlorophyll::None,
287                    placement: self.placement,
288                    sprout: Some(Box::new(Sprout {
289                        value: self.value,
290                        placeholder: self.placeholder,
291                        fill: self.fill,
292                        hint: self.hint,
293                        caret: self.caret,
294                        selection: self.selection,
295                        keypad: self.keypad,
296                        lines,
297                    })),
298                    at,
299                    ..Bud::bare()
300                }
301            }
302        }
303    };
304}

309/// How many lines a field has: one, or as many as its value wraps to.
310///
311/// The one thing that tells a [`TextInput`] from a [`TextArea`]. Everything a field does reads the
312/// same way in either -- what differs is which axis the value grows along, and so which axis the
313/// field scrolls, which keys are about lines, and whether a newline is a character it holds.
314#[derive(Copy, Clone, Debug, Default, PartialEq, Eq)]
315pub(crate) enum Lines {
316    /// One line, as wide as its value, scrolling across.
317    #[default]
318    One,
319    /// As many lines as the value wraps to at the box's width, scrolling down.
320    Many,
321}
322
323impl Lines {
324    /// The axis the value grows along, which is the one the field scrolls.
325    fn axes(self) -> Axes {
326        match self {
327            Lines::One => Axes::Horizontal,
328            Lines::Many => Axes::Vertical,
329        }
330    }
331
332    /// How many cells across the run wraps at, given the width it was last drawn at.
333    ///
334    /// A field of one line never wraps: its run is as wide as its own value by declaration, so the
335    /// answer is not read off a width that may not have been resolved yet.
336    fn columns(self, shaped: &Shaped, width: f32) -> usize {
337        match self {
338            Lines::One => usize::MAX,
339            Lines::Many => shaped.columns(width),
340        }
341    }
342}

357/// The six elements a field is made of, and how many lines it has.
358///
359/// Carried on the field, which is what makes every verb addressed to the field able to reach the
360/// part it actually changes -- and what makes an element a field at all, since nothing else grows
361/// one.
362#[derive(Component, Copy, Clone, Debug, PartialEq, Eq)]
363pub(crate) struct Parts {
364    pub(crate) run: Leaf,
365    pub(crate) hint: Leaf,
366    pub(crate) caret: Leaf,
367    /// The selection on the line it begins: from its start to its end where the two share a line,
368    /// and to the run's right edge where they do not.
369    pub(crate) head: Leaf,
370    /// Every whole line the selection covers between the one it begins on and the one it ends on.
371    pub(crate) body: Leaf,
372    /// The selection on the line it ends, from the run's left edge, where that is not the line it
373    /// began on.
374    pub(crate) tail: Leaf,
375    pub(crate) lines: Lines,

378/// Where the caret is and what is selected, in characters of the value.
379///
380/// Two indices rather than a range, because which end moves is what a shifted arrow key needs to
381/// know: `anchor` is where the selection was begun and `caret` is where it has reached, so the two
382/// are equal exactly when nothing is selected.
383#[derive(Component, Copy, Clone, Debug, Default, PartialEq, Eq)]
384pub(crate) struct Editing {
385    pub(crate) caret: usize,
386    pub(crate) anchor: usize,
387}
388
389impl Editing {
390    /// A caret at `index`, with nothing selected.
391    pub(crate) fn at(index: usize) -> Self {
392        Self {
393            caret: index,
394            anchor: index,
395        }
396    }
397
398    /// The selected span, low end first.
399    pub(crate) fn span(self) -> Range<usize> {
400        match self.caret <= self.anchor {
401            true => self.caret..self.anchor,
402            false => self.anchor..self.caret,
403        }
404    }
405
406    /// Whether anything is selected.
407    fn collapsed(self) -> bool {
408        self.caret == self.anchor
409    }
410
411    /// The same, held inside a value `length` characters long.
412    fn clamped(self, length: usize) -> Self {
413        Self {
414            caret: self.caret.min(length),
415            anchor: self.anchor.min(length),
416        }
417    }
418}

420/// What one keystroke did.
421pub(crate) enum Applied {
422    /// The value changed, and this is what it and the caret became.
423    Wrote(String, Editing),
424    /// The caret moved and the value did not. A selection is a caret with its anchor left behind,
425    /// so selecting is this as well.
426    Moved(Editing),
427    /// The selected span, to go on the clipboard. The value is unchanged.
428    Copied(String),
429    /// The same span, with the value it came out of and where that leaves the caret.
430    Cut {
431        text: String,
432        written: String,
433        editing: Editing,
434    },
435    /// The clipboard was asked for, to be written in at the caret when it answers.
436    ///
437    /// The one keystroke a field cannot finish on its own: what is on the clipboard is the host's
438    /// to say and it does not say it now, so the write happens in the frame the answer lands.
439    Pasting,
440    /// `Enter` on a field, or `Ctrl+Enter` on an area.
441    Submitted,
442    /// Nothing a field does.
443    Nothing,
444}

446/// One keystroke against a value and a caret. The whole of what editing means.
447///
448/// Pure, and the only place the rules live: what a key does to a value is arithmetic over character
449/// indices, and separating it from the tree is what lets every case be stated as one.
450///
451/// Indices are **characters**, not bytes -- the space [`Shaped`](crate::text::shape) lays a run out
452/// in and the space a [`tint`](crate::Grow::tint) is written in, so a caret, a highlight and a
453/// range all mean the same thing by the same number.
454///
455/// `wrap` is the value as it wrapped, for a field of more than one line, and `None` for a field of
456/// one. It is what the keys that are about lines are answered against -- a line is a fact about the
457/// wrap and not about the value -- and its absence is what makes `Enter` a submission and `Up` and
458/// `Down` nothing at all.
459pub(crate) fn applied(
460    value: &str,
461    editing: Editing,
462    stroke: Keystroke,
463    wrap: Option<Wrap<'_>>,
464) -> Applied {
465    let characters: Vec<char> = value.chars().collect();
466    let editing = editing.clamped(characters.len());
467    let extend = stroke.modifiers.shift;
468    let span = editing.span();
469    let length = characters.len();
470    // A command rather than a character. Held, a key says what to do with the value instead of
471    // what to put in it, so it is answered before the key's own meaning is.
472    if stroke.modifiers.control {
473        // A selection is what the clipboard verbs work over, and an empty one is nothing to work
474        // over: a field with its caret between two characters has no span to copy and none to cut.
475        // Taking the whole value instead would be a rule nobody asked for.
476        let selected = || characters[span.start..span.end].iter().collect::<String>();
477        return match stroke.key {
478            Key::Typed('a') | Key::Typed('A') => Applied::Moved(Editing {
479                anchor: 0,
480                caret: characters.len(),
481            }),
482            Key::Typed('c') | Key::Typed('C') if !editing.collapsed() => {
483                Applied::Copied(selected())
484            }
485            Key::Typed('x') | Key::Typed('X') if !editing.collapsed() => Applied::Cut {
486                text: selected(),
487                written: spliced(&characters, span.clone(), ""),
488                editing: Editing::at(span.start),
489            },
490            Key::Typed('v') | Key::Typed('V') => Applied::Pasting,
491            // What submits an area, whose bare `Enter` is a newline. Answered for a field too, so
492            // the chord means one thing wherever it is pressed.
493            Key::Enter => Applied::Submitted,
494            _ => Applied::Nothing,
495        };
496    }
497    match stroke.key {
498        Key::Typed(character) => Applied::Wrote(
499            spliced(&characters, span.clone(), &character.to_string()),
500            Editing::at(span.start + 1),
501        ),
502        Key::Backspace => {
503            // A selection is what is removed where there is one; otherwise the character before the
504            // caret. The two are one rule -- delete the span -- with an empty span reaching back by
505            // one first.
506            let removed = match editing.collapsed() {
507                true => span.start.saturating_sub(1)..span.end,
508                false => span,
509            };
510            if removed.is_empty() {
511                return Applied::Nothing;
512            }
513            Applied::Wrote(
514                spliced(&characters, removed.clone(), ""),
515                Editing::at(removed.start),
516            )
517        }
518        Key::Delete => {
519            let removed = match editing.collapsed() {
520                true => span.start..(span.end + 1).min(characters.len()),
521                false => span,
522            };
523            if removed.is_empty() {
524                return Applied::Nothing;
525            }
526            Applied::Wrote(
527                spliced(&characters, removed.clone(), ""),
528                Editing::at(removed.start),
529            )
530        }
531        Key::Left => Applied::Moved(moved(editing, length, Toward::Left, extend, wrap)),
532        Key::Right => Applied::Moved(moved(editing, length, Toward::Right, extend, wrap)),
533        Key::Home => Applied::Moved(moved(editing, length, Toward::Start, extend, wrap)),
534        Key::End => Applied::Moved(moved(editing, length, Toward::End, extend, wrap)),
535        // A field is one line, so there is no line above or below to move to. An app reading its
536        // own keys is what steps a list of them.
537        Key::Up | Key::Down if wrap.is_none() => Applied::Nothing,
538        Key::Up => Applied::Moved(moved(editing, length, Toward::Up, extend, wrap)),
539        Key::Down => Applied::Moved(moved(editing, length, Toward::Down, extend, wrap)),
540        // On a field, not an edit and not a caret: the app is told, and what that means is the
541        // app's. On an area it is the one character a key cannot otherwise put in the value.
542        Key::Enter => match wrap {
543            None => Applied::Submitted,
544            Some(_) => Applied::Wrote(
545                spliced(&characters, span.clone(), "\n"),
546                Editing::at(span.start + 1),
547            ),
548        },
549        // Both answered before a field is ever asked, because both move focus wherever focus is:
550        // `Tab` steps it and `Escape` takes it away. A field never sees either.
551        Key::Tab | Key::Escape => Applied::Nothing,
552    }
553}

555/// Text put in at the caret, replacing whatever was selected.
556///
557/// The rule a paste is applied by, and the general case of the one a typed character is: what
558/// arrives is a string rather than a character, and it is written in at exactly the same place.
559///
560/// Control characters are dropped, which is the rule a keystroke already arrives under. A newline
561/// is the exception on an area, where it is a character the value holds; on a field it is dropped
562/// with the rest, because a field is one line and a newline in it would be a character no cell can
563/// be measured for. A carriage return is a newline's other spelling, and is read as one.
564pub(crate) fn inserted(value: &str, editing: Editing, text: &str, lines: Lines) -> Applied {
565    let characters: Vec<char> = value.chars().collect();
566    let span = editing.clamped(characters.len()).span();
567    let written: String = text
568        .replace("\r\n", "\n")
569        .chars()
570        .filter(|character| match (lines, character) {
571            (Lines::Many, '\n') => true,
572            _ => !character.is_control(),
573        })
574        .collect();
575    if written.is_empty() {
576        return Applied::Nothing;
577    }
578    Applied::Wrote(
579        spliced(&characters, span.clone(), &written),
580        Editing::at(span.start + written.chars().count()),
581    )
582}

584/// The value with a span of it replaced by `text`, which is empty where the span is being removed.
585fn spliced(characters: &[char], span: Range<usize>, text: &str) -> String {

588        .copied()

594/// Which way a caret was asked to go.
595#[derive(Copy, Clone, PartialEq, Eq)]
596enum Toward {
597    Left,
598    Right,
599    Start,
600    End,
601    Up,
602    Down,
603}
604
605/// Where the caret lands, and what that leaves selected.
606///
607/// An unshifted arrow against a selection **collapses it to the edge it points at** rather than
608/// stepping from the caret. That is what every editor does and what a reader means by it: the
609/// selection was the thing being moved away from.
610///
611/// The keys that are about lines read the wrap. `Home` and `End` go to the ends of the line the
612/// caret is on; `Up` and `Down` go to the same column of the line above or below, or to the ends of
613/// the value where there is no such line -- and a column past the end of a shorter line is that
614/// line's end, which is where a reader expects to land. Without a wrap there is one line, and its
615/// ends are the value's.
616fn moved(
617    editing: Editing,
618    length: usize,
619    toward: Toward,
620    extend: bool,
621    wrap: Option<Wrap<'_>>,
622) -> Editing {
623    let span = editing.span();
624    let caret = match (toward, extend, editing.collapsed()) {
625        (Toward::Left, false, false) => span.start,
626        (Toward::Right, false, false) => span.end,
627        (Toward::Left, _, _) => editing.caret.saturating_sub(1),
628        (Toward::Right, _, _) => (editing.caret + 1).min(length),
629        (Toward::Start, _, _) => match wrap {
630            Some(wrap) => wrap.ends(wrap.cell_of(editing.caret).1).0,
631            None => 0,
632        },
633        (Toward::End, _, _) => match wrap {
634            Some(wrap) => wrap.ends(wrap.cell_of(editing.caret).1).1,
635            None => length,
636        },
637        (Toward::Up, _, _) => match wrap {
638            Some(wrap) => match wrap.cell_of(editing.caret) {
639                (_, 0) => 0,
640                (column, line) => wrap.index_at(column, line - 1),
641            },
642            None => editing.caret,
643        },
644        (Toward::Down, _, _) => match wrap {
645            Some(wrap) => {
646                let (column, line) = wrap.cell_of(editing.caret);
647                match line >= wrap.cell_of(length).1 {
648                    true => length,
649                    false => wrap.index_at(column, line + 1),
650                }
651            }
652            None => editing.caret,
653        },
654    };
655    match extend {
656        true => Editing {
657            caret,
658            anchor: editing.anchor,
659        },
660        false => Editing::at(caret),
661    }
662}

670/// Grows a field's six parts under it, in the drain that grew the field.
671fn sprout(grove: &mut Grove, field: Leaf, sprout: Sprout) {
672    let at = grove
673        .tree
674        .spawned_at(field)
675        .unwrap_or(core::panic::Location::caller());
676    let typeface = grove.tree.typeface(field);
677    let lines = sprout.lines;
678    // Every name first, so the parts can be placed against each other as they are grown.
679    let (run, run_growth) = grove.naming.leaf();
680    let (hint, hint_growth) = grove.naming.leaf();
681    let (caret, caret_growth) = grove.naming.leaf();
682    let (head, head_growth) = grove.naming.leaf();
683    let (body, body_growth) = grove.naming.leaf();
684    let (tail, tail_growth) = grove.naming.leaf();
685    let parts = Parts {
686        run,
687        hint,
688        caret,
689        head,
690        body,
691        tail,
692        lines,
693    };
694    // A run sized along the axis the value grows on and held to the box on the other: as wide as
695    // its own value and one line tall, centred, on a field; as wide as the box and as tall as it
696    // wraps to, from the top, on an area. Its extent along that axis is what the field's is
697    // measured from, so a value larger than the box is what makes the field scrollable and nothing
698    // has to say so. It sits in front of every mark, because a mark drawn over it would cut into
699    // the glyph it stands against.
700    let line = |elevation: i32| Placement {
701        location: Some(match lines {
702            Lines::One => Location::new().xs(
703                left(0.px()).width(content()),
704                center_y(50.pct()).height(1.letters()),
705            ),
706            Lines::Many => {
707                Location::new().xs(left(0.px()).right(100.pct()), top(0.px()).height(content()))
708            }
709        }),
710        elevation: Some(Elevation::up(elevation)),
711        typeface,
712        manner: Manner {
713            // The hit test reads the top of the stack and stops, so every part of a field has to be
714            // intangible or the field itself would never be the top of it.
715            gestures: Gestures {
716                intangible: true,
717                ..Gestures::default()
718            },
719            ..Manner::default()
720        },
721        ..Placement::default()
722    };
723    // The caret and the selection are spans of the run's own character cells, so all are anchored
724    // to it: the caret is rewritten by `refresh` whenever it moves, and the selection by `settled`
725    // every frame it is drawn.
726    let against = |elevation: i32, visible: bool| Placement {
727        location: Some(head_at(0, Some(0))),
728        anchor: Some(Anchored { to: run, at }),
729        elevation: Some(Elevation::up(elevation)),
730        manner: Manner {
731            gestures: Gestures {
732                intangible: true,
733                ..Gestures::default()
734            },
735            visible: Visible(visible),
736            ..Manner::default()
737        },
738        ..Placement::default()
739    };
740    let mark = |fill: Fill, placement: Placement| Bud {
741        chlorophyll: Chlorophyll::Panel,
742        pigment: Some(Pigment::Panel(PanelPigment {
743            fill,
744            rounding: Default::default(),
745        })),
746        placement,
747        at,
748        ..Bud::bare()
749    };
750    // The selection says it is hidden, because nothing is selected yet. The caret always has
751    // something to show, so it declares itself shown and lets focus be the only thing that hides
752    // it.
753    for (leaf, growth) in [
754        (head, head_growth),
755        (body, body_growth),
756        (tail, tail_growth),
757    ] {
758        grove.tree.grow(
759            leaf,
760            growth,
761            Some(field),
762            mark(sprout.selection, against(0, false)),
763        );
764    }
765    let empty = sprout.value.is_empty();
766    grove.tree.grow(
767        run,
768        run_growth,
769        Some(field),
770        Bud {
771            chlorophyll: Chlorophyll::Text,
772            pigment: Some(Pigment::Text(TextPigment { fill: sprout.fill })),
773            lettering: Some(Lettering(sprout.value)),
774            placement: line(2),
775            at,
776            ..Bud::bare()
777        },
778    );
779    let mut hint_placement = line(2);
780    hint_placement.manner.visible = Visible(empty);
781    grove.tree.grow(
782        hint,
783        hint_growth,
784        Some(field),
785        Bud {
786            chlorophyll: Chlorophyll::Text,
787            pigment: Some(Pigment::Text(TextPigment { fill: sprout.hint })),
788            lettering: Some(Lettering(sprout.placeholder)),
789            placement: hint_placement,
790            at,
791            ..Bud::bare()
792        },
793    );
794    grove.tree.grow(
795        caret,
796        caret_growth,
797        Some(field),
798        mark(sprout.caret, against(1, true)),
799    );
800    grove.tree.set_parts(field, parts);
801    grove.tree.set_editing(field, Editing::default());
802    grove.tree.set_keypad(field, sprout.keypad);
803    refresh(grove, field);
804    debug!(leaf = field.id(), "field sprouted");
805}

807/// Where the caret sits at character `index` of the run: the cell that character wrapped into.
808fn caret_at(index: usize) -> Location {
809    Location::new().xs(
810        left(anchor().left() + anchor().character(index)).width(CARET.px()),
811        top(anchor().top() + anchor().character(index)).height(anchor().letters(1.0)),
812    )
813}
814
815/// The selection on the line character `from` is on: to character `to` where it is on the same
816/// line, and to the run's right edge where it is not.
817fn head_at(from: usize, to: Option<usize>) -> Location {
818    let across = left(anchor().left() + anchor().character(from));
819    Location::new().xs(
820        match to {
821            Some(to) => across.right(anchor().left() + anchor().character(to)),
822            None => across.right(anchor().right()),
823        },
824        top(anchor().top() + anchor().character(from)).height(anchor().letters(1.0)),
825    )
826}
827
828/// Every whole line between the one character `from` is on and the one character `to` is on.
829fn body_at(from: usize, to: usize) -> Location {
830    Location::new().xs(
831        left(anchor().left()).right(anchor().right()),
832        top(anchor().top() + anchor().character(from) + anchor().letters(1.0))
833            .bottom(anchor().top() + anchor().character(to)),
834    )
835}
836
837/// The line character `to` is on, from the run's left edge up to it.
838fn tail_at(to: usize) -> Location {
839    Location::new().xs(
840        left(anchor().left()).right(anchor().left() + anchor().character(to)),
841        top(anchor().top() + anchor().character(to)).height(anchor().letters(1.0)),
842    )
843}

845/// Puts the parts back in step with the value and the caret.
846///
847/// Runs at the drain, after whatever changed either of them, so the frame that took the keystroke is
848/// the frame the caret has moved in. The selection is not placed here: it is placed at the end of
849/// the drain, where focus is final and so is what it is drawn against.
850pub(crate) fn refresh(grove: &mut Grove, field: Leaf) {
851    let Some(parts) = grove.tree.parts(field) else {
852        return;
853    };
854    let length = grove
855        .tree
856        .lettering(parts.run)
857        .map(|value| value.chars().count())
858        .unwrap_or_default();
859    let editing = grove.tree.editing(field).clamped(length);
860    grove.tree.set_editing(field, editing);
861    grove
862        .tree
863        .set_location(parts.caret, caret_at(editing.caret));
864    grove.tree.set_visible(parts.hint, length == 0);
865    // The caret is kept in view by the region the field already is, against the extent this frame's
866    // R3 measures rather than the one the last frame left -- which is what makes typing past the
867    // edge of the box scroll it in the same frame.
868    grove.sought.push((field, ScrollTo::show(parts.caret)));
869}

871/// One keystroke, delivered to the element holding focus.
872///
873/// Anything but a field makes nothing of one, which is ordinary rather than a drop: the key was
874/// delivered and reported, and having no use for it is what most elements do.
875pub(crate) fn typed(grove: &mut Grove, field: Leaf, stroke: Keystroke) {
876    let Some(parts) = grove.tree.parts(field) else {
877        return;
878    };
879    let value = value(grove, parts);
880    let shaped = shaped(grove, parts, &value);
881    let wrap = match parts.lines {
882        Lines::One => None,
883        Lines::Many => Some(shaped.wrap(columns(grove, parts, &shaped))),
884    };
885    match applied(&value, grove.tree.editing(field), stroke, wrap) {
886        Applied::Wrote(written, editing) => wrote(grove, field, parts, written, editing),
887        Applied::Moved(editing) => {
888            grove.tree.set_editing(field, editing);
889            refresh(grove, field);
890        }
891        Applied::Copied(text) => grove.clipboard.write(text),
892        Applied::Cut {
893            text,
894            written,
895            editing,
896        } => {
897            grove.clipboard.write(text);
898            wrote(grove, field, parts, written, editing);
899        }
900        // The one keystroke that finishes in another frame. The read is started here and the write
901        // happens where its answer is drained, which is `pasted`.
902        Applied::Pasting => {
903            let (queue, wake) = (grove.queue.clone(), grove.wake.clone());
904            grove.clipboard.read(&queue, &wake, Some(field));
905        }
906        Applied::Submitted => {
907            grove.drift.submitted.insert(field);
908            debug!(leaf = field.id(), "submitted");
909        }
910        Applied::Nothing => {}
911    }
912}

914/// What the clipboard answered, written in at the caret of the field that asked for it.
915///
916/// A frame or more after the `Ctrl+V` that asked, which is the whole reason the answer is an op:
917/// what a clipboard holds is the host's to say and it does not say it now. Everything from here is
918/// the ordinary write the keystroke would have made, so the paste is
919/// [`edited`](crate::Pollen::edited) like anything else the person at the keyboard did.
920pub(crate) fn pasted(grove: &mut Grove, field: Leaf, text: &str) {
921    let Some(parts) = grove.tree.parts(field) else {
922        return;
923    };
924    if let Applied::Wrote(written, editing) = inserted(
925        &value(grove, parts),
926        grove.tree.editing(field),
927        text,
928        parts.lines,
929    ) {
930        wrote(grove, field, parts, written, editing);
931    }
932}

987/// What a field makes of the gestures dispatch reported this frame.
988///
989/// **A field reads interaction; interaction knows nothing about fields.** A tap is a statement
990/// about where the caret goes, a hold is one about where a selection begins, and a drag is one
991/// about how far it reaches -- but each is a field's reading of an ordinary gesture, not something
992/// a gesture carries. So this asks what was reported about the leaves it owns and queues the same
993/// [`select`](crate::Grow::select) an app would write.
994fn gestured(grove: &mut Grove) {
995    for (field, parts) in grove.tree.fields() {
996        // A tap says where the caret goes and collapses whatever was selected. A gesture that
997        // became a drag was never a tap, so a drag out of a field to scroll the page behind it
998        // leaves the field exactly as it found it.
999        if let Some(at) = grove.drift.clicked.get(&field).copied() {
1000            let index = index_at(grove, parts, at);
1001            grove.queue.push(Op::Select {
1002                leaf: field,
1003                range: index..index,
1004            });
1005        }
1006        // A hold says the same thing a tap does about where the caret goes, and takes focus with
1007        // it: a held press is not a tap, so nothing has moved either. It is what begins a
1008        // selection, since the drag out of a hold is the field's whatever it declared.
1009        if let Some(at) = grove.drift.held.get(&field).copied() {
1010            let index = index_at(grove, parts, at);
1011            grove.queue.push(Op::Focus(Intent::To(field)));
1012            grove.queue.push(Op::Select {
1013                leaf: field,
1014                range: index..index,
1015            });
1016        }
1017        // A drag selects from where it began to where it has reached. Stated as one span rather
1018        // than as two moves, because that is what it is -- and low end last where the drag went
1019        // leftwards, which is how the anchor stays the end that was pressed.
1020        //
1021        // The anchor is read from the field and not from where the drag began. It is a character,
1022        // and the hold that started the selection already put it there; a *point* is not, because
1023        // the value scrolls under it the moment the drag reaches the edge -- so re-reading one
1024        // would move the end the selection was measured from as the field followed the caret.
1025        //
1026        // Where it has reached is the **open gesture** where there is one, and the move where the
1027        // gesture has already closed -- which is the release, and is the last of the movement. A
1028        // pointer held still reports nothing, and a drag that stopped moving is still a drag.
1029        let reached = grove
1030            .drift
1031            .dragged
1032            .get(&field)
1033            .map(|drag| drag.current)
1034            .or_else(|| interaction::dragging(grove, field));
1035        if let Some(to) = reached {
1036            let anchor = grove.tree.editing(field).anchor;
1037            let caret = index_at(grove, parts, to);
1038            grove.queue.push(Op::Select {
1039                leaf: field,
1040                range: anchor..caret,
1041            });
1042            // A pointer past the edge is a reader still asking for more of the value, and the
1043            // caret it is being taken to is further out every frame. So the field owes itself the
1044            // frames that get there, the way anything driving its own motion does.
1045            if beyond(grove, field, parts, to) {
1046                grove.again();
1047            }
1048        }
1049    }
1050}

1052/// Puts every field's parts back in step with focus.
1053///
1054/// At the end of the drain, where focus is already final: a tap settles it at dispatch and an
1055/// [`Op::Focus`] settles it here, so by now there is nothing left that could move it. That is what
1056/// keeps a caret an ordinary [`visible`](crate::Grow::visible) write inherited by R7 like anything
1057/// else, instead of a product patched up after the pass that composes it.
1058///
1059/// What is selected is not cleared with focus. A selection is state and focus is not, so a field
1060/// stepped away from and back into is as it was left -- while a *tap* back into it collapses the
1061/// selection, because a tap says where the caret goes.
1062///
1063/// The selection is placed here as well as shown, every frame it is drawn. Its geometry is the
1064/// layout's, read off the wrap by the same [`character`](crate::Anchor::character) the caret is --
1065/// but *how many boxes* it takes is a fact about which lines its two ends fell on, and that is read
1066/// here against the width the run was last drawn at. A frame that changes the wrap under a
1067/// selection is answered on the frame after, which is the one frame the drawn and the declared can
1068/// disagree.
1069///
1070/// The soft keyboard is settled here too, and it is the same statement the caret is: a platform's
1071/// own keyboard is raised for the field that holds focus and lowered for everything else, so
1072/// nothing about a phone is declared anywhere -- being a field is the whole of it.
1073fn settled(grove: &mut Grove) {
1074    let focused = grove.focus.held();
1075    for (field, parts) in grove.tree.fields() {
1076        let showing = Some(field) == focused;
1077        grove.tree.set_visible(parts.caret, showing);
1078        let selected = grove.tree.editing(field).span();
1079        if !showing || selected.is_empty() {
1080            for mark in [parts.head, parts.body, parts.tail] {
1081                grove.tree.set_visible(mark, false);
1082            }
1083            continue;
1084        }
1085        let value = value(grove, parts);
1086        let shaped = shaped(grove, parts, &value);
1087        let wrap = shaped.wrap(columns(grove, parts, &shaped));
1088        let (_, first) = wrap.cell_of(selected.start);
1089        let (_, last) = wrap.cell_of(selected.end);
1090        let same = first == last;
1091        grove.tree.set_location(
1092            parts.head,
1093            head_at(selected.start, same.then_some(selected.end)),
1094        );
1095        grove.tree.set_visible(parts.head, true);
1096        grove
1097            .tree
1098            .set_location(parts.body, body_at(selected.start, selected.end));
1099        grove.tree.set_visible(parts.body, last > first + 1);
1100        grove.tree.set_location(parts.tail, tail_at(selected.end));
1101        grove.tree.set_visible(parts.tail, !same);
1102    }
1103    let wanted = focused.and_then(|leaf| grove.tree.keypad(leaf));
1104    grove.keyboard.raise(wanted);
1105}

1107/// Selects a span of the value outright.
1108///
1109/// `range` is read as anchor-then-caret rather than low-then-high, so a span whose end precedes its
1110/// start is a selection reaching backwards -- which is what a drag leftwards is, and what a shifted
1111/// arrow continues from.
1112pub(crate) fn select(grove: &mut Grove, field: Leaf, range: Range<usize>) {
1113    if grove.tree.parts(field).is_none() {
1114        debug!(leaf = field.id(), "select dropped: not a field");
1115        return;
1116    }
1117    grove.tree.set_editing(
1118        field,
1119        Editing {
1120            anchor: range.start,
1121            caret: range.end,
1122        },
1123    );
1124    refresh(grove, field);
1125}

1127/// Rewrites the whole value, leaving the caret at the end of it.
1128///
1129/// Takes the parts the drain already looked up to tell a field from a run, so the one question that
1130/// answers it is asked once.
1131///
1132/// Not reported as [`edited`](crate::Pollen::edited): that is what the person at the keyboard did,
1133/// and an app that wrote the value already knows what it wrote.
1134pub(crate) fn lettered(grove: &mut Grove, field: Leaf, parts: Parts, value: String) {
1135    let length = value.chars().count();
1136    grove.tree.set_lettering(parts.run, value);
1137    grove.tree.set_editing(field, Editing::at(length));
1138    refresh(grove, field);
1139}

1141/// Whether a point has left the field along the axis it scrolls.
1142///
1143/// That axis and not the whole box: a pointer below a one-line field is at a character like any
1144/// other, and the field has nowhere to go for it -- and a pointer beside an area is on the line it
1145/// is level with.
1146fn beyond(grove: &Grove, field: Leaf, parts: Parts, at: Position) -> bool {
1147    let box_of = grove.tree.drawn(field);
1148    match parts.lines {
1149        Lines::One => at.x < box_of.left() || at.x > box_of.right(),
1150        Lines::Many => at.y < box_of.top() || at.y > box_of.bottom(),
1151    }
1152}

1154/// Which character of the run a point falls on.
1155///
1156/// The column is rounded rather than floored, so pressing past the middle of a character puts the
1157/// caret after it -- which is where a hand aiming between two characters means. The line is floored,
1158/// because a hand is on the line it is on. Which index that cell is, on a run that wraps, is the
1159/// wrap's to say.
1160fn index_at(grove: &Grove, parts: Parts, at: Position) -> usize {
1161    let cell = grove.tree.cell(parts.run);
1162    if cell.width <= 0.0 || cell.height <= 0.0 {
1163        return 0;
1164    }
1165    let drawn = grove.tree.drawn(parts.run);
1166    let column = ((at.x - drawn.left()) / cell.width).round().max(0.0) as usize;
1167    let line = ((at.y - drawn.top()) / cell.height).floor().max(0.0) as usize;
1168    let value = value(grove, parts);
1169    let shaped = shaped(grove, parts, &value);
1170    shaped
1171        .wrap(columns(grove, parts, &shaped))
1172        .index_at(column, line)
1173}
