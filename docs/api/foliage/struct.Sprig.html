Struct Sprig 

pub struct Sprig { /* private fields */ }
Expand description

A piece of the tree you can carry off the main thread.

Send + Clone, so a background thread – or your own ECS, at whatever version you like, since nothing but plain data crosses – can grow and change elements without ever touching the engine’s world. Carries the same verbs as Canopy and no way to sample: reads happen at the frame callsite, where the engine is quiescent.

Everything queued here is applied at the top of the next frame, ahead of that frame’s own commands, in the order it arrived.
