Expand description

What react/react_any re-fire at build time: a tuple of Clone-able components (arity 1-4; tuple-only so the impls can’t collide with a foreign Component impl). Re-inserts only the FIRST present member – one fire is sufficient because reaction bodies read the current state of everything they depend on, that’s the pattern.

Required Methods§

Re-inserts the entity’s current value; true if anything was inserted.
