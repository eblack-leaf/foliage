Struct Greenhouse 

Source 
pub struct Greenhouse<R: Root> { /* private fields */ }
Expand description

An app grown with no window: input written in, time moved by hand, and frames run on request.

Nothing runs on its own. Every input method queues what a window would have queued and returns, and frame is what takes it in – so a test reads the way the loop runs, one frame at a time, and nothing it did not write can happen between two of its lines.

pub fn settle(&mut self) -> usize

Runs frames a display’s interval apart until nothing more is owed: every motion landed, every report delivered, every gesture past becoming a hold. Hands back how many it ran.

What an app asked for with again_in is not waited on: an ambient frame is asked for again every time, and would never settle.

§Panics

If thirty seconds of frames go by and something is still owed – an app asking for again every frame, or a motion that does not end.

pub fn render(&mut self) -> Option<Picture>

Draws what the last frame settled and reads it back.

At one device pixel per logical pixel, so a point in the picture is the point the tree was laid out in. None where the machine has no adapter to draw with.

The first call acquires the device, and what is already grown is stated to it whole; every frame after that is handed to it as it runs, as a window’s renderers are.
