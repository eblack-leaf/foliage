Expand description

How an element is set up before it grows: where it sits, how it stacks, how it behaves.

Every spec carries the same set, so Panel::new(), Text::new() and Bare::new are configured identically. Sealed – Author is pub(crate), so this can be called but never implemented, and the set stays exactly what the engine knows how to apply.

Provided Methods§

fn at(self, location: Location) -> Self

Where this element sits and how big it is.

fn elevate(self, e: Elevation) -> Self

Draw order relative to its siblings. Required – there is no default, because a silently-chosen layer is the kind of thing found much later.

fn grid(self, grid: Grid) -> Self

Lays children out on a grid. Required on anything with children: a child’s Location resolves against its parent’s grid, and a parent without one is a panic at spawn rather than a silent misplacement.

fn anchored(self, leaf: Leaf) -> Self

Resolves anchor() values in this element’s Location against leaf rather than against its parent.

Independent of parenting: the target can sit anywhere in the tree, and anchoring to it changes nothing about who owns, clips or elevates this element. What it buys is stacking – an element placed below the one before it follows when that one wraps to another line, which a fixed offset cannot.

A Location carrying anchor() values and no anchor set here cannot resolve.

fn opacity(self, value: f32) -> Self

Starting opacity, inherited by everything beneath.

fn align(self, h: HorizontalAlignment, v: VerticalAlignment) -> Self

How content sits within this element’s own box.

fn interactive(self) -> Self

Competes for gestures: the topmost interactive element under the pointer wins.

fn pass_through(self) -> Self

Notified when a gesture crosses it, but never wins one – for overlays and decoration that must not eat input.

fn holds_drag(self) -> Self

Refuses drag-panning through this element, for a knob or slider owning its own drag.

fn round_hit_area(self) -> Self

Hit-tests as a circle rather than a rectangle.

fn overscroll(self, passes: bool) -> Self

Whether scroll this element cannot consume passes outward to an ancestor.

On by default – which is what lets a drag inside a region still move the page behind it once the region hits its own end. Turn it off to trap scrolling inside.

fn clip_to_viewport(self) -> Self

Clips this element to the viewport rather than to its nearest scrolling ancestor.

fn aspect(self, ratio: AspectRatio) -> Self

Constrains the resolved box to a width:height ratio.

fn sized_by_content(self, width: bool, height: bool) -> Self

Sizes the box from the text’s own measured extent rather than bounding it.

fn font(self, font: FontId) -> Self

Draws this element’s text in a face registered with Foliage::font, rather than the built-in one.

fn size(self, size: FontSize) -> Self

The character cell this element measures against, for elements that carry no text of their own.

letters resolves against the entity’s own FontSize, which a Text gets for free and nothing else does – so a Bare or Panel holding a run of text stated in characters had no cell to measure and resolved to nothing. Naming the same size its contents use lets a container be sized in the units of what it contains, which is the point of stating a height in characters rather than pixels.

Text has its own size that also sets what is drawn; this is only the measure.
