Expand description

A seed placed by a box.

Everything the engine draws as a rectangle – a Stem, a Panel, a Text, an Icon, an Image, a Polygon – and nothing else.

It is a separate trait from Place rather than a method on it because a Line has no box to state: it is two ends, said with between. An at it could be handed and would ignore is the kind of surface that has to be remembered rather than read, so it is not there to hand it.

Sealed: it can be called, never implemented.
