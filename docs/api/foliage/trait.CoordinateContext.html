Expand description

Marker for which coordinate space a Position, Area, Section or Points is expressed in.

Carried as a type parameter so the two real spaces cannot be mixed by accident – a Section<Logical> will not go where a Section<Physical> is wanted. Convert deliberately with to_physical/to_logical and the current ScaleFactor.
