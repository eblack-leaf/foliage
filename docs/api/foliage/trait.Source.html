Expand description

Plain numbers as placement sources.

Every unit names itself at the call site, which is what keeps an expression readable when it mixes them: right(100.pct() - 16.px()).

These read the trunk. The same units against another element are on trunk() and anchor().

Required Methods§

Source

fn px(self) -> Length

Logical pixels.

Source

fn pct(self) -> Length

A percentage of the trunk’s extent on the axis the role names. 100.pct() is the whole of it, so right(100.pct()) is the trunk’s right edge.

Source

fn col(self) -> Length

A one-based column of the trunk’s grid.

The role decides which part of that column is meant: a near role gives its left edge, a far role its right edge, a centre role its middle, and a size role the width of a span of that many columns, gaps included. So left(1.col()).right(1.col()) is exactly the first column.

Source

fn row(self) -> VerticalLength

A one-based row of the trunk’s grid, read the same way col is.

Source

fn letters(self) -> Length

A count of character cells, at the element’s own font size.

The right tool whenever the count is genuinely known ahead of time: it costs nothing to resolve and it says what it means. Where the count is not known ahead of time, content() measures instead.

The element’s own font, because that is the only one it is composed in. A count in the font of another element is anchor().letters(n).

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety", so this trait is not object safe.
