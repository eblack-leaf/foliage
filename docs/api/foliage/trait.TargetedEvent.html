Trait TargetedEvent

    // Required method

Expand description

An event send_to/trigger_targets can aim at an entity. bevy 0.19 removed trigger_targets — an EntityEvent now carries its target inside itself — so foliage’s targeted events store an entity field the seam below rewrites per target. Implement via the #[targeted_event] attribute (injects the field, implements Event/EntityEvent, generates new(<payload fields>) — authors never write Entity::PLACEHOLDER); generics like Resolve<C>/Resolved<C> implement it by hand.
