Struct Resolve 

pub struct Resolve<U>
where
    U: Send + Sync + 'static,
{ /* private fields */ }
Expand description

“Recompute U for this entity” – the request half of the resolve protocol, paired with Resolved.

Fired at whatever owns the computation, typically because an input it depends on changed. Handlers are expected to be idempotent: a redundant request should recompute the same answer rather than misbehave, since several inputs can each ask in one frame.
