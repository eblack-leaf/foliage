Expand description

Lets a component be tweened by Animation.

Implementors decompose themselves into scalar channels and reassemble from them. The channel order is the contract between the two halves – apply must read the same indices interpolations wrote, since nothing else enforces the correspondence.

Register a custom implementation with Foliage::enable_animation (pub(crate) – engine-internal registration; the built-in animatable types do this themselves, and an app never implements Animate for its own types).
