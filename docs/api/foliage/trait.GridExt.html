Trait GridExt

    // Required methods

Expand description

The numeric literal vocabulary for layout: 20.pct(), 8.px(), 2.col(). Implemented for every integer and float type, so a bare literal works.

Required Methods§

fn pct(self) -> LocationValue

A percentage of the parent’s own box on this axis. 100.pct() is the full extent.

fn px(self) -> LocationValue

A fixed number of logical pixels.

fn col(self) -> LocationValue

A 1-based column line in the parent’s Grid. 1.col().as_left() is the left edge of column one; as a right edge the same index is inclusive, so 1.col().as_left().with(1.col().as_right()) is exactly one column wide.

fn row(self) -> LocationValue

A 1-based row line in the parent’s Grid, inclusive as a bottom edge just as col is as a right edge.

fn letters(self) -> LocationValue

A multiple of one character’s advance at the entity’s own FontSize – for sizing a box to the text it will hold.
